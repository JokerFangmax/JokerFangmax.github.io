## 1. 这篇论文解决什么问题

[01](../forcing_01/) 的 Scheduled Sampling 有一个被脚注掩盖的代价：要逐 token 决定「用真值还是模型预测」，就必须逐 token 串行——第 $t$ 步的混合决策依赖 $\tilde{y}_{1:t-1}$。教师强制之所以是加速器上的标准配置，恰恰因为它的条件（金标前缀）**事先已知**，整个序列可以一次前向并行、反向传播一次穿完所有时间步。SS 把这个「已知」破坏掉了。

本文用数字把这个矛盾钉死（MultiWOZ 对话任务，论文 Table 1）：教师强制 **47 步/秒**，Sequential SS **0.13 步/秒**——慢 **两个数量级**（论文摘要的口径：并行化后只需原训练时间的 0.3%）。长序列任务（摘要、图像生成）上 Sequential SS 干脆跑不动。

论文的三条贡献：

1. 一个**全并行**的历史混合训练算法（多轮「并行采样 + 混合」），操作数严格多于串行版但适配 GPU/TPU；
2. **等价性定理**（Theorem 2.1）：$p=1$、$K\ge T$ 时，多轮并行混合的条件分布收敛到真采样解码——补回了 [01](../forcing_01/) 里「教师强制 ↔ 采样解码」之间的清晰插值；
3. 四个任务（对话、摘要、图像生成、翻译）的系统评测：多数任务持平或超过教师强制，对话与图像上有实质提升。

## 2. 最小背景

- [01. Scheduled Sampling](../forcing_01/)：逐 token 抛硬币混合金标历史与模型预测、$p$ 随训练增大——本篇把它重命名为 **Sequential SS** 并作为被并行化的对象；
- [02. Scheduled Sampling for Transformers](../forcing_02/)：两遍解码（金标条件下预测 → 混合 → 混合序列上算损失）。本篇 §4.5 会说明它就是并行方案的 $K=1$ 特例；
- **自注意力的并行推理**：Transformer 类模型对多个时间步的推理可以同时进行（给定条件前缀）——这是并行采样步骤得以成立的架构前提；RNN 做不到这一点，所以 Sequential SS 在 RNN 上并无不适（[01](../forcing_01/) 脚注「训练不比基线慢」只在 RNN 成立）。

## 3. 方法总览

**一句话主线**（论文 Figure 1）：把「构造混合历史」从串行的逐 token 循环改成 $K$ 个**轮次（pass）**，每轮两步且两步都对全部时间步并行——**并行采样**：以第 $k-1$ 轮的混合序列为条件，一次性对每个位置 $t$ 采样 $\hat{y}^k_t \sim p_\theta(\cdot \mid \tilde{y}^{k-1}_{1:t-1}, x)$；**并行混合**：每个位置独立抛硬币，以概率 $p$ 取刚采的 $\hat{y}^k_t$、以概率 $1-p$ 取金标 $y_t$，其中前 $k-1$ 个位置不参与重采、直接从上一轮复制。$K$ 轮结束后，把最终混合序列 $\tilde{y}^K$ 当作「金标」再做一次教师强制式的训练前向，对真实目标累积对数似然损失。

| 组件 | 做什么 | 并行性 |
|---|---|---|
| 并行采样（每轮） | 全部位置同时各采一个 token，条件是上一轮的混合前缀 | 一次前向 |
| 并行混合（每轮） | 逐位置独立抛硬币：$y_t$（概率 $1-p$）或 $\hat{y}^k_t$（概率 $p$）；位置 $t<k$ 冻结复制 | 逐元素，无依赖 |
| 损失前向（最后） | 以 $\tilde{y}^K$ 为条件序列的教师强制训练，算 $\sum_t \log p_\theta(y_t \mid \tilde{y}^K_{1:t-1}, x)$ | 一次前向 |

与 [01](../forcing_01/) 的关键差别有两处：**历史来自多轮迭代**（第 $k$ 轮的条件是第 $k-1$ 轮的混合，而非金标），以及**采样自模型自身**（不是均匀分布）。监督目标不变——仍是对真实 $y_t$ 的对数似然。

## 4. 核心原理完整推导

### 4.1 Sequential SS 的目标（被并行化的对象）

自回归条件分解下，教师强制直接最大化训练集对数似然（论文 Eq. 1）：

$$
\theta^{*} = \arg\max_{\theta}\, \mathcal{L}_{\text{tf}}(\theta) = \arg\max_{\theta} \sum_{i=1}^{N} \sum_{t=1}^{T_i} \log p_\theta\big(y^i_t \mid y^i_{1:t-1},\ x^i\big)
\tag{Eq.1}
$$

Sequential SS（论文 Algorithm 1）用同样的目标函数，只把条件前缀换成随机混合 $\tilde{y}_{1:t}$：对 $t = 1,\dots,T$ 依次——采样 $\hat{y}_t \sim p_\theta(\cdot \mid \tilde{y}_{1:t-1}, x)$，再抛硬币定 $\tilde{y}_t = y_t$（概率 $1-p$）或 $\hat{y}_t$（概率 $p$）；最后累积 $\sum_t \log p_\theta(y_t \mid \tilde{y}_{1:t-1}, x)$。$p \to 0$ 退化为教师强制，$p \to 1$ 就是采样解码工况；训练中用调度逐步增大 $p$。

串行性一目了然：$\tilde{y}_t$ 的选择依赖 $\tilde{y}_{1:t-1}$，循环写法无法展开。

### 4.2 Parallel SS：算法与复制规则

论文 Algorithm 2（单条样本）：

$$
\begin{aligned}
&\text{初始化 } \tilde{y}^0_t = y_t \quad (\text{金标})\\
&\text{for } k = 1, \dots, K:\\
&\quad \text{并行采样：} \hat{y}^k_t \sim p_\theta\big(\cdot \mid \tilde{y}^{k-1}_{1:t-1},\ x\big) \quad \forall t\\
&\quad \text{并行混合：} \tilde{y}^k_t = \begin{cases} \tilde{y}^{k-1}_t & t < k \ (\text{冻结复制})\\[2pt] y_t \ \text{概率}\ 1-p,\ \ \hat{y}^k_t \ \text{概率}\ p & t \ge k \end{cases}\\
&\text{返回损失：} \sum_t \log p_\theta\big(y_t \mid \tilde{y}^{K}_{1:t-1},\ x\big)
\end{aligned}
$$

最不显然的是**冻结复制规则**（$t < k$ 时直接抄上一轮）：位置 1 只在第 1 轮被混合，位置 2 只在前 2 轮被重采，位置 $t$ 只在前 $\min(t, K)$ 轮被重采。这不是实现细节，而是收敛性的机关——每多跑一轮，就多「敲定」一个前缀位置。

<details>
<summary><b>展开：T=3、p=1 的手工走查——每轮敲定一个位置</b></summary>

设 $p=1$（混合永远取采样值）、$K=3$、序列长 $T=3$：

| 轮次 | 采样条件 | 各位置结果 |
|---|---|---|
| $k=1$ | $\tilde{y}^0 = $ 金标 | 无位置冻结（$t<1$ 不存在）；$\tilde{y}^1_1 \sim p_\theta(z_1)$，$\tilde{y}^1_2 \sim p_\theta(\cdot\mid y_1)$，$\tilde{y}^1_3 \sim p_\theta(\cdot\mid y_{1:2})$ |
| $k=2$ | $\tilde{y}^1$ | 位置 1 冻结；$\tilde{y}^2_2 \sim p_\theta(\cdot\mid \tilde{y}^1_1)$，$\tilde{y}^2_3 \sim p_\theta(\cdot\mid \tilde{y}^1_{1:2})$ |
| $k=3$ | $\tilde{y}^2$ | 位置 1、2 冻结；$\tilde{y}^3_3 \sim p_\theta(\cdot\mid \tilde{y}^2_{1:2})$ |

跟踪每个位置**最后一次被重采**时的条件（这才是它的最终分布）：

- 位置 1 定于第 1 轮：$\tilde{y}^1_1 \sim p_\theta(z_1)$ ✓ 与采样解码的第一个 token 同分布；
- 位置 2 定于第 2 轮：条件是 $\tilde{y}^1_1$，而它已经是正确的 $z_1$ 样本 → $\tilde{y}^2_2 \sim p_\theta(\cdot\mid z_1)$ ✓；
- 位置 3 定于第 3 轮：条件是 $\tilde{y}^2_{1:2} = (z_1, z_2)$（前两个都已敲定）→ $\tilde{y}^3_3 \sim p_\theta(\cdot\mid z_{1:2})$ ✓。

三者的联合恰是 $p_\theta(z_1)\,p_\theta(z_2\mid z_1)\,p_\theta(z_3\mid z_{1:2}) = p_\theta(z_{1:3})$——一次完整的采样解码。冻结规则的作用就是保证「位置 $t$ 最后一次重采时，它的条件前缀 $1:t-1$ 已全部敲定」，这要求位置 $t$ 至少经历 $t$ 轮，即 $K \ge T$。

$p<1$ 时同一结构仍然成立，只是每个位置的终值在「金标」与「采样」之间按 $1-p$/$p$ 混合——于是 $K$ 轮得到的条件序列是：前缀若干个「真采样解码」位置 + 后面「越来越接近金标条件」的混合位置。

</details>

### 4.3 收敛定理（Theorem 2.1）

**定理**（论文 Theorem 2.1）：序列长 $T$，取 $p=1$、$K \ge T$，则第 $K$ 轮条件 token 的提议分布 $q^K_\theta(z_{1:T})$ 与随机采样解码的似然 $p_\theta(z_{1:T})$ 完全相同：

$$
q^K_\theta(z_{1:T}) = p_\theta(z_{1:T})
$$

<details>
<summary><b>展开：归纳法证明的三步骨架（论文 §2.3）</b></summary>

证明是对「轮数 $K$」和「位置 $t$」的双重归纳，骨架：

1. **基例**：第一个 token 在第 1 轮就按 $p_\theta(z_1)$ 采样（构造使然），$q^1_\theta(z_1) = p_\theta(z_1)$；
2. **对 $K$ 归纳（前缀不变）**：若 $q^K_\theta(z_{1:t}) = p_\theta(z_{1:t})$ 对某个 $K \ge t$ 成立，则第 $K+1$ 轮上这些位置被冻结复制，分布不变；
3. **对 $t$ 归纳（链式推进）**：构造保证 $t \ge K$ 时 $q^{K+1}_\theta(z_{t+1}\mid z_{1:t}) = p_\theta(z_{t+1}\mid z_{1:t})$（这只在 $p=1$ 时成立——$p<1$ 时硬币会以 $1-p$ 概率放回金标，破坏等式）。于是链式法则分解

$$
q^{K+1}_\theta(z_{1:t+1}) = q^{K+1}_\theta(z_{t+1}\mid z_{1:t})\, q^{K+1}_\theta(z_{1:t}) = p_\theta(z_{t+1}\mid z_{1:t})\, p_\theta(z_{1:t}) = p_\theta(z_{1:t+1})
$$

只要 $K \ge T$，所有位置都被「敲定」，联合分布逐位吻合。∎

注意定理的对象是**条件序列的提议分布**，不是模型本身——它说明的是「多轮并行混合造出来的历史，分布上就是模型自己的采样解码历史」。这正是 [01](../forcing_01/) 想要而没能严格给出的东西：$\epsilon_i$（或 $p$）在两个端点之间插值时，端点 $p=1$ 处的语义现在有了定理保证。

</details>

### 4.4 与 02 两遍解码的关系

[02](../forcing_02/) 的两遍解码 = 本篇 $K=1$：第一遍在金标前缀下并行产出全位置预测（≈ 第 1 轮的并行采样），混合后第二遍在混合序列上算损失（≈ 损失前向）。两点差别：

| | 02（两遍解码） | 03（Parallel SS） |
|---|---|---|
| 混合的对象 | 预测的**嵌入表示**（argmax/软混合） | 采样的 **token** |
| 多轮推广 | 无 | $K$ 轮，条件逐轮逼近采样解码 |

02 的 §4.5 曾指出其固有近似：预测只在金标前缀下做出，模型见不到「错误复合」的历史。03 的多轮结构正是解药——第 $k$ 轮的条件是第 $k-1$ 轮的混合，历史里的采样 token 会逐轮向前传播、复合。

### 4.5 成本账

操作数上 Parallel SS **严格多于** Sequential SS（每轮都是完整前向），但墙钟时间反过来——加速器吃并行、吐串行。MultiWOZ 实测（§6.1）：教师强制 47 步/秒，$K=1$ 的 Parallel SS 35 步/秒（约慢 25%），Sequential SS 0.13 步/秒——**比并行版慢约两个数量级**（论文摘要口径：并行化后训练时间低至串行的 0.3%）。轮数增加线性吃速度：$K=10$ 时降到 10 步/秒。

| Parallel SS | 1.00 | 98.38 | 3.97 |

$p=0.5$、$K=1$：FID 52.39 → 41.47（**降 20%**）、IS 5.64 → 6.42（**升 13.8%**）——这是全文最硬的增益。$p=1.0$ 再次崩盘（FID 98.38），与对话任务同型：**课程（混合金标）不可省，纯自身历史训练行不通**。

### 6.4 翻译（WMT 2014 英德）

教师强制 500k 步：**28.74** BLEU；前 250k 步教师强制 + 后 250k 步 Parallel SS（$p=0.5$、$K=1$）：**28.57**——没有提升。论文的假设：摘要、对话、图像任务的**输出序列远长于**翻译，SS 的收益本就应在长序列上显形（错误复合的距离更长）；但论文自己标注「需要进一步验证」。对照 [02](../forcing_02/) 在 IWSLT/KFTT 两个小翻译任务上也只有边际差异——「SS 对翻译基本无效」这条负面经验跨两篇论文成立。

## 8. 局限与个人评价

- **理论与实践的巨大缝隙**：定理要求 $p=1$、$K\ge T$，实验最优点却是 $p=0.5$、$K=1$——收敛保证的配置恰是实测最差的配置（$p=1$ 两处崩盘、$K$ 增大均值不涨）。定理证明的是「能到达采样解码」，实践要的是「便宜的插值」，两者只在 $K=1$ 的极端折扣下相遇。论文没有解释为什么单轮就够，这是一个开放问题；
- **头条数字与表格对不上**：摘要与正文三次引用「1.6 BLEU（11.5%）提升」，但 Table 1 内最好均值 14.73 对 14.11 只有 +0.62、最好最大值 15.38 对 14.62 只有 +0.76——1.6 从表里推不出来（可能来自未报告的单次重启）。引用这篇的结论时应以表内数字为准；
- **Sequential SS 只跑了单次**（论文自己注明），而 Parallel SS 是 5 次重启的均值——两个数量级的速度差是实的，但 BLEU 对比（14.55 vs 14.35）的统计强度有限；
- **任务依赖性强且无跨任务解释**：图像（+20% FID）> 对话 ≈ 摘要（greedy）> 翻译（无效应）。「长输出才有收益」的假设论文只给了猜想未给验证（比如按输出长度分桶分析）；
- **个人评价**：这是三部曲里工程判断最好的一篇——它没有发明新的训练目标，而是把 [01](../forcing_01/) 的目标在并行硬件上**忠实且便宜地**实现出来（0.3% 的训练时间），并且诚实地做了 Sequential/Parallel 的唯一正面对比。「$K=1$ 就够」这个经验结论，实质上宣告了 [02](../forcing_02/) 式两遍解码已是充分形式——多余的轮数买不回等量的质量。它留下的最大遗产是那个未被填上的理论缝隙：**为什么一轮回头看金标、一轮看自己，就足以教会模型应对错误？**这个问题在视频扩散时代会被 Self Forcing 用「rollout + 视频级分布监督」重新回答。
