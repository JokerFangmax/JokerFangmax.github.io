# 从 Laplace-Beltrami 到 1.3mm：一次方法全流程的数学审计

这是一个真实研究项目的复盘。目标：3D 耳廓 mesh → 85 个解剖 landmark（四条解剖曲线：外耳轮 25 点、耳甲 30 点、内耳轮 20 点、上对耳轮 10 点），评测指标为逐点欧氏距离均值。系统当前状态：dev-OOF 1.402mm / 官方 test 1.272mm（第一名 1.05mm）。

这篇文章做一件事：**把整个 pipeline 放回数学原理层面**——每一步在数学上到底做了什么假设、牺牲了什么，然后用这些原理反过来解释三十多个实验的结论为什么是它们现在的样子，最后给出尚未测量过的改进空间。你会发现：**几乎所有"失败"的实验结论，都是网络数学结构的必然推论**，而不是训练技巧问题。

## 一、全流程：每一步在数学上做了什么

### 1.1 数据预处理：商掉刚体变换群

```
原始全头扫描 → 仿射对齐 (aligned mm 帧) → 固定配置 crop 盒裁耳 → 规范化 (canon 帧, scale≈141.95) → mesh + normals
                                                        ↘ 4×有界旋转 (≤20°) 缓存视图
```

预处理是一条离线流水线（训练与推理共用同一份代码路径），分三步：

**(a) 对齐**：全头 mesh 转到统一姿态（aligned mm 帧）。

**(b) 裁剪**：在对齐后的全头上，按固定配置盒 x∈[−45,25], y∈[50,115], z∈[−50,55] 裁出耳区。注意这是**配置驱动的硬盒**，不依赖 landmark——裁剪语义与标注约定同源。

**(c) 规范化**：平移到盒中心 + 各向同性缩放 1/141.95 + **右耳反射到左耳**（canonical side = left，共用一套左右模型）。每个样本文件同时保存三样东西：`verts_canon`（模型唯一看到的世界）、`verts_orig`（对齐 mm 帧下的**同序顶点**，一一对应）、`T_aligned_to_local`（4×4 双射变换）。

数学上，对齐 + 规范化 = 把数据**商掉刚体变换群与等比缩放，再商掉左右反射群**（模掉 ISO(3) × ℝ⁺ × ℤ₂）。好处：后续学习器不必学一个 8 维 nuisance 群的不变性。代价：规范化本身引入共享的仿射误差——所有 landmark 一起偏移的低频全局量。这部分误差是可被平均吸收的（后续 ensemble 会吃掉它）。

**逆变换：不需要显式矩阵求逆。** 解码是 soft-argmax：

$$\text{coords} = \mathrm{softmax}\left(\frac{\text{logits}}{T} + \log\,\text{mass}\right) \cdot \text{verts}$$

softmax 权重在 canon 帧算出（热图由模型在 canon 几何上产生），但**加权的顶点坐标用的是 `verts_orig`**。预测是顶点的凸组合 ∑wᵢvᵢ，而凸组合与仿射变换可交换：

$$\sum_i w_i\, v_i^{orig} = T^{-1}\!\left(\sum_i w_i\, v_i^{canon}\right)$$

同一组权重作用在 orig 顶点上，结果自动落回 mm 帧——**隐式、精确、零数值误差**，连右耳的反射都被自动消掉（decode 用的就是这只右耳自己的 orig 顶点）。显式矩阵路径也存在（TTA 视图逆变换：`(p/scale − c)@M + c` 回 canon、再 `B⁻¹(p − t)` 回对齐帧），实测往返误差 ~3e-6 mm。评测时预测与 `landmarks_orig` 同帧直接逐点比距离，整条链在 test 上无 train/test 偏移。

误差度量本身值得注意：85 点逐点欧氏距离的均值是一个 **L2 点态度量**。它逐点惩罚偏离，**不奖励曲线整体形状正确**——这条曲线上的点整体沿曲线滑一格，误差照样记满 85 份。这个看似平凡的度量选择，后文会看到它决定了整个误差的主模态。

### 1.2 MAE 预训练：学习表示 φ

DiffusionNet 骨干 + spatial_patch 掩码重建，得到 latent 场 φ: mesh → ℝ¹²⁸。

数学本质是**自监督表示学习**：强迫 latent 能线性重建"以各 landmark 为中心的方向场"——φ 是这个场的充分统计量的某种实现。40 epoch 后冻结骨干，供下游 coarse 定位使用。

### 1.3 Coarse：热图定位（σ 退火 4→2→1）

每个 landmark 一张热图 Hᵢ(x) ≈ exp(−‖x−lᵢ‖²/2σ²)，soft-argmax 解码。

训练分布下最优热图逼近 **E[heat | mesh]**——L2 损失下的条件期望。σ 退火是逐步锐化的变分：先学大尺度支撑、再精化相位。关键性质：**L2 下的点估计是 mean-seeking 的**。当标注本身沿曲线有相位噪声（不同标注员在同一条脊线上放点位置不同）时，模型学到的是"标注分布的中心"，而非个体的真相位。记住这一点。

### 1.4 Refiner：局部 patch 回归

以 coarse 为中心取欧氏半径 4/12mm 两尺度 patch（各 128 点），条件点 Transformer + 区域头，回归 Δ = E[l − c | patch]。

**局部条件均值回归**。Jitter 增强（0/0.5/1.5/3mm 采样）是对 coarse 误差分布的分布鲁棒覆盖。它的天花板已由独立审计给出：patch 内容对残差的解释力只有 **2.1% SSE**——残差信息基本不在局部 patch 里。

### 1.5 SR：向约束集投影

目标定义在表面上、预测在表面外，最近顶点投影（nearest-32）严格合法，稳定贡献 ~0.015mm。

### 1.6 部署聚合

5-fold OOF 链 → 逐点平均。实测 OOF→test 比率 0.911：**同样的系统，聚合让 test 从 1.40 降到 1.27**。这个数字后来被证明是长期叙事悲观化的来源之一。

## 二、DiffusionNet：热方程如何成为网络骨架

这是全文的数学核心。我们部署的实例（从 checkpoint config 核实）：`mesh_xyz_normals` 6 维输入 → first_lin → 4 个 DiffusionNetBlock（C_width=128，谱方法 k_eig=64）→ 128 维 shared latent → 4 个区域头 → 85 张顶点热图 → mass-aware soft-argmax 解码。

### 2.1 地基：Laplace-Beltrami 与曲面的傅里叶基

一切从曲面 M 上的**热方程**开始：

$$\frac{\partial u}{\partial t} = -\Delta u$$

Δ 是 Laplace-Beltrami 算子——欧氏 ∇² 在流形上的内禀推广。它的特征值问题

$$\Delta \phi_i = \lambda_i \phi_i, \qquad \lambda_i \geq 0$$

给出曲面的"傅里叶基"：

| 欧氏空间 | 曲面 M |
|---|---|
| 傅里叶基 $e^{ikx}$ | 特征向量 $\phi_i$ |
| 频率 $k^2$ | 特征值 $\lambda_i$ |
| 低频 = 平滑 | 小 $\lambda_i$ = 全局形状（耳廓整体弯曲） |
| 高频 = 细节 | 大 $\lambda_i$ = 局部细节（脊线、凹坑） |

热方程的解是热核卷积：

$$u(t) = e^{-t\Delta}u(0) = \sum_i e^{-\lambda_i t}\,\langle u,\phi_i\rangle\,\phi_i$$

一个**低通滤波器**：每个谱分量按 e^{−λᵢt} 衰减。t=0 不滤波；t→∞ 只剩常函数。

预计算（每个 mesh 一次）：cotan 权重质量矩阵 M（编码"面积"，保证离散化不变性）、稀疏拉普拉斯 L、`eigsh` 求 **k_eig=64** 个最小特征对、以及把切向梯度写成稀疏矩阵的 gradX/gradY。

### 2.2 核心操作：LearnedTimeDiffusion

每个 block 的第一步是整个方法的心脏：

```python
self.diffusion_time = nn.Parameter(torch.Tensor(C_inout))  # 每通道一个 t

# forward:
x_spec    = Φᵀ M x                     # 投到谱域
x_diffuse = Φ · diag(e^{-λ t_c}) · x_spec   # 第 c 通道自己的滤波器
```

**每个特征通道学习自己的扩散时间 t_c——一个单参数谱滤波器 g(λ) = e^{−t_c λ}。** 128 个通道 = 128 个不同截止尺度的可学习低通滤波器组。这与几何处理里的 HKS（Heat Kernel Signature）同族：HKS 是固定一组 t 的热核响应，DiffusionNet 把 t 变成可学参数。

两个数学上极其重要的细节：

**（a）t 被 clamp 到 ≥1e-8——只能学"滤多少"，不能放大。** e^{−λt} ≤ 1，谱上永远不会放大高频。这是一个强结构先验：网络只能通过后续 MLP **非线性地组合**几何证据，不能凭空创造高频几何信息。

**（b）截断在 k_eig=64。** λ₆₄ 以上的频率**整个不存在于网络的世界里**。这不是超参数清单里普通的一项——它是一个频率宪法，规定了网络能看见的世界的一个边界。第三节会看到，这个边界精确预言了一整族实验结论。

### 2.3 Block 结构：三路信息 + 内禀性

每个 DiffusionNetBlock（共 4 个）：

```
x_in (V×128)
   ├── x_diffuse = e^{-Δt} x          ← 多尺度上下文（"周围几何长什么样"）
   ├── ∇x_diffuse (gradX/Y 稀疏乘)     ← 一阶微分几何（"坡向哪边、多陡"）
   └── SpatialGradientFeatures        ← 旋转等变的梯度内积（下详）
x_out = MLP([x_in, x_diffuse, x_grad_feat]) + x_in     ← 残差
```

**SpatialGradientFeatures 的构造很讲究**。切向梯度 (g_x, g_y) 是切平面上的 2D 向量，而曲面没有规范的正交坐标系——每个顶点的局部框架可任意旋转。要让特征**内禀**（不依赖框架选择），代码把梯度当复数 z = g_x + i·g_y，用一个复数线性层 A = A_re + i·A_im，取内积型特征 ⟨z, Az⟩：

```python
B = (A_re + i·A_im)(g_x + i·g_y)      # 复数线性
dots = tanh(Re(z* · B))                # 内积
```

数学原理：梯度旋转 θ ⇔ z 乘 e^{iθ}，而 ⟨z, Az⟩ 型双线性型是旋转等变的（A 正规时完全不变）。**免费获得旋转等变性**——前提是法向一致朝向（我们的 mesh 满足，故 `with_gradient_rotations=True`）。

整个 block 的哲学：x_in 是"我已知道什么"，x_diffuse 是"我在多尺度上下文里像什么"，梯度特征是"我的局部微分几何是什么"，逐点 MLP 融合，残差保底。**信息融合全部通过几何算子进行**——这让网络对刚性旋转部分天然稳健（但 xyz 输入通道仍泄漏姿态信息，所以我们还是做了显式旋转增强；这也埋下了 TTA 各视图相位差异的伏笔）。

### 2.4 解码：mass-aware soft-argmax 与温度

$$\text{coords} = \mathrm{softmax}\left(\frac{\text{logits}}{T} + \log \text{mass}\right) \cdot \text{verts}$$

`+log(mass)` 做面积加权，否则三角剖分密集区被系统性偏爱（离散化偏置）。温度 T 对应训练时 σ 退火：**T 大时解码是热图一阶矩（mean），T 小时趋于 argmax（mode）**。无论哪种，输出的本质仍是标注分布的中心估计——在相位噪声下这是系统性软肋。

### 2.5 Refiner 看到的世界

Refiner 的 latent 输入取自 backbone 的 128 维逐顶点特征（patch 内 128 个顶点，float16 压缩）。也就是说，**refiner 看到的"局部几何证据"= 已经经过 4 层谱低通滤波 + 梯度融合的表示**。它能修正什么、不能修正什么，继承 coarse 表示的频率视野。

## 三、误差的三分量分解：一个统一框架

把系统看作估计器 f: mesh → ℝ^{85×3}，dev 误差可分解为三个几乎正交的分量：

$$
\underbrace{E}_{\text{总误差}} \;\approx\; \underbrace{A}_{\text{标注内在方差}} \;+\; \underbrace{B}_{\text{表示/估计不足}} \;+\; \underbrace{C}_{\text{估计器方差}}
$$

| 分量 | 内容 | 审计状态 |
|---|---|---|
| **A** | 标注约定不可复现（端点 tip 距几何终止 2.6mm；同脊线上放点位置因人而异） | 预注册判据已触发：不改 target 定义，1.1mm 族不可达；逐点 GT 天花板 **1.3522mm**（OOF 空间） |
| **B** | 表示的信息瓶颈：φ 里没有解码残差所需的信噪比 | 四路独立审计全关：latent 精度低于 B1（P17）；post-hoc 读出 α→0（P19）；训练期辅助监督 ≡ shuffled 控制（P20）；**输入本身不含所需信息**（P22）。被丢弃的采集通道也无信号（P26） |
| **C** | 种子/视图/数据序方差 | 视图 TTA +0.014mm（真实但 sub-bar）；种子误差相关 0.846；OOF→test 聚合比率 0.911 |

三重证据链把系统钉在一条**很紧的 Pareto 前沿**上。但真正有趣的是：**这些结论在 DiffusionNet 的数学结构里早已写好**。

## 四、谱截断如何预言了实验结论

用第二节的两个结构性先验——k_eig=64 截断、每通道纯低通 e^{−λt}——逐条回看实验记录，会发现"失败"结论不是孤立的清单，而是**数学结构的必然推论**：

### 4.1 "高阶共享形变是盲区"（P18）的机制

因果链：高阶区域形变 → 表现为谱域中 λ 中高段分量 → 被结构性衰减（截断 + 滤波双重压制）→ latent 信噪比不足 → coarse 热图取条件众数，高阶形变被平均掉。

实测：残差 = 平滑高阶共享区域形变，解释 17–41% 的误差。与推理完全吻合。

### 4.2 读出为什么注定失败（P19/P20）

读出高阶 latent 需要 latent **保留**那些模式的可分信息；但谱衰减在表示形成时就把它们压掉了。所以 post-hoc 读出 α→0、训练期监督 ≡ shuffled（辅助梯度指向已衰减的子空间）**在原理上就是必然**。这两个实验分别从"事后"和"事中"攻击同一个瓶颈，双双失败恰恰是最强的机制证据。

### 4.3 换架构为什么没用（P30）

PTv3-lite（逐点欧氏注意力，无谱截断）在 outer/inner_helix（脊线=中高频结构）区域确实赢了，concha（平坦，无高频可挖）输——**不是 PTv3 更好，是它没有我们的低通先验；而输入信息总量两边一样（P22 已封）**。整体 +0.714mm：内禀 vs 全局坐标的适配成本吞掉了局部收益。容量翻倍 −0.009mm 同理：**加宽一个看不到高频的滤波器组，不解决信息不存在的问题**。

### 4.4 TTA 的相位结构（P29）

xyz 通道携带姿态信息，但内禀路径（diffuse/梯度）旋转不敏感 → 视图间差异集中在"绝对位置→热图相位"通路 → **视图噪声近零均值、相位偏差 view-invariant**（实测确认）。TTA 只能平均掉视图子分量，平均不掉相位错位——所以只有 +0.014mm。这是网络半内禀结构的直接推论。

### 4.5 误差主模态 = 曲线相位错位（P23）与度量选择

标注分布在 arc-length 方向有方差（A 分量的一维子空间）；coarse 是 mean-seeking 的众数估计，在曲线重参数化群上没有锚——**必然滑到分布中心而非个体的真相位**。而 L2 点态度量逐点记账，让这种"整段同滑"成为最便宜的误差出口。四个分量在此汇合：度量（1.1 节）、mean-seeking（1.3 节）、标注方差（A）、表示瓶颈（B）。

### 4.6 一个量纲混淆的教训（P27→P31）

双耳不对称 1.58mm > 误差预算 1.40mm 曾被用来推断"双侧信息不可用"。Phase 31 的双侧 GT oracle 审计推翻了它：**1.58mm 界定的是逐点几何不对称，而两只耳朵共享 subject 级的高阶模式系数**（L-R 系数相关实测 0.67–0.79，shuffled 0.06）。量纲不同的两个量不能互相 bound——这是把推理锚定在"量的语义"而非"数字大小"上的教训。但同实验也测到：把 oracle 修正朴素加到 B1 上是负收益（−0.33mm），因为 B1 误差与残差基近正交（cos −0.24）——**信号真实 ≠ 桥接免费**，增益活在哪个基座上必须实测。

## 五、数学原理指向的未测空间

按"原理是否支持 × 是否已被测量"排序：

### 5.1 抬高谱截断：k_eig 64 → 128/256

频率天花板抬一档。**从未测过**（P30 关闭的是"换架构/加容量"，没有关闭"抬谱截断"）。成本 = 重算几何 operators + 重训。原理预测：增益集中在脊线区（inner/outer_helix）。⚠️ 诚实注记：P22 的"输入不可观测"是在当前表示下测的，抬 k_eig 相当于**部分重开 B 分量**——作为对照实验注册，预期中等。

### 5.2 纯低通 → 带通/小波型谱滤波器

把每通道 (t_c) 推广为 g(λ) = a·λ·e^{−tλ} 一类的带通窗（heat wavelet / learned spectral filter 族），保留中频结构。改动只在 `LearnedTimeDiffusion` 一个类内，其余机器不动。与 5.1 正交可叠加。

### 5.3 曲率输入通道

目前 C_in 只有 xyz+normals；主曲率/形状指数是 Δ 的局部函数（纯谱几何量），加进输入是"重开 B"最廉价的一刀。

### 5.4 C 分量收割（进行中）

种子 × fold × 视图全栈平均。数学保底（Jensen：预测平均的误差 ≤ 误差的平均），但种子相关 0.846 意味着方差衰减有限——5 条链的独立分量只有 ~15%。预期落在 0.02–0.05mm，作用是注册为部署组件而非翻盘。

### 5.5 相位重参数化（对 A/B 交界，最有数学美感）

既然误差主模态是曲线 arc-length 平移群的作用，就显式建模它：不修 85 个点，而是学一个 **1D 单调微分同胚 ψ: [0,1]→[0,1]**（每条曲线 5–8 个参数），把预测曲线重参数化到目标相位。与"从 mesh 学绝对曲线几何"（已关闭的 P14/P16）不同，这是低维受约束的**相对**修正问题。它与双侧信息天然接口：对侧耳的相位是 subject 特异且 mesh 可观测（0.67–0.79），学习式整合的正确形式很可能就是"用对侧 pin 相位"。

### 5.6 目标重定义（对 A，唯一能动天花板的）

逐点 GT 天花板 1.3522 是测量值不是猜测。若榜首团队的 endpoint 更接近几何终止点，这一步同时**解释并缩小**与 1.05 的差距（我们 test 空间天花板 ~1.23 vs 他们 1.05）。属于数据治理，需要真人重标注或规则化 target。

## 六、总判断

这个系统已经处在一条非常紧的 Pareto 前沿上：

- **B（表示）**：四路审计 + 架构轴 + 容量轴全关。但谱截断本身没测过——这是原理指出的、唯一合规的重开方向；
- **A（标注方差）**：1.35 天花板有预注册的量化触发，只能靠 target 重定义移动；
- **C（方差）**：数学保底、量级有限，正在收口。

一句话总结这次审计的方法论收获：**把实验结论放回模型的数学结构里，"失败"会从孤立的清单变成系统的推论；而尚未测量的空间，会从数学结构的不对称处自己浮现出来**——本例中，就是一个被 k_eig=64 和纯低通先验画出的频率边界。
