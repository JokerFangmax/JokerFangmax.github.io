# 前缀和：从区间和到子数组计数

> 本篇是刷题沉淀的算法模板之一。核心思想一句话：**预处理出"从头累到 i"的信息，把任意区间的查询变成两次前缀信息的运算。**

---

## 1. 定义与基本形态

给定数组 $a_0, a_1, \dots, a_{n-1}$，定义**前缀和**：

$$
pre[i] = a_0 + a_1 + \cdots + a_{i-1}, \qquad pre[0] = 0
$$

即 $pre[i]$ 表示**前 $i$ 项之和**（不含第 $i$ 项，下标从 0 计）。于是任意区间 $[l, r]$（闭区间）的和为：

$$
sum(l, r) = pre[r+1] - pre[l]
$$

**下标差一是前缀和最常见的事故来源**，强烈建议固定一种约定并坚持使用。本文统一用"左闭右开的 $pre$ 含义"：`pre[i] = 前 i 项之和，pre[0] = 0`。

### 1.1 基础模板

```cpp
int n = nums.size();
vector<long long> pre(n + 1);
for (int i = 0; i < n; i++)
    pre[i + 1] = pre[i] + nums[i];

// 查询区间 [l, r] 的和：O(1)
long long rangeSum = pre[r + 1] - pre[l];
```

两个工程习惯：

1. **`pre[0] = 0` 的哨兵位**：让"从下标 0 开始的区间"不需要特判；
2. **前缀和开 `long long`**：$n$ 个 $10^9$ 级别的数累加轻松爆 `int`，这是性价比最高的保险。

### 1.2 空间优化

如果只查询不重复利用，可以不存整个数组，边遍历边维护一个滚动变量 `pre`——这在后面的"配哈希表"套路中是标准写法。

---

## 2. 前缀和技术成立的根基：运算可逆

前缀和并不是"天然的"，它能工作是因为**加法有逆运算**：

$$
sum(l, r) = pre[r+1] - pre[l] \iff pre[r+1] = sum(l,r) + pre[l]
$$

"减法可以精确移除前一段的贡献"——这个性质决定了哪些量可以前缀化：

| 量 | 运算 | 可逆？ | 可否前缀化 |
|----|------|--------|-----------|
| 区间和 | $+$ | ✅ 有减法 | ✅ |
| 区间异或 | $\oplus$ | ✅ 自逆（$a\oplus a=0$） | ✅ |
| 区间乘积（模素数意义下） | $\times$ | ✅ 乘法逆元 | ✅（模意义） |
| 区间最大/最小值 | $\max/\min$ | ❌ 不可逆 | ❌ 需 ST 表 / 线段树 / 单调队列 |
| 区间按位与 | $\&$ | ❌ | ❌ |

**典型误区**：想用 `prefixMax[j] - prefixMax[i]` 求区间最值。反例：$a = [5,1,3]$，区间 $[1,2]$ 的最大值是 3，但 $prefixMax[2] = 5$ 来自已出界的下标 0，$\max$ 无法"减去"它的贡献。详见[单调队列](../monotonic_queue/)一文。

## 3. 前缀和 + 哈希表：子数组计数套路

这是前缀和在算法题中最重要的进阶用法。问题形态：

> **统计和满足某条件的子数组个数 / 找和满足条件的子数组。**

### 3.1 推导

"子数组 $nums[i..j]$ 的和为 $k$"翻译成前缀和语言：

$$
pre[j+1] - pre[i] = k \iff pre[i] = pre[j+1] - k
$$

于是从左到右扫描 $j$，问题变成：**我左边有多少个前缀和等于 $pre[j] - k$？**——"统计前面出现过多少个某值"，正是哈希表的职责。用一个 `unordered_map<long long, int>` 记录「前缀和 → 出现次数」即可，总复杂度从暴力的 $O(n^2)$ 降到 $O(n)$。

### 3.2 通用模板

```cpp
// 统计和为 k 的子数组个数（LeetCode 560）
unordered_map<long long, int> cnt;
cnt[0] = 1;                      // 空前缀：从下标 0 开始恰好凑出 k 的情形
long long pre = 0;
int ans = 0;
for (int x : nums) {
    pre += x;
    ans += cnt.count(pre - k) ? cnt[pre - k] : 0;
    cnt[pre]++;                  // 先查询后插入：k=0 时不会自己匹配自己
}
```

三个必须记住的细节（都是常见 WA 点）：

1. **`cnt[0] = 1` 不能漏**：代表空前缀；
2. **先查询、后插入**：否则 $k=0$ 时 `pre - k == pre` 会错误匹配到自己（多算一个空子数组）；
3. **元素含负数时窗口类做法全部失效**（无单调性），本套路不受影响，反而是唯一线性解。

### 3.3 条件变形

同一骨架，把"匹配什么"换掉即可应对一族题目：

| 题目 | 条件 | 哈希表键 | 备注 |
|------|------|---------|------|
| [LC 560. 和为 K 的子数组](https://leetcode.cn/problems/subarray-sum-equals-k/) | $pre_j - pre_i = k$ | 前缀和 | 模板原题 |
| [LC 974. 和可被 K 整除的子数组](https://leetcode.cn/problems/subarray-sums-divisible-by-k/) | $pre_j \equiv pre_i \pmod K$ | 前缀和对 K 的**非负余数** | 负数取模：`((x % K) + K) % K` |
| [LC 523. 连续的子数组和](https://leetcode.cn/problems/continuous-subarray-sum/) | 同余 + 长度 ≥ 2 | 余数 → 最早下标 | `cnt[0] = -1` |
| [LC 525. 连续数组](https://leetcode.cn/problems/contiguous-array/) | 0/1 个数相等（把 0 看作 −1 即和为 0） | 前缀和 → 最早下标 | 求**最长** |
| [LC 325. 和等于 k 的最长子数组](https://leetcode.cn/problems/maximum-size-subarray-sum-equals-k/) | $pre_j - pre_i = k$ | 前缀和 → 最早下标 | 求**最长** |
| [LC 1248. 统计「优美子数组」](https://leetcode.cn/problems/number-of-sub-arrays-with-odd-sum/) | 奇偶性（前缀奇数个数） | 前缀奇偶计数 | 0/1 前缀 |

注意一个分岔：**求"个数"存次数，求"最长/最短"存最早（或最晚）出现的下标**——前者累加，后者算距离。

## 4. 其他变体速览

### 4.1 差分（前缀和的逆操作）

给区间 $[l, r]$ 整体加 $v$、最后查询每个位置的值：令 $d[l] += v,\ d[r+1] -= v$，对 $d$ 做前缀和即还原。相当于"前缀和是求和方向的累积，差分是修改方向的累积"。代表题：[LC 1109. 航班预订统计](https://leetcode.cn/problems/corporate-flight-bookings/)、[LC 1094. 拼车](https://leetcode.cn/problems/car-pooling/)。

### 4.2 二维前缀和

$$
pre[i][j] = pre[i-1][j] + pre[i][j-1] - pre[i-1][j-1] + a[i][j]
$$

查询子矩阵 $(x_1,y_1,x_2,y_2)$（容斥）：

$$
S = pre[x_2][y_2] - pre[x_1-1][y_2] - pre[x_2][y_1-1] + pre[x_1-1][y_1-1]
$$

代表题：[LC 304. 二维区域和检索](https://leetcode.cn/problems/range-sum-query-2d-immutable/)、[LC 1314. 矩阵区域和](https://leetcode.cn/problems/matrix-block-sum/)。

### 4.3 前缀计数 / 前缀布尔

前缀化不限于数值求和：`pre[i] = 前 i 项中满足 P 的元素个数`（如"前 i 项里有多少个奇数"、"有多少个元音字母"）也遵循同一套"区间查询 = 两个前缀相减"的逻辑。代表题：LC 1248、[LC 2063. 所有元音子串](https://leetcode.cn/problems/vowels-of-all-substrings/)。

### 4.4 前缀和 + 二分

前缀和单调（要求元素非负）时，"求和恰好/至少为 x 的最短子数组"可以二分前缀和。注意元素含负数时前缀和不单调，只能上单调队列（见[单调队列](../monotonic_queue/)中的 LC 862）。

---

## 5. 决策速查

遇到子数组问题时的思考顺序：

1. **问"区间和/个数"** → 先想前缀和；元素非负且窗口有单调性时也可想滑动窗口；
2. **问"区间最值"** → 前缀和出局，看窗口是否滑动（单调队列）/ 是否静态（ST 表）/ 是否带修改（线段树）；
3. **求个数** → 前缀和 + 哈希表存**次数**；求最长/最短 → 存**最早/最晚下标**；
4. **元素有负数** → 滑动窗口基本失效，前缀和 + 哈希表是主力。
