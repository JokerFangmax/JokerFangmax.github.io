# AT 05：单调栈——下一个更大元素与柱状图矩形

> **核心思想一句话：及时丢弃永远不可能再成为答案的候选者——"比我晚来还比我强"的元素一到，我就再无出头之日，立刻出局。**
> 理论后盾：[DSA 4 §16：直方图最大矩形](../../DSA/DSA_4/)。姊妹篇：[单调队列](../monotonic_queue/)——同一思想加上"过期淘汰"维度，两文开头的对照表值得先看。

---

## 1. 这个模板解决什么问题

一切"找左/右第一个比它大（小）的元素"的问题。它看似小技巧，实则是**"枚举每个元素作为最值的那段区间"** 的通用武器——柱状图矩形、贡献计数、每日温度、接雨水全部收入麾下。

暴力是每个位置向两边扫，$O(n^2)$。单调栈的观察：

> 元素 $a_j$ 想成为"某位置 $i$ 右边第一个更大元素"，当且仅当 $j > i$ 且 $a_j > a_i$，且 $j$ 与 $i$ 之间没有更大的挡路者。**一旦来了个 $a_j \ge a_i$（$j > i$），$a_i$ 对所有 $i$ 之后的询问都不再是答案——它该出局了。**

于是栈内元素"等待被更强的后来者判决"，从栈底到栈顶递减（找更大元素时）。

## 2. 代码模板

### 2.1 统一骨架：下一个更大元素

```cpp
// 求每个 i 右边第一个严格大于 a[i] 的下标，无则 -1
vector<int> nextGreater(vector<int>& a) {
    int n = a.size();
    vector<int> ans(n, -1);
    stack<int> st;                        // 存下标，对应值从栈底到栈顶严格递减
    for (int i = 0; i < n; i++) {
        while (!st.empty() && a[st.top()] < a[i]) {
            ans[st.top()] = i;            // 弹栈的瞬间 = 被弹元素的答案揭晓时刻
            st.pop();
        }
        st.push(i);
    }
    return ans;
}
```

**读法**：主循环压栈，`while` 弹栈——**弹栈不是清理，是结算**：栈顶元素等的"右边第一个更大元素"就是当前来的 $a_i$。扫描结束还在栈里的元素，答案为 $-1$。

三个方向的变体全靠改比较符与循环方向：

| 要求 | 弹栈条件 | 栈内单调性 |
|------|---------|-----------|
| 右边第一个**更大** | `a[st.top()] < a[i]` 弹 | 递减 |
| 右边第一个**更小** | `a[st.top()] > a[i]` 弹 | 递增 |
| 左边第一个更大/更小 | **从右往左**扫，条件同上 | 同上 |

**存下标还是存值**：需要知道"隔多远"（每日温度要距离、矩形要宽度）必须存下标；只要值（LC 496）存值也行——**统一存下标**最不容易错。

### 2.2 柱状图最大矩形：哨兵技巧

对每根柱子 $i$，找到左右第一个比它矮的边界 $L_i, R_i$，则它能支撑的最大矩形面积为 $a_i \times (R_i - L_i - 1)$。单调栈一次扫描同时拿到两个边界，诀窍是**右端补一个高度 0 的哨兵**，把栈里所有待结算柱子清仓：

```cpp
int largestRectangleArea(vector<int>& heights) {
    heights.push_back(0);                 // 右哨兵：扫描结束时自动清仓
    int n = heights.size(), ans = 0;
    stack<int> st;                        // 下标栈，高度从栈底到栈顶严格递增（找更矮边界）
    for (int i = 0; i < n; i++) {
        while (!st.empty() && heights[st.top()] >= heights[i]) {
            int h = heights[st.top()]; st.pop();
            int left = st.empty() ? -1 : st.top();   // 左边界 = 弹出后的新栈顶
            ans = max(ans, h * (i - left - 1));      // 右边界 = 当前 i
        }
        st.push(i);
    }
    return ans;
}
```

两个细节：

- **左边界为什么是弹出后的新栈顶**：被弹柱子的左边界不是它自己的下标，而是"它左边第一个更矮的柱子"——恰好是栈里垫在它下面的那个（栈严格递增保证）。栈空则左边界为 $-1$（虚拟哨兵）；
- **`>=` 还是 `>`**：相等高度用 `>=` 弹掉时，被弹柱子算出的宽度会偏小，但它**后面那个等高柱子**会补回完整宽度——答案不丢，所以两个都能 AC。这是单调栈最经典的"看着可疑其实没事"的点。

### 2.3 贡献法计数：子数组最值之和

"所有子数组的最大值之和"（[LC 907](https://leetcode.cn/problems/sum-of-subarray-minimums/) 的最小值版）：每个元素 $a_i$ 作为**最大值**管辖的子数组个数是 $(i - L_i) \times (R_i - i)$，其中 $L_i, R_i$ 是两侧第一个 $\ge a_i$ 的位置。总贡献 $\sum a_i \times (\text{左宽度}) \times (\text{右宽度})$。

**防重复计数的关键**：相等元素必须在一侧取严格、一侧取不严格——左边界用"第一个 $>$ "，右边界用"第一个 $\ge$"，两个等高元素就不会把同一个子数组的最大值算两遍。谁严谁松是约定，但**必须一严一松**。

<details>
<summary><b>LC 907 子数组最小值之和：贡献法完整代码</b></summary>

```cpp
int sumSubarrayMins(vector<int>& arr) {
    const long long MOD = 1e9 + 7;
    int n = arr.size();
    vector<int> left(n), right(n);
    stack<int> st;
    for (int i = 0; i < n; i++) {              // left[i]: 左边第一个 < arr[i] 的下标（严格）
        while (!st.empty() && arr[st.top()] >= arr[i]) st.pop();
        left[i] = st.empty() ? -1 : st.top();
        st.push(i);
    }
    while (!st.empty()) st.pop();
    for (int i = n - 1; i >= 0; i--) {         // right[i]: 右边第一个 <= arr[i] 的下标（不严格）
        while (!st.empty() && arr[st.top()] > arr[i]) st.pop();
        right[i] = st.empty() ? n : st.top();
        st.push(i);
    }
    long long ans = 0;
    for (int i = 0; i < n; i++)
        ans = (ans + (long long)arr[i] * (i - left[i]) * (right[i] - i)) % MOD;
    return ans;
}
```

自查：`arr = [3,1,2,4]` → 17（子数组最小值 $3+1+1+1+2+1+2+2+4+4$... 逐个算：$3,1,2,4,\\min(3,1)=1,\\min(1,2)=1,\\min(2,4)=2,\\min(3,1,2)=1,\\min(1,2,4)=1,\\min(3,1,2,4)=1$，合计 $17$）。
</details>

## 3. 常见变形与坑

| 变形 | 一句话做法 |
|------|-----------|
| 循环数组找下一个更大（LC 503） | 扫两遍：`for (int i = 0; i < 2n; i++)`，取 `i % n`，第二遍只弹不压（或照压，答案会被覆盖成更早的，注意只在 `ans` 为 $-1$ 时写） |
| 二维矩阵每行是直方图（LC 85） | 逐行累计高度，每行跑一遍 §2.2 |
| "前 i 个元素的最大值"（LC 901 跨度） | 求左边第一个更大元素，跨度 = 当前下标 − 该元素下标 |
| 子数组最值计数（LC 907/2104） | 贡献法 §2.3 |
| 接雨水（LC 42） | 单调栈按行接（见 §4.4 对照） |

**坑清单**：

1. **弹栈条件写反**是最高频错误：求"更大"时栈内递减、弹的是"更小的栈顶"——背不住就记"栈里留的都是还没等到答案的，新来的若比它大，它就等到了"；
2. **哨兵忘加**：§2.2 没有右哨兵时，扫描结束还要 `while` 清仓一遍结算残余柱子——加哨兵后循环体内自然覆盖，**二选一，别都做也别都不做**；
3. **相等元素的重复计数**：贡献法必须一严一松（§2.3）；
4. **栈里存值却要算宽度**：宽度 = 下标差，存值就丢了这个信息；
5. **取模**：贡献法中间乘积用 `long long`，每步 `% MOD`。

## 4. 样题精讲

### 4.1 洛谷 P5788 【模板】单调栈

> [题目链接](https://www.luogu.com.cn/problem/P5788)。给 $n$ 个数，输出每项右边第一个大于它的数的下标（从 1 开始），没有则输出 0。

§2.1 骨架加两处本地化：下标 1-based（`i + 1`）、初值 0（无答案不输出 $-1$）。$n$ 可达 $3 \times 10^6$，读入用 `scanf`：

```cpp
#include <cstdio>
#include <stack>
#include <vector>
using namespace std;

int main() {
    int n;
    scanf("%d", &n);
    vector<int> a(n), ans(n, 0);
    for (int i = 0; i < n; i++) scanf("%d", &a[i]);
    stack<int> st;                       // 下标栈，值从栈底到栈顶严格递减
    for (int i = 0; i < n; i++) {
        while (!st.empty() && a[st.top()] < a[i]) {
            ans[st.top()] = i + 1;       // 右边第一个更大（1-based）
            st.pop();
        }
        st.push(i);
    }
    for (int i = 0; i < n; i++) printf("%d ", ans[i]);
    return 0;
}
```

自查：`a = [1, 4, 2, 3, 5]` → `2 5 4 5 0`（1 的答案是 4 在下标 2；4 等 5 在下标 5；2 等 3 在下标 4；3 等 5 在下标 5；5 没有）。每个元素至多进出栈一次，$O(n)$。

### 4.2 LeetCode 84. 柱状图中最大的矩形（困难）

§2.2 模板原样套用。值得做的是**手推一遍** `heights = [2,1,5,6,2,3]`：弹 6 得面积 $6$，弹 5 得面积 $10$（最大矩形来了），末尾哨兵清仓时弹 3、2、1 分别得 $3, 8, 6$——答案是 $10$。把"左边界 = 弹出后的新栈顶"这一步在纸上画出来，这题就再也不会写错。题解：[LeetCode 84](../../LeetCode/LeetCode_84/)。

### 4.3 LeetCode 739. 每日温度（中等）

下一个更大元素的原型题，答案从"下标"改成"距离"——`ans[st.top()] = i - st.top()`，一个字符的改动。这正是**统一存下标**的红利。题解：[LeetCode 739](../../LeetCode/LeetCode_739/)。

### 4.4 LeetCode 42. 接雨水（困难）：单调栈 vs 双指针

接雨水有两条正路，对照着看能理解单调栈的边界：

| | 单调栈（按行） | 双指针（按列） |
|---|--------------|--------------|
| 思路 | 维护递减栈，遇到更高柱子就结算**横向**一层的雨水 | 左右两指针向中间收敛，短的一侧结算**纵向**一列 |
| 每次结算 | `min(左挡板, 当前柱) - 弹出柱高` × 宽度 | `min(maxL, maxR) - 当前柱高` |
| 复杂度 | $O(n)$ | $O(n)$，空间 $O(1)$ |

单调栈版本质是"每个凹坑按行横着填"，双指针版是"每列竖着填"——**同一个答案的不同剖分**。面试先写哪个都对，但两种都要会。题解：[LeetCode 42](../../LeetCode/LeetCode_42/)。
