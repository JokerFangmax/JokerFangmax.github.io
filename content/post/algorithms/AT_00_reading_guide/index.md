# AT 00：刷题模板系列导读——速查总表与选型地图

> 本系列共 22 篇（本篇 + [01](../AT_01_vector_bitmap/)–[21](../AT_21_sorting/)），为 [DSA 系列](../../DSA/DSA_1/)（邓俊辉《数据结构》14 章笔记）中的每个数据结构与算法配一份**刷题武器**：完整可提交的 C++17 模板 + 洛谷/LeetCode 样题精讲。
> 分工：DSA 系列讲**为什么**（原理与证明），本系列讲**怎么写**（模板、变形、坑、题目地图）；仓库 [LeetCode 栏目](../../LeetCode/)是逐题题解，本系列按专题组织。
> 本篇随时可弃——它只是一张地图，正文从你需要的专题进。

---

## 1. 系列主线：模板是「不动点」

刷题时真正可复用的资产不是题解，是**模板**——一组写熟到不会错的代码，赛场上只剩「识别题型 → 套模板 → 改状态定义」三步。本系列每篇的结构都为这个流程服务：

| 节 | 回答的问题 |
|---|-----------|
| ① 解决什么问题 | 题面长什么样时想起它 |
| ② 代码模板 | 背什么（含不变量与边界） |
| ③ 常见变形与坑 | 改哪里、哪里会 RE/TLE/WA |
| ④ 样题精讲 | 完整套用示范 |
| ⑤ 题目清单 | 练什么（按变形分组） |
| ⑥ 与其他篇的联系 | 组合技 |

一个贯穿全系列的判断标准（与 DSA 理论系列呼应）：**每个数据结构都是一次「放弃什么换什么」的交易**——堆放弃全序换 $O(\log n)$ 最值、并查集放弃结构信息换均摊 $O(\alpha(n))$ 等价判定、哈希放弃有序性换 $O(1)$ 定位。认出题目愿意放弃什么，模板就选对了。

## 2. 一句话速查表（21 篇）

| # | 专题 | 一句话核心思想 |
|---|------|--------------|
| [01](../AT_01_vector_bitmap/) | 向量与位图 | 倍增扩容买来分摊 $O(1)$ 尾插；位图用 $1/64$ 的空间换集合 |
| [02](../AT_02_binary_search/) | 二分与二分答案 | 半开区间 + `while (lo < hi)` 统一左/右边界；答案单调就能二分 |
| [03](../AT_03_linked_list/) | 链表 | 虚拟头节点消灭头特判；快慢指针一次遍历拿位置信息 |
| [04](../AT_04_stack/) | 栈 | 最近匹配关系天然 LIFO；表达式求值 = 数字栈 + 运算符栈 |
| [05](../AT_05_monotonic_stack/) | 单调栈 | 「比我早来还比我弱」的候选者永远可以丢弃 |
| [06](../AT_06_queue_monotonic_queue/) | 队列与单调队列 | 窗口是先进先出的；双端单调队列让最值查询摊还 $O(1)$ |
| [07](../AT_07_binary_tree/) | 二叉树 | 递归三段式（左子树→右子树→合并）覆盖 90% 树题 |
| [08](../AT_08_bst_balanced_tree/) | BST 与平衡树 | 顺序操作先想 `set`/`map`；要 rank/kth/分裂合并才手写 Treap |
| [09](../AT_09_heap/) | 堆 | 只维护最值在哪，放弃全序换 $O(\log n)$；TopK 用 K 小顶堆 |
| [10](../AT_10_union_find/) | 并查集 | 只回答「是否同集合」，把动态等价关系维护到近乎 $O(1)$ |
| [11](../AT_11_graph_bfs_dfs/) | 图的存储与遍历 | 先写对存图、背熟遍历框架，剩下只是「访问时干什么」 |
| [12](../AT_12_shortest_path/) | 最短路 | 非负单源堆 Dijkstra；负权/判负环 SPFA；多源或 $n\le 500$ 用 Floyd |
| [13](../AT_13_mst/) | 最小生成树 | 稀疏图 Kruskal、稠密图 Prim；两者都是 PFS 换优先级函数 |
| [14](../AT_14_articulation_bcc/) | 关节点与 BCC | 一遍 DFS：树边继承 low、回边只取 dfn；根与非根双判定 |
| [15](../AT_15_segment_tree/) | 线段树与树状数组 | 完全覆盖的节点只记账不下推（lazy），查询路过再结账 |
| [16](../AT_16_kdtree/) | kd-tree | 轮流按维切中位数；查询用超矩形距离剪枝 |
| [17](../AT_17_hash_table/) | 哈希表 | 放弃有序性换 $O(1)$ 定位；赛场上重点是防卡（自定义哈希） |
| [18](../AT_18_string_hash/) | 字符串哈希 | 前缀指纹让任意子串 $O(1)$ 比较；二分 + hash 求 LCP |
| [19](../AT_19_kmp/) | KMP | 失配也有信息：next 表让文本指针永不回退 |
| [20](../AT_20_trie/) | Trie 与 01-Trie | 公共前缀折叠成共享路径；01-Trie 把按位贪心变成走反位 |
| [21](../AT_21_sorting/) | 排序 | 通用排序交给 `std::sort`；手写只在卡快排/逆序对/小值域/比较器四场景 |

## 3. 选型地图：从题目特征到模板

### 3.1 按操作特征选数据结构

| 题目要求 | 首选 | 退化到 | 见 |
|---------|------|--------|-----|
| 有序 + 随机定位 | 平衡树（`set`/`map`） | 离线排序 + 二分 | [08](../AT_08_bst_balanced_tree/) |
| 只取最值、来去频繁 | 堆 | 对顶堆（双端第 K 大） | [09](../AT_09_heap/) |
| 等价类合并/查询 | 并查集 | 带权（关系随距离传递） | [10](../AT_10_union_find/) |
| 区间加/区间和/最值 | 线段树 | 可减信息用树状数组 | [15](../AT_15_segment_tree/) |
| 前缀/子串匹配 | Trie / 字符串哈希 / KMP | 按查询类型三分 | [18](../AT_18_string_hash/)、[19](../AT_19_kmp/)、[20](../AT_20_trie/) |
| 「下一个更大/更小」 | 单调栈 | 窗口版用单调队列 | [05](../AT_05_monotonic_stack/)、[06](../AT_06_queue_monotonic_queue/) |
| 平面/高维近邻 | kd-tree / 分治 | — | [16](../AT_16_kdtree/) |
| 位置未知只知道结果 | 二分答案 | 判定函数套任意模板 | [02](../AT_02_binary_search/) |

### 3.2 图论题的第一问：边权有没有负的

```
负权？ ── 无 ──→ 单源：堆优化 Dijkstra [12]        多源/n≤500：Floyd [12]
       └─ 有 ──→ 判负环：SPFA [12]   无负环最短路：SPFA/Bellman-Ford [12]
连通性问题（不关心长度）：并查集 [10] / DFS [11]
割点/桥/连通分量：Tarjan [14]
```

### 3.3 「手写 vs STL」决策表

| 需求 | 用 STL | 手写的时机 |
|------|--------|-----------|
| 排序 | `std::sort`（introsort 不退化） | 卡快排的题（LC 912）、逆序对（归并）、值域小（计数）→ [21](../AT_21_sorting/) |
| 有序集合 | `set`/`multiset` | 要 rank/kth/前驱后继批量操作、可持久化 → Treap（[08](../AT_08_bst_balanced_tree/)） |
| 优先队列 | `priority_queue` | 要删除任意元素（懒删除可绕过）、两堆合并（左式堆）→ [09](../AT_09_heap/) |
| 哈希 | `unordered_map` | key 是自定义类型/被卡哈希 → 自定义哈希函数（[17](../AT_17_hash_table/)） |
| 队列/栈 | `queue`/`stack`/`deque` | 固定大小卡常（数组模拟）→ [04](../AT_04_stack/)、[06](../AT_06_queue_monotonic_queue/) |

## 5. 复杂度速查（背这张表）

| 结构/算法 | 查找 | 插入/删除 | 备注 |
|-----------|------|----------|------|
| 有序向量 + 二分 | $O(\log n)$ | $O(n)$ 移位 | 读多写少 |
| 哈希表 | $O(1)$ 期望 | $O(1)$ 期望 | 无序；最坏可被卡 |
| 平衡树 | $O(\log n)$ | $O(\log n)$ | 有序遍历/前驱后继 |
| 堆 | 取最值 $O(1)$ | $O(\log n)$ | 建堆 $O(n)$（Floyd） |
| 并查集 | — | 均摊 $O(\alpha(n))$ | 路径压缩 + 按秩/大小合并 |
| 线段树 | $O(\log n)$ | $O(\log n)$ | 区间修改需 lazy |
| 树状数组 | $O(\log n)$ | $O(\log n)$ | 常数小；只管可减信息 |
| Trie | $O(\lvert s\rvert)$ | $O(\lvert s\rvert)$ | 与字符集大小线性 |
| Dijkstra（堆） | — | — | $O(m\log m)$，非负权 |
| SPFA | — | — | 最坏 $O(nm)$，判负环 |
| Floyd | — | — | $O(n^3)$，多源 |
| Kruskal / Prim | — | — | $O(m\log m)$ / $O(n^2)$ 或 $O(m\log n)$ |
| KMP | — | — | 匹配 $O(n+m)$，求 next $O(m)$ |
