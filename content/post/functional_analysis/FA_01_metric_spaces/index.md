# 泛函分析 01：从距离到度量空间

> 📖 本系列基于步尚全《泛函分析基础》（清华大学出版社）整理，保留教材定理编号便于对照。本篇覆盖 §1.1–1.2。

---

## 1. 这一篇解决什么问题？

先看三个来自不同领域的问题：

1. **解方程组**：迭代序列 $x^{(k)}$ 一步一步逼近解——"逼近"是什么意思？收敛到哪？
2. **逼近函数**：用多项式去逼近连续函数——两个函数之间的"距离"是什么？
3. **数列空间**：把无穷数列 $\{x_n\}$ 当成一个"点"——点与点之间怎么量距离？

这三个问题的对象完全不同（向量、函数、数列），但**解决它们的手法惊人地一致**：定义距离 → 在距离上谈收敛 → 在收敛上谈解的存在性。泛函分析的第一个动作，就是把这种共性提炼成公理——**度量空间**。它在泛函分析中的地位，正如 $\mathbb{R}$ 在微积分中的地位：是一切讨论的舞台。

本篇回答：**"距离"到底要满足哪几条公理才算距离？这些公理各自承担什么职责？围绕距离自然长出哪些拓扑概念（开集、闭集、闭包、稠密、连续）？**

---

## 2. 先立地图：数学里的"空间"到底指什么？

在进公理之前，先把整门课的对象——"空间"——的谱系画出来。泛函分析（functional analysis）这个名字里的"分析"容易让人以为它只是微积分的延伸，但它的实际做法是：**把微积分里对"函数"的研究，升级为对"函数组成的无穷维空间"的研究**。而"空间"这个词在整个数学里是分层的——每一层 = 裸集合 + 一层结构，结构越多，能说的定理越多，但适用范围也越窄。

### 2.1 谱系塔：集合 → 拓扑 → 度量 → 赋范 → 内积

```
集合 X                    什么都没有：只有"点"，点与点无法比较
  │ + 开集族（哪些子集算"开"）
  ▼
拓扑空间                   能谈：收敛、连续、连通、紧（定性）
  │ + 距离函数 d(x,y)
  ▼
度量空间                   能谈：定量——球、ε-δ、Lipschitz、完备
  │ + 线性结构（加法 x+y、数乘 αx）
  ▼
线性空间 + 度量            能谈：子空间、凸组合、线性算子
  │ + 范数 ‖·‖（长度公理化，诱导 d(x,y)=‖x−y‖）
  ▼
赋范空间                   能谈：范数球、算子范数、级数收敛
  │ + 完备性（Cauchy 列都收敛）
  ▼
Banach 空间                能谈：不动点、开映射、一致有界（三大定理的家）
  │ + 内积 ⟨x,y⟩（角度公理化，诱导范数）
  ▼
内积空间                   能谈：正交、投影、夹角
  │ + 完备性
  ▼
Hilbert 空间               能谈：正交基、Fourier 展开、正交分解
                              ——最接近欧氏几何的无穷维空间
```

读这张塔的三个要点：

- **每上升一层是"加结构"，不是"换地方"**。同一支歌可以在这座塔的各层演唱：$C[0,1]$（连续函数全体）配上 $d_\infty$ 是度量空间（本篇）、配上一致收敛范数是 Banach 空间（FA 04）、$L^2$ 配内积是 Hilbert 空间（FA 07/08）。**点集不变，结构变，定理就变**；
- **箭头是"诱导"关系**：范数诱导度量（$d(x,y)=\|x-y\|$，FA 04）、度量诱导拓扑（球全体的并就是开集——本篇 §4 就是构造这个）、内积诱导范数（$\|x\|=\sqrt{\langle x,x\rangle}$，FA 07）。所以 Hilbert ⊂ Banach ⊂ 赋范 ⊂ 度量 ⊂ 拓扑——**越往上越特殊，塔顶的定理最强但适用面最窄**；
- **代数结构与拓扑结构是两条独立的轴**。泛函分析的本质是研究"线性运算 × 极限运算"的相容性：线性空间管代数（加法/数乘），度量管拓扑（收敛/连续），赋范空间是两者相遇的第一站（FA 04 的主线）。内积则是锦上添花的几何层（有角度、有正交）。

### 2.2 每层买到什么、失去什么

| 层级 | 加了什么 | 买到 | 代价（越往上假设越强） |
|------|---------|------|------|
| 拓扑空间 | 开集族 | 收敛/连续的最一般定义 | 收敛序列可能不唯一刻画拓扑；无定量工具 |
| 度量空间 | 距离 $d$ | 球、ε-δ、完备性可定义 | 未必有加法——"两点相加"没有意义 |
| 赋范空间 | 线性 + 范数 | 凸性、线性算子、级数 | 范数未必来自内积（无角度/正交） |
| Banach | 完备性 | 不动点定理、开映射、闭图像 | 完备性要对每个空间逐一验证 |
| Hilbert | 内积 + 完备 | 正交基、投影定理、最佳逼近 | 结构最强，典型例子只剩 $L^2$ 一族 |

一个直观的对照：在 Hilbert 空间里"求一点到子空间的最短距离"是垂足问题（投影定理，FA 07）；在 Banach 空间里这个问题变得困难（最佳逼近未必唯一——FA 12 逼近论）；在一般度量空间里连"点到子空间最短"都未必存在（子空间不闭时）。**同一问题在塔的不同层有完全不同的命运，这就是"选对空间"的意义**——泛函分析讲义里反复出现的句式"设 $X$ 是 Banach 空间"，翻译过来就是：以下定理用到完备性，请确认你的空间有这个结构。

### 2.3 本系列（与教材）的路线

步尚全教材与线性泛函的主流讲法一样，**从度量空间进入，跳过一般拓扑空间的公理**——这不是偷懒，而是因为：分析学真正需要拓扑概念（开集、闭集、连续、稠密）的地方，度量诱导的拓扑已经全部够用；一般拓扑（非度量拓扑）的价值要到点集拓扑、代数几何等课程才体现。所以系列的路线是这座塔的一条登顶路径：

| 篇 | 落在塔的哪层 | 关键词 |
|---|---|---|
| **本篇** | 度量空间 | 距离公理、开集、连续 |
| FA 02 | 度量 + 完备化 | Cauchy 列、紧性（完备性进 Banach 的门票） |
| FA 04 | 赋范空间 | 线性结构 × 范数（两条轴相遇） |
| FA 07–08 | 内积 → Hilbert | 正交、投影、正交基 |
| FA 10–11, 14 | Banach 空间上的算子 | 三大定理、谱论——泛函分析的主战场 |

一句话总纲：**泛函分析 = 在"函数的无穷维空间"这座塔上，把微积分的定理（极限、连续、微分方程）逐层重建，并看清楚每条定理到底住塔的哪一层。**本篇从塔的度量层出发。

## 3. 核心定义与直觉

### 3.1 度量公理：四条缺一不可

**定义 1.1.1**　设 $X$ 为集合，$d: X \times X \to \mathbb{R}$。称 $d$ 为 $X$ 上的**度量**（metric），若：

1. **非负性**：$\forall x, y\in X,\ d(x,y) \ge 0$；
2. **非退化性**：$d(x,y) = 0 \iff x = y$；
3. **对称性**：$d(x,y) = d(y,x)$；
4. **三角不等式**：$d(x,y) \le d(x,z) + d(z,y)$。

$(X, d)$ 称为**度量空间**（metric space）。

**每条公理在干什么？** 这不是随便挑的四条，各自有明确的职责：

| 公理 | 职责 | 去掉会怎样 |
|------|------|-----------|
| 非负性 | 距离是"代价"的度量，不能为负 | 负距离无任何解释 |
| 非退化性 | **不同点必须可区分** | 退化为**伪度量**（pseudometric）——ML 里的相似度矩阵常只满足这个弱化版本 |
| 对称性 | 从 A 到 B 和从 B 到 A 代价相同 | 有向距离/交通网络（不对称代价）需要脱离本框架 |
| 三角不等式 | **绕路不会更近**——分析学的真正引擎 | 极限的唯一性、连续性刻画全部崩塌 |

四条中**三角不等式是灵魂**：本篇后面所有定理（开集性质、闭包刻画、连续性刻画）的证明，最终都在反复使用它。前三条是"距离"这个日常概念的忠实翻译，第四条才是数学上的实质约束。

**ML 连接**：度量学习（metric learning）学出的"距离"常违反三角不等式或对称性——严格说学到的不是度量而是某种相似度。泛函分析的整套理论（收敛、完备性、不动点）只在真度量上成立，这是"能不能套用分析工具"的分界线。

### 3.2 基本例子：同一个世界，不同的距离

教材给出十个例子（例 1.1.1–1.1.10），按"空间"分类整理：

| 空间 | 度量 | 备注 |
|------|------|------|
| $A \subset \mathbb{K}$ | $\|x - y\|$ | 最原始 |
| $\mathbb{K}^n$ | $d_p(x,y) = \left(\sum |x_i - y_i|^p\right)^{1/p}$，$d_\infty = \max_i \|x_i - y_i\|$ | 有限维的 $p$-范数族 |
| $C[a,b]$（连续函数） | $d_\infty(f,g) = \max_{t} \|f(t) - g(t)\|$（一致度量）；$d_p$（积分度量） | **默认度量是 $d_\infty$** |
| 离散度量 | $d(x,y) = 0$ 若 $x=y$，否则 $1$ | 任何集合都能赋的"最粗"度量——反例工厂 |
| $s$（所有数列） | $d(x,y) = \sum_n \frac{1}{2^n}\frac{\|x_n - y_n\|}{1+\|x_n - y_n\|}$ | 逐项压缩再求和，让**所有**数列两两距离有限 |
| $\ell^\infty$（有界数列） | $d_\infty(x,y) = \sup_n \|x_n - y_n\|$ | |
| $\ell^p$（$p$-可和数列） | $d_p(x,y) = \left(\sum_n \|x_n - y_n\|^p\right)^{1/p}$，$1 \le p < \infty$ | 三角不等式非平凡，见 3.3 |

三个值得注意的点：

1. **$s$ 空间的度量是"工程杰作"**：$\frac{t}{1+t}$ 把任意大的差异压到 $[0,1)$，$\frac{1}{2^n}$ 让无穷和收敛——结果是无约束的数列全体也构成度量空间。这个手法（逐项压缩 + 加权求和）在概率论（期望的截断处理）和 ML（损失函数的饱和设计）里反复出现。
2. **$C[a,b]$ 有两个天然度量**：$d_\infty$（逐点最坏误差）与 $d_p$（平均误差）。直观上 $d_p$ 更"松"——后面会看到这个差别实质巨大（完备性！Blog 02 的主角）。
3. **离散度量是反例工厂**：任何集合赋离散度量后，**所有子集既开又闭**（见例 1.2.2）。每当一个直觉性的命题可疑时，先拿离散度量试一遍。

### 3.3 三角不等式不是免费的：Hölder 与 Minkowski

$d_p$ 在 $\ell^p$ 上满足三角不等式——这不是显然的，需要两个经典不等式。

**定理 1.1.1（Hölder 不等式）**　设 $1 < p, q < \infty$，$\frac{1}{p} + \frac{1}{q} = 1$（$p, q$ 互为**共轭指数**），$x \in \ell^p$，$y \in \ell^q$。则

$$
\sum_{n=1}^{\infty} |x_n y_n| \le \left(\sum_n |x_n|^p\right)^{1/p} \left(\sum_n |y_n|^q\right)^{1/q}
$$

**证明（完整——这个证明方法本身值得学）**：分三步。

**第一步：Young 不等式**。$\alpha, \beta \ge 0$ 时

$$
\alpha\beta \le \frac{\alpha^p}{p} + \frac{\beta^q}{q}
$$

教材的证明是几何的：曲线 $u = t^{p-1}$（反函数 $t = u^{q-1}$）把矩形 $[0,\alpha]\times[0,\beta]$ 分成两部分，矩形面积 $\alpha\beta$ 不超过曲线下两块面积之和 $\frac{\alpha^p}{p} + \frac{\beta^q}{q}$（两种位置关系统一处理）。*（凸函数视角的等价证明：$e^{\frac{1}{p}\ln\alpha^p + \frac{1}{q}\ln\beta^q} \le \frac{1}{p}e^{\ln\alpha^p} + \frac{1}{q}e^{\ln\beta^q}$，即指数函数的凸性。）*

**第二步：归一化**。不妨设 $\sum |x_n|^p = \sum |y_n|^q = 1$（否则用 $x_n' = x_n / \|x\|_p$ 替换，把不等式两边同除归一化因子）。此时对每项用 Young：$|x_n y_n| \le \frac{|x_n|^p}{p} + \frac{|y_n|^q}{q}$，求和得 $\sum|x_ny_n| \le \frac{1}{p} + \frac{1}{q} = 1$。

**第三步：反推一般情形**。两边乘回归一化因子即得。

$p = q = 2$ 时即 **Cauchy–Schwarz 不等式**——Hölder 是它在整个 $p$-族上的推广。$p=1, q=\infty$ 情形也成立（注 1.1.1）。

**Minkowski 不等式**（教材中作为 Hölder 的推论证明）：

$$
\left(\sum_n |x_n + y_n|^p\right)^{1/p} \le \left(\sum_n |x_n|^p\right)^{1/p} + \left(\sum_n |y_n|^p\right)^{1/p}
$$

**证明思路**：$|x_n + y_n|^p = |x_n + y_n|\cdot|x_n+y_n|^{p-1} \le |x_n||x_n+y_n|^{p-1} + |y_n||x_n+y_n|^{p-1}$，对两项分别用 Hölder（注意 $(p-1)q = p$），整理即得。

有了 Minkowski，$\ell^p$ 中 $d_p(x,y) = \|(x_n - z_n) + (z_n - y_n)\|_p \le \|x - z\|_p + \|z - y\|_p$——三角不等式成立。**Hölder 和 Minkowski 是 $\ell^p$（以及 Blog 04 的 $L^p$）世界的宪法**，后面反复调用。

## 4. 开集、闭集：从球出发的拓扑

### 4.1 球与开集

设 $(X, d)$ 度量空间，$x_0 \in X$，$r > 0$：

$$
B(x_0, r) = \{x : d(x_0, x) < r\}\ \text{（开球）},\quad
\bar{B}(x_0, r) = \{x: d(x_0,x) \le r\}\ \text{（闭球）},\quad
S(x_0, r) = \{x : d(x_0,x) = r\}\ \text{（球面）}
$$

**定义 1.2.1**　$x_0 \in M$ 是 $M$ 的**内点**，若存在 $r > 0$ 使 $B(x_0, r) \subset M$。所有内点构成 $M$ 的**内部** $M^\circ$。$M = M^\circ$ 时 $M$ 为**开集**；$F$ 为**闭集**若 $F^c = X \setminus F$ 为开集。

三个必须建立的直觉（每个都对应一个易错点）：

1. **"开"和"闭"不是一对互补形容词**：$(0,1]$ 在 $\mathbb{R}$ 中既不开也不闭。正确的理解是：开集 = 包含每个点的某个邻域；闭集 = 补集是开集。
2. **开闭性相对于环境空间**：$[\frac{1}{2}, 1]$ 是 $Y = [0,1]$（作为 $\mathbb{R}$ 的子空间）的开集，但不是 $\mathbb{R}$ 的开集。"在哪个空间里谈"必须交代。
3. **开球的闭包未必是闭球**：离散度量空间中 $B(x_0, 1) = \{x_0\}$ 已经闭了，但 $\bar{B}(x_0, 1) = X$。有限维欧氏空间的直觉（$\overline{B} = \bar{B}$）不能带走。

**定理 1.2.1 / 1.2.2（开集与闭集的基本性质）**

- $\emptyset, X$ 既开又闭；
- 任意多个开集之并是开集；**有限**多个开集之交是开集；
- 任意多个闭集之交是闭集；**有限**多个闭集之并是闭集。

证明是三角不等式的直接练习。**"有限"二字是实质约束**：$\bigcap_{n=1}^\infty (-\frac{1}{n}, \frac{1}{n}) = \{0\}$ 在 $\mathbb{R}$ 中不开——无穷交会破坏开性。这个"任意并、有限交"结构正是**拓扑**（topology）的公理（教材在此点明：度量空间是特殊的拓扑空间，泛函分析只研究度量空间范畴）。

### 4.2 聚点与闭包

**定义 1.2.2**　$x$ 是 $M$ 的**聚点**（accumulation point），若任意 $r > 0$，$M \cap (B(x,r)\setminus\{x\}) \neq \emptyset$——任何邻域里都**有别人的点**。$\bar{M} = M \cup M'$（$M'$ 为导集）称为 $M$ 的**闭包**（closure）。

**定理 1.2.3（闭包的等价刻画）**

$$
\bar{M} = \{x \in X : \forall r > 0,\ M \cap B(x, r) \neq \emptyset\}
$$

即 $\bar{M}$ = "任何邻域都碰到 $M$" 的点——**离 $M$ 距离为零的一切点**。这是后续最常用的刻画（教材明确说以后默认用这个定义）。

**定理 1.2.4**　$\bar{M}$ 是闭集，且是**包含 $M$ 的最小闭集**。（对偶地，$M^\circ$ 是含于 $M$ 的最大开集。）

**推论 1.2.1**　$M$ 闭 $\iff M = \bar{M}$。

注意区分 $M$ 中的点和 $M$ 的聚点：$M = (0,1] \cup \{2\}$ 时 $0$ 是聚点（但 $0 \notin M$），$2 \in M$ 却**不是**聚点（某邻域里没有别的 $M$ 的点）——孤立点属于 $M$ 但不是聚点。

### 4.3 连续性：开集的逆像刻画

**定义 1.2.3**　$T: X_1 \to X_2$ 在 $x_0$ 连续：$\forall \varepsilon > 0$，存在 $\delta > 0$，$d_1(x, x_0) < \delta \Rightarrow d_2(Tx, Tx_0) < \varepsilon$。等价地 $T(B(x_0,\delta)) \subset B(Tx_0, \varepsilon)$。

这和高等数学的 $\varepsilon$-$\delta$ 定义完全同构，只是把绝对值换成了度量。两个新概念：

- **Lipschitz 映射**：$d_2(Tx, Ty) \le C\, d_1(x, y)$。Lipschitz ⟹ 连续（取 $\delta = \varepsilon/C$）。这是"连续"的强化版——Blog 03 的压缩映射就是 Lipschitz 常数 $< 1$ 的映射，也是 ML 里网络稳定性分析（梯度 Lipschitz ⟹ 训练稳定）的基石。
- **离散定义域上的映射自动连续**（$\delta = 1/2$ 时球只有自己一个点）——又一个离散度量反例。

**定理 1.2.5（连续性的开集刻画）**　$T$ 连续 $\iff$ 任何开集 $G \subset X_2$，逆像 $T^{-1}(G)$ 是 $X_1$ 的开集。

**证明（完整——这是"理论上十分重要"的结果，后续多个定理的基础）**

（⟹）设 $T$ 连续，$G$ 开，$x \in T^{-1}(G)$。则 $Tx \in G$，存在 $\varepsilon > 0$ 使 $B(Tx, \varepsilon) \subset G$。由 $x$ 处连续性，存在 $\delta$ 使 $T(B(x,\delta)) \subset B(Tx, \varepsilon) \subset G$，即 $B(x,\delta) \subset T^{-1}(G)$。故每点是内点，$T^{-1}(G)$ 开。

（⟸）任取 $x \in X_1$，$\varepsilon > 0$。开球 $B(Tx, \varepsilon)$ 是开集，故 $T^{-1}(B(Tx, \varepsilon))$ 开且包含 $x$，于是存在 $\delta$ 使 $B(x, \delta) \subset T^{-1}(B(Tx,\varepsilon))$，即 $T(B(x,\delta)) \subset B(Tx, \varepsilon)$。∎

**为什么这个刻画重要？** 它把连续性——一个逐点的、$\varepsilon$-$\delta$ 的分析性质——翻译成了一个**整体的、纯拓扑的陈述**。"连续 = 开集的逆像是开集"意味着连续性只依赖于空间的开集结构（拓扑），不依赖于具体度量的选取。两个不同度量若生成同样的开集，则连续映射完全相同——这是"度量等价"概念（Blog 02）的伏笔。**ML 连接**：分类器 $f$ 的连续性决定决策边界的行为；开集刻画说明"连续"本质是"不撕裂空间"的结构性质。

**定理 1.2.6**　闭集版本同样成立：$T$ 连续 $\iff$ 闭集的逆像是闭集。证明用 $T^{-1}(F^c) = (T^{-1}(F))^c$ 在两版之间过渡。

**序列刻画**（定理 1.3.3，提前引用）：$T$ 在 $x_0$ 连续 $\iff$ 任何 $x_n \to x_0$ 都有 $Tx_n \to Tx_0$。反证时取 $\delta = 1/n$ 构造反例序列——这个"取 $\delta = 1/n$"技巧在全系列反复出现。

### 4.4 稠密与可分

**定义 1.2.4**　$M \subset X$ **稠密**（dense）若 $\bar{M} = X$；$X$ **可分**（separable）若存在至多可数的稠密子集。

直觉：$M$ 稠密 = 空间里任何点都能被 $M$ 的点**逼近到任意精度**；可分 = 空间虽大，但一个可数的"坐标网格"就能锚定全部点——**这是"空间能用算法表示"的数学前提**。

教材的四个标准结论（证明思路值得各花五分钟）：

| 空间 | 可分？ | 证明骨架 |
|------|--------|---------|
| $\mathbb{K}^n$ | ✅ | 有理点 $\mathbb{Q}^n$ 稠密 |
| $\ell^p$，$1 \le p < \infty$ | ✅ | "尾零有理序列"集合可数且稠密——尾部用 $\ell^p$ 收敛截断，头部用 $\mathbb{Q}^n$ 逼近 |
| $C[a,b]$（$d_\infty$） | ✅ | 有理系数多项式（Weierstrass 逼近 + 有理数逼近系数） |
| $\ell^\infty$ | ❌ | 经典反例：$\{0,1\}^{\mathbb{N}}$ 是不可数集，两两距离为 $1$；任何稠密集必须给每个点配半径 $\frac{1}{4}$ 内的专属元素 ⟹ 不可数 |

$\ell^\infty$ 不可分的证明是**对角论证法**的漂亮应用，也埋下伏笔：$\ell^\infty$ 是"太大"的空间——它的对偶（Blog 06）会大到不可分，与 $\ell^p$（$p<\infty$）形成鲜明对照。

**定理 1.2.7**　可分度量空间的子空间仍可分。（证明：从稠密列的每个球里挑一个落在 $Y$ 中的点。）

**ML 连接**：可分性是"函数空间能否离散化处理"的门槛。核方法中特征映射的像空间（RKHS，Blog 08）是可分 Hilbert 空间——这正是能用可数基展开（Fourier 级数式的）的原因。

## 6. 易混淆辨析

| 概念对 | 辨析 |
|--------|------|
| **内点 vs 聚点** | 内点：邻域整个含于 $M$（从内看）；聚点：邻域总有 $M$ 的其他点（从外看）。$2 \in (0,1]\cup\{2\}$ 是内点吗？不是（它不在任何含于 $M$ 的球心）；是聚点吗？不是（邻域可不含其他点）——孤立点。 |
| **$M^\circ$ vs $\bar M$** | 对偶概念：最大开子集 vs 最小闭超集。$\overline{M^c} = (M^\circ)^c$。 |
| **开球 vs 开集** | 开球必开（定理 1.2.1 前的证明），但开集不一定是球。开集是"若干球之并"。 |
| **稠密 vs 可分** | 稠密是**子集对空间**的关系；可分是**空间自身**的性质（存在可数稠密集）。可分 ⟹ 每个子空间可分（定理 1.2.7），反之不然。 |
| **逐点连续 vs 一致连续 vs Lipschitz** | 严格递强。$\delta$ 可以依赖点（逐点）/不依赖点（一致）/线性控制（Lipschitz）。本篇只需逐点连续，但 Lipschitz 已登场——它是 Blog 03 的主角。 |
| **$d_p$ vs $d_\infty$（在 $C[a,b]$ 上）** | $d_\infty$ 控制"最坏点"，$d_p$ 控制"平均"。$d_\infty$-收敛（一致收敛）严格强于 $d_p$-收敛。两者完备性命运不同（Blog 02 揭晓：$d_\infty$ 完备、$d_p$ 不完备！）。 |

## 7. ML 连接小结

- **度量学习**：学到的"距离"常只是伪度量（非退化性失效——不同样本可零距离）或违反三角不等式；泛函分析工具链只在真度量上成立。
- **$\ell^p$ 家族**：$\ell^1$/$\ell^2$ 范数正则化（Lasso/Ridge）就是在这个空间族里选房子——稀疏性偏好 $\ell^1$（"角更尖"），光滑性偏好 $\ell^2$。Hölder 不等式正是 $p$-范数对偶性 $\ell^p{}^* = \ell^q$（Blog 06/08）的第一块砖。
- **离散度量**：k-means 的 0-1 指示、one-hot 编码的内蕴几何都是离散式的——"所有点两两等距"意味着没有可利用的几何结构。

## 9. 习题精选（教材习题 1 选摘）

**题 1**：证明离散度量空间中任何子集既开又闭。
*提示*：任取 $x \in M$，$B(x, \frac{1}{2}) = \{x\} \subset M$，故 $M$ 开；$M^c$ 同理开，故 $M$ 闭。

**题 2**：设 $M$ 为度量空间 $X$ 的子集。证明 $x \in \bar M \iff d(x, M) := \inf_{y \in M} d(x,y) = 0$。
*提示*：直接用定理 1.2.3 的邻域刻画翻译。"到集合距离为零"与"任何球都碰到 $M$"是同一句话。

**题 3**：证明 $\mathbb{Q}$ 在 $\mathbb{R}$ 中稠密但 $\mathbb{R}$ 按 $d(x,y) = |x - y|$ 可分。
*提示*：稠密性用有理数逼近；可分性直接取 $\mathbb{Q}$ 本身作为可数稠密集。

**题 4**：在 $C[0,1]$ 上比较 $d_1(f,g) = \int_0^1 |f-g|\,dt$ 与 $d_\infty$：证明 $d_1(f_n, f) \to 0$ 不保证 $d_\infty(f_n, f) \to 0$。
*提示*：取 $f_n$ 为 $[0, \frac{1}{n}]$ 上的尖峰（高 $1$、底 $\frac{2}{n}$ 的三角），$d_1 \le \frac{1}{n} \to 0$ 但 $d_\infty = 1$。反过来 $d_\infty \to 0 \Rightarrow d_1 \to 0$（积分被最大值控制）——**单向蕴含**。

**题 5**（思考题）：$s$ 空间的度量 $d(x,y) = \sum \frac{1}{2^n}\frac{|x_n-y_n|}{1+|x_n-y_n|}$ 中，两项各起什么作用？如果去掉 $\frac{1}{2^n}$ 加权会怎样？
*提示*：$\frac{t}{1+t}$ 保证每项有界，$\frac{1}{2^n}$ 保证级数收敛。去掉加权后调和级数型发散（如 $x_n - y_n \equiv 1$ 时每项 $\ge \frac{1}{2}$）。
