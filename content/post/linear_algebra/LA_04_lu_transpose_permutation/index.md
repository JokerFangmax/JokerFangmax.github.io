# 线性代数 04：A=LU 分解、转置与置换

> 📖 本篇覆盖 Strang《Introduction to Linear Algebra》第 5 版 §2.6–2.7，是 Chapter 2 的收官篇。前置：[LA 03](../LA_03_matrix_operations_inverse/)（逆序法则、消元矩阵的逆）。

---

## 1. 这一篇解决什么问题？

Strang 在 §2.6 开头说：本节"几乎纯粹是实用的"（almost purely practical）。它回答三件事：

1. **消元能不能"整体打包"？**——一串 $E_{ij}$ 把 $A$ 变成 $U$，把 $E^{-1}$ 们收拢成一个矩阵 $L$，就得到全书最重要的分解之一：

$$
A = LU = (\text{下三角，对角线全 1})(\text{上三角，对角线是主元})
$$

LAPACK/MATLAB 的 `lu`、`A\b`，Cholesky、稀疏求解器，全部建立在这个分解上。**"很多线性代数的关键思想，仔细看都是矩阵分解"**——本篇是这句话的第一次兑现；

2. **解方程的正确姿势：Factor once, Solve many。** 左端（$A$）决定 $L,U$，与右端无关——分解一次，之后每个新右端 $b$ 只花 $n^2$（对比重新消元的 $\frac13 n^3$）。这是**把 Ax=b 从一次性动作升级为基础设施**的工程思想；

3. **换行怎么办？转置是谁？**——置换矩阵 $P$ 补全分解为 $PA=LU$（覆盖一切可逆矩阵）；转置 $A^T$ 则远不止"沿对角线翻转"——它有一个**内积意义**（$\,(Ax)^Ty = x^T(A^Ty)$），由它自然长出对称矩阵、$A^TA$、正交矩阵（Ch 4 的全部主角）。

## 2. A=LU：消元的逆过程打包（§2.6）

### 2.1 从 2×2 看懂

$$
A = \begin{bmatrix}2&1\\6&8\end{bmatrix},
\qquad
E_{21}A = \begin{bmatrix}1&0\\-3&1\end{bmatrix}\begin{bmatrix}2&1\\6&8\end{bmatrix} = \begin{bmatrix}2&1\\0&5\end{bmatrix} = U.
$$

正向（$E_{21}A=U$，乘数 $\ell_{21}=3$）是消元；**反向**（$U$ 回 $A$）只需把减法换成加法：

$$
\underbrace{\begin{bmatrix}1&0\\3&1\end{bmatrix}}_{L=E_{21}^{-1}}
\begin{bmatrix}2&1\\0&5\end{bmatrix}
= \begin{bmatrix}2&1\\6&8\end{bmatrix} = A.
\qquad \boxed{A=LU}
$$

3×3 时（无换行）$E_{32}E_{31}E_{21}A = U$，两边左乘逆：

$$
A = \underbrace{E_{21}^{-1}E_{31}^{-1}E_{32}^{-1}}_{L}\,U.
$$

**逆必须倒序出现**（LA 03 的袜子-鞋法则）——而正是这个倒序成全了 $L$ 的美好性质：

### 2.2 关键定理：乘数在 L 中原位落位，不混合

**$L$ 的 $(i,j)$ 元恰好是乘数 $\ell_{ij}$**，对角线全 1——矩阵乘法本来会"把数字搅在一起"，这里偏偏不搅。教材 Example 1：

$$
A = \begin{bmatrix}2&1&0\\1&2&1\\0&1&2\end{bmatrix}
= \underbrace{\begin{bmatrix}1&0&0\\\tfrac12&1&0\\0&\tfrac23&1\end{bmatrix}}_{L}
\underbrace{\begin{bmatrix}2&1&0\\0&\tfrac32&1\\0&0&\tfrac43\end{bmatrix}}_{U}
$$

（$A$ 对称时 $U$ 的对角线除以主元后就是 $L^T$——见 §4 的 $LDL^T$。）

**为什么不搅？** 原因一句话（教材的"key reason"）：**消元中被减去的主元行，从来不是 $A$ 的原始行，而永远是 $U$ 的行**。写出第 3 行的关系：

$$
\text{Row}_3(A) = \ell_{31}\,\text{Row}_1(U) + \ell_{32}\,\text{Row}_2(U) + 1\cdot\text{Row}_3(U),
$$

这正是 $A=LU$ 的第 3 行展开——系数 $\ell_{31},\ell_{32},1$ 就是 $L$ 的第 3 行。对比正向乘积 $E_{32}E_{31}E_{21}$：行 3 先被行 1 改过一遍的行 2 影响（交叉项 $\ell_{32}\ell_{21}$ 冒出来），乘数互相污染；逆序 $E^{-1}$ 的乘积里各行"只管自己"，乘数干净落座。**LA 03 §3.2 的 $FE$ 出现 20 而 $E^{-1}F^{-1}$ 不出现的实验，机制就在这里。**

### 2.3 零结构的预测与失效

| 事实 | 用途 |
|------|------|
| $A$ 的某行开头是零 $\Rightarrow$ $L$ 对应行同样开头是零 | 该行无需消元，省计算 |
| $A$ 的某列开头是零 $\Rightarrow$ $U$ 对应列同样开头是零 | 零列原样存活 |
| **矩阵中间的零，消元扫过时很可能被填掉** | 别指望稀疏性自动保留（稀疏存储要靠 band 结构，见 §2.6 成本节） |
| 某主元位置为 0 且下方无救 $\Rightarrow$ **$A=LU$ 不存在** | 需要换行 → $PA=LU$（§5） |

**LDU 再平衡**：$LU$ 不对称（$U$ 对角线是主元、$L$ 是 1）。把主元抽出来放中间，两边对称对待：

$$
A = LDU,\qquad D=\text{diag}(\text{主元})，\quad L,U\ \text{对角线全 1}.
$$

例（教材式 (3)）：$\begin{bmatrix}2&4\\6&19\end{bmatrix} = \begin{bmatrix}1&0\\3&1\end{bmatrix}\begin{bmatrix}2&0\\0&5\end{bmatrix}\begin{bmatrix}1&2\\0&1\end{bmatrix}$——主元 $2,5$ 进 $D$，乘数 3 留在 $L$。

### 2.4 Factor once, Solve many

计算机解 $Ax=b$ 的标准架构（LAPACK 的设计哲学，教材引其用户手册原话：单系统一次性求解的情况"如此少见、节省如此重要，以至于根本没提供只解单个系统的子程序"）：

```
① Factor：对 A 消元 → L, U           成本 ~n³/3，与 b 无关
② Solve：Lc = b（前代，自上而下）
          Ux = c（回代，自下而上）      成本 ~n²，每个新 b 一次
```

验证：$LUx = Lc = b \Rightarrow Ax=b$ ✓。教材 Example 3 的数字版：$u+2v=5,\ 4u+9v=21$，乘数 4 存进 $L$，前代把右端变成 $c=(5,1)$，回代得 $x=(3,1)$。

### 2.5 成本账（本篇最实用的数字）

| 操作 | 计数 | 来源 |
|------|------|------|
| 消元到 $U$（左端） | $\sum_{k=1}^n k^2 = \frac{n^3}{3}+O(n^2)$ 次乘法（精确计数 $\frac{n^3-n}{3}$；减法同数，浮点合计 $\frac{2n^3}{3}$） | 第 1 列清零 $n^2$、第 2 列 $(n-1)^2$……**和式 ≈ $\int_0^n x^2dx=\frac{n^3}{3}$**（"sum of squares is like the integral of $x^2$"） |
| 处理右端（前代+回代） | **恰好 $n^2$** | $(n{-}1)+(n{-}2)+\cdots+1$ 加 $1+2+\cdots+n$，配对 $(n{-}1,1),(n{-}2,2),\dots$ 每对和为 $n$，共 $n$ 对 |
| 带状矩阵（带宽 $w$）到 $U$ | $nw^2$（代替 $\frac13 n^3$） | 每列只清 $w$ 个零、主元行长 $w$ |
| 带状 Solve | $2nw$（代替 $n^2$） | |
| 三对角（$w=1$） | 到 $U$ 只要 $n$ 级 | LA 01 的差分矩阵、二阶差分 $K$ 都在这里 |

尺寸感（教材给的）：$n=1000$ 稠密随机矩阵在 PC 上约 1 秒；按 $n^3$ 规律，$n$ 翻倍时间 ×8，$n=10^5$ 稠密要一百万秒——所以**实践中靠稀疏性（band/稀疏 LU）和迭代法（Ch 11）活命**。

**Pascal 彩蛋**（Worked Example 2.6 A）：对称 Pascal 矩阵 $P=\text{pascal}(4)$ 恰好分解为 $P=LU$，其中 $L$ 是下三角 Pascal、$U=L^T$、主元全 1。MATLAB 的 `lu` 算不出它（部分主元会选 3 不选 1），要用 `chol`——理论分解与工程实现第一次分道扬镳。

## 3. 转置：不止是翻转（§2.7）

### 3.1 定义与运算法则

**转置**（transpose）：$(A^T)_{ij} = A_{ji}$，即沿主对角线翻转（$m\times n \to n\times m$）。法则表：

$$
(A+B)^T = A^T+B^T,\qquad
\boxed{(AB)^T = B^TA^T},\qquad
(A^{-1})^T = (A^T)^{-1}.
$$

乘积法则**倒序**（又一次倒序！和 $(AB)^{-1}$ 同款）。证明思路从向量情形开始：$(Ax)^T = x^TA^T$——$Ax$ 是 $A$ 列的组合，$x^TA^T$ 是 $A^T$ 行的组合，**同一组向量换了个说法**；多列情形逐列套用（LA 03 的"逐列处理"再立一功）。

第三个法则：转置与求逆**可交换**（先转再逆 = 先逆再转），且 $A$ 可逆 $\iff$ $A^T$ 可逆。

### 3.2 内积、外积、以及 $A^T$ 的真身

用矩阵语言重写点积，"T 在里面还是外面"决定一切：

$$
\text{内积（一个数）}：\ x\cdot y = x^Ty,\ (1\times n)(n\times1);\qquad
\text{外积（秩一矩阵）}：\ xy^T,\ (n\times1)(1\times n).
$$

Strang 顺手展示内积的应用清单：功 =（位移）$^T$（力）、热损 =（压降）$^T$（电流）、收入 =（数量）$^T$（价格）——"我们真的已经站在应用数学的心脏边上"。

然后是本节最重要的一句话：**"沿对角线翻转"不是数学**。$A^T$ 的真身是——

$$
\boxed{\ (Ax)^Ty = x^T(A^Ty)\ }
$$

**$A^T$ 是唯一能把 $A$ "挪到内积另一边"的矩阵**。对每个 $x,y$ 都成立的这个等式反过来确定了 $A^T$ 的每一个元素。教材用差分矩阵演示：$(x_2-x_1)y_1 + (x_3-x_2)y_2$ 整理成 $x_1(-y_1) + x_2(y_1-y_2) + x_3(y_2)$——差分从 $x$ 挪到 $y$ 身上时**自动长出负号和负的转置**。

**彩蛋（文末 "The Transpose of a Derivative"）**：把 $A$ 换成求导 $\frac{d}{dt}$、内积换成积分 $\int x(t)y(t)\,dt$，"转置"升级为**伴随**（adjoint）。分部积分显示

$$
\left(\frac{d}{dt}\right)^{T} = -\frac{d}{dt}
$$

——**导数的转置是负导数**（反对称算子），中心差分矩阵 $A^T=-A$ 是它的离散化身。这条线通向 Ch 8（线性变换）与 FA 系列（Hilbert 空间中的伴随算子）；力学里"力 × 虚位移"的对称性、物理里自伴算子的实谱，源头都在 $(Ax)^Ty=x^T(A^Ty)$ 这一行等式里。

### 3.3 对称矩阵：$S=LDL^T$

**对称矩阵**（symmetric）$S^T=S$，Strang 给专属字母 $S$，并断言"这是所有矩阵中最重要的"（Ch 6 将揭晓：实特征值 + 正交特征向量）。

三个直接事实：

1. **$A^TA$ 恒对称**（任意长方形 $A$）：$(A^TA)^T = A^T(A^T)^T = A^TA$。一行证明，价值连城——**"大多数从长方形矩阵 $A$ 出发的科学问题，最终都落在 $A^TA$ 或 $AA^T$ 上"**（最小二乘、图拉普拉斯、协方差、注意力 $\mathrm{softmax}$ 前的 $KQ^T$ 对称化……）。注意 $A^TA$（$n\times n$）与 $AA^T$（$m\times m$）一般不同、但都对称、**对角线都非负**（对角元 = $A$ 的列/行与自己的点积）；
2. **对称的逆对称**：$(S^{-1})^T=(S^T)^{-1}=S^{-1}$；
3. **对称的分解对称**：$S=LDL^T$。对称矩阵的 $LDU$ 中 $U=L^T$——两翼互为镜像，主元夹在中间。**计算量与存储直接减半**（$\frac13n^3\to\frac16n^3$）。数值例子（Worked Example 2.7 B）：

$$
S=\begin{bmatrix}1&4&5\\4&2&6\\5&6&3\end{bmatrix},\quad
\ell_{21}=4,\ \ell_{31}=5,\ \ell_{32}=1,\quad
\text{主元 } 1,\ -14,\ -8\ \to D,\qquad \det S=(1)(-14)(-8)=112.
$$

（主元积 = 行列式，Ch 5 的预告。）

**块版应用**（Worked Example 2.7 C，最小二乘的鞍点矩阵）：$S=\begin{bmatrix}I&A\\A^T&0\end{bmatrix}$ 对称且重要，块消元给出 $S=LDL^T$、中间块是 $-A^TA$——" saddle point matrix"是 Ch 4 最小二乘与 KKT 条件的前哨。

### 3.4 正交矩阵（先混个脸熟）

**正交矩阵**（orthogonal）$Q$：$Q^T = Q^{-1}$。等价于"列是互相垂直的单位向量"（Problem 39 两条均可由 $Q^TQ=I$ 逐列读出）。它把"求逆"降格为"转置"——免费的可逆性，Ch 4（Gram–Schmidt 产出 $Q$）、Ch 7（SVD 两翼都是 $Q$）的主角。

## 4. 置换矩阵与 PA=LU（§2.7 后半）

### 4.1 置换矩阵的家底

**定义**：$P$ = 单位矩阵的行任意重排（每行每列恰一个 1）。

| 性质 | 内容 |
|------|------|
| 计数 | $n\times n$ 共 $n!$ 个（$3!=6$、$4!=24$、$5!=120$） |
| 封闭性 | $P_1P_2$ 还是置换矩阵 |
| 逆 = 转置 | $P^{-1}=P^T$（行交换矩阵自己就是自己的逆） |
| 保内积 | $(Px)^T(Py)=x^Ty$（重排不改变点积——Problem 12） |
| 奇偶 | $n!$ 个置换一半偶一半奇；$\det P=\pm1$（奇偶性） |

$P^{-1}=P^T$ 的证明可触摸版：$P$ 第 1 行的那个 1，与 $P^T$ 第 1 列（即 $P$ 第 1 行转过来的列）的 1 相撞得 1，与其余列的 1 错开得 0——所以 $PP^T=I$。

### 4.2 PA=LU：补全后的最终形态

无换行的 $A=LU$ 覆盖不了"主元位置为 0 需要换行"的矩阵。把所有换行**提前**打包成一个 $P$，对 $PA$ 做标准消元：

$$
\boxed{\ PA = LU\ }
$$

教材例子（$a_{11}=0$，换行 1、2 后 $\ell_{31}=2,\ \ell_{32}=3$ 正常消元）：

$$
A=\begin{bmatrix}0&1&1\\1&2&1\\2&7&9\end{bmatrix}
\ \xrightarrow{\ P_{12}\ }\ PA=\begin{bmatrix}1&2&1\\0&1&1\\2&7&9\end{bmatrix}
= \begin{bmatrix}1&0&0\\0&1&0\\2&3&1\end{bmatrix}
\begin{bmatrix}1&2&1\\0&1&1\\0&0&2\end{bmatrix}.
$$

两条路线、一个结论：换行提前（$PA=LU$，工业标准）或换行置后（$A=L_1P_1U_1$，更"优雅"但少用）。**对一切可逆 $A$，都存在 $P$ 使 $PA=LU$**——这是消元分解的完全体。

**工程真相**：实际代码（MATLAB `[L,U,P]=lu(A)`）**不取第一个可用主元，而取列中绝对值最大者**（部分主元法，partial pivoting）——即使代数上不需要换行也换，为的是压低浮点舍入误差（§11.1 的主题）。所以实战中 $P$ 里常有"数学上不必要的"换行，但 $PA=LU$ 形式不变。**理解置换、让计算机干活**是 Strang 的建议；手算只做 $A=LU$，别跟 $P$ 纠缠。

**换行与对称的恩怨**（Worked Example 2.7 A）：左乘 $P$ 会破坏对称——$PS$ 不再对称；但**右乘 $P^T$ 恰好救回来**：$PSP^T$ 保证对称（其转置还是自己）。"行怎么重排，列就跟着怎么重排"——合同变换（congruence）的雏形，Ch 6 特征值、Ch 8 基变换的同款动作。

## 5. 例子与反例速查

| 命题 | 真假 | 例子 / 反例 |
|------|------|------------|
| $E_{21}E_{32}$ 与 $E_{32}E_{21}$ 的逆序积里乘数都不混合 | ❌ | 只有**逆矩阵按倒序乘**（$E_{21}^{-1}E_{32}^{-1}$）才干净落位；正向积冒交叉项 |
| $A$ 可逆 $\Rightarrow A=LU$ 存在 | ❌ | $\begin{bmatrix}0&1\\1&0\end{bmatrix}$ 可逆但需换行，只有 $PA=LU$ |
| 消元右端成本与左端同量级 | ❌ | 左 $\frac13n^3$、右 $n^2$——大矩阵上差一个 $n$ 因子 |
| 三对角矩阵的 $L,U$ 仍是三对角 | ✅ | 带宽不增（带外零保留）；但**逆**是稠密的（LA 03 的 $K^{-1}$） |
| $A^TA = AA^T$（方阵 $A$） | ❌ | 教材例：$A^TA\neq AA^T$，各自对称但不同（$m\neq n$ 时连尺寸都不同） |
| $A^2=\mathbf 0$ 可能 | ✅ | $\begin{bmatrix}0&1\\0&0\end{bmatrix}$；但 $A^TA=\mathbf 0$ 只可能 $A=\mathbf 0$（对角元是列范数平方） |
| 行交换矩阵是对称的 | ✅ | $P_{ij}^T=P_{ij}=P_{ij}^{-1}$；一般置换不必对称但总有 $P^{-1}=P^T$ |
| 对称矩阵乘对称矩阵仍对称 | ❌ | $(AB)^T=BA\neq AB$（除非可交换）；$ABA$、$A^2$ 则对称 |
| 置换矩阵保内积 | ✅ | $(Px)\cdot(Py)=x\cdot y$；但 $Px\cdot y\neq x\cdot Py$（除非 $P=P^T$） |
| $P$ 的幂最终回到 $I$ | ✅ | 有限群 $P^k=I$ 必然发生（Problem 37）；循环置换 $P^3=I$ |

## 6. 易混淆辨析

| 概念对 | 辨析 |
|--------|------|
| **$A=LU$ vs $PA=LU$ vs $A=L_1P_1U_1$** | 无换行 / 换行提前（工业标准）/ 换行置后（教科书对称性更好）。都只要求 $A$ 可逆（后者俩覆盖奇异以外全部） |
| **$LU$ vs $LDU$ vs $LDL^T$** | $U$ 带主元（不对称美）/ 主元抽进 $D$、两翼对角全 1（对称矩阵时右翼自动 $=L^T$）。**约定：见到 $LDU$ 即默认 $U$ 对角线全 1** |
| **$E$（正向乘积）vs $L$（逆向乘积）** | $E=E_{32}E_{31}E_{21}$ 混合乘数（$L^{-1}$），丑；$L=E_{21}^{-1}E_{31}^{-1}E_{32}^{-1}$ 干净收纳乘数。**记 $L$ 弃 $E$** |
| **$(AB)^T=B^TA^T$ vs $(AB)^{-1}=B^{-1}A^{-1}$** | 两条倒序法则结构相同，但转置版对**一切**形状合法的乘积成立，逆版要求可逆；记住一个就记住另一个 |
| **转置 vs 伴随** | 矩阵有限维：同一个东西；算子无穷维（微分、积分）：叫伴随，且 $(d/dt)^T=-d/dt$ 反对称——"翻转"直觉在函数世界失灵，"挪到内积另一边"的定义继续工作 |
| **$A^TA$ vs $AA^T$** | 尺寸 $n\times n$ vs $m\times n$ 不一（哦不，$m\times m$）；都对称、都半正定（对角 $\ge0$）；数据科学里前者是特征协方差、后者是样本协方差——**同一个 $A$ 的两张脸**（Ch 7 SVD 同时对角化两者） |
| **$\det P$ vs sign 变量** | 同一个东西：换行次数奇偶决定 $\pm1$；lu 代码里 `sign = -sign` 每换一次翻一次——就是行列式在实时记账（Ch 5 性质：换行变号） |

## 7. ML / 应用连接

- **`scipy.linalg.lu_factor / lu_solve`、`cho_factor`**：Factor-Solve 范式的直接实现。同一 $A$ 服务多个 $b$ 的场景在 ML 里俯拾皆是：高斯过程对测试 batch 的预测、贝叶斯线性回归后验采样、逆运动学多目标查询。**Kronecker/低秩结构让"Factor"一步降到近平价**——Kronecker-法则是 $A=VDV^T$ 型分解的推广，正合本篇主题；
- **Cholesky = 对称正定时的 $LDL^T$ 极简版**（$D$ 开根号吸收进两翼，$S=LL^T$）：多元高斯采样 `x = μ + Lz`（$z\sim\mathcal N(0,I)$）就是把 $\Sigma=LL^T$ 当 Factor 用——**"采样 = 用因子乘标准正态"**是 LA 12 PCA、VAE 变分推断的地基；
- **$A^TA$ 的谱地位**：协方差矩阵 $\frac1n X^TX$、图拉普拉斯 $B^TB$（$B$=关联矩阵，LA 16）、最小二乘正规方程 $A^TA\hat x=A^Tb$（LA 08）——三个 ML 核心对象都是本篇这个"恒对称"构造的后代；
- **部分主元 = 数值健壮性**：$P$ 的工程选取规则（列最大者上位）说明**数学上等价的算法在浮点下不等价**——同一 $A=LU$，主元选法不同误差可以差几个数量级（Ch 11 条件数给出定量版）。写自定义求解器时"不选主元"是最常见的事故源；
- **导数的伴随 = 反向传播**：$(Ax)^Ty=x^T(A^Ty)$ 正是自动微分的骨架——损失对中间量的梯度 = 算子**伴随**作用在下游梯度上。$d/dt$ 的伴随是 $-d/dt$（分部积分），神经网络一层线性映射 $W$ 的伴随是 $W^T$（backprop 里 grad 的转置传播）。**转置不是记号，是"梯度往回走"的数学身份**。

## 8. 习题精选（Problem Set 2.6–2.7 选摘）

**题 1**（2.6 #3）：消元把 $x+y+z=5,\ x+2y+3z=7,\ x+3y+6z=11$ 化为 $x+y+z=5,\ y+2z=2,\ z=2$。乘数 $\ell_{31},\ell_{32}$ 各是多少？写出 $L$ 并验证 $A=LU$。
*提示*：$\ell_{31}=1,\ \ell_{32}=2$；第 3 行 $[\,1\ 3\ 6\,] = 1\cdot[\,1\ 1\ 1\,]+2\cdot[\,0\ 1\ 2\,]+1\cdot[\,0\ 0\ 1\,]$——"乘数落位"机制的手算版。

**题 2**（2.6 #9–10 型）：$A=\begin{bmatrix}1&2\\3&c\end{bmatrix}$。哪个 $c$ 使第二主元为零、必须换行（$A=LU$ 不存在）？再取 $B=\begin{bmatrix}1&2&0\\2&c&1\\0&1&1\end{bmatrix}$ 问哪个 $c$ 让第三主元为零且换行无救（奇异）？
*提示*：$c=6$（列 2 = 2 倍列 1）；$c$ 满足 $(c-4)(1)-1=0$ 即 $c=5$ 时主元 3 位置为 0 且下方同为 0——$x=(1,-1,2)$ 型非零解。

**题 3**（2.6 #25–26，K 矩阵）：对 $n=6$ 的二阶差分矩阵 $K$（对角 2、副对角 $-1$）写出 $K=LU$（$L,U$ 各只有两条非零对角），并手算 $7K^{-1}$（第 1 行 $(6,5,4,3,2,1)$，对角上方第 $i$ 行 $=i\times$第 1 行，下方第 $j$ 列 $=j\times$第 1 列）。
*提示*：$L$ 副对角全 $-1/2$；$K\cdot 7K^{-1}=7I$ 可逐行验证。$nK^{-1}$ 的 $\min(i,j)(n+1-\max(i,j))/(n+1)$ 型公式是格林函数的矩阵版。

**题 4**（2.7 #2）：$A=\begin{bmatrix}1&2\\3&4\end{bmatrix}$，$B=\begin{bmatrix}0&1\\1&0\end{bmatrix}$。验证 $(AB)^T=B^TA^T\neq A^TB^T$，并算 $A^TA$ 与 $AA^T$ 确认两者不同但都对称。
*提示*：$B$ 本身是置换矩阵，$AB$ 是"交换 $A$ 的列"——转置后变"交换 $A^T$ 的行"，顺序的教训具体化。

**题 5**（2.7 #17）：找 2×2 对称矩阵 $S$：(a) 奇异；(b) 可逆但必须换行（无 $LU$）；(c) 有 $LDL^T$ 但无 $LL^T$（因 $D$ 有负元）。
*提示*：(a) $\begin{bmatrix}1&2\\2&4\end{bmatrix}$；(b) $\begin{bmatrix}0&1\\1&0\end{bmatrix}$；(c) $\begin{bmatrix}1&2\\2&1\end{bmatrix}$（主元 $1,-3$）。

**题 6**（2.7 #38）：任意方阵 $M$ 分解 $M=S+A$，$S$ 对称、$A$ 反对称（$A^T=-A$）。求 $S,A$ 用 $M$ 与 $M^T$ 表达的公式。
*提示*：$S=\frac12(M+M^T)$，$A=\frac12(M-M^T)$——"对称+反对称"是矩阵空间的正交分解（Ch 4 会回来）。

**题 7**（2.7 #22 型）：对 $A=\begin{bmatrix}0&1&3\\1&2&1\\2&7&9\end{bmatrix}$ 求 $PA=LU$。
*提示*：$P=P_{12}$；$L=\begin{bmatrix}1&0&0\\0&1&0\\2&3&1\end{bmatrix}$，$U$ 见 §4.2——换行提前后乘数照常落位。

## 9. 逻辑推导概念图

下面把全篇的推理链画成一棵树：顶部是出发点（消元的逆过程与转置的内在定义），箭头是推理方向，每一步只用上游的结论。读者可据此核对哪个定理用了哪条假设——把某条出发点遮住，顺着断掉的箭头就能看到它下游塌掉什么。

```text
出发点 A：消元 = 左乘一串 E_ij（LA 02），E^-1 只把 -l 改回 +l
出发点 B：转置的内在定义 (Ax)^T y = x^T (A^T y)
│
├─ A + 逆序法则 → L = E_21^-1 E_31^-1 E_32^-1，乘数原位落座
│   │   （关键机制：被减去的主元行永远是 U 的行，不是 A 的原始行）
│   ├─ 无换行且凑齐 n 个主元 → A = LU（L 单位下三角，U 对角线是主元）
│   │   ├─ 主元抽进 D → A = LDU
│   │   └─ A 对称 → U = L^T → S = L D L^T（计算量减半）
│   ├─ 主元位置为 0 且下方无救 → A = LU 不存在
│   │   → 换行提前打包成 P → PA = LU
│   └─ Factor 一次（n^3/3，与 b 无关）+ 每个新 b Solve 一次（n^2）
│
├─ B → (AB)^T = B^T A^T（倒序；向量情形逐列套用）
│   ├─ (A^T A)^T = A^T A → A^T A 恒对称、对角线非负
│   ├─ 对称 S：逆对称，分解对称（S = L D L^T）
│   └─ P^T P = I → P^-1 = P^T → 正交矩阵 Q^T = Q^-1 的先声
│       ▼
└─ 主结论：对一切可逆 A，存在置换 P 使 PA = LU——消元分解的完全体
```

| 出发点 | 买到什么 | 撤掉它失去什么 |
|--------|---------|----------------|
| 逆必须倒序相乘（袜子-鞋法则） | $L=E_{21}^{-1}E_{31}^{-1}E_{32}^{-1}$ 倒序乘出、乘数原位落座（正向积 $FE$ 冒交叉项 20 的对照） | $L$ 的 $(i,j)$ 元不再是乘数 $\ell_{ij}$，$A=LU$ 作为乘数收纳盒的价值消失 |
| 被减去的主元行永远是 $U$ 的行（不是 $A$ 的原始行） | 乘数不混合的机制：$L$ 干净落位而 $E$ 正向乘积互相污染 | 只剩现象没有原因——为什么偏偏是逆序积干净，无法回答 |
| 主元位置为 0 且下方无救时允许换行 | $PA=LU$ 覆盖一切可逆矩阵 | 可逆矩阵 $\begin{bmatrix}0&1\\1&0\end{bmatrix}$ 无处安放（有 $PA=LU$ 而无 $A=LU$） |
| 转置的内在定义 $(Ax)^Ty=x^T(A^Ty)$ | $(AB)^T=B^TA^T$；$A^TA$ 恒对称的一行证明；转置升级为伴随（$(d/dt)^T=-d/dt$） | 转置退化为沿对角线翻转的记号操作，差分从 $x$ 挪到 $y$ 身上自动长出负号的演示无从解释 |
| $P^{-1}=P^T$（置换的结构性质） | 保内积 $(Px)^T(Py)=x^Ty$；正交矩阵 $Q^T=Q^{-1}$ 的先声；$PSP^T$ 保持对称 | 左乘 $P$ 破坏对称、右乘 $P^T$ 救回来的解释链断掉 |
