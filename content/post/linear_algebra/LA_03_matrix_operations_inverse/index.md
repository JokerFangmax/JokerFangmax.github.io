# 线性代数 03：矩阵运算与逆矩阵

> 📖 本篇覆盖 Strang《Introduction to Linear Algebra》第 5 版 §2.4–2.5。前置：[LA 02](../LA_02_elimination/)（消元矩阵、置换矩阵、结合律）。

---

## 1. 这一篇解决什么问题？

上一篇把消元的每一步写成了矩阵乘法（$E_{32}E_{31}E_{21}A = U$）。本篇回答随之而来的两个问题：

1. **矩阵乘法到底有几种"看法"？**（§2.4）——教科书只教一种（行乘列点积），Strang 给出**四种**。这不是炫技：四种观点各自对应后面一个主题（列观点 → 线性变换的组合；行观点 → 消元；列×行观点 → 秩一分解、SVD；块观点 → Schur 补、数值算法）。理解"同一个乘法四副面孔"，是从"会算"到"会用"的分水岭；
2. **逆矩阵：谁能有、怎么求、为什么常常不要求？**（§2.5）——可逆性是对方阵问的第一个问题。本篇给出 Gauss–Jordan 求逆算法、**逆序法则** $(AB)^{-1}=B^{-1}A^{-1}$，以及一个反直觉的工程事实：**实践中几乎从不显式计算 $A^{-1}$**——解 $Ax=b$ 用消元直接得多（成本 $n^3/3$ vs 求逆 $n^3$）。

本篇的暗线：**"$A$ 可逆吗"有一整条等价判据链**（$n$ 个主元 / $\det A\neq0$ / $Ax=0$ 只有零解 / 行列式 / 秩……），Strang 说书的最后一页列了 14 条。本篇先把链条上最常用的几环接起来。

## 2. 矩阵乘法的四种观点（§2.4）

### 2.0 形状法则

$$
\underbrace{A}_{m\times n}\ \underbrace{B}_{n\times p} = \underbrace{C}_{m\times p},
\qquad \text{$A$ 的列数必须等于 $B$ 的行数。}
$$

记住这对形状，四种观点的合法性全部从它读出。加法则要求形状完全相同（逐元素相加，和向量一样）。

### 2.1 四种观点一张表

以 $(AB)_{ij}$ 为靶心，四种算法殊途同归：

| 观点 | 内容 | 何时用 |
|------|------|--------|
| **① 元素（行×列）** | $(AB)_{ij} = (\text{row } i \text{ of } A)\cdot(\text{col } j \text{ of } B)$，共 $mp$ 个点积、每个 $n$ 步，合计 $mnp$ 次乘法 | 手算、编程默认 |
| **② 列** | $A$ 乘 $B$ 的每一列：$AB = [\,Ab_1\ \cdots\ Ab_p\,]$，$AB$ 的每列是 $A$ 列的组合 | 理解 $A$ 的"作用"（线性变换）；$AA^{-1}=I$ |
| **③ 行** | $A$ 的每一行乘整个 $B$：$AB$ 的每行是 $B$ 行的组合 | 消元（$E$ 左乘 $A$） |
| **④ 列×行** | $AB = \sum_{k=1}^{n} (\text{col } k \text{ of } A)(\text{row } k \text{ of } B)$，$n$ 个 $m\times p$ 矩阵之和 | 秩一分解、SVD 的雏形 |

**观点④是四种里最少人知道、而 Strang 自认最值得讲的**（"I feel like a magician explaining a trick"）。演示（2×2，观点①需要 4 个点积 8 次乘法；观点④是 2 个完整矩阵相加，同样 8 次乘法）：

$$
\begin{bmatrix}a&b\\c&d\end{bmatrix}\begin{bmatrix}E&F\\G&H\end{bmatrix}
= \begin{bmatrix}a\\c\end{bmatrix}\begin{bmatrix}E&F\end{bmatrix} + \begin{bmatrix}b\\d\end{bmatrix}\begin{bmatrix}G&H\end{bmatrix}
= \begin{bmatrix}aE&aF\\cE&cF\end{bmatrix} + \begin{bmatrix}bG&bH\\dG&dH\end{bmatrix}.
$$

每个"列×行"都是**秩一矩阵**（每列都是同一向量的倍数）。Ch 7 的 SVD 说任何矩阵都是这种积的和——观点④是它的第一块砖。

**内外积对比**（例 2）：行×列（$1\times n$ 乘 $n\times1$）是**内积**（inner product，得一个数）；列×行（$n\times1$ 乘 $1\times n$）是**外积**（outer product，得一个 $n\times n$ 矩阵）。ML 里的 outer product 更新、Hebbian 学习规则都是后者。

### 2.2 运算法则：六条成立，一条不成立

| 法则 | 公式 | 状态 |
|------|------|------|
| 加法交换 | $A+B=B+A$ | ✅ |
| 加法结合 | $A+(B+C)=(A+B)+C$ | ✅ |
| 分配 | $c(A+B)=cA+cB$；$A(B+C)=AB+AC$；$(A+B)C=AC+BC$ | ✅（左分配、右分配**分别**成立） |
| 乘法结合 | $A(BC)=(AB)C$ | ✅（括号可移动——"线性代数依赖此法则"） |
| 幂 | $A^p = A\cdots A$（$p$ 个），$A^pA^q=A^{p+q}$，$(A^p)^q = A^{pq}$，$A^0=I$ | ✅（注意 $A$ 必须是方阵） |
| **乘法交换** | $AB=BA$ | ❌ **一般不成立** |

**交换律失败的两种层次**：形状不同（$A$ 是 $m\times n$、$B$ 是 $n\times m$ 时 $AB$ 是 $m\times m$、$BA$ 是 $n\times n$，连比较资格都没有）；形状相同值也不同（随手一例：$AB=\begin{bmatrix}1&0\\0&0\end{bmatrix}$、$BA=\begin{bmatrix}1&0\\1&0\end{bmatrix}$）。**能和所有方阵交换的只有 $cI$**——单位矩阵是矩阵世界里唯一"民主"的乘法对象。

分配律的证明值得看一眼 Strang 的说法：**一列一列地证**。$A(b+c) = Ab + Ac$ 对第一列成立，"That is the key to everything—linearity"。线性性从第一列扩散到整个矩阵——这个"逐列处理"的思维方式贯穿全书（也是 ML 里 batch 处理的数学原型）。

### 2.3 计算量与 Strassen

方阵 $n\times n$ 相乘：$n^2$ 个元素、每个 $n$ 次乘法，共 $n^3$。$n=100$ 时是一百万次。教材的注记很有意思：数学家曾以为 $2\times2$ 乘法最少要 $2^3=8$ 次乘法，直到 Strassen 找到 **7 次**的办法；用分块递归外推，目前最好计数约 $n^{2.376}$（教材第 5 版时的纪录）——逼近 $n^2$（即"只读一遍数据"的下限）。但 Strang 补了冷冷一句：这些算法"太别扭，科学计算仍然按普通 $n^3$ 方式做"。**理论复杂度与工程可用性是两回事**——GPU 上的 cuBLAS 到今天仍以分块的经典算法为主。

### 2.4 块矩阵与 Schur 补

矩阵可以**切**成块（block）再运算。只要"A 的列切法与 B 的行切法对齐"，块乘法就像普通乘法一样进行：

$$
AB = \Big[\,A_1\ \ A_2\,\Big]\begin{bmatrix}B_1\\B_2\end{bmatrix} = A_1B_1 + A_2B_2.
$$

两个最重要的应用：

**（1）观点④即块乘法**：把 $A$ 的每个列、$B$ 的每个行各当一个块，$AB$ = 列块 × 行块之和。

**（2）块消元与 Schur 补**。对 $2\times2$ 分块矩阵 $\begin{bmatrix}A&B\\C&D\end{bmatrix}$（这里 $A,B,C,D$ 是块），用块乘法执行消元——把第一块行乘 $CA^{-1}$ 从第二块行减去（对照数值情形的 $c/a$）：

$$
\begin{bmatrix} I & 0 \\ -CA^{-1} & I \end{bmatrix}
\begin{bmatrix} A & B \\ C & D \end{bmatrix}
= \begin{bmatrix} A & B \\ 0 & \boxed{D - CA^{-1}B} \end{bmatrix}
$$

右下角的 $S = D - CA^{-1}B$ 称为 **Schur 补**（Schur complement）——正是标量消元中 $d - cb/a$ 的矩阵版。它在数值线性代数（分块 LU）、概率图模型（高斯条件分布）、控制论（传递函数化简）中都是常客。

**（3）图与邻接矩阵**（Worked Example 2.4 A，本篇的明星应用）：无向图的邻接矩阵 $S$（$S_{ij}=1$ 若节点 $i,j$ 有边），则

$$
(S^2)_{ij} = \sum_k S_{ik}S_{kj} = \text{从 } i\text{ 到 }j\text{ 的 2 步路径数},
$$

一般地 $S^N$ 的 $(i,j)$ 元数出 $N$ 步路径数——矩阵乘法**天然就是路径计数器**。教材例：4 节点图中 $S^2$ 在 (1,1) 位置是 2（走 1-2-1 和 1-3-1）。ML 连接：这就是 GNN 里"消息传递 $k$ 层后感受 $k$ 跳邻域"的矩阵本质。

## 3. 逆矩阵（§2.5）

### 3.1 定义与六条笔记

**定义**：方阵 $A$ **可逆**（invertible / nonsingular），若存在同尺寸矩阵 $A^{-1}$ 使

$$
A^{-1}A = AA^{-1} = I.
$$

直觉：**$A$ 做什么，$A^{-1}$ 就撤销什么**（Whatever A does, $A^{-1}$ undoes）。

Strang 给了六条笔记（浓缩版）：

| # | 内容 | 备注 |
|---|------|------|
| 1 | 可逆 $\iff$ 消元凑出 $n$ 个非零主元（允许换行） | 算法判据；消元本身不需要算出 $A^{-1}$ 就能解 $Ax=b$ |
| 2 | 逆唯一；左逆 = 右逆 | 括号证明见下 |
| 3 | 可逆时 $Ax=b$ 有唯一解 $x=A^{-1}b$ | 但**不要真的这样算**（§3.4） |
| 4 | **若存在 $x\neq0$ 使 $Ax=0$，则 $A$ 不可逆** | 没有"撤销零"的办法：$A^{-1}\mathbf 0 = \mathbf 0 \neq x$。最常用的不可逆信号 |
| 5 | 2×2 公式：$\begin{bmatrix}a&b\\c&d\end{bmatrix}^{-1} = \frac{1}{ad-bc}\begin{bmatrix}d&-b\\-c&a\end{bmatrix}$ | $ad-bc$ 即**行列式**（Ch 5 前传）：$\det A\neq0$ 才可逆 |
| 6 | 对角矩阵可逆 $\iff$ 对角元全非零；逆是取倒数 | |

**笔记 2 的证明**（"proof by parentheses"，一行看完）：设 $BA=I$ 且 $AC=I$，则

$$
B = B\,I = B(AC) \overset{\text{结合律}}{=} (BA)C = I\,C = C.
$$

左逆右逆自动相等——方阵的世界里"单边逆"不存在，这个便利在长方形矩阵（Ch 3 起的 $m\times n$）中就没了，届时左逆右逆可以不同、甚至只有一边存在。

### 3.2 逆序法则：袜子与鞋

$$
\boxed{\ (AB)^{-1} = B^{-1}A^{-1}\ },\qquad (ABC)^{-1} = C^{-1}B^{-1}A^{-1}.
$$

验证只需一眼：$(AB)(B^{-1}A^{-1}) = A(BB^{-1})A^{-1} = AIA^{-1} = I$（括号移动 = 结合律，又一次）。

Strang 的比喻：**先穿袜子再穿鞋，脱的时候先脱鞋**（inverses come in reverse order）。这不是玩笑，是本法则最可靠的记忆锚点——所有"复合操作的逆"都倒序：复合函数 $(f\circ g)^{-1} = g^{-1}\circ f^{-1}$、正向传播与反向传播、编译与反编译。

**消元矩阵的逆**（承接 LA 02）：$E$ 做减法（行 2 减 $\ell$ 倍行 1），$E^{-1}$ 做加法——把 $-\ell$ 改成 $+\ell$ 即可：

$$
E = \begin{bmatrix}1&0&0\\-5&1&0\\0&0&1\end{bmatrix},
\qquad
E^{-1} = \begin{bmatrix}1&0&0\\5&1&0\\0&0&1\end{bmatrix}.
$$

**一个关键现象**（为 LA 04 铺路）：两个消元矩阵的**正向乘积会混出新的数**，**逆的乘积不会**。教材例 3：$F$ 从行 3 减 4 倍行 2、$E$ 从行 2 减 5 倍行 1，则

$$
FE = \begin{bmatrix}1&0&0\\-5&1&0\\20&-4&1\end{bmatrix}\ \text{（冒出 } 20!\text{）},
\qquad
(FE)^{-1} = E^{-1}F^{-1} = \begin{bmatrix}1&0&0\\5&1&0\\20&4&1\end{bmatrix}^{-1}\cdots
$$

正向顺序 $FE$ 里，行 3 先被行 2 改过一遍、又受行 1 影响（5×4=20）；逆序 $E^{-1}F^{-1}$ 里各乘数 $5,4$ **原位落座**互不干扰。这正是下一节选 $A=LU$（而不是 $A=EU$）的原因：**$L=E^{-1}$ 收纳全部乘数而不产生交叉项**。

### 3.3 Gauss–Jordan 求逆

把 $A^{-1}$ 按列拆开：$AA^{-1}=I$ 等价于 $n$ 个方程 $Ax_j = e_j$（$e_j$ = $I$ 的第 $j$ 列）。**同时**解这 $n$ 个方程：在 $A$ 右侧拼上整个 $I$ 做增广矩阵，一路消元到底（消完下方还消上方），左边化成 $I$ 时右边自动是 $A^{-1}$：

$$
[\,A\ \ I\,]\ \xrightarrow{\ \text{行消元}\ }\ [\,I\ \ A^{-1}\,].
$$

**完整例子**（Strang 的最爱矩阵 $K$：三对角，对角 2、副对角 $-1$——二阶差分矩阵）：

$$
K=\begin{bmatrix}2&-1&0\\-1&2&-1\\0&-1&2\end{bmatrix},\qquad
K^{-1}=\frac14\begin{bmatrix}3&2&1\\2&4&2\\1&2&3\end{bmatrix}.
$$

主元 $2,\ \frac32,\ \frac43$，乘积恰为 $4=\det K$（主元积 = 行列式，Ch 5 的伏笔）。关于 $K^{-1}$ 的三个观察，每个都有大道理：

1. $K$ 对称 $\Rightarrow$ $K^{-1}$ 对称（转置与求逆可交换秩序，LA 04 证）；
2. **$K$ 三对角（稀疏），但 $K^{-1}$ 全满（稠密）**——带状矩阵的逆一般是稠密矩阵。这是"别显式求逆"的第二个理由：你想要的稀疏性在逆里丢了；
3. $K^{-1}$ 里出现 $\det K=4$ 作分母——**行列式为零时分母爆炸**，可逆 = 除得动。

**成本对比**（§2.5 明算的账）：求 $A^{-1}$ 需解 $n$ 个方程，总计 $\approx n^3$；而单解一个 $Ax=b$ 只要 $\approx n^3/3$。解一个右端就动用全部消元机器、还要多付三倍——**$x = A^{-1}b$ 是数学等式，不是计算建议**。

### 3.4 可逆性判据：主元测试的完整证明

**定理**：方阵 $A$ 可逆 $\iff$ 消元产生 $n$ 个非零主元（允许换行）。

**（⟸）** $n$ 个主元时，Gauss–Jordan 能解出全部 $Ax_j=e_j$，得右逆；消元 = 左乘一串可逆矩阵（$E$、$P$、除主元的对角阵）$M$ 使 $MA=I$，这又是左逆；由笔记 2，两者是同一个 $A^{-1}$。

**（⟹）** 反证四步（值得抄在笔记本上）：

1. 若凑不齐 $n$ 个主元，消元会产生一个零行；
2. 消元是左乘可逆矩阵 $M$：$MA$ 有零行；
3. 若 $AC=I$ 成立，两边左乘 $M$：$MAC=M$，但 $MA$ 的零行 $\Rightarrow$ $M$ 有零行；
4. 可逆矩阵 $M$ 不能有零行（零行意味着 $M$ 不可逆）。矛盾。∎

顺带收获：**$AC=I \Rightarrow CA=I$**——对方阵，验证一边就够了。

### 3.5 两个快判法与三族好矩阵

| 命题 | 内容 | 直觉 |
|------|------|------|
| **对角占优可逆** | $\|a_{ii}\| > \sum_{j\neq i}\|a_{ij}\|$ 对每行成立 $\Rightarrow A$ 可逆 | 主对角"一票压过"全行；证明见下 |
| **三角可逆 ⟺ 对角元非零**；三角的逆保持三角 | 上三角的逆上三角 | 回代不产生下三角项 |
| **单位下三角 $L$ 的逆仍是单位下三角** | Gauss–Jordan 直接构造（教材例 6） | LA 04 的 $L$ 就有这个血统 |

**对角占优定理的证明**（三行，漂亮）：设 $Ax=\mathbf 0$ 有非零解 $x$，取其最大分量 $|x_i|$。第 $i$ 个方程要求

$$
\underbrace{a_{ii}x_i}_{\text{大小} > \sum_{j\neq i}\|a_{ij}\|\,|x_i|} = -\sum_{j\neq i}a_{ij}x_j
\quad\text{右边} \le \sum_{j\neq i}\|a_{ij}\|\,|x_j| \le \sum_{j\neq i}\|a_{ij}\|\,|x_i| < \|a_{ii}x_i\|,
$$

矛盾。故 $Ax=\mathbf 0$ 只有零解，由判据链 $A$ 可逆。∎ （教材例子：$A$ 满足 $3>2$ 可逆；$B$ 不占优但也偶然可逆——占优是充分不必要；$C$ 奇异。）

**差分矩阵的逆 = 求和矩阵**（Worked Example 2.5 A，呼应 LA 01 §4.1）：下三角差分矩阵（对角 $1$、下副对角 $-1$）的逆是全 1 下三角求和矩阵——Gauss–Jordan 三步消出来。若把右上角 $(1,3)$ 位置改成 $-1$，三行之和变为零，$x=(1,1,1)$ 成为 $Ax=\mathbf 0$ 的非零解——**不可逆的信号以"$Ax=\mathbf 0$ 出非零解"的形式最先冒头**，与 LA 01 的循环差分矩阵 $C$ 完全同构。

**Pascal 矩阵彩蛋**（Worked Example 2.5 C）：下三角 Pascal 矩阵 $L$（元素为二项式系数）主元全 1，逆是**隔条对角线变号**的自己。组合恒等式 $(1+x)^{-1}$ 系数交替的矩阵版——数学各角落的呼应。

## 4. 例子与反例速查

| 命题 | 真假 | 例子 / 反例 |
|------|------|------------|
| $AB=BA$（同尺寸方阵） | ❌ | 默认不等；能与所有方阵交换的只有 $cI$ |
| $(AB)^{-1}=A^{-1}B^{-1}$ | ❌ | 必须倒序 $B^{-1}A^{-1}$——袜子与鞋 |
| $A+B$ 可逆 $\Rightarrow A,B$ 各自可逆 | ❌ | 数字版：$3+(-3)=0$；矩阵同理，$A+B$ 的可逆性与因子基本无关 |
| $A,B$ 可逆 $\Rightarrow AB$ 可逆 | ✅ | $(AB)^{-1}=B^{-1}A^{-1}$；逆命题也成立 |
| $\det A\neq0$（即 $ad-bc\neq0$）$\Rightarrow$ 可逆 | ✅ | 2×2 公式直接给出逆 |
| $Ax=\mathbf 0$ 有非零解 $\Rightarrow A$ 不可逆 | ✅ | Note 4；$\begin{bmatrix}1&2\\2&4\end{bmatrix}$：$x=(2,-1)$ |
| 稀疏矩阵的逆稀疏 | ❌ | 三对角 $K$ 的逆全满 |
| 带状矩阵的逆带状 | ❌ | 同上（同一条事实的两个说法） |
| 三角矩阵的逆三角 | ✅ | 上三角逆上三角、单位下三角逆单位下三角（例 6） |
| 对角占优是可逆的必要条件 | ❌ | $B$：$2$ 不大于 $1+1$，但 $B$ 可逆——充分不必要 |
| $S^N$ 计数图上 $N$ 步路径 | ✅ | 邻接矩阵幂 = 路径计数器（Worked Example 2.4 A） |

## 5. 易混淆辨析

| 概念对 | 辨析 |
|--------|------|
| **$A^{-1}$ vs $\frac{1}{A}$** | 逆是**矩阵**，满足 $AA^{-1}=I$；没有"除以矩阵"这回事（MATLAB 的 `A/b` 是解方程的语法糖）。数世界 $a\cdot a^{-1}=1$ 与此同构，但矩阵还有不可逆问题 |
| **左逆 vs 右逆** | 方阵：一边成立即两边成立且相等（括号证明）；长方形矩阵（Ch 3+）：可能只有单边逆——从方阵走向长方形时这是第一个失去的性质 |
| **$A^{-1}b$（数学） vs 解 $Ax=b$（计算）** | 前者是解的**表达式**，后者才是**算法**。显式求逆成本 $n^3$ 是解方程 $n^3/3$ 的三倍，且稀疏性丢失 |
| **奇异 vs 不可逆** | 同义词。奇异 = singular = 不可逆 = nonsingular 的反义；三个名字一件事（列相关、凑不齐主元、$\det=0$、$Ax=0$ 有非零解……判据链上任一环） |
| **$(AB)^{-1}$ vs $(BA)^{-1}$** | $AB$ 与 $BA$ 是不同矩阵（甚至不同形状），各自的逆也不同；共同点：$\det(AB)=\det(BA)$（Ch 5） |
| **Schur 补 $D-CA^{-1}B$ vs 标量 $d-cb/a$** | 同一消元动作的两种规模：块的"乘数"是 $CA^{-1}$（矩阵左乘）；顺序不可交换——$D-CA^{-1}B$ 不是 $D-A^{-1}CB$ |
| **$A^0=I$ vs 数字 $a^0=1$** | 完全同构：幂法则 $A^pA^q=A^{p+q}$ 要求 $A$ 是方阵，负幂 = 逆的幂（$A^{-2}=(A^{-1})^2$），前提可逆 |

## 6. ML / 应用连接

- **别显式求逆**（数值课第一诫）：`np.linalg.solve(A, b)` 而非 `np.linalg.inv(A) @ b`。三倍成本之外，逆的数值误差通常更大（条件数平方级放大，Ch 11）。一个反例场合：当同一 $A$ 要配成百上千个不同 $b$ 时，预计算分解（不是逆）才划算；
- **协方差矩阵与高斯**：多元高斯 $\mathcal N(\mu, \Sigma)$ 的密度需要 $\Sigma^{-1}$ 与 $\det\Sigma$——$\Sigma$ 可逆 ⟺ 没有特征冗余（线性相关）。特征共线时 $\Sigma$ 奇异，正规方程 $\hat\beta = (X^TX)^{-1}X^Ty$ 无解——这是线性回归的病根，Ch 3 用广义逆/最小二乘收尾；
- **Schur 补在概率图模型**：分块高斯 $(x_1, x_2)$，条件分布 $\Sigma_{11\mid 2} = \Sigma_{11} - \Sigma_{12}\Sigma_{22}^{-1}\Sigma_{21}$——正是 Schur 补。消息传递推断的每一步都在做块消元；
- **邻接矩阵幂 = 路径计数**：GNN 的 $k$ 层消息传递 ≈ $k$ 阶邻接的传播；PageRank 的幂迭代是 $S$（列归一化邻接阵）幂的收敛故事（LA 10 特征值视角、LA 16 正式讲）；
- **Strassen 与深度学习**：矩阵乘法是 transformers 的算力主体（$\sim n^3$），所以 Strassen 类算法、稀疏/低秩近似（MLA、Mixture-of-Experts 的块对角）全是围绕 $n^3$ 的攻防。观点④（列×行）直接对应"注意力头 = 秩一/低秩更新"的现代理解；
- **外积学习规则**：Hebbian 学习 $\Delta W = \eta\, xy^T$ 是观点④的最小单位——单个样本对权重的贡献就是一个秩一外积。整个训练 = 秩一矩阵的累加。

## 7. 习题精选（Problem Set 2.4–2.5 选摘）

**题 1**（2.4 观点训练）：$A=\begin{bmatrix}1&2\\3&4\end{bmatrix}$，$B=\begin{bmatrix}5&6\\7&8\end{bmatrix}$。用四种观点各算一遍 $AB$，核对结果一致；数一下每种方式做了几次标量乘法。
*提示*：① 4 个点积 × 2 次乘法 = 8；④ $\binom{1}{3}\binom{5}{6} + \binom{2}{4}\binom{7}{8}$，2 个秩一矩阵，同样 8 次。

**题 2**（2.4 #型，块乘法）：设 $A=\begin{bmatrix} I & 0 \\ C & I \end{bmatrix}$（$I$ 为 $2\times2$，$C$ 为 $2\times2$）。求 $A^{-1}$ 并验证。
*提示*：块消元矩阵的逆：$\begin{bmatrix} I & 0 \\ -C & I \end{bmatrix}$。"减 $C$ 倍第一块行"的逆是"加回去"。

**题 3**（2.5）：$A=\begin{bmatrix}4&3\\8&6\end{bmatrix}$。用三种不同判据说它不可逆。
*提示*：$\det = 24-24=0$；第二行减 2 倍第一行成零行（只有 1 个主元）；$Ax=\mathbf 0$ 有解 $x=(3,-4)$（或 $(-3,4)$）。

**题 4**（2.5，Gauss–Jordan 实操）：求 $\begin{bmatrix}1&1&0\\0&1&1\\1&0&1\end{bmatrix}$ 的逆，或证明不存在。
*提示*：三行之和 $=2\times$（各列和为 2），先看 $Ax=\mathbf 0$：$(1,1,1)$ 行和各为 2 不为零，不能直接判死。做 Gauss–Jordan：$[\,A\ I\,]$ 消元后左半出现零行（行 3 − 行 1 + 行 2 = 0），奇异的实锤——$x=(1,-1,1)$ 检验 $Ax=\mathbf 0$ ✓。

**题 5**（2.5，逆序综合）：$E_{21}$（$\ell=2$）、$E_{32}$（$\ell=3$）如 LA 02。分别计算 $E_{32}E_{21}$ 与 $E_{21}^{-1}E_{32}^{-1}$，观察哪个矩阵里乘数"干净落位"。
*提示*：正向积出现 $6$（= 2×3）交叉项；逆序积里 $2,3$ 各归其位——这正是 $A=LU$ 选 $L=E^{-1}$ 的全部理由。

**题 6**（2.4 A，图计数）：4 节点图，边 1-2、1-3、2-4、3-4。写出邻接矩阵 $S$，算 $S^2$，验证 $(S^2)_{23} = 2$（2→1→3 与 2→4→3），并数出从 1 到 1 的 2 歹路径。
*提示*：1→2→1、1→3→1，故 $(S^2)_{11}=2$。

## 8. 逻辑推导概念图

下面把全篇的推理链画成一棵树：顶部是出发点（矩阵乘法的定义与逆的定义），箭头是推理方向，每一步只用上游的结论。读者可据此核对哪个定理用了哪条假设——把某条出发点遮住，顺着断掉的箭头就能看到它下游塌掉什么。

```text
出发点 A：矩阵乘法定义（(AB)ij = A 的行 i 点积 B 的列 j，形状对齐）
出发点 B：逆的定义 A^-1 A = A A^-1 = I
│
├─ A + 结合律 → 四种观点殊途同归
│   ├─ 列观点 → 逐列线性 → 分配律一列一列地证
│   ├─ 行观点 → 消元 = 左乘一串 E_ij（LA 02 的语言）
│   ├─ 列×行观点 → AB = 秩一矩阵之和（SVD 的第一块砖）
│   └─ 块观点（切法对齐）→ 块消元 → Schur 补 S = D - CA^-1 B
│
├─ B + 结合律（括号证明）→ 左逆 = 右逆，逆唯一
│
├─ B + 结合律 → 逆序法则 (AB)^-1 = B^-1 A^-1（先穿袜子后脱鞋）
│   └─ E^-1 只把 -l 改回 +l，逆序积中乘数原位落座
│       → LA 04 收拢出 L = E^-1 的动机
│
├─ Gauss–Jordan：[A I] 行消元到底 → [I A^-1]（n 个 Axj = ej 同时解）
│   │
│   ▼
└─ 判据链：可逆 ⟺ n 个非零主元 ⟺ Ax = 0 只有零解 ⟺ det ≠ 0（2×2 即 ad-bc）
    ├─ Ax = 0 出非零解 → 不可逆（无法撤销零，Note 4）
    └─ 对角占优 → Ax = 0 只有零解（最大分量反证）→ 可逆
```

| 出发点 | 买到什么 | 撤掉它失去什么 |
|--------|---------|----------------|
| 形状法则（$A$ 的列数 = $B$ 的行数） | 四种乘法观点共享同一合法性来源；交换律失败的第一种层次（$AB$ 是 $m\times m$、$BA$ 是 $n\times n$，连比较资格都没有） | 块乘法的对齐条件无从谈起，Schur 补 $D-CA^{-1}B$ 的推导失去前提 |
| 结合律（括号可移动） | 左逆 = 右逆的一行括号证明；逆序法则的验证只靠移动括号；消元链 $E_{32}E_{31}E_{21}A$ 不必写括号 | 方阵里单边逆的存在无法排除——长方形矩阵（Ch 3 起）真正会出现的事，在方阵这里就说不清了 |
| 逆的定义 $A^{-1}A=AA^{-1}=I$ | $Ax=b$ 唯一解 $x=A^{-1}b$；Note 4（存在 $x\neq 0$ 使 $Ax=\mathbf 0$ 则不可逆——没有撤销零的办法） | 判据链没有锚点，可逆性只剩一个空洞的名字 |
| $Ax=\mathbf 0$ 只有零解（Note 4 的逆否） | 不可逆的最快信号；对角占优定理的落点（最大分量反证的收尾一步） | 差分矩阵右上角改 $-1$ 后 $x=(1,1,1)$ 这个非零解信号读不出来，只能退回去硬算 $\det$ |
| 逆序法则 $(AB)^{-1}=B^{-1}A^{-1}$ | $E^{-1}$ 们的乘积里乘数原位落座、不产生交叉项——LA 04 选 $L=E^{-1}$ 的全部理由 | 正向积 $FE$ 冒出 $20=5\times4$ 的现象无法解释，$A=LU$ 的动机消失 |

## 9. 小结与下一篇

- **四种乘法观点**是全系列复用率最高的工具：列观点管理解、行观点管消元、列×行管分解、块观点管工程；
- **可逆性判据链**（本篇接通四环）：$n$ 主元 ⟺ $\det\neq0$ ⟺ $Ax=\mathbf0$ 只有零解 ⟺ 可逆。Ch 3 会接上"列独立/秩 $r=n$"两环，Ch 5 接行列式环，Ch 6 接"特征值全非零"环；
- **逆序法则**与"减法的逆是加法"合流，下一集推出主角：把一串 $E_{ij}^{-1}$ 收拢成**一个**下三角矩阵 $L$，消元整体打包为 $A=LU$——LA 04 的全部内容。
