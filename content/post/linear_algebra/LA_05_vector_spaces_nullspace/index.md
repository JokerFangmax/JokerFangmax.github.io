# 线性代数 05：向量空间、零空间与完全解

> 📖 本篇覆盖 Strang《Introduction to Linear Algebra》第 5 版 §3.1–3.3。前置：[LA 04](../LA_04_lu_transpose_permutation/)（消元、$A=LU$）。本章是全书"第三个理解层次"的开篇——从数字、向量升级到**空间**。

---

## 1. 这一篇解决什么问题？

Strang 在 Chapter 3 开头说：新手看矩阵计算看到的是一堆**数字**，你看到的是**向量**，而这一章要到达**第三个（也是最高的）层次**——不看个别的列，看"向量的**空间**"。他直言：**不见向量空间与其子空间，你就没有真正理解 $Ax=b$**。

本篇回答三个问题：

1. **"空间"到底是什么？**（§3.1）——向量空间的八条规则、子空间的两条检验，以及由矩阵 $A$ 天然长出的第一个空间：**列空间** $C(A)$。核心定理一句话：$Ax=b$ 有解 $\iff$ $b$ 在 $C(A)$ 里；
2. **$Ax=0$ 的解集长什么样？**（§3.2）——答案是一个空间：**零空间** $N(A)$。消元把它彻底算清：主元列/自由列、特殊解、$R=\mathrm{rref}(A)$、秩 $r$。顺带收获全书最重要的计数定理 $r+(n-r)=n$；
3. **$Ax=b$（$b\neq 0$）的全部解长什么样？**（§3.3）——答案是"**一个特解 + 整个零空间**"：$x=x_p+x_n$。非齐次的解集不再是空间（不含原点），而是一个**被平移过的空间**。最后由秩 $r$ 对 $m,n$ 的关系收口为四种情形全景表。

一条贯穿的哲学：**LA 02 的消元不是删掉坏方程的杂技，而是同时回答两个结构问题**——"这一列是不是前面列的组合？""这一行是不是前面行的组合？"（§3.2 末的 Elimination: The Big Picture）。空间语言让算法的意义显形。

---

## 2. 向量空间与子空间：从向量到空间（§3.1）

### 2.1 八条规则与三个非典型空间

**向量空间**（vector space）是一组"向量"加上向量加法与数乘两种运算，且运算结果**留在空间内**，并满足八条规则：

| 组 | 规则 |
|---|------|
| 加法 (1)–(4) | $x+y=y+x$；$x+(y+z)=(x+y)+z$；存在唯一零向量 $x+0=x$；每个 $x$ 有唯一 $-x$ |
| 数乘 (5)–(6) | $1x=x$；$(c_1c_2)x=c_1(c_2x)$ |
| 连接 (7)–(8) | $c(x+y)=cx+cy$；$(c_1+c_2)x=c_1x+c_2x$ |

最重要的实例是 $\mathbb R^n$：所有 $n$ 个实分量的列向量。但"向量"远不止列向量——Strang 给了三个非典型空间，破除"向量 = 一列数"的执念：

| 空间 | "向量"是什么 | 维数 |
|------|------------|------|
| $M$ | 所有实 $2\times2$ 矩阵 | 4（一个基是 $E_{11},E_{12},E_{21},E_{22}$） |
| $F$ | 所有实函数 $f(x)$ | 无穷维 |
| $Z$ | 只有零向量 | 0（最小可能的空间） |

函数空间 $F$ 有重要的子空间 $P_n$（次数 $\le n$ 的多项式）——FA 系列里 $C[a,b]$、$L^2$ 的雏形。每个空间都有自己的零向量：零矩阵、零函数、$(0,0,0)$。

### 2.2 子空间：两条检验

**子空间**（subspace）是向量空间内部的一个集合（含 $\mathbf 0$），只须验证两条：

$$
\text{(i) } v+w \text{ 在集合内} \qquad \text{(ii) } cv \text{ 在集合内}
$$

两条合一：**含 $v,w$ 则必须含所有组合 $cv+dw$**。零向量不用单独检验——取 $c=0$ 即得 $0v=\mathbf 0$ 必在集合内。**$\mathbb R^3$ 的全部子空间**只有四类：过原点的直线、过原点的平面、整个 $\mathbb R^3$、零空间 $Z$。

**反面教材**（教材 Example 1–2，把两条检验各自的失守演给你看）：

| 集合 | 哪条失败 | 见证 |
|------|---------|------|
| 第一象限 $\{(x,y): x\ge0, y\ge0\}$ | (ii) | $(2,3)$ 在，但 $(-1)\cdot(2,3)=(-2,-3)$ 出去 |
| 两个对角象限拼起来 | (i) | $(2,3)+(-3,-2)=(-1,1)$ 落到第二象限，出去 |
| 不过原点的平面 | (ii)（取 $c=0$） | 零向量都不在里面 |

矩阵空间 $M$ 里的子空间同样生动：上三角矩阵 $U$、对角矩阵 $D$（$D$ 还是 $U$ 的子空间！）、对称矩阵、$cI$ 组成的"矩阵直线"。而**可逆矩阵的集合不是子空间**（$A+(-A)=0$ 奇异）、**奇异矩阵的集合也不是**（两个奇异矩阵可以加出可逆阵——LA 03 反例表的同款事实）。

**组合观**（Problem Set 3.1 的两条深挖）：子空间的**交** $S\cap T$ 仍是子空间（$x,y$ 同在两边则 $x+y$、$cx$ 同在两边）；**并** $S\cup T$ 一般不是（两条过原点的直线之并，加法就出界）——包含两者的最小子空间是**和** $S+T$。这与集合直觉相反，是"空间"与"集合"的分水岭。

### 2.3 列空间 C(A)：b 住在哪

**列空间**（column space）$C(A)$：$A$ 的列的**所有**线性组合。由于 $Ax$ 恰是列的组合，

$$
\boxed{\ C(A) = \text{所有 } Ax\ }
\qquad\Longrightarrow\qquad
Ax=b \text{ 有解} \iff b\in C(A).
$$

这是本节的全部要点。三个立刻的观察：

1. **$C(A)$ 是 $\mathbb R^m$ 的子空间**（$m\times n$ 矩阵的列有 $m$ 个分量）——列空间住在"行数"的空间里；
2. 加法数乘封闭免费得到：组合的组合还是组合；
3. **"张成"**（span）：任意向量集合 $S$（本身可以不是子空间）的所有组合构成子空间 $SS$——包含 $S$ 的最小子空间。列空间即"列的张成"。

教材 Example 5 三个 $2\times?$ 矩阵看全三种命运：

| 矩阵 | 列空间 | $Ax=b$ |
|-------|--------|--------|
| $I=\begin{bmatrix}1&0\\0&1\end{bmatrix}$ | 整个 $\mathbb R^2$ | 任何 $b$ 可解，解唯一 |
| $A=\begin{bmatrix}1&2\\2&4\end{bmatrix}$ | 一条直线（列 2 = 2 列 1） | 仅 $b$ 在线上时可解 |
| $B$（$2\times3$，三列张成 $\mathbb R^2$） | 整个 $\mathbb R^2$ | 任何 $b$ 可解，解**不唯一** |

$B$ 的例子最值得看：$b=(5,4)$ 既是列 2 + 列 3（$x=(0,1,1)$）又是 2·列 1 + 列 3（$x=(2,0,1)$）——**同一个 $b$，多个解**。原因：$B$ 有自由列（Ch 2 预告过的"多余向量"），下一节正式命名。

Worked Example 3.1 A 的逆向设计题也值得记：想造 $A$ 使 $Ax=b_1,\ Ax=b_2$ 可解而 $Ax=b_3$ 不可解？最省事的办法是**把 $b_1,b_2$ 直接当 $A$ 的两列**。此时 $Ax=b_3$ 不可解当且仅当 $b_3$ 不是 $b_1,b_2$ 的组合——若 $b_3$ 偏偏是组合，则**任何**以 $b_1,b_2$ 为列（或包含它们）的矩阵都救不了：列空间含 $b_1,b_2$ 就必含其一切组合。"空间"的封闭性反过来成了**不可能性证明**。

## 3. 零空间与特殊解（§3.2）

### 3.1 N(A) 是子空间

**零空间**（nullspace）$N(A)$：$Ax=\mathbf 0$ 的**全部**解。三行验证它是子空间：$Ax=\mathbf 0,\ Ay=\mathbf 0 \Rightarrow A(x+y)=\mathbf 0+\mathbf 0=\mathbf 0$，$A(cx)=c\mathbf 0=\mathbf 0$。封闭，完毕。

位置关系务必钉死：

$$
C(A)\subseteq\mathbb R^m \quad(\text{列住处}),\qquad
N(A)\subseteq\mathbb R^n \quad(\text{解 } x \text{ 的住处}).
$$

为什么 $Ax=0$ 值得单独立一节？因为它是**解集的"骨架"**：$Ax=b$ 的任意两个解之差在 $N(A)$ 里（$A(x_1-x_2)=\mathbf 0$），所以零空间决定了"多解长什么样"——§3.3 的 $x=x_p+x_n$ 就从这里来。

### 3.2 主元列、自由列与特殊解

消元（$A\to U\to R$）不改零空间，于是解 $Ax=\mathbf 0$ 的标准流程：

1. 消元找出**主元列**（pivot columns）与**自由列**（free columns）；
2. 每个自由变量轮流取 1（其余自由变量取 0）；
3. 回代解出主元变量——得到一个**特殊解**（special solution）。

**完全定理**：$N(A)$ = 特殊解的所有组合，特殊解恰有 $n-r$ 个（自由变量个数）。

**例 1**（$2\times2$，$A$ 奇异）：

$$
A=\begin{bmatrix}1&2\\3&6\end{bmatrix},\qquad
x_1+2x_2=0 \ \xrightarrow{\ x_2=1\ }\ s=(-2,1),\qquad
N(A)=\{c\,s\}.
$$

**例 2**（$1\times3$，一个方程三个未知数）：$A=[1\ 2\ 3]$，方程 $x+2y+3z=0$ 的解集是 $\mathbb R^3$ 中一个过原点的平面，两个特殊解：

$$
s_1=(-2,1,0),\qquad s_2=(-3,0,1),\qquad N(A)=\{c_1s_1+c_2s_2\}.
$$

注意这个平面上的向量全部垂直于 $(1,2,3)$——**零空间垂直于 $A$ 的行**。这不是巧合，是 §3.5"四个基本子空间两两正交"的第一次现身。对照：$x+2y+3z=6$ 的解也构成平面，但**不过原点，不是子空间**（$\mathbf 0$ 不是解）——非齐次的解集 = 平移过的子空间，§3.3 的全部剧情。

**例 3**（三种矩阵的命运）：可逆方阵 $A$、竖长矩阵 $B$（加行）、横宽矩阵 $C$（加列）：

| 矩阵 | 零空间 | 原因 |
|------|--------|------|
| 方阵可逆 | $Z$（只有零向量） | 每列都有主元，无自由变量 |
| 竖长（$m>n$，加行） | 通常仍是 $Z$ | 加方程只会让零空间更小或不变 |
| 横宽（$m<n$，加列） | 必有非零解 | 至少 $n-m$ 个自由变量 |

**计数定理**（Counting Theorem）：

$$
\underbrace{r}_{\text{主元变量}} + \underbrace{(n-r)}_{\text{自由变量}} = n,
$$

以及它的一条重磅推论：**矮宽矩阵（$n>m$）必有 $Ax=\mathbf 0$ 的非零解**——未知数比方程多，至少 $n-m$ 个自由变量。这条定理在 ML 里的分量后面再说。

### 3.3 R = rref(A)：把答案印在矩阵上

从 $U$ 再走两步得到**简化行阶梯形式**（reduced row echelon form）$R=\mathrm{rref}(A)$：①主元上方也消出零；②主元除成 1。全程右端仍是 $\mathbf 0$，所以

$$
N(A)=N(U)=N(R).
$$

**为什么？**（Worked Example 3.2 A，一行证明）$EA=R$ 且 $E$ 可逆时：$Ax=\mathbf 0\Rightarrow Rx=E(Ax)=\mathbf 0$；反之 $Rx=\mathbf 0\Rightarrow Ax=E^{-1}(Rx)=\mathbf 0$。两边互推，解集相同。（LA 02 的"消元不改解"至此有了完整的可逆矩阵语言。）

$R$ 的妙处：**特殊解直接从自由列读出——把自由列的数字反号**。教材主例（$U\to R$）：

$$
U=\begin{bmatrix}1&0&2&2\\0&2&0&4\end{bmatrix}
\ \longrightarrow\
R=\begin{bmatrix}1&0&2&2\\0&1&0&2\end{bmatrix},
\qquad
s_1=(-2,0,1,0),\quad s_2=(-2,-2,0,1).
$$

（$R$ 的自由列 3、4 分别是 $(2,0)^T$ 与 $(2,2)^T$，**整体反号**即是特殊解的对应分量。）

一个 $4\times7$ 的全景例（$R$ 的主元在第 1、2、6 列）：

$$
R=\begin{bmatrix}1&0&x&x&x&0&x\\0&1&x&x&x&0&x\\0&0&0&0&0&1&x\\0&0&0&0&0&0&0\end{bmatrix}
$$

三个主元变量 $x_1,x_2,x_6$，四个自由变量 $x_3,x_4,x_5,x_7$，四个特殊解。顺带一问：$R$ 的列空间是什么？列有 4 个分量且第 4 分量恒为 0——$C(R)=\{(b_1,b_2,b_3,0)\}$，$\mathbb R^4$ 里的一个三维子空间。

### 3.4 秩与秩一矩阵 A=uv^T

**秩**（rank）$r$ = 主元个数 = $R$ 的非零行数。它是矩阵的**真实尺寸**："0=0"的方程不该计数，重复行、可组合掉的行在消元中归零。三个定义层次（一次比一次高）：

| 层次 | 定义 |
|------|------|
| 数字 | 主元个数 |
| 向量 | $r$ 个独立行（列）——§3.4 正式定义"独立" |
| 空间 | $r=\dim C(A)=\dim C(A^T)$，$n-r=\dim N(A)$ |

**秩一矩阵**是极简标本：只有一个主元 ⟹ **每行都是主元行的倍数，同时每列都是主元列的倍数**。于是

$$
\boxed{\ A = uv^T\ }\quad(\text{列}\times\text{行，LA 03 观点④的最小单位})
$$

教材例：

$$
A=\begin{bmatrix}1&3&10\\2&6&20\\3&9&30\end{bmatrix}
=\begin{bmatrix}1\\2\\3\end{bmatrix}\begin{bmatrix}1&3&10\end{bmatrix}=uv^T.
$$

秩一几何全景：行空间 = 过 $v$ 的直线，零空间 = 垂直于 $v$ 的平面（$Ax=\mathbf 0$ 即 $u(v^Tx)=0$ 即 $v^Tx=0$），列空间 = 过 $u$ 的直线。**一行(列)定乾坤**——这是 SVD"任何矩阵 = 秩一矩阵之和"（LA 12）的最小案例。

Worked Example 3.2 C 的提醒：**秩对参数敏感**。$\begin{bmatrix}1&2&3\\2&4&c\end{bmatrix}$ 型矩阵，$c\neq6$ 时 $r=2$、一个特殊解 $(-2,1,0)$；恰好 $c=6$（行 2 = 2 倍行 1）时跌成 $r=1$、两个特殊解。矩阵族的秩在临界参数处跳变——Ch 11 条件数的又一伏笔。

## 4. 完全解：x = x_p + x_n（§3.3）

### 4.1 增广矩阵与可解条件

现在 $b\neq\mathbf 0$。行操作要同步作用于右端，照旧打包进**增广矩阵** $[A\ b]$，一路消到 $[R\ d]$。教材主例（$3\times4$）：

$$
[A\ b]=\left[\begin{array}{cccc|c}1&3&0&2&1\\0&0&1&4&6\\1&3&1&6&7\end{array}\right]
\ \longrightarrow\
[R\ d]=\left[\begin{array}{cccc|c}1&3&0&2&1\\0&0&1&4&6\\0&0&0&0&0\end{array}\right]
$$

第三行变成 $0=0$——**这一步是生死判定**。左端行 3 = 行 1 + 行 2，右端必须同样成立：$1+6=7$ ✓。一般地，$R$ 的每个零行在 $d$ 中对应位置必须也是 0：

$$
\boxed{\ Ax=b \text{ 可解} \iff b \text{ 满足与 } A \text{ 的行相关的同样组合条件} \iff b\in C(A)\ }
$$

本例的可解条件是 $b_1+b_2=b_3$（$\mathbb R^3$ 中的一个平面，正是列空间）。Worked Example 3.3 C 把"行组合"请到台前：消元发现 $2(\text{行}1)+(\text{行}2)-(\text{行}3)=\mathbf 0$，则可解条件为 $2b_1+b_2-b_3=0$——**左端行的组合关系必须被右端复制**。这些行组合向量（本例 $y=(2,1,-1)$）住在 $A^T$ 的零空间里，§3.5 将给它名字：**左零空间** $N(A^T)$。

### 4.2 一个特解 + 整个零空间

可解时，全部解的结构是本节唯一主角：

$$
\boxed{\ x_{\text{complete}} = x_p + x_n\ }
\qquad
Ax_p=b,\quad Ax_n=\mathbf 0.
$$

**特解**（particular solution）$x_p$ 的标准取法（"my favorite"）：**自由变量全取 0，主元变量直接从 $d$ 读出**。主例中 $R$ 的主元列是 1、3，自由列是 2、4：

$$
x_p=(1,0,6,0),\qquad
s_1=(-3,1,0,0),\quad s_2=(-2,0,-4,1),
$$

$$
x_{\text{complete}}=(1,0,6,0)+c_1(-3,1,0,0)+c_2(-2,0,-4,1),\qquad c_1,c_2\in\mathbb R.
$$

三个易错点（Problem Set 3.3 #13 专门考）：

1. **$x_p$ 不乘任意常数**——$2x_p$ 不再满足 $Ax=b$（除非 $b=\mathbf 0$）。任意常数只属于 $x_n$ 部分；
2. **$x_p$ 不唯一**——解线上任何一点都可以当特解（自由变量全 0 只是**一种**取法）；
3. **自由变量全 0 的 $x_p$ 未必是最短解**——$\|x\|$ 最小的解在 Ch 4（最小二乘/伪逆）才登场。

### 4.3 四种情形全景表

秩 $r$ 相对 $m,n$ 的位置决定 $Ax=b$ 的命运——全系列引用率最高的一张表：

| 情形 | 形状 | $R$ 的样子 | 解的个数 |
|------|------|-----------|---------|
| $r=m=n$ | 方阵可逆 | $[I]$ | **恰一解**（$x=A^{-1}b$，LA 02–04 的世界） |
| $r=m<n$ | 矮宽，行满秩 | $[I\ F]$ | **无穷多解**（每个 $b$ 都可解） |
| $r=n<m$ | 高瘦，列满秩 | $\begin{bmatrix}I\\0\end{bmatrix}$ | **0 或 1 解**（$b$ 须满足 $m-n$ 个条件） |
| $r<m,\ r<n$ | 非满秩 | $\begin{bmatrix}I&F\\0&0\end{bmatrix}$ | **0 或无穷多解** |

两种"满秩"各自的特点清单（教材原文列出的性质）：

**列满秩 $r=n$（高瘦）**：所有列都是主元列；没有自由变量/特殊解；$N(A)=Z$；**有解则唯一**。Ch 4 将补上第 5 条：此时 $A^TA$ 可逆——最小二乘的命根子。

**行满秩 $r=m$（矮宽）**：所有行都有主元，$R$ 无零行；**对一切 $b$ 可解**；$C(A)=\mathbb R^m$；零空间有 $n-m$ 个特殊解。

教材 Example 2 演示行满秩：$x+y+z=3,\ x+2y-z=4$（两平面不平行，交线即解集）。消元后 $R=\begin{bmatrix}1&0&3\\0&1&-2\end{bmatrix}$、$d=(2,1)$：

$$
x_p=(2,1,0),\qquad s=(-3,2,1),\qquad
x_{\text{complete}}=(2,1,0)+c(-3,2,1)\ \ (\text{整条直线}).
$$

验证：$2+1+0=3$ ✓、$2+2-0=4$ ✓；$-3+2+1=0$ ✓、$-3+4-1=0$ ✓。

## 5. 例子与反例速查

| 命题 | 真假 | 例子 / 反例 |
|------|------|------------|
| 向量空间必须含零向量 | ✅ | 取 $c=0$：$0v=\mathbf 0$ 必在空间内——不是额外公理，是推论 |
| 两个子空间的并 $S\cup T$ 是子空间 | ❌ | 两条过原点的直线之并：$(1,0)+(0,1)$ 出界 |
| 两个子空间的交 $S\cap T$ 是子空间 | ✅ | 同时在两边的 $x,y$，其和与倍数也同时在两边 |
| 不过原点的平面是子空间 | ❌ | $c=0$ 一票否决 |
| $b\in C(A)$ 时 $Ax=b$ 的解集是子空间 | ❌ | 解集 $=x_p+N(A)$，不含 $\mathbf 0$（除非 $b=\mathbf 0$） |
| 加方程（加行）会使零空间变大 | ❌ | 只会变小或不变：$N(B)\subseteq N(A)$（$B$ 多几行时） |
| 加列会使零空间变大 | ✅ | $n$ 增而 $r$ 至多不变 → 自由变量增多 |
| $n>m$ ⟹ $N(A)\neq Z$ | ✅ | 至少 $n-m$ 个自由变量（计数定理推论） |
| $R$ 与 $A$ 有相同列空间 | ❌ | 行操作改列空间（$C(R)=\{(b_1,b_2,b_3,0)\}$ 例）；相同的只是零空间与行空间 |
| 秩一矩阵 $A=uv^T$ 的零空间是平面 | ✅ | $v^Tx=0$：垂直于 $v$ 的整个平面（$\mathbb R^3$ 时） |
| 特解 $x_p$ 乘任意常数仍是特解 | ❌ | $A(cx_p)=cb\neq b$；任意常数只属于零空间部分 |
| 矩阵族的秩随参数连续变化 | ❌ | $c=8$ 处秩从 2 跳到 1（Worked 3.2 C）；秩只取整数 |

## 6. 易混淆辨析

| 概念对 | 辨析 |
|--------|------|
| **向量空间 vs 子空间** | 子空间只须验两条封闭（其余六条继承自宿主空间）；"空间"是绝对概念，"子空间"是相对概念（$D$ 是 $U$ 的子空间、$U$ 是 $M$ 的子空间） |
| **$C(A)\subseteq\mathbb R^m$ vs $N(A)\subseteq\mathbb R^n$** | 列空间住行的空间、零空间住列的空间——$m\times n$ 矩阵的两个子空间分居两个不同宇宙。搞反是本章第一大事故 |
| **列空间 vs 列的集合** | $C(A)$ 含所有组合 $Ax$，不止那 $n$ 列；列本身可能重复相关，空间只看"张成了多大" |
| **$Ax=0$ 的解集 vs $Ax=b$ 的解集** | 前者是子空间（过原点），后者是它的平移 $x_p+N(A)$（不过原点，不是子空间）。"空间"归零空间，"位置"归特解 |
| **特解 $x_p$ vs 特殊解 $s$** | 特解对应 $Ax=b$（自由变量全 0 的那种）；特殊解对应 $Ax=\mathbf 0$（自由变量轮流取 1）。名字只差一个字，角色完全不同 |
| **主元列 vs 主元变量** | 主元列是 $A$（$R$）的列的分类；主元变量是 $x$ 的分量的分类，一一对应。**用 $A$ 的主元列（不是 $R$ 的！）作为 $C(A)$ 的基**——§3.5 的重要提醒 |
| **秩 $r$ vs $\min(m,n)$** | $r\le\min(m,n)$ 恒成立；$r=\min(m,n)$ 称满秩。$r$ 既是主元数也是 $C(A)$ 与 $C(A^T)$ 的维数——一个数同时管行管列管零空间（$n-r$） |
| **可解 vs 唯一** | 完全独立的两件事：可解性由 $b\in C(A)$（行满秩则恒可解），唯一性由 $N(A)=Z$（列满秩则唯一）。四种情形 = 两个布尔量的真值表 |

## 7. ML / 应用连接

- **超定 vs 欠定：四种情形表就是 ML 建模的分类学**。回归任务里 $X$ 高瘦（样本 $\gg$ 特征）≈ 列满秩：$Xw=y$ 无解（数据有噪声），Ch 4 用最小二乘找"最好"的近似——前提 $X^TX$ 可逆正是列满秩；反过来**参数 $\gg$ 样本**（大模型时代常态）≈ 行满秩矮宽：无穷多解里挑哪个？**正则化就是给零空间施加选择规则**（weight decay 挑范数最小者，ridge 的 $X^TX+\lambda I$ 恰好堵死零方向）；
- **零空间 = 模型的不变方向**。$x_n\in N(A)$ 意味着 $A(x_p+x_n)=Ax_p$：沿零空间移动不改变输出。深度学习里的对称性/等变性（平移不变、尺度不变）、对抗扰动（在 Jacobian 零空间里躲过分类器）、"flat minima"（损失面在哪些方向平坦）——都是零空间概念的不同马甲；
- **秩 = 有效自由度**。$r$ 个主元列张成 $C(A)$：数据矩阵的秩就是"真实独立的信息维数"。特征共线 → 秩亏 → 无穷多解/不可解；LoRA 微调用 $\Delta W=UV^T$（秩 $\ll n$）把可训练参数从 $n^2$ 压到 $r(n+m)$——本篇秩一分解 $A=uv^T$ 的直接工业化；
- **特殊解与稀疏解**：$n-r$ 个特殊解给出零空间的完整坐标。压缩感知更进一步：在无穷多解中挑**最稀疏**的那个（$\ell_1$ 代替 $\ell_0$ 的松弛）——行满秩矮宽系统里寻找稀疏特解是整套压缩感知理论的舞台；
- **`numpy` 对应物**：`sympy.Matrix.rref()` 直接给出 $R$ 与主元列号；`np.linalg.lstsq`（最小二乘）、`np.linalg.matrix_rank`（数值秩，容忍浮点误差——理论秩是整数跳变的，数值秩要设阈值，Ch 11 的主题）；
- **Kirchhoff 电流定律**（Problem Set 3.2 #32）：电路节点"流入=流出"写成 $A^Ty=\mathbf 0$——零空间 = 满足守恒的全部电流分配。图/网络的"环流"空间是其推广，LA 16 讲图拉普拉斯时回来。

## 8. 习题精选（Problem Set 3.1–3.3 选摘）

**题 1**（3.1 #10）：$\mathbb R^3$ 的下列子集哪些是子空间？(a) $b_1=b_2$；(b) $b_1=1$；(c) $b_1b_2b_3=0$；(d) $(1,4,0),(2,2,2)$ 的所有组合；(e) $b_1+b_2+b_3=0$；(f) $b_1\le b_2\le b_3$。
*提示*：(a)(d)(e) ✅；(b) 不含零向量；(c) $(1,0,5)+(0,1,5)=(1,1,5)$ 积非零，加法出界；(f) $c=-1$ 破坏序。

**题 2**（3.1 #23）：给 $A$ 添加一列 $b$ 得 $[\,A\ b\,]$，列空间什么时候不变？为什么 $Ax=b$ 可解 $\iff$ $A$ 与 $[\,A\ b\,]$ 列空间相同？
*提示*：不变 $\iff b$ 已是 $A$ 列的组合（$\iff$ 可解）。若 $b\notin C(A)$，新列空间严格变大。

**题 3**（3.2，特殊解实操）：$A=\begin{bmatrix}1&2&3\end{bmatrix}$ 的两个特殊解是什么？再对 $\begin{bmatrix}1&2&3\\2&4&c\end{bmatrix}$ 分别处理 $c\neq6$ 与 $c=6$：秩、自由变量、特殊解各是什么？
*提示*：$(-2,1,0),(-3,0,1)$；$c\neq6$ 时 $r=2$、$x_2$ 自由、$s=(-2,1,0)$；$c=6$ 时 $r=1$、两个自由变量、再加 $s=(-3,0,1)$。

**题 4**（3.2 #50，重要）：$A,B$ 是 $n\times n$ 且 $AB=I$。用 $\mathrm{rank}(AB)\le\mathrm{rank}(A)$ 证明 $A$ 可逆，从而 $BA=I$。
*提示*：$n=\mathrm{rank}(I)\le\mathrm{rank}(A)\le n$，故 $r=n$、$A$ 可逆；$B=A^{-1}$ 自动是双边逆——LA 03 的"单边逆不存在"用秩一句话解决。

**题 5**（3.2 #51）：$A$ 是 $2\times3$、$B$ 是 $3\times2$ 且 $AB=I_2$。证明 $BA\neq I_3$，并构造一例。
*提示*：$\mathrm{rank}(BA)\le\mathrm{rank}(A)\le2<3$。例：$A=\begin{bmatrix}1&0&0\\0&1&0\end{bmatrix}$，$B=A^T$，则 $BA=\mathrm{diag}(1,1,0)$。**矩形世界的右逆不是左逆**——$m\neq n$ 时"伪逆"登场（Ch 4）。

**题 6**（3.3 主例跟进）：对 $A=\begin{bmatrix}1&3&0&2\\0&0&1&4\\1&3&1&6\end{bmatrix}$、$b=(1,6,7)$，写出完全解；再把 $b$ 换成 $(1,6,8)$ 判定可解性。
*提示*：$(1,0,6,0)+c_1(-3,1,0,0)+c_2(-2,0,-4,1)$；$1+6\neq8$，零行处 $0=1$，无解。

**题 7**（3.3 #22）：若 $Ax=b$ 有无穷多解，$Ax=B$（新右端）可能恰有一解吗？可能无解吗？
*提示*：不可能恰一解——无穷多解 ⟹ $N(A)\neq Z$ ⟹ 任何可解的右端都有整条解线（$x_1+c\,s$）。可能无解（$B\notin C(A)$）。

**题 8**（3.3 Challenge #35，K 矩阵回归）：$K$ 是 $9\times9$ 二阶差分矩阵（对角 2、副对角 $-1$），解 $Kx=(10,\dots,10)$。
*提示*：方程即 $x_{i+1}-2x_i+x_{i-1}=-10$，解是抛物线 $x_i=5i(10-i)$：$x=(45,80,105,120,125,120,105,80,45)$，峰值 $125$ 在 $i=5$。九个点恰好落在抛物线上——离散格林函数（LA 04 习题 3 的 $\min(i,j)$ 公式）与 $K^{-1}$ 稠密的又一见证。

## 9. 逻辑推导概念图

下面把全篇的推理链画成一棵树：顶部是出发点（向量空间的八条规则与 $Ax$ 的结构），箭头是推理方向，每一步只用上游的结论。读者可据此核对哪个定理用了哪条假设——把某条出发点遮住，顺着断掉的箭头就能看到它下游塌掉什么。

```text
出发点 A：向量空间八条规则 → 子空间两条检验（加法/数乘封闭）
出发点 B：Ax 恰是 A 的列的组合
│
├─ B → C(A) = 所有 Ax → Ax=b 可解 ⟺ b ∈ C(A)
│   └─ 组合的组合还是组合 → C(A) 是 R^m 的子空间
│
├─ Ax = 0 的解集封闭 → N(A) 是 R^n 的子空间
│   ├─ 消元不改解（EA=R，E 可逆）→ N(A) = N(U) = N(R)
│   │   ├─ 主元列/自由列 → 每个自由变量给一个特殊解
│   │   └─ 特殊解 = 把 R 的自由列整体反号
│   ├─ 计数定理：r（主元变量）+ (n-r)（自由变量）= n
│   │   └─ 矮宽（n>m）必有 Ax=0 的非零解
│   └─ r = 1 → 每行是主元行的倍数 → A = uv^T
│
├─ 任意两个解之差落在 N(A) → 非齐次解集 = xp + N(A)（平移过的子空间）
│   ├─ 特解 xp：自由变量全 0，主元变量从 d 读出
│   └─ 可解条件：R 的零行在 d 中对应位置也为 0 ⟺ b ∈ C(A)
│       ▼
└─ 主结论：秩 r 对 m,n 的位置 → 四种情形
    （恰一解 / 无穷多解 / 0 或 1 解 / 0 或无穷多解）
```

| 出发点 | 买到什么 | 撤掉它失去什么 |
|--------|---------|----------------|
| 数乘封闭（ii）（含 $c=0$） | 零向量免费在内（是推论不是公理）；不过原点的平面一票否决 | 每个集合都要单独检验零向量；$b_1=1$ 这类集合为何不是子空间说不清 |
| 加法封闭（i） | $S\cap T$ 仍是子空间；$N(A)$ 的三行验证 | 两个对角象限拼起来 $(2,3)+(-3,-2)=(-1,1)$ 出界的原因消失——为何并 $S\cup T$ 一般不是子空间无从回答 |
| $Ax$ 恰是列的组合 | 可解判据 $b\in C(A)$；$C(A)$ 免费成为 $\mathbb R^m$ 的子空间 | Worked Example 3.1 A 的不可能性证明（列空间含 $b_1,b_2$ 就必含其一切组合）做不出来 |
| 消元不改解（$EA=R$，$E$ 可逆） | $N(A)=N(U)=N(R)$；特殊解从 $R$ 的自由列反号直接读出 | 特殊解没有印在矩阵上的读法，每个 $Ax=\mathbf 0$ 都要从头手解 |
| 两个解之差落在 $N(A)$ | 完全解 $x=x_p+x_n$；非齐次解集 = 平移过的子空间（不含原点） | $A(cx_p)=cb\neq b$ 这类易错点无从解释；四种情形表塌掉一半 |
| 计数定理 $r+(n-r)=n$ | 矮宽矩阵（$n>m$）必有非零解；自由变量个数 $n-r$ 一眼读出 | 加列使零空间变大、加行只使它变小或不变的方向性失去根据 |

## 10. 小结与下一篇

本篇的两个空间 + 一个结构：

| 对象 | 定义 | 回答的问题 |
|------|------|-----------|
| $C(A)\subseteq\mathbb R^m$ | 列的所有组合（= 所有 $Ax$） | **哪些 $b$ 有解？** |
| $N(A)\subseteq\mathbb R^n$ | $Ax=\mathbf 0$ 的所有解 | **多解时长什么样？** |
| $x=x_p+x_n$ | 特解（自由变量全 0）+ 特殊解的组合 | **全部解的完整描述** |

四种情形表把 LA 02 的"三种失败"升级为精确分类：$r$ 对 $m,n$ 的位置一眼定生死。

但两个深刻的遗留问题：① $C(A)$ 与 $N(A)$ 究竟**多大**（"维数"还未正式定义）？② $A^T$ 也有列空间与零空间——$C(A^T)$、$N(A^T)$ 与 $C(A)$、$N(A)$ 之间有什么关系？答案是全书的封面图：**四个基本子空间**及其维数公式 $r,\ r,\ n-r,\ m-r$，以及它们之间惊人的两两正交结构。那是 LA 06 的内容——系列的中枢篇。
