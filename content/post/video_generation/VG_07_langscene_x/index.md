# 视频生成 07：LangScene-X——稀疏视图的 3D 语言场与离散量化压缩

> 📺 视频生成系列第 7 篇。前篇：[视频生成 06：VideoScene——把视频扩散蒸馏成一步 3D 场景生成](../VG_06_videoscene/)。
> 论文：*LangScene-X: Reconstruct Generalizable 3D Language-Embedded Scenes with TriMap Video Diffusion*（arXiv:2507.02813，ICCV 2025，Fangfu Liu 一作，Hao Li / Jiawei Chi / Hanyang Wang / Minghui Yang / Fudong Wang，Yueqi Duan 通讯，清华 & NTU & 蚂蚁）。
> 系列的「生成什么」阶段走到第三站：03/04 生成**对象**，05/06 重建**场景**，本篇给场景装上**语义**——重建出来的世界不仅要能看，还要能「指哪问哪」。

---

## 1. 这篇论文解决什么问题？

**稀疏视图的开放词汇 3D 场景理解**：输入少至两张图，输出一个 3D 场景表示，支持任意视角渲染 + 任意文本查询（"毛绒玩具在哪？"→ 渲染一张相关性热图，激活最高的位置就是它）。

### 1.1 已有路线与其天花板

| 路线 | 代表 | 机制 | 天花板 |
|---|---|---|---|
| 2D 开放词汇分割 | LSeg | 逐像素 CLIP 特征 + 文本相似度 | 没有真正的 3D——换视角要重算，且无视角间一致性 |
| 逐场景语言场 | LERF / LangSplat / LangSurf | NeRF/3DGS 里嵌 CLIP 特征，**逐场景优化** | ① 要稠密已标定视图（20+ 张）；② 场景专属自编码器压 512 维特征——每换一个场景重训一次，慢且易过拟合；③ 稀疏视图下重建伪影直接污染语义 |
| 可泛化语言高斯 | LSM、GP-NeRF | 前馈模型直接从多图出语义 3D | 限于特定域（物体、室内）；模型容量有限，伪影多 |

### 1.2 LangScene-X 的答案：生成范式统一重建与理解

核心洞察（与 VG 05 一脉相承）：稀疏视图下重建和理解都缺信息，而**缺的信息可以让生成先验补**——并且补的不只是 RGB：**多模态信息（外观/几何/语义）可以统一在同一个视频扩散模型里生成**。三段式：

1. **TriMap 视频扩散**：两张图 → 49 帧 3D 一致的 RGB + 法线图 + 分割图（一次生成三种模态）；
2. **LQC 语言量化压缩器**：512 维 CLIP 特征 → 3 通道**离散**码，在大规模数据上训练一次、所有场景通用——干掉逐场景自编码器；
3. **语言嵌入表面场**：把语义对齐到生成法线定义的 3D 表面上，支持任意视角的开放词汇查询。

实验（LERF-OVS）：mAcc 80.85 / mIoU 50.52——比逐场景优化、用稠密视图的 LangSplat（35.72/15.37）**翻倍还多**，比 2D 的 LSeg（64.17/39.94）也大幅领先。

## 2. 所需背景最小集

1. **CLIP 与密集语言特征**：CLIP 图文共享嵌入空间，文本查询 = 特征空间点积。LSeg 把 CLIP 变成逐像素密集特征；语言场的查询本质是「渲染特征 · 文本嵌入」的相关性图。
2. **语言嵌入场**（LERF → LangSplat）：沿射线/高斯聚合 CLIP 特征。工程痛点：512 维特征 × 百万高斯太贵——LangSplat 用**场景专属自编码器**压到 3 维连续 latent，渲染 latent 再解码；OpenGaussian 用逐场景 codebook。**都是每场景重训**。
3. **VQ-VAE 式向量量化**：连续向量 → 最近邻查表映射到码本条目 $\{e_1,\dots,e_k\}$；查表不可导，用 straight-through 估计器（梯度直通）+ 字典损失训练。本篇的 LQC 是它的语言特征版。
4. **VG 05（ReconX）**：「生成即观测」范式——视频扩散在稀疏视图间插值出新观测。本篇同一课题组，把该范式从「补 RGB 观测」推广到「补 RGB + 几何 + 语义三模态观测」。

## 3. 方法总览

**编号约定**：正文中的 Eq.N 一律指论文原公式编号；被引用的公式块右侧以 \tag{N} 标出同一编号，可与论文对照。

**一句话主线**：输入两张稀疏视图，先让视频扩散模型在两图之间「补」出一批 3D 一致的观测——每帧同时带 RGB（外观）、法线（几何）、分割（语义）三种图，再把 512 维的语言特征压成 3 通道离散码（一次训练、所有场景通用），最后把语义钉在生成法线定义的 3D 表面上拟合语言场——输出一个任意视角可渲染、任意文本可查询的 3D 场景。

| 步骤 | 做什么（白话） | 为什么需要这一步 |
|---|---|---|
| ① TriMap 视频扩散补观测 (§4.1) | 把两张输入图当首尾帧，让视频扩散模型插值出 49 帧互相一致的观测，每帧同时生成 RGB、法线、分割三种模态 | 两张图太稀疏，重建和理解都缺信息；且三种模态由同一个模型一起生成，外观/几何/语义天生对齐，不用事后缝合 (§1.2) |
| ② LQC 量化压缩语言特征 (§4.2) | 把每个像素 512 维的 CLIP 特征压成 3 通道离散码——在一张 2048 条目的共享码本里查最近邻；只在 COCO 上训一次，所有场景通用 | 语言场要给百万级高斯存特征，512 维存不起；压到 3 通道的连续表示又经不住渲染噪声，离散码可像纠错一样「弹回」正确码点；还省掉了老方法每场景重训一个压缩器的开销 (§2) |
| ③ 表面场重建与语义嵌入 (§4.3) | 用生成帧初始化点云并训练 3D 高斯：先用 RGB 和法线把几何练好，再把语义作为每个高斯的 3 通道语言属性贴到法线定义的表面上 | 语义不钉在几何上就会在 3D 空间里涂抹、跨物体渗漏；法线监督分阶段「先全信、再只信自洽的」，防止生成伪影污染几何 |

```
两张稀疏视图
   │
   ├─① TriMap 视频扩散 (CogVideoX DiT 底座, i2v 改为首尾帧插值)
   │     四阶段渐进训练:
   │       (1) 大规模 web 数据 → 通用关键帧插值 (一周)
   │       (2) ~10K 3D 一致视频 (RealEstate10K+ACID) → 学 3D 一致性
   │       (3) + StableNormal 标注的 200 段法线视频 → 学几何
   │       (4) + SAM2 标注的 300 段分割视频 → 学语义
   │     推理: 两张图 → 49 帧 × {RGB, 法线, 分割(s/m/l 三层级)}
   │
   ├─② LQC 语言量化压缩器 (COCO 上训练一次, 全场景通用)
   │     512 维 CLIP → 编码器 → 3 维连续 → 最近邻查表 (码本 K=2048)
   │     → 3 通道离散 latent (可像 RGB 一样渲染) → 解码器 → 512 维
   │
   └─③ 语言嵌入表面场
         DUSt3R 初始化点云 → 3DGS
         5000 步: RGB L2 + 渐进法线正则 (Eq.7-8, 角度过滤)
         +5000 步: 语义 L2 + 2D/3D 聚类损失 (Eq.9)
         高斯带 3 通道语言属性, 查询时渲染→LQC 解码→文本点积
```

三个组件的分工：**TriMap 管「生成足够多且多模态一致的观测」**（稀疏→稠密，单模态→三模态）；**LQC 管「语言特征的存储与传输」**（通用、压缩、可渲染）；**表面场管「把三者钉在同一个几何上」**（语义贴着表面走，不飘在半空）。

## 4. 核心机制完整推导

### 4.1 TriMap 视频扩散：一个模型，三种模态，四步课程

**架构改造（保持预训练先验的最小手术）**：CogVideoX-5B 的 i2v 改为首尾帧插值——首帧 $I_f$、尾帧 $I_e$ 零填充成一个与视频同尺寸的条件视频，因果 VAE 编码后与同尺寸高斯噪声 latent 拼接，迭代去噪。架构尽量不动，预训练知识尽量保留（与 VG 06 的哲学一致：改起点和条件，不动主干）。

**关键设计：渐进式多任务训练**。三种模态（RGB $\mathcal{D}_I$、法线 $\mathcal{D}_N$、分割 $\mathcal{D}_S$）都是 3 通道图，可共享同一 DiT 主干——域映射器 $\mathcal{M}$ 只是数据格式约定。训练目标（Eq.1）是标准扩散损失：

$$
\mathcal{L}_{\text{diff}}=\mathbb{E}_{x,\epsilon\sim\mathcal{N}(0,I),\,t,\,\mathcal{D}_i\in\mathcal{M}}\Big[\big\|\epsilon-\epsilon_\theta(x_t,t,\mathcal{D}_i)\big\|_2^2\Big],\tag{1}
$$

但**训练分四个阶段逐步加模态**：

| 阶段 | 数据 | 步数 | 学到什么 |
|---|---|---|---|
| 1 | 大规模 web 视频 | 一周 | 通用关键帧插值（继承 CogVideoX 先验） |
| 2 | ~10K 段 3D 一致视频（RealEstate10K + ACID） | 2000 步 lr 1e-5 | 帧间 3D 一致性（相机运动 ≠ 内容运动） |
| 3 | +200 段 StableNormal 标注法线 | 800 步 | 几何模态（RGB+法线联合） |
| 4 | +300 段 SAM2 标注分割 | 1000 步 | 语义模态（RGB+法线+分割联合） |

**为什么渐进而不是直接混合训练**：三种模态的域差距大（照片 vs 法线图 vs mask），一次性混训会让小数据模态（200/300 段）被大数据模态淹没、且容易灾难性遗忘预训练先验。渐进课程让每个新模态都**站在已有能力的肩膀上**——阶段 4 学语义时，模型已经会生成 3D 一致的 RGB+法线，语义只要「贴上去」。消融（§6.3）显示去掉渐进训练 mIoU 掉 7.4（51.68→44.25）。这与 VG 04 的 co-evolution（两个模型互相喂数据）是同一问题的两种解法：**多源知识的整合，要么互相喂（模型间），要么排队学（模型内）**。

推理时 TriMap 从两张输入图生成 **三层级分割 $\{\mathbb{M}^h\mid h=s,m,l\}$**（小/中/大粒度）——SAM2 的多粒度输出被蒸馏进了视频扩散的条件分布里。

### 4.2 LQC：语言量化压缩器（Eq.2–6）

**问题**：语言高斯要存特征。512 维 × 百万高斯存不起；LangSplat 的答案是场景专属自编码器压到 3 维**连续** latent——但连续表示在极端压缩（3 通道）+ 大规模数据下保不住语言性质（论文 Fig.7：连续 AE 的 L2 收敛在 1e-3，LQC 到 1e-4）。

**论据**：语言特征天然是**离散的**——同一类别的区域共享相近的特征分布。对离散源，最优压缩是存类别索引（$\log_2 2048=11$ bit），不是存 3 个连续浮点。

**机制**（VQ-VAE 的语言版）：可学习码本 $E=\{e_1,\dots,e_k\}$，$e\in\mathbb{R}^D$（$K=2048$，$D=3$）。CLIP 特征 $x$ 过编码器得 $z_e(x)$，最近邻查表（Eq.2）：

$$
z_q(x)=e_k,\quad k=\arg\min_j\big\|z_e(x)-e_j\big\|_2 .\tag{2}
$$

训练三件套（Eq.3–6）：

$$
\mathcal{L}_r=\big\|x-\text{decoder}\big(z_e(x)+\text{sg}(z_q(x)-z_e(x))\big)\big\|_2^2,\tag{3}
$$

$$
\mathcal{L}_{emb}=\big\|\text{sg}[z_e(x)]-E\big\|_2^2,\tag{4}
$$

$$
\mathcal{L}_{mask}=\big\|\hat{x}\cdot T-x\cdot T\big\|_2^2,\tag{5}
$$

$$
\mathcal{L}_{lqc}=\lambda_1\mathcal{L}_r+\lambda_2\mathcal{L}_{emb}+\lambda_3\mathcal{L}_{mask},\tag{6}
$$

$\lambda=1/0.2/0.5$，在 COCO 上 batch 16 训 500K 步，一次训练全场景通用。逐项读：

- $\mathcal{L}_r$：重构损失，sg（stop-gradient）实现 straight-through——查表挡住了梯度，就把解码器梯度**抄送**给编码器；$\mathcal{L}_{emb}$：字典学习，把码本条目拉向编码器输出（经典 VQ-VAE 两步）；
- $\mathcal{L}_{mask}$ 是 LQC 的独有贡献：**伪 mask 监督**——直接约束文本激活图 $x\cdot T$（特征与文本的点积）在压缩前后一致。重构损失管「特征像」，激活损失管「**查询行为**像」——下游要的本来就是激活图，那就直接监督激活图。

### 4.3 语言嵌入表面场（Eq.7–9）

**底座**：DUSt3R 从生成帧初始化稀疏点云 → 3DGS，每个高斯带一个 3 通道语言属性（LQC 离散 latent 的连续松弛）。训练两阶段：先 5000 步 RGB + 法线，再 5000 步加语义。

**渐进法线正则（Eq.7–8）**：生成的法线先验 $\mathbf{N}$ 监督渲染法线 $\mathbf{N}_p$：

$$
\mathcal{L}_{normal}=\begin{cases}\|\mathbf{N}_p-\mathbf{N}\|_1,& \text{step}<T_n\\[2pt]\|\mathbf{N}_p-\hat{\mathbf{N}}\|_1\end{cases},\tag{7}
$$

$$
\theta_p=\arccos\Big(\frac{\mathbf{N}_p\cdot\mathbf{N}}{\|\mathbf{N}_p\|\,\|\mathbf{N}\|}\Big),\tag{8}
$$

其中 $\hat{\mathbf{N}}$ 把**角度差超过阈值 $\tau_{thr}$ 的区域过滤掉**——两阶段策略：前 $T_n$ 步全信（快速对齐），之后只信「与当前渲染基本一致」的法线（离群剔除）。这与 VG 05 的置信度加权是同一家族——**「该信谁、信多少」的信任分配**——但信号不同：ReconX 用 DUSt3R 的匹配置信度（外部信号），这里用法线角度一致性（自洽性信号，不需要额外模型）。

**语义聚类（Eq.9）**：除语义 L2 外，基于生成分割 $\mathbb{M}$ 的两个聚类约束：

$$
\mathcal{L}_{s2d}=\big\|\hat{\mathbf{F}}_{lang}(v_1)-\hat{\mathbf{F}}_{lang}(v_2)\big\|_2,\quad v_1,v_2\in\mathbb{M},\tag{9}
$$

**同一 mask 内的渲染语言特征应当一致**（把同一物体的特征拉到一起）；$\mathcal{L}_{s3d}$ 在高斯属性上做对应的 3D 聚类（论文该式排版有瑕疵，按上下文读作高斯语义特征相对其簇中心的 KL 型散度，不逐符号转写）。动机：语言特征要**贴着物体表面**——不约束的话，特征会在 3D 空间里涂抹、跨物体渗漏，边界处两个物体的激活互相污染。

## 5. toy 实验：离散码本 = 噪声信道上的纠错解码

LQC 相对连续自编码器的优势，可以抽成一句话：**渲染通道（3DGS 光栅化的噪声 + 边界 alpha 混合）是噪声信道，离散码 + 最近邻查表 = 该信道上的纠错解码**。线性玩具验证这个机制论（numpy，64 类语义，质心单位向量模拟 CLIP 特征，64 个码点排成 4×4×4 网格，最小码距 2/3）：

- **设定**：两条管线共享**同一个理想编码器**（特征 → 最近类质心 → 该类码点）——只比较解码端。渲染通道：内部像素 latent 加每维 0.08 噪声；20% 边界像素 latent = 0.85·code(前表面) + 0.15·code(后表面) + 噪声（alpha 合成，前表面主导）。连续管线直接解码渲染后的 latent（LangSplat 式）；VQ 管线先 snap 到最近码点再解码（LQC 式）。解码器（随机特征 ridge）在干净码点上训练，两管线同一套。
- **指标**：内部像素特征余弦（vs 类质心）/ 区域级定位准确率 / mIoU / 边界父类对齐（解码特征与两个父类质心余弦的较大者）。

| 方案 | 余弦(内) ↑ | 定位(内) ↑ | mIoU ↑ | 边界父类 ↑ |
|---|---|---|---|---|
| **A 不压缩 32 维/像素**（逐像素 2D，无渲染，LSeg 式） | 0.764 | 1.000 | 0.856 | — |
| **B 不压缩·经渲染**（特征空间 85:15 混合） | 0.763 | 1.000 | 0.842 | 0.757 |
| **C 连续 3 通道·干净渲染** | 0.991 | 1.000 | 0.938 | — |
| **D VQ 3 通道·干净渲染** | 1.000 | 1.000 | 0.919 | — |
| **E 连续 3 通道·渲染噪声+混合** | 0.935 | 1.000 | 0.852 | 0.788 |
| **F VQ 3 通道·同样渲染**（LQC 式） | **0.998** | 1.000 | **0.880** | **0.858** |
| **G VQ·噪声 0.50 > 半码距 0.33** | 0.226 | 0.709 | 0.146 | 0.277 |
| **H VQ·码本 K=16 < 类别 64** | 0.464 | 0.369 | 0.241 | 0.452 |
| **I VQ·对等 5:5 混合**（平局） | 0.998 | 1.000 | 0.679 | 0.235 |

六条读法：

- **C vs D（干净条件下等价）**：没有信道噪声时，连续和离散压缩都能近乎无损——**压缩本身不是难点，难的是压缩表示要过渲染信道**。
- **E vs F（核心对照）**：同样噪声，连续解码把噪声**原样传进特征**（余弦 0.935）；VQ 先 snap 后解码，噪声在半码距内被**完全吸收**（0.998）。边界同理：连续混合给出两个父类各 ~0.79 的中间激活（软边界），snap 给出赢者通吃的硬边界（0.858）——这就是论文 Fig.8「更锐利的边界」的机制版。
- **F > A（量化连类内噪声一起抹掉）**：F 的内部余弦 0.998 高于不压缩的 A（0.764）——量化把 CLIP 特征的类内抖动也归零了。对**类别级**查询这是净化；代价是**实例级**区分被抹平（同一类的两个实例特征完全相同）——语言场的查询粒度被码本粒度封顶。
- **G（纠错半径是悬崖）**：噪声范数超过半码距（0.33）后 snap 系统性选错码点，全指标崩盘（0.226/0.709/0.146）。**离散化的保护是有条件的**：3DGS 渲染误差必须小于码距的一半——这是 K=2048（码本密度）与渲染质量之间的隐性合同。
- **H（容量不足 = 混叠）**：码本 16 个码点装 64 类，每 4 类共享一个码点——特征退化为簇均值（0.464），定位接近随机猜（0.369 ≈ 1/同类数）。码本大小就是语义分辨率。
- **I（平局是离散化的盲区）**：两个表面对等混合（各 50%）时，混合点落在两个父码点的中垂面上，往往 snap 到**第三方类别**（父类对齐 0.235）——连续解码反而给出诚实的「一半一半」激活。真实场景里这对应半透明边界或两物体深度交错处。
- 一个玩具外的观察：像素级 argmax 定位对 VQ 有隐性偏见——离散化让同类像素特征完全相同，单个越过纠错半径的坏像素会与真区域**平级**抢 argmax；改成区域级平均激活（LERF 式 relevancy 的真实用法）后偏见消失。指标粒度要与表示粒度匹配。

## 7. 与其他论文的联系

**系列内**：

- **VG 05（ReconX）**：同一课题组的范式延续。ReconX 生成 RGB 观测补几何，本篇生成 **RGB+法线+分割** 三模态观测补几何**和语义**——「生成即观测」从重建任务推广到理解任务。工程差异也值得注意：ReconX 把 DUSt3R 点云作为**条件**注入扩散（Eq.10–11），本篇把 DUSt3R 降级为**初始化器**——3D 一致性主要靠视频扩散自己（阶段 2 的 3D 一致数据微调），条件通路省了。
- **VG 06（VideoScene）**：两篇都把 CogVideoX 改造成稀疏视图插值器。VideoScene 用 MVSplat 粗渲染当蒸馏起点（快），本篇用四阶段课程直接教会底座多模态生成（全）——**效率与模态广度的两条路线**。VideoScene 的 DDPNet「按输入质量选噪声级」与本篇 LQC「按码点距离纠错」是同一个主题的两种表达：生成系统的鲁棒性越来越依赖显式的离散决策。
- **VG 04（Make-Your-3D）**：co-evolution 是**模型间**的知识整合（两个模型互相喂数据），本篇的渐进训练是**模型内**的知识整合（一个模型排队学多域）——多源知识整合的两种课程设计，VG 12 的版图里归为一格。
- **RL 系列预告**：LQC 的 straight-through + 字典学习是离散表示学习的标准组件；VG 09（DreamReward-X）的奖励模型与这里的 L_mask「直接监督下游行为」共享一个方法论——**监督你要的东西，而不是它的代理**。

**系列外**：

- **LangSplat / LangSurf / OpenGaussian**：逐场景语言场的代表；本篇的 LQC 直接对标它们的场景专属自编码器——从「每场景一个压缩器」到「全网一个码本」，是**局部组件到全局资产**的转变（与 VG 06 里 MVSplat 从独立方法变成系统组件同一潮流）。
- **LSM / GP-NeRF**：可泛化路线的前驱（前馈出语义 3D）；本篇证明生成范式（先造稠密多模态观测再拟合）比纯前馈（直接回归）在稀疏视图下天花板更高——与 VG 05 对 MVSplat 的胜利是同一论点的语义版。
- **VQ-VAE（van den Oord）**：LQC 的直系血统；新颖之处在 $\mathcal{L}_{mask}$——把监督从「重构特征」改为「重构查询行为」，这是任务感知压缩（task-aware compression）的小范本。
- **SAM2 / StableNormal**：基础模型给基础模型当标注工——「标注瓶颈」正在从人工转向模型生成，TriMap 的 200+300 段标注视频是这条流水线的缩影。

## 8. 局限与思考

**论文未明说的问题**：

1. **全场景覆盖的机制不明**：TriMap 每次生成 49 帧插值——两张输入视图之间。但语言场要覆盖整个场景（包括输入视图背后），论文没有说明是 ReconX 式滑窗增量生成、还是只评估输入视图间的区域。评估协议（LERF-OVS 的查询视角分布）也没有交代查询视角是否在生成帧覆盖范围内——**「重建到的」和「评估的」范围是否一致**，直接决定数字的解释力。
2. **无运行时数字**：与 VG 06 形成刺眼对比（那边把 2.98 s 写进标题级卖点）。TriMap 49 帧多模态生成的采样步数、语言场 10000 步训练的耗时都未报告——生成范式的理解任务，推理成本几何是悬案。
3. **ScanNet 的 +14.92 与表格对不上**（§6.2 已述）——小笔误，但提醒读者：本系列所有数字以表格为准。

**我的补充思考**：

4. **离散化的三笔账**（toy 的 G/H/I 行）：纠错半径（渲染噪声 < 半码距的隐性合同）、码本容量（语义分辨率 = K）、平局盲区（对等混合 snap 到第三方）。真实系统里 K=2048 对单场景 20–50 个类别绰绰有余，但**开放词汇的「开放」上限被码本封顶**——训练集（COCO）里没有的概念组合，LQC 只能压到最近的码点。语言场的泛化性 = 码本的覆盖度，这是比「CLIP 是开集」更强的一个约束。
5. **量化抹平实例级信息**：toy 的 F 行余弦 0.998 > A 行 0.764——类内抖动被归零。查询「那只**左边的**泰迪熊」需要实例级特征区分，离散码本把这类查询挡在门外（OpenGaussian 的 coarse-to-fine codebook 正是在这个问题上较劲）。**压缩率的收益和查询粒度是一对显式交易**。
6. **多模态一致性的来源值得追问**：三种模态由同一 DiT 生成、共享同一条去噪链——RGB/法线/分割的一致性来自**联合分布**而非后处理对齐。这是「生成式多模态」相对「多模型拼接」（先 LSeg 再法线估计再各自重建）的结构优势：**一致性在生成时一次到位，不用事后缝合**。VG 08（Physics3D）会把模态清单再拉长一格——物理属性。
7. **$\mathcal{L}_{mask}$ 的方法论值得单独记**：监督「文本激活图的一致性」而不是「特征的重构」——下游任务直接进损失。这个模式在 VG 09 会以更大的规模重现（reward model 直接优化人类偏好而非代理指标）。**评估什么就监督什么**，简单到像废话，但压缩/对齐文献里大量工作仍在监督代理。

## 附录 A：toy 实验设定

线性语义世界（numpy，300 图 × 4 查询，seed 固定）：64 类，质心 $t_c\in\mathbb{R}^{32}$ 单位向量（类间余弦 ≈ ±0.18）；CLIP 类内噪声每维 0.15；查询 $T=t_c+0.1\epsilon$。码空间：4×4×4 网格 64 码点（$[-1,1]^3$，最小码距 2/3）。编码器（两管线共享、理想化）：最近质心分类 → 该类码点 + 每维 0.02 编码噪声。渲染通道：内部 latent + 每维 0.08 噪声；20% 边界像素 latent = 0.85·code(c₁)+0.15·code(c₂)+噪声（alpha 合成）。解码器：随机特征 ridge（512 ReLU 单元 + 线性跳连），干净码点 → 质心，两管线同一套。VQ = snap 到最近码点后解码；G 行噪声 0.50；H 行码本 = 64 码点的 k-means 16（解码目标 = 簇均值质心）；I 行混合权重 5:5。指标：内部像素特征余弦；区域级定位（各类内部像素平均激活的类间 argmax）；mIoU（激活 > 0.5·max vs GT 类别 mask）；边界父类对齐 = max(cos(x̂, t_{c₁}), cos(x̂, t_{c₂}))。
