# 视频生成 06：VideoScene——把视频扩散蒸馏成一步 3D 场景生成

> 📺 视频生成系列第 6 篇。前篇：[视频生成 05：ReconX——用视频扩散重建任意稀疏视图场景](../VG_05_reconx/)。
> 论文：*VideoScene: Distilling Video Diffusion Model to Generate 3D Scenes in One Step*（arXiv:2504.01956，CVPR 2025 **Highlight**，Hanyang Wang / Fangfu Liu 共同一作，Jiawei Chi，Yueqi Duan 通讯，清华大学）。
> 本篇是"如何变好"阶段（对齐→搜索→引导）的第一站：**蒸馏**。VG 05 问"视频先验能不能重建场景"，本篇问"能不能快 60 倍地重建"。

---

## 1. 这篇论文解决什么问题？

VG 05（ReconX）确立了"生成即观测"范式：视频扩散模型在两个参考帧之间插值出 32 帧 3D 一致的新视角，喂给 3DGS。但这个范式有两个被继承下来的病：

| 病 | 来源 | 代价 |
|---|---|---|
| **慢** | 视频扩散从纯噪声出发要几十步去噪（CogVideoX-5B 默认 50 步 DDIM，>2 分钟；ViewCrafter 206 s） | 比前馈方法慢几个数量级，"生成即观测"沦为"分钟级观测" |
| **缺 3D 约束** | 视频模型在 2D RGB + 时间一致性上训练，不懂稳定几何 | 生成帧里有动态残留（人走动、物体交互）、相机几何漂移——正是 VG 05 要用置信度加权去兜底的东西 |

**VideoScene 的目标**：两个输入视图（位姿已知，或 COLMAP/DUSt3R 估）→ 一步生成 49 帧 3D 一致视频。结果：**总耗时 2.98 秒**（MVSplat 前馈 + 渲染 ~0.5 s + 一步 DDIM ~2.5 s），对比 CogVideoX-5B 原版 179 s、ViewCrafter 206 s、SVD 934 s——**约 60× 加速**，且质量（FVD 103.4）反超所有基线的 50 步结果。

### 1.1 为什么不直接套一致性蒸馏

把 LCM/一致性蒸馏直接搬到"视频→3D"会失败，论文 §3.2 给出三个理由，每一个都值得咀嚼：

1. **效率**：蒸馏只减少步数，不改变起点——从纯噪声到高质量视频的单步映射本身就难学。
2. **可控性**：标准去噪是从随机分布出发的随机过程，即使有图像条件，也很难强制一致的相机轨迹与 3D 连贯。
3. **起点失配**：标准 SNR 调度下训练用的 $x_T$ 仍残留 $x_0$ 的低频信息，而推理从纯噪声 $x_T$ 出发——**训练和推理的起点分布不一致**，步数越少退化越重（零终端 SNR / 反向蒸馏等修补都不够）。

三点的公共病根：**纯噪声是个低信息起点**。VideoScene 的回答简单粗暴——换掉起点。

## 2. 所需背景最小集

**编号约定**：正文中的 Eq.N 一律指论文原公式编号；被引用的公式块右侧以 `\tag{N}` 标出同一编号，可与论文对照。

1. **一致性模型 / 一致性蒸馏**（论文 §3.1，Eq.1–3）：把引导式反向扩散看作求解 PF-ODE，一致性函数 $\mathbf{f}:(x_t,t)\mapsto x_\epsilon$ 直接把轨迹上任意点映到轨迹起点（ODE 的解），自洽性 $\mathbf{f}(x_t,t)=\mathbf{f}(x_{t'},t')$（Eq.1）。蒸馏损失（Eq.2）让学生在相邻两点 $(x_{t_{n+1}},\hat x_{t_n}^\phi)$ 上输出一致，$\hat x$ 由教师模型一步 ODE 解算（Eq.3）；LCM 把它搬进潜空间并注入 CFG。学成后 $x_\epsilon=f_\theta(x_T,T)$ **一步出样本**。
2. **MVSplat**（VG 05 的对手之一）：图像对 + 位姿 → cross-view transformer + cost volume → 前馈出 3DGS。快（亚秒），插值视角质量好，外推/OOD 弱——**在本文里它被雇佣为"粗渲染器"**，弱点由视频扩散先验补。
3. **Contextual bandit**（论文附录 6.3）：多臂老虎机 + 上下文——agent 观察状态（上下文）选动作，只拿到该动作的奖励，没有完整回报轨迹。比完整 RL 弱一档：**单步决策，无长期信用分配**。本文用它的地方小而准（§4.3）。

## 3. 方法总览

**一句话主线**：输入两张图（带位姿），先让一个前馈模型秒出一张粗但 3D 一致的场景草稿、渲染成视频，再把视频扩散模型蒸馏成"从草稿出发一步跳出精修视频"，最后按草稿质量决定该精修还是该重画——全程 3 秒。

| 步骤 | 做什么（白话） | 为什么需要这一步 |
|---|---|---|
| ① 前馈出粗场景 | 两张图直接塞进 MVSplat，前馈出一张粗 3D 场景（有伪影，但相机几何连贯）（§4.1） | 亚秒级拿到 3D 一致底稿——后面所有生成都贴着它走，几何不用靠去噪过程自己悟 |
| ② 渲染成视频当起点 | 沿插值相机轨迹把粗场景渲染成 49 帧，当作蒸馏的起点而不是纯噪声（§4.1） | 纯噪声是低信息起点；换掉它才能整体跳过最耗时、最没信息的早期去噪步，且训练和推理从同一处出发（§1.1 的起点失配被根治） |
| ③ 一致性蒸馏 | 训练学生模型把"粗渲染 + 一点噪声"一步映回干净视频（§4.1） | 视频扩散 50 步采样要 2 分钟；学成后一步出结果，分钟级压到秒级 |
| ④ 学会选噪声级 | 策略网络 DDPNet 读粗渲染本身，学出"这个输入该加多少噪声"（§4.2） | 粗渲染干净要少加噪声保结构、有伪影要多加噪声让先验重画——固定一档没有安全档，最优值逐输入而变 |
| ⑤ 一步生成 | 推理时：DDPNet 选噪声级，加一次噪，学生一步跳出 49 帧视频 | 前四步合账：0.5 秒渲染 + 2.5 秒一步生成 = 2.98 秒，质量还反超基线的 50 步 |

```
两张输入图 + 位姿 (COLMAP/DUSt3R 可估)
   │
   ├─(MVSplat 前馈: 匹配/融合双视图信息)──> 粗 3DGS 场景 (有伪影, 但 3D 一致)
   │        │
   │   (沿插值相机轨迹 o(c) 渲染 49 帧, Eq.5)
   │        ▼
   │   粗渲染视频 {I_Render} ──(VAE 编码)──> x_0^r   ← 蒸馏的"3D-aware 起点"
   │        │
   │        ├──训练: 随机 t ∈ [0, T'] 加噪 x_t^r = α_t·x_0^r + σ_t·ε
   │        │        一致性蒸馏损失 Eq.6 (学生 vs EMA 学生, 教师一步 ODE)
   │        │        DDPNet 并行训练: 策略网络学选 t (奖励=-MSE, Eq.7-9)
   │        │
   │        └──推理: DDPNet 读 x_0^r 选最优跳步 t*
   │                 x_{t*}^r = α_{t*}·x_0^r + σ_{t*}·ε ──(学生一步)──> 视频
   ▼
2.98 s: 0.5 s 前馈渲染 + 2.5 s 一步生成 (49 帧)
```

两个组件各管一件事：**leap flow distillation**（§3.3）换起点、对齐训练与推理；**DDPNet**（§3.4）在推理时决定"跳到哪"。注意一个精妙的角色反转：VG 05 里视频扩散给 3DGS 当先验（生成喂重建），本文里 3DGS 前馈模型给视频扩散当先验（渲染喂蒸馏）——**谁是谁的先验，取决于谁快**。

## 4. 核心机制完整推导

### 4.1 leap flow：把起点从纯噪声换成 3D 一致的粗渲染

标准一致性蒸馏（Eq.4）：从数据分布采 $x_0$，前向加噪到随机时刻 $t$：

$$
x_t=q(x_0,\epsilon,t)=\alpha_tx_0+\sigma_t\epsilon,\qquad \forall t\in[0,T]. \tag{4}
$$

VideoScene 的改动：$x_0$ 换成粗渲染视频的潜变量 $x_0^r$（Eq.5），且 $t$ 只在 $[0,T']$（$T'<T$）里采：

$$
\{I_{\mathrm{Render}}\}_{\tau=1}^{\mathcal{T}}=g\big(S(I_{\mathrm{Input}}^i,c^i),\,o(c^i)\big),\qquad i=\{0,1\}, \tag{5}
$$

$S$ = MVSplat（稀疏视图重建），$o$ = 插值相机轨迹，$g$ = 渲染器。蒸馏损失（Eq.6）仍是 LCM 形式：

$$
\mathcal{L}_{D}=\mathbb{E}_{x,t}\Big[d\Big(\mathbf{f}_\theta(x_{t_{n+1}}^r,t_{n+1}),\ \mathbf{f}_{\theta^-}\big(\hat{\mathbf{x}}_{t_n}^\phi(x_{t_{n+1}}^r),t_n\big)\Big)\Big], \tag{6}
$$

教师模型从 $x_{t_{n+1}}^r$ 一步 ODE 估计 $\hat x_{t_n}^\phi$，喂给 EMA 学生。**推理完全复刻训练**：从 $x_0^r$ 出发，加噪到 DDPNet 选的 $t^*$，学生一步出结果。

三重收益（论文 §3.3 的论证）：

1. **跳过低信息阶段**：$t$ 近 $T$ 的去噪步最难（先验信息少）、最耗时——粗渲染把 3D 结构直接放到起点，这些步整体被跳过（"leap"之名）。
2. **训练/推理同分布**：两边都从 $x_0^r$ + 加噪出发，标准 CD 的起点失配病根除。
3. **3D 约束内嵌**：$x_0^r$ 本身从 3D 表示渲染而来——相机轨迹、几何连贯在起点就锁定了，不靠去噪过程祈祷。

**代价也明码标价**：输出质量的上限被 $x_0^r$ 的质量夹住——MVSplat 的伪影、模糊都会传进起点。这就是 DDPNet 存在的理由。

### 4.2 DDPNet：选噪声级是 contextual bandit 问题

推理时的两难（论文 §3.4 原文论证）：粗渲染质量高 → 少加噪声，精修细节、保留结构；粗渲染有伪影（结构扭曲、模糊、光照不一致）→ 需要更多噪声，让先验"重画"——但噪声过大又淹没 3D 信息、退回纯噪声生成。**最优跳步 $t^*$ 逐输入而变，且不存在免费的最优折中**。

形式化为 contextual bandit：

| 要素 | 对应 |
|---|---|
| 状态（上下文） | 粗渲染潜变量 $x_0^r$ |
| 动作 | 跳步时刻 $t\in[0,T']$，策略 $\pi_\psi(t\|x_0^r;\psi)$ |
| 奖励 | $r(x_0^r,t)=-\mathcal{L}_{MSE}$，其中 $\mathcal{L}_{MSE}=\mathrm{stopgrad}\big(\|x_0^{pred}(t)-x_0\|_2^2\big)$（Eq.7–8） |
| 学习 | 策略梯度最大化 $\mathcal{L}_{DDP}(\psi)=\mathbb{E}_{t\sim\pi_\psi}[r(x_0^r,t)]$（Eq.9） |

$x_0^{pred}(t)$ 由学生模型去噪一步后反解（Eq.7）。两个工程细节见功力：① **stopgrad + 无梯度回传**——MSE 只更新策略网络，蒸馏主干完全不受扰动（策略是"观测者"不是"参与者"）；② **DDPNet 只在前 4000 步全量训练**——它是 4 层 2D CNN（~0.02 GB，对比主干 66 GB），参数少，早停防过拟合。

**为什么是 bandit 而不是完整 RL**：决策是单步的（选一个 $t$，生成一次，拿一次奖励），没有动作序列、没有延迟回报——用策略梯度学单步决策，恰好是 contextual bandit 的定义。**这是 RL 工具箱在本系列的第一次出场**：最轻的 RL 组件（单步决策）解决的是"超参逐输入自适应"问题；VG 09/10 将看到完整 RL（序列决策 + 奖励模型）如何做对齐与测试时搜索。

## 5. toy 实验：噪声是先验的解锁钥匙

两个机制（leap 起点的价值、动态选噪声级）可以在线性流形世界里分离检验。设定（numpy，2000 场景）：

- **场景**：$x_0\in\mathbb{R}^{32}$ 只在前 8 维（信号维/流形）非零；粗渲染 $x_0^r$ = 信号维加噪（std 0.3）+ **50% 概率在流形外 24 维带伪影**（幅度 2.0——MVSplat 幻觉出的多余几何）。
- **一步模型的现象学**（噪声级 $\lambda$ 的函数）：输出 = 原样保留 $(1-\lambda)$ + 先验投影（流形外成分按 $(1-\lambda)$ 衰减）+ 重画方差 $0.5\lambda\cdot\epsilon$。这是"低噪声=保守局部精修、高噪声=先验驱动重画"的线性漫画——**噪声是先验的解锁钥匙：噪声越大，模型越敢把输入当建议而不是命令**。
- **策略**：读 $x_0^r$ 的流形外能量做逻辑回归 → $\lambda$（DDPNet 的解析化身；奖励 = $-\mathrm{MSE}$ 与论文 Eq.8 同构）。

| 方案 | 干净场景 ↓ | 伪影场景 ↓ | 平均 ↓ |
|---|---|---|---|
| **A 纯噪声起点·一步**（标准一致性蒸馏） | 1.477 | 1.503 | 1.490 |
| **B leap flow 固定小步长** $\lambda=0.1$ | **0.341** | 3.435 | 1.888 |
| **C leap flow 固定大步长** $\lambda=0.9$ | 1.060 | **1.101** | 1.081 |
| **D leap flow + DDPNet 动态策略**（学习版） | **0.320** | 1.109 | **0.715** |
| **E oracle 逐场景最优 $\lambda$** | 0.323 | 1.111 | 0.717 |

四条读法：

- **A 行**：纯噪声起点的一步生成只有先验均值 + 生成方差——粗渲染信息没有通道进场，误差 >1（连"输出零"都不如，因为重画方差全空间注入）。这就是 CogVideoX 一步 FVD 753（比 50 步的 521 还差）的 toy 写照。
- **B vs C 的两难**：小步长对干净输入是精修（0.341，全场最佳单格），对伪影输入是灾难（伪影原样保留并放大相对误差到 3.4）；大步长洗掉伪影（3.44→1.10）但也把真实细节抖掉（0.34→1.06）。**固定 $\lambda$ 没有安全档**——这正是论文 §3.4 论证 DDPNet 必要性的定量版本。
- **D ≈ E**：学习版策略（单特征逻辑回归）追平 oracle——因为"流形外能量"这个状态特征对"该不该重画"几乎完全可分。真实 DDPNet 是 4 层 CNN 读 latent，任务同构：**从输入本身读出输入的质量，再决定信它几分**。
- **伪影场景的 1.11 > 干净场景的 0.32**：即使最优 $\lambda$，重画也只能把伪影洗到"先验均值 + 重画方差"的水平——**起点的病，蒸馏治不了全部**（对应论文 failure case：语义差异过大时生成视频直接穿过关闭的门）。

## 6. 训练与推理细节 + 论文实验

### 6.1 超参速查（§4.1 + 附录）

| 项 | 值 |
|---|---|
| 前馈粗渲染 | MVSplat（参数冻结） |
| 视频扩散底座 | CogVideoX-5B-I2V @ 720×480（50 步 DDIM 原版 >2 min） |
| 微调两阶段 | attention 层预热 900 步 lr 1e-4；蒸馏 20K iterations lr 3e-5（AdamW），只更新 transformer block 的 attention 层 |
| 数据 | RealEstate10K，49 连续帧等间隔采样，首末帧为条件，batch 2 |
| 硬件 | 8×A100 (80G)，两天；显存账：主干 66 GB + leap flow 10 GB + DDPNet 0.02 GB ≈ 76 GB |
| DDPNet | 4 层 2D CNN，仅前 4000 步训练 |
| 推理 | 2.98 s（渲染 0.5 + 一步 DDIM 2.5） |

### 6.2 主对比（Table 1，RealEstate10K 120 个大角度基准场景）

| 方法（步数） | FVD ↓ | 美学 ↑ | 主体一致 ↑ | 背景一致 ↑ |
|---|---|---|---|---|
| SVD（50） | 424.68 | 0.4906 | 0.9305 | 0.9287 |
| DynamiCrafter（50） | 458.27 | 0.5336 | 0.8898 | 0.9349 |
| CogVideoX-5B（50） | 521.04 | 0.5368 | 0.9179 | 0.9460 |
| CogVideoX-5B（1） | 753.02 | 0.3987 | 0.7842 | 0.8976 |
| **VideoScene（1）** | **103.42** | 0.5416 | 0.9259 | **0.9461** |
| VideoScene（50） | 98.67 | 0.5570 | 0.9320 | 0.9407 |

**读表**：VideoScene 一步（103.42）不仅碾压所有基线的一步（753–1221），**还比它们 50 步的结果好 4–5 倍**，且与自己的 50 步（98.67）几乎持平——蒸馏几乎没有质量损失。基线的一步 vs 50 步全线崩（SVD 424→1221），即 §1.1 说的"起点失配在少步数下退化"。

**Cross-dataset**（Table 2，RealEstate10K 训练 → ACID 测试）：VideoScene 一步 FVD 121.93，微调过的 CogVideoX 一步 464.87 / 50 步 114.04——**一步结果超过基线 50 步**，泛化性来自视频扩散先验 + 3D 起点的双重锚定。

**结构一致性**（Fig.5）：从生成视频抽帧对做特征匹配 + RANSAC 对极约束过滤，VideoScene 的内点匹配最多——几何一致性不靠 FVD 间接暗示，被对极几何直接认证。

### 6.3 消融（Table 3）

| 设置 | FVD ↓ |
|---|---|
| 粗渲染视频本身（base） | 171.38 |
| w/o 3D-aware leap flow（3D 微调 + 标准蒸馏） | 543.53 |
| w/o DDPNet（固定跳步） | 106.28 |
| **完整** | **97.53** |

**leap flow 是最大单项**（543.53→106.28 的量级差距）：标准蒸馏的一步生成在这个任务上彻底失败，换掉起点才有一切。DDPNet 贡献收尾的 8.6%——与 toy 里 D vs C 的比例同量级（0.715 vs 1.081 的差距主要来自固定步长的两难）。注意 base 渲染视频本身 FVD 171.38：蒸馏后的输出（97.53）**好于它的起点**——视频扩散先验确实在精修粗渲染，不是单纯复制。

## 8. 局限与思考

**论文自认**：失败案例是输入视图语义差异过大（如门后是完全不同的房间）——生成视频直接穿门而过，因为粗渲染的插值轨迹假设了场景连通性。

**我的补充思考**：

1. **上限被起点夹住**：leap flow 把 3D 一致性放进起点，也把 MVSplat 的能力边界放进起点——MVSplat 插值视角尚可、外推弱的毛病（VG 05 Table II）会直接限制 $x_0^r$ 的质量。toy 的伪影场景行（最优也只有 1.11）是这件事的定量漫画：**蒸馏能洗掉伪影，洗不回没被看见的内容**。粗渲染器换成更强的（如 VG 05 的 ReconX 本身？）会怎样——论文未做，是个自然的后续。
2. **toy 的现象学假设要诚实标注**：一步模型 = $(1-\lambda)$ 保留 + $\lambda$ 投影 + $0.5\lambda$ 重画方差，是"低噪声保守、高噪声重画"的线性漫画。真实一致性模型在 $\lambda$ 轴上的行为远比线性插值复杂（不同频段的恢复次序不同），但"噪声解锁先验"的定性结构是稳健的——VG 11（CFG-Ctrl）将从控制论角度给出同一现象的另一种数学化。
3. **DDPNet 的奖励是 MSE 对 GT**：策略学的是"像训练集"，不是"几何正确"或"用户想要"——奖励函数的来源决定策略的品味。这是奖励设计问题的最小案例，VG 09（DreamReward-X）正面处理"奖励从哪来"。
4. **FVD 不是 3D 度量**：主表用 FVD/美学/一致性（VBench 系），全是 2D 分布距离——论文用 RANSAC 对极匹配补了结构证据，但"3D 场景生成"的评估至今没有像 PSNR 之于重建那样的标准度量。**生成式 3D 的评估学落后于方法学**，这是整个系列的悬案，VG 12 收官时再结。
5. **76 GB 训练显存**：蒸馏的训练成本 ≈ 原模型微调（66+10 GB）——**蒸馏把推理成本换成一次性训练成本**，对 served 模型是划算的交换，对一次性应用则不然。效率的账要分训练/推理两端记。

## 附录 A：toy 实验设定

线性流形世界（numpy，2000 场景，seed 固定）：$x_0\in\mathbb{R}^{32}$ 前 8 维（流形）$N(0,I)$、后 24 维为零；粗渲染信号维加噪 std 0.3，50% 场景流形外加伪影（幅度 2.0 的随机向量）；一步模型 $x_{\hat{}}(λ)=\text{保留}(1-\lambda)\,x_0^r+\text{投影}\lambda\,P(x_0^r)+0.5\lambda\epsilon$（$P$ 零化流形外分量）；A 行纯噪声起点 = 先验均值 + $0.5\epsilon$ 全空间注入；策略 = 流形外能量单特征逻辑回归（200 训练场景，梯度下降），$\lambda=\mathbb{P}(\text{伪影})\times0.98$；oracle = 逐场景解析扫描 $\lambda\in[0,1]$（含流形外重画噪声项）。指标：$\|\hat x-x_0\|/\|x_0\|$。
