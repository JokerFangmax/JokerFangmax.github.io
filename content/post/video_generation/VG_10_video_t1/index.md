# 视频生成 10：Video-T1——视频生成的测试时扩展

> 📺 视频生成系列第 10 篇。前篇：[视频生成 09：DreamReward——3D 生成的人类偏好对齐](../VG_09_dreamreward_x/)。
> 论文：*Video-T1: Test-Time Scaling for Video Generation*（arXiv:2503.18942，ICCV 2025；Fangfu Liu 与 Hanyang Wang 共同一作（前者兼通讯），Yimo Cai、Kaiyan Zhang、Xiaohang Zhan、Yueqi Duan（通讯）；清华 & 腾讯）。
> 「如何变好」的第二个杠杆：搜索。09 把 reward 信号写进训练损失（对齐），本篇把 reward 信号留到推理时用（选择）——同一个信号，两种花法，后果截然不同。

---

## 1. 这篇论文解决什么问题？

**推理时多花算力，能换来更好的视频吗？** LLM 已经给出肯定答案（o1 式的长思考、best-of-N、verifier 引导的树搜索），但视频生成领域的测试时扩展（test-time scaling, TTS）没人系统研究过。两个视频特有的困难：① 帧间强时序连续性——不能像文本那样在任意 token 处自由分支；② 多步去噪过程——「生成一个候选」本身就是几十步的迭代，资源扩展的粒度不好定。

Video-T1 的答案是一个重构：**把视频的测试时扩展看作搜索问题**——从高斯噪声空间到目标视频分布的采样是一条轨迹，TTS = 在轨迹森林里用 verifier 引导的启发式搜索找更好的那条。贡献三条：① 形式化（生成器 G / 测试验证器 V / 启发式搜索 f 三元组）；② 两条搜索算法（Random Linear Search 与 Tree-of-Frames）；③ 六个模型 × 多 verifier 的系统实验——training-free，即插即用。

---

## 2. 所需背景最小集

1. **LLM 测试时扩展**（RL 系列已铺垫）：best-of-N 采样 + verifier 重排；过程奖励 + 树搜索（MCTS）。本篇是这套范式向视频的移植，但「过程」从 token 变成了帧块。
2. **verifier vs reward model 的区别**：VG 09 的 Reward3D 是**训练出来**的偏好代理（进损失、被梯度优化）；本篇的 test verifier 是**现成的、只用来打分**的多模态模型（VisionReward / VideoScore / VideoLLaMA3）——不参与任何训练。这个区别是 §7 对比的核心。
3. **自回归视频生成**：Pyramid-Flow、NOVA 等逐块生成帧——生成到一半的视频是合法中间态，**这是树搜索的前提**（能在中途分支、评估、剪枝）。扩散式模型（CogVideoX：整段联合去噪）没有这个结构，只能整条生成完再比。
4. **VBench**：16 维视频生成 benchmark（质量/语义两大类），本篇的「真值」评估协议。

---

## 3. 方法总览

**一句话主线**：输入一段文本，让不重训的视频生成器从多个不同的初始噪声各生成一版候选视频（或边生成边剪枝），再由只打分、不参与训练的 verifier 挑出最好的一版输出——推理时多花算力，换更好的视频。

| 步骤 | 做什么（白话） | 为什么需要这一步 |
|---|---|---|
| ① 采一批起点 | 文本固定不变，采 $N$ 个不同的初始高斯噪声——每个噪声将来会长成一条不同的候选视频 | 单次生成的质量听天由命；先把「一次抽奖」变成「多次抽奖」，后面才有得挑 (§4.1) |
| ② 按路线生成候选 | 路线 A（线性搜索，所有模型可用）：每个噪声都完整生成到底，得到 $N$ 条成品视频。路线 B（Tree-of-Frames，仅自回归模型）：只在段边界把存活候选各分支两份延续、当场评估剪掉一半再继续生成 | A 最笨最稳、收益有 best-of-N 保底；B 的省钱逻辑是「差的候选不再继续花生成算力」，总代价大幅下降 (§4.2/§4.3) |
| ③ verifier 打分 | 用现成的多模态模型给视频打分；对生成到一半的视频，先预筛「帧够不够清晰、有没有成为好帧的潜力」，再把 prompt 拆成首帧/中间动作/结尾状态三段子问题分别评估 | 搜索的全部收益取决于「分数能不能挑出好视频」；半成品直接打分不可靠，预筛 + 拆问是在提高早期分数对成片质量的预测力 (§4.3) |
| ④ 集成并选最好 | 不同 verifier 的分数没有共同量纲：先各自给候选排名次，再把名次平均，选名次最高的那条输出 | 单个 verifier 有噪声和各自偏好，名次平均能互相抵消；不集成就把挑选质量押在单个模型的好坏上 (§4.3) |

```
文本 prompt c ──► 生成器 G (不重训)
                    │  N 个高斯噪声 z^(i) = 搜索森林的根
                    ▼
┌─ 路线 A: Random Linear Search (Alg.1) ─────────────┐
│  每个噪声完整去噪 T-1 步 → N 条完整视频             │
│  verifier 打分 s^(i) = V(x^(i), c) → argmax        │
│  代价: T·N 个节点, O(TN)                            │
└─────────────────────────────────────────────────────┘
┌─ 路线 B: Tree-of-Frames (Alg.2, 仅自回归模型) ─────┐
│  段边界分支 b_t=2 × 启发式剪枝保 k_t                │
│  ├─ image-level alignment: 半成品帧先验质量再分支   │
│  ├─ hierarchical prompting: 三段式子 prompt 评估    │
│  └─ 自适应分支: 换段时注入额外噪声                  │
│  代价: worst O(TN), 实际 b_t=1 居多 + 几何收缩      │
│        → O(N+T)                                     │
└─────────────────────────────────────────────────────┘
                    ▼
多 verifier 集成: î = argmax (1/|M|)Σ_v c_v·Rank_v(f^i)
```

关键分工：**G 提供「可能性的池」（可以生成什么）**；**V 提供「好坏的标量场」（哪个更好）**；**f 决定「算力怎么花」（在哪儿分支、剪谁）**。TTS 的全部设计空间就在 f 里。

---

## 4. 核心机制完整推导

### 4.1 形式化：视频是噪声空间里的退化树（§3.1）

视频生成器 $G:\ c\mapsto\mathbb{R}^{H\times W\times C\times T}$ 把文本映射为 $T$ 帧视频。把生成过程倒过来看：一个视频对应噪声空间里的一条路径——从根节点（高斯噪声 $\mathbf{z}$）出发，经 $T$ 步到叶子（成片）。**一条视频 = 一条链；$N$ 个初始噪声 = 一片森林**。在此视图上定义三元组：

- 测试验证器 $V:\ \mathbb{R}^{H\times W\times C\times T}\times c\to\mathbb{R}$（视频 + 条件 → 标量分）；
- 启发式搜索 $f:\ G\times V\times(\mathbb{R}^{H\times W\times C})^{N}\times c\to\mathbb{R}^{H\times W\times C\times T}$（输入 $N$ 个根，输出一条根到叶的路径）。

目标：在 $N$ 条（或经分支扩展的更多条）路径中，选最终质量最高的那条。TTS = 加大 $N$、或让 $f$ 更聪明地分配算力。

### 4.2 Random Linear Search（Alg.1）：最笨也最稳的基线

采 $N$ 个噪声 $\mathbf{z}^{(i)}$，每个完整去噪成视频，解码，verifier 打分，取 $\hat i=\arg\max_i s^{(i)}$。代价：$T\cdot N$ 个节点，生成复杂度 $O(TN)$、逐样本评估 $O(1)$。

论文点出它的两个结构性限制：**线性结构**（必须穷举所有候选，没有优化余地）与**孤立结构**（各候选之间无反馈交互——好候选的前缀信息不能复用）。但它的收益有一个干净的统计骨架：若池内样本质量 iid，best-of-N 的期望收益近似

$$
\mathbb{E}[\max_{i\le N} q_i]\;\approx\;\mu+\sigma\sqrt{2\ln N},
$$

**对数级回报**——$N$ 翻倍只换来常数级的质量提升，这就是论文所有 TTS 曲线「随算力增长但逐渐收敛到上限」的机制（§5 toy 实验 1 精确复现这条曲线）。

### 4.3 Tree-of-Frames（Alg.2）：只在段边界花钱

ToF 把搜索搬进生成过程。维护优先队列 $Q$，每步：

1. **分支**：每个存活节点 $f$ 生成 $b_t$ 个延续（自适应分支：仅在段切换处 $b_t=2$，其余时刻 $b_t=1$，并在切换处注入额外噪声增加多样性）；
2. **评估**：启发式奖励 $h_m\leftarrow H(f_m,t)$——verifier 对部分生成视频打分；
3. **剪枝**：候选按累计分数堆排序，保留前 $k_t$ 个。

**复杂度（附录 A.3 的推导）**：单层代价 $O(k_{t-1}b_t+b_t\log(k_{t-1}b_t))$（生成 + 堆排序，逐节点评估 $O(1)$）；整体 $O\big(k_0+\sum_t[k_{t-1}b_t+b_t\log(k_{t-1}b_t)]\big)$。取 $k_0=N$、分支上限 $b=2$ 的最坏情形是 $O(N+TN+2T\log N)=O(TN)$——**与 linear 持平是下界保证**；但由于剪枝只保留均值以下皆弃（$k_t\approx k_{t-1}b_t/2$）、且 $b_t=1$ 占绝大多数时刻，$k_t$ 几何收缩到 1 后每步只剩单路径，总代价化为 **$O(N+T)$**——搜索头的开销 $O(N)$ + 一条完整路径的生成 $O(T)$。

三个让「部分视频也能被有意义地评估」的技术件：

- **Image-level alignment**（附录 A.1）：部分去噪的帧先过一个二值检查（是否清晰到可评估），再过潜在质量检查（有没有成为好帧的潜力），低潜力候选提前拒绝；
- **Hierarchical prompting**（附录 A.2）：用 DeepSeek-R1-8B 把输入 prompt 分解为**三段式子 prompt**——首帧静态场景描述（颜色/物体数/相对位置）、中间帧动作与运动方向、结尾期望状态；各段 verifier 拿对应子 prompt 评估（首帧查核心语义，中间查动作连续性，结尾查整体文-视频对齐）；
- **Multi-verifier**（§3.4）：不同 verifier 量纲不可比，用**秩**做共同货币——$\hat i=\arg\max_i\big(\tfrac{1}{|\mathcal M|}\sum_{v\in\mathcal M}c_v\cdot\mathrm{Rank}_v(f^{(i)})\big)$，$c_v$ 为 verifier 权重。

 hierarchical prompting 的本质值得点破：**提高「早段观测对最终质量的预测力」**。树搜索敢不敢早剪枝，完全取决于部分视频的分数能不能外推到成片——这一点 §5 的 toy 实验 2 会给出精确的机制化版本。

## 5. toy 实验：best-of-N 的统计骨架与剪枝的风险结构

把「生成器」抽象为 $S=8$ 段的路径：每段贡献 $x_s\sim\mathcal N(0,\sigma_s^2)$（总方差归一），视频质量 $q=\sum_s x_s$；「verifier」= 真实质量 + 噪声 $\sigma_v$（多 verifier 平均 → $\sigma_v/\sqrt n$）；对部分视频的打分 = 前缀和 + 同样噪声。Linear = $N$ 条完整路径取 argmax（代价 $S\cdot N$）；ToF = 段 1 保留 $N/2$、段 2 保 2、段 3 保 2、之后单路径（代价 $3N+2S-2$）。蒙特卡洛 3000 次。

**实验 1：N 扫描（均匀世界）**——质量单位 = 池总标准差：

| $N$ | linear 质量 | 代价 | ToF 质量 | 代价 | ToF Δ vs 池展开 | 无噪 best-of-N |
|---|---|---|---|---|---|---|
| 1 | −0.016 | 8 | — | — | — | 0.004 |
| 2 | 0.532 | 16 | 1.171 | 20 | +0.137 | 0.560 |
| 4 | 1.007 | 32 | 1.319 | 26 | −0.095 | 1.029 |
| 8 | 1.403 | 64 | 1.522 | 38 | −0.254 | 1.419 |
| 16 | 1.710 | 128 | **1.690** | **62** | −0.376 | 1.764 |
| 32 | 2.021 | 256 | 1.842 | 110 | −0.495 | 2.067 |

（Δ = 选中质量 − 段 1 全部 $2N$ 候选各自单次展开的最优；负值 = 剪枝丢分，正值 = 后期分支的额外选择增益。）

**实验 2：世界结构 × 剪枝风险**（$N=16$，段 1 前缀与最终质量的相关 $\rho_1$ 由方差分布决定）：

| 世界 | $\rho_1$ | linear | ToF | ToF Δ |
|---|---|---|---|---|
| front（首段解释 44% 方差） | 0.666 | 1.717 | **2.219** | +0.144 |
| equal（每段均等） | 0.354 | 1.719 | 1.637 | −0.447 |
| back（末段主导） | 0.088 | 1.693 | 0.797 | **−1.279** |

**实验 3：生成器池**（$N=16$）：

| 池 | $N{=}1$ 基线 | linear | 提升 | 池上限 |
|---|---|---|---|---|
| 高方差池（大模型） | −0.001 | 1.742 | **+1.743** | 1.771 |
| 低方差池（轻量模型） | −0.004 | 0.346 | +0.350 | 0.443 |
| 能力上限池（cap=0.5，拍手） | −0.221 | 0.484 | +0.704 | 0.500 |

**实验 4：verifier 质量**（$N=16$，无噪上限 1.758）：

| 配置 | linear | ToF |
|---|---|---|
| $\sigma_v{=}0.1$（好 verifier） | 1.755 | 1.727 |
| $\sigma_v{=}0.2$（默认） | 1.727 | 1.645 |
| $\sigma_v{=}0.3$（差 verifier） | 1.685 | 1.579 |
| $\sigma_v{=}0.3$ × 3 verifier 集成 | **1.728** | **1.696** |
| $\sigma_v{=}0.2$ + 偏置 $\beta{=}0.5$ | 1.528 | 1.322 |
| $\sigma_v{=}0.2$ + 偏置 $\beta{=}1.0$ | 1.234 | 0.956 |

六条读法：

- **对数级回报（实验 1）**：linear 的选中质量精确贴住无噪 best-of-N 上限（0.532/1.007/1.403/1.710/2.021 vs 0.560/1.029/1.419/1.764/2.067），按 $\sqrt{2\ln N}$ 增长——**$N$ 从 16 加到 32（算力翻倍）只多换 0.31σ**。论文所有 TTS 曲线的「增长但收敛」就是这条对数曲线的实证版；$\sigma_v=0.2$ 的误选损失很小（两列几乎重合），说明 verifier 噪声在 best-of-N 里是二阶问题。
- **同质量约一半代价（实验 1）**：ToF(16) 质量 1.690 ≈ linear(16) 的 1.710，代价 62 vs 128；ToF(32) 用 110 帧超过 linear(16) 用 128 帧的质量。对应论文 Table 1 的 GFLOPs 3.2 倍差距。
- **剪枝风险完全由 $\rho_1$ 决定（实验 2，核心行）**：front 世界（首帧观测能预测成片）ToF **又便宜又好**（2.219 > 1.717，Δ 为正——早剪枝几乎无损，后期分支反而白赚选择增益）；back 世界（首帧与成片脱钩）ToF 崩到 0.797，剪掉了最好的路径。linear 在三个世界完全不变（总方差相同）——**ToF 的全部风险集中在「早段观测的预测力」上，而 hierarchical prompting + image-level alignment 就是论文把世界从 back 推向 front 的手段**。
- **搜索收益由池决定（实验 3）**：高方差池 +1.743、低方差池只有 +0.350（收益按 $\sigma$ 等比缩水——论文里轻量的 NOVA 只涨 +1.58% 的机制版）；能力上限池把质量推到 cap（0.484 ≈ 0.500）就停——**论文失败案例「A person is clapping」的手部细节：池里根本没有好样本，推理算力买不到不存在的能力**。
- **集成的价值是降噪（实验 4）**：3 个 $\sigma_v{=}0.3$ 的 verifier 取平均 ≈ 单个 $\sigma_v{=}0.17$（1.728 vs 无噪 1.758）——对应论文「集成进一步提升 TTS 并缓解单个 verifier 的偏置」（论文用秩平均做跨量纲集成，降噪机制相同）。
- **偏置的代价是有界误选（实验 4，对照 VG 09）**：verifier 带与质量无关的系统性偏置 $\beta$，$\beta{=}1.0$ 时选中质量降到 1.234——损失 0.5σ，但**仍是正收益、仍在池的分布内**。对比 VG 09 toy 的 B/D 行：梯度优化 + 同样有偏的代理 → 真实偏好 −1288、跑出分布 38σ。**同一份偏好信号，用在梯度里可以被 hack 出分布，用在选择里只能选错池内的样本**——这是对齐（训练时）与搜索（推理时）最深刻的结构性差异。

## 6. 训练与推理细节 + 论文实验

### 6.1 实验设置速查

| 项 | 值 |
|---|---|
| 生成器（6 个，0.6B–5B，全部不重训） | 扩散式：CogVideoX-2B/5B、OpenSora-v1.2；自回归：NOVA、Pyramid-Flow (SD3 / FLUX) |
| 测试验证器 | VisionReward（29 个加权问题）、VideoScore（LMM 初始化 + 人类多维度评分数据训练）、VideoLLaMA3；VBench 作真值 verifier 对照上限 |
| 搜索预算 | Linear：$N=1\sim30$；ToF：$N=1\sim7$（仅 3 个自回归模型） |
| 层级提示词 | DeepSeek-R1-8B（LLaMA-8B 蒸馏）分解为三段子 prompt |
| 代价度量 | 扩展 NFE = 总去噪步数 × latent 时间长度 |

### 6.2 主结果

**Table 1（推理代价，GFLOPs，Linear vs ToF）**：Pyramid-Flow (FLUX) $5.22\times10^7$ vs $1.62\times10^7$；Pyramid-Flow (SD3) $3.66\times10^7$ vs $1.13\times10^7$；NOVA $4.02\times10^6$ vs $1.41\times10^6$——**ToF 稳定省约 2.9–3.2 倍**。

**Table 2（VBench，baseline → +TTS，Total / Quality / Semantic 及三个代表性维度）**：

| 模型 | Total | Semantic | Object Class | Scene | Multiple Objects |
|---|---|---|---|---|---|
| CogVideoX-5B | 81.61→84.42 | 77.04→84.83 | 85.23→99.38 | 53.20→63.07 | 62.11→84.47 |
| CogVideoX-2B | 80.91→83.89 | 75.83→78.39 | 83.37→88.89 | 51.14→52.94 | 62.63→63.79 |
| OpenSora-v1.2 | 79.76→81.65 | 73.39→80.63 | 82.22→98.29 | 42.44→48.82 | 63.34→66.99 |
| Pyramid-Flow (SD3) | 81.72→85.31 | 69.62→79.21 | 86.67→90.31 | 43.20→58.39 | 50.71→78.00 |
| Pyramid-Flow (FLUX) | **81.61→86.51** | 71.61→82.56 | 93.49→99.69 | 47.65→56.07 | **61.08→88.93** |
| NOVA | 78.56→79.80 | 57.63→59.03 | 91.36→93.91 | 45.22→47.69 | 67.87→69.89 |

读表四点：① **六个模型全涨**——training-free 的收益是普遍的；② 涨幅集中在 **Scene / Object Class / Multiple Objects**（+16%/+19%/+45% 量级）——「好不好」容易由 verifier 判断的维度；③ **Motion Smoothness / Temporal Flickering 几乎不动**（论文自认）——verifier 看不见（或奖励不到）的时间维度属性，搜索就无法优化；④ NOVA 只 +1.58%——轻量自回归模型受益边际（toy 实验 3 低方差池）。

**附录 B.3（算力换参数）**：Pyramid-Flow (2B) + TTS 在多个维度上**接近甚至超过 HunyuanVideo (13B) 的单次生成**——推理算力与参数量在质量轴上可互换，这是 TTS 叙事的卖点，也是争议点（§8）。

**分析**：不同 verifier 在同一模型上给出不同增长曲线（各有所重）；多 verifier 集成进一步提升并缓解偏置；大模型受益更多（更宽的搜索空间）。

## 7. 与其他论文的联系

**系列内**：

- **VG 09（正面对照：reward 的两种花法）**：同一份偏好信号，09 让它的梯度进损失（对齐），本篇只用它的取值做选择（搜索）。后果的结构性差异由两篇 toy 合唱：梯度优化 + 有偏代理 = 分布外爆炸（VG 09 B/D 行，−1288）；best-of-N + 有偏代理 = 有界误选（本篇实验 4，$\beta{=}1$ 仍 +1.23σ）。**搜索只能选择、不能创造**——它是 Goodhart-安全的，代价是收益只有 $\sqrt{2\ln N}$ 的对数级。
- **VG 06（VideoScene，效率 vs 质量的两极）**：06 用蒸馏把算力从推理搬到训练（50 步 → 1 步）；本篇把算力在推理时加倍花（1 个 → 30 个候选）。尖锐的问题是中间地带：蒸馏压平了采样步数，是否也压平了样本方差？toy 实验 3 说搜索收益 ∝ 池的方差——**一步模型的输出若趋同，搜索空间也随之坍缩**。「先蒸馏再搜索」还是「留足方差不蒸馏」，是效率-质量曲线上同一枚硬币的两面。
- **VG 08（Physics3D，verifier 的隐/显谱系）**：08 的 SVD 分数场是隐式 verifier（梯度形式直接进 SDS），09 是训练出来的显式 reward model，本篇是现成的显式 verifier——三篇合起来是「评估信号从哪来、怎么用」的完整谱系。
- **VG 12 预告**：四类干预地图（引导/蒸馏/对齐/搜索）至此集齐三翼——搜索杠杆的关键限制「verifier 看得见什么，搜索就优化什么」将与 CFG 的「引导强度有副作用」在 12 篇合流成「干预的代价」总表。

**系列外**：

- **LLM 测试时扩展（o1 / best-of-N / MCTS + process reward）**：Video-T1 的两条算法分别是 rejection sampling 与树搜索的视频版；区别在「过程」的粒度——token 级过程奖励在视频里没有对应物，层级提示词的段式评估是它的粗粒度替代（RL 系列测试时搜索篇的正向汇合点）。
- **Inference-time scaling for diffusion（图像版前驱）**：图像上的 best-of-N / noise selection 已有工作；本篇的新意在树结构利用了视频的自回归性——**架构决定可搜索性**（§8）。
- **VBench / VisionReward / VideoScore**：评估基础设施反过来成为推理组件——「benchmark 当 loss 用」是测试时扩展范式的通用模式（LLM 的 math-verifier 同理）。

## 8. 局限与思考

**论文自认的局限**：Motion Smoothness / Temporal Flickering 等维度提升有限，归因于当前基础模型（verifier 与生成器双方）的限制；失败案例「拍手」的手部细节无法靠加算力修复。

**我的补充思考**：

1. **评估的循环性（与 VG 09 同病）**：增益由 VBench 度量，而 test verifier（VisionReward 等）与 VBench 的维度高度重合——TTS 优化的是「verifier 看得见的维度」，再拿看得见这些维度的 benchmark 验收，增益有自我兑现的成分。真正独立的检验是人工评估或 verifier 与 VBench 不重合的维度（恰是不涨的那些）。
2. **算力的账没算 wall-clock**：NFE 与 GFLOPs 是理论量；30 候选意味着 30 次完整生成的延迟（可并行但要 30 倍硬件）。TTS 在视频这种重负载模态上的实际可用性（延迟敏感 vs 批量离线场景）论文未讨论。
3. **架构决定可搜索性**：ToF 只适用 3 个自回归模型——扩散式的 CogVideoX 整段联合去噪，中途无合法中间态可分支。这是一个被论文轻描淡写的深刻约束：**为可搜索性设计生成架构**（可中断、可分支、段级可评估）可能是下一代视频模型的设计维度，就像 KV-cache 之于推理加速。
4. **$\rho_1$ 是 ToF 的命门（toy 实验 2）**：早剪枝的安全性完全取决于首段观测对成片的预测力。论文用层级提示词人工推高 $\rho_1$，但对首帧质量与成片质量天然脱钩的视频（强运镜、后期才出现的主体、首帧统一的系列视频），ToF 会系统性剪掉好路径——**树搜索不是免费的午餐，它把算力风险换成了结构风险**。
5. **对数回报的经济性**：$\sqrt{2\ln N}$ 意味着算力翻倍只换常数级提升、且很快饱和（toy：N=16→32 只 +0.31σ）。2B+TTS 追平 13B 是漂亮的故事，但 13B+TTS 呢？搜索与规模不是替代关系而是叠加关系——论文没有探索「又大又搜」的边界，那里才是 TTS 真实的性价比问题。
6. **与 VG 09 合读的总教训**：偏好信号进梯度 = 高收益高风险（Goodhart 无界），只进选择 = 低收益低风险（误选有界）。真实系统大概率要两者混用（先用搜索探明池的形状，再用梯度在安全方向上推）——这两篇是同一设计空间的两端，VG 12 会把这条轴画进版图。

## 附录 A：toy 实验设定

搜索 toy（numpy，seed 固定，蒙特卡洛 3000 次）：生成器 = $S=8$ 段路径，段贡献 $x_s\sim\mathcal N(0,\sigma_s^2)$，总方差归一为 1（世界结构 front/equal/back 由 $\{\sigma_s\}$ 的几何分布决定，$\rho_1=\sigma_1$ 为段 1 前缀与最终质量的相关）；verifier = $q+\varepsilon$，$\varepsilon\sim\mathcal N(0,\sigma_v)$，$n$ 个 verifier 平均时 $\sigma_v/\sqrt n$；偏置版观测 $q+\beta s$（$s\sim\mathcal N(0,1)$ 与质量无关）。Linear：$N$ 条完整路径取 argmax，代价 $8N$。ToF：段 1 生成 $2N$ 候选保 $N/2$、段 2 保 2、段 3 保 2、段 4–8 单路径（$b{=}1$）、末段按完整观测选 1，代价 $3N+14$；Δ 池展开 = 选中质量 − 段 1 全部 $2N$ 候选各自独立展开一次的最优质量（反事实参考，非上界——ToF 后期分支的实现在途选择可使其为正）。能力上限池：最终质量 $\min(q, 0.5)$。相对论文的简化：质量是一维标量（真实 VBench 16 维且 verifier 对各维敏感度不同）；段边界与分支数固定（论文自适应）；无 image-level alignment 的二值预筛；「帧代价」按节点数计（论文 NFE 按去噪步 × latent 长度）。
