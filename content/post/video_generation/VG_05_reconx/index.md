# 视频生成 05：ReconX——用视频扩散重建任意稀疏视图场景

> 📺 视频生成系列第 5 篇。前篇：[视频生成 04：Make-Your-3D——主体驱动 3D 生成的分布调和](../VG_04_make_your_3d/)。
> 论文：*ReconX: Reconstruct Any Scene from Sparse Views with Video Diffusion Model*（arXiv:2408.16767，CVPR 2025，Fangfu Liu / Wenqiang Sun / Hanyang Wang 等共同一作，清华 & HKUST，Yueqi Duan 通讯）。
> 本篇开始系列进入"3D 场景生成"阶段：不再生成单个主体，而是整个场景——而且输入只有两三张图。与 VG 04 同一课题组：VG 04 问"怎么生成指定主体"，本篇问"怎么把看到的碎片补成完整世界"。

## 1. 这篇论文解决什么问题？

**Sparse-view 3D 场景重建 / 新视角合成（NVS）**：给定一个场景的两三张照片（少到 2 张），重建完整 3D 场景，支持任意新视角的渲染。

### 1.1 为什么难：病态问题

NeRF / 3DGS 的常规协议是几百张图 + COLMAP 位姿。视图稀疏到个位数时问题是**欠定**的：未见区域（墙壁背面、遮挡处、视角间隙）在观测里没有任何约束，任何填补都自洽——优化器会以伪影、扭曲、模糊的形式"任意选择"一个解。

### 1.2 已有路线与其天花板

| 路线 | 代表 | 一句话机制 | 缺什么 |
|---|---|---|---|
| 正则化稀疏 3DGS/NeRF | SparseNeRF、DNGaussian、FSGS | 逐场景优化 + 深度老师/频率压制防过拟合 | **信息**：正则不携带新信息，未见区域仍空白；需已知位姿 |
| 前馈泛化模型 | pixelSplat、MVSplat | 大数据上训网络，从图像对直接回归 3DGS | **外推/OOD**：分布内尚可，出分布平均答案即错（§6.2 Cross 档崩到 PSNR 11–14） |
| 生成先验重建 | ReconFusion、CAT3D | 扩散模型生成新视角观测（与 ReconX 同范式） | 方向对、旧引擎：SDS 慢（ReconFusion）/ 多视图扩散批次间弱耦合（CAT3D） |
| 位姿无关重建 | InstantSplat（DUSt3R） | 图像对直接回归点云（无需位姿）初始化 3DGS | **信息**：只回归看得见的部分，未见区域仍空 |

（每条路线的机制细节、卡住的原因与直观类比，见下方折叠块。）

<summary><b>展开：四条路线逐条拆解——机制、为什么卡、一句话类比</b></summary>

**路线 1：正则化稀疏 NeRF/3DGS。** 仍是 VG 02 §3 的逐场景优化，但 2–3 张图太容易过拟合，于是往损失里加约束：预训练深度估计器当「老师」罚深度不对（SparseNeRF）、压制高频细节不许模型编造纹理（DNGaussian）。**卡在哪**：§1.1 说了欠定是**信息**问题——未见区域在观测里零信息，而正则化只能防「看得见的区域乱选解」（压伪影、防编造），**它本身不携带新信息**：墙背面该长什么样，深度老师也不知道。结果：伪影变模糊，空白还是空白；且整条路线默认已知位姿。类比：考试缺页，它只帮你把会做的题检查一遍，缺页的题还是空着。

**路线 2：前馈泛化模型。** 不做逐场景优化，而是在大规模「多视角图 + 位姿」数据上训一个网络，输入两张图**直接回归**出一组 3DGS；架构里塞几何先验——极线约束（同一物点在两图中的成像位置受一条几何直线约束，用它限制注意力只沿该看的线看、不全图乱看）。**卡在哪**：回归目标本身高度歧义（同一对图像对应无数合理 3D），网络实际学到的是训练分布内的**「平均答案」**——正是 VG 01 §5.1 的「平均关联而非强绑定」：分布内小视角差时平均答案凑合（§6.2 Easy 档 26+ dB）；要外推（Hard 档视角差 200+ 帧，掉到 16）或换域（Cross 档：训练是室内房间、测试是物体特写，11–14 dB 崩到不可用）时，平均答案就是错答案。且受 3D 训练数据稀缺限制（VG 02 §4.1：带位姿多视角数据贵）。类比：背题库的模型，题库外原形毕露。

**路线 3：生成先验重建。** 与 ReconX 同范式：扩散模型生成新视角观测，把欠定补成良定。**天花板不在范式、在已有实例的引擎**：ReconFusion 走 SDS 式梯度蒸馏（VG 02 §4.3 的病全数继承：逐案例优化小时级、过饱和模糊）；CAT3D 用多视图扩散，每次生成几张、**批次之间的一致性靠运气**（每批独立采样），且闭源。ReconX 换引擎的收益是结构性的：视频扩散的时间注意力让 32 帧在**同一次生成内**被耦合（VG 02 §2.3），帧间一致性不再靠采样运气。

**路线 4：位姿无关重建。** DUSt3R（§2 背景 4 有详）从图像对直接回归 pointmap（每像素的 3D 坐标）+ 置信度，不需要位姿；InstantSplat 拿它的点云当 3DGS 初始化，几分钟收敛。**卡在哪**：DUSt3R 本身也是前馈回归——两张图里**匹配得上的部分**才有点，没看见的区域照样空白（置信度低 = 不可见）。它治的是「位姿难获取」的并发症，没治「信息缺失」的主病。

**统一视角**：四条路线各缺一块——① 缺信息（正则 ≠ 信息）、② 缺外推能力（平均答案出分布即错）、③ 方向对但引擎弱、④ 缺信息（只回归看得见的）。ReconX 的位置 = **路线 3 的方向 + 视频扩散引擎（结构性帧间耦合）+ 3D 结构条件（保证生成的观测贴着已有几何走）**。

</details>

### 1.3 ReconX 的答案：把重建改写成生成

核心一句话（论文原意的直译）：**生成更多观测，把欠定的 3D 创造问题变成良定的 3D 重建问题**。工具是大型预训练视频扩散模型——它看过海量真实世界视频，天然携带"场景长什么样"的先验。但视频扩散不能直接用：**生成的帧之间 3D 视角一致性差**（它是时间轴模型，不是相机轨迹模型），直接拿去训 3DGS 会得到一团浆糊。

ReconX 的三段式解法：① DUSt3R 从稀疏图建全局点云 → 编码为 **3D 结构条件**；② 条件注入视频扩散，在两个参考帧之间**插值**出 32 帧 3D 一致的新观测；③ **置信度感知**的 3DGS 从生成视频恢复场景（生成帧有残余不一致，按置信度加权 + LPIPS 去伪影）。

## 2. 所需背景最小集

（**编号约定**：本篇正文中的 Eq.N 一律指 ReconX 论文的原公式编号；被引用的公式块在右侧以 $\tag{N}$ 标出同一编号，可与论文对照——但各式的完整上下文以论文为准，博客只展开与主线相关的部分。）

1. **扩散模型训练目标**（VG 01）：$\mathcal{L}=\mathbb{E}\|\epsilon-\epsilon_\theta(x_t,t,c)\|_2^2$（论文 Eq.2），$x_t=\sqrt{\bar\alpha_t}x_0+\sqrt{1-\bar\alpha_t}\epsilon$（Eq.1）。ReconX 的视频扩散建在 LDM 潜空间上。
2. **视频扩散先验**（VG 02）：SDS 路线（DreamFusion 系）把扩散当可微先验逐样本蒸馏——慢；ReconX 与 VG 02 讲的"多视图扩散替代 SDS"思路同族，但更进一步：**直接让视频扩散输出一批帧当训练数据**，先验以数据形式进场而非以梯度形式进场。
3. **3D Gaussian Splatting**（论文 Eq.3–5）：场景 = 一组 3D 高斯（位置 $\mu$、协方差 $\Sigma=RSS^TR^T$、不透明度 $\alpha$、SH 颜色 $c$）；光栅化投影 $\Sigma'=JW\Sigma W^TJ^T$，按深度排序 alpha 合成 $C=\sum_i c_i\alpha_i\prod_{j<i}(1-\alpha_j)$。本篇只用到"3DGS = 一个可微的、显式的场景参数化 + 快速渲染器"这层理解。
4. **DUSt3R**（论文 Eq.6–7）：端到端无约束立体——图像对 $(I_1,I_2)$ 直接回归 pointmap $(P_{1,1},P_{2,1})$ 与**置信度图** $\mathcal{C}$，训练损失按置信度加权。关键性质：置信度低 = 像素匹配差 = 该区域 3D 信息不可靠。这个置信度在 ReconX 里被第二次雇佣（§4.4）。
5. **DynamiCrafter**：图像到视频（I2V）扩散模型，ReconX 的底座——首尾帧插值能力是整个 pipeline 的引擎。

## 3. 方法总览

**一句话主线**：输入两三张图，先拼一张场景的 3D 骨架底稿，让视频扩散模型贴着骨架"补"出 32 个新视角的观测，最后掂量着信这些观测、拟合出完整场景。

| 步骤 | 做什么（白话） | 为什么需要这一步 |
|---|---|---|
| ① 建点云底稿 | DUSt3R 每次看两张图直接回归 3D 点 + 可信度，全局对齐拼成一张点云地图（§4.2） | 后面所有生成都需要"场景长什么样"的几何底稿；副产品"可信度"后面还要复用 |
| ② 压成摘要卡 | 把几十万个点压缩成定长的 3D 结构条件（§4.2） | 点太多直接用太贵（注意力平方账）；压成定长才能塞进扩散模型 |
| ③ 视频扩散补观测 | 首尾帧放两个参考视角，中间生成 30 个过渡视角（§3 图） | 未见区域的唯一信息来源——把"缺观测"变成"生成观测"，欠定变良定 |
| ④ 生成时查骨架 | 每帧生成时同时查参考照片和骨架卡（§4.3） | 视频扩散只懂"2D+时间"、不懂相机几何；骨架是几何锚，防各帧各想各的 |
| ⑤ 鲁棒收尾 | 32 帧按逐帧逐像素可信度加权拟合 3DGS（§4.4） | 生成的帧有残余矛盾，无差别地信会被带偏 |

输入 $K$ 张稀疏视图（少到 2 张），输出可渲染任意新视角的 3D 场景（论文 Fig.2）：

```
稀疏视图 I = {I^1..I^K}（无需位姿）
   │
   ├─(DUSt3R: 连通图 G(V,E) → 逐对 pointmap + 置信度
   │   → 全局对齐优化 Eq.9)──> 全局点云 P
   │                                │
   │                    (transformer 编码器 Eq.10:
   │                     FPS 降采样 1/8 + cross-attn + PosEmb)
   │                                ▼
   │                      3D 结构条件 F(P)
   │                                │
   │   参考帧对 (I_ref^{i-1}, I_ref^i) ──(DynamiCrafter I2V,
   │        首尾帧 = 两参考帧;  dual cross-attn Eq.11 注入 F(P);
   │        多条件 CFG;  λ_F tanh 门控)──> 32 帧 3D 一致视频
   │                                │
   │                                ▼
   └────> 置信度感知 3DGS (Eq.14: C·(L1 + SSIM + LPIPS),
           DUSt3R 逐帧置信度; 初始化 = 首末帧 pointmap;
           省略自适应密度控制, 1000 步收敛)
                        │
                        ▼
                 完整 3D 场景（含未见区域）
```

要点先行：

- **视频插值 = 视角插值**：首尾帧放两个参考视图，中间 30 帧"填"的是两视角之间的过渡——这是把视频扩散的时间轴**重新解释为相机轨迹**。前提假设是训练数据（RealEstate10K 房产视频等）里时间推移 ≈ 相机运动，对室内/景观 walkthrough 成立。
- **3D 条件不是可选项**：不加结构条件，视频扩散各帧独立幻觉，3DGS 拿到的是互相矛盾的数据（§5 toy 的 B 行，帧间不一致度 1.19）。
- **最后一段是"脏数据鲁棒拟合"**：生成的 32 帧再好也有残余不一致，置信度加权 + LPIPS 负责"该信谁、信多少"。

三条要点其实是**三层递进的保障**，各治一层病——视频扩散的一致性保证不是一步到位的，是一层一层补出来的：

| 层 | 机制 | 保证什么 | 治不了什么 |
|---|---|---|---|
| 1. 时间注意力（底座自带） | 32 帧同批次耦合（VG 02 §2.3） | 相邻帧**统计连贯**（"画面不该突兀地变"是学出来的） | 帧间几何矛盾：连贯的视频完全可以每帧都合理、帧间互相矛盾（这帧墙米色、下帧浅灰） |
| 2. 3D 结构条件（Eq.10–11） | 全帧共享同一骨架 $\mathcal{F}(\mathcal{P})$ | 帧间**几何一致性**（大幅：消融单项贡献 +3.2 dB） | 残余不一致仍存在——条件是软约束（注意力加权），不是硬投影 |
| 3. 置信度 3DGS（Eq.13–14） | 逐帧逐像素掂量着信 | 脏帧/不可靠区域少污染优化（toy：均匀 0.534 → 加权 0.357） | **一致地错**的帧——置信度度量的是"匹配可靠度"不是"内容正确度"（§8 思考 2 的盲区） |

读法：第 1 层是与 CAT3D 的分界（批次内耦合 vs 批次间零耦合），第 2 层是本文主贡献，第 3 层是收尾的必需品而非锦上添花——只看第 2 层会误以为 3D 条件一劳永逸，toy 的 D 行（25% 系统性坏帧把均匀拟合拖回 B 水平）说明没有第 3 层，好条件生成的好数据照样被脏帧稀释。

<details>
<summary><b>展开：视频扩散模型在这个 pipeline 里到底扮演什么角色——三问三答</b></summary>

**问 ①：视频扩散的作用就是"给定首尾两帧、生成中间帧"？**

对，但要点在「重新解释」。DynamiCrafter 本来是 I2V 插值模型：首尾帧放两头，中间填 30 帧。ReconX 没有改这个机制，改的是**语义**：把「视频的时间轴」重新解释为「相机的轨迹」——首尾帧 = 两个参考视角，中间 30 帧 = 两视角之间的过渡视角。所以它生成的不是"视频"，是**一批新视角的观测**。这个重新解释能成立，靠的是训练数据的性质（§1.3 与 §8：RealEstate10K 房产视频里时间推移 ≈ 相机运动）。

**问 ②：训练数据给了场景先验，所以各帧场景的一致性有部分保证？**

对，但要分清这是哪种"一致"。视频扩散的一致性来自**时间注意力**（VG 02 §2.3）：同一次生成内 32 帧被耦合，相邻帧"看起来连贯"。但这是**统计意义上的连贯**（学出来的"画面不该突兀地变"），不是**几何意义上的一致**（每帧对应同一组 3D 点）。区别很实在：连贯的视频完全可以"每帧都合理、帧间互相矛盾"——这帧说墙是米色、下帧说浅灰，各自都像真的，拼起来 3DGS 就是一团浆糊。这也是它比 CAT3D 强但仍不够的原因：CAT3D 批次间靠采样运气（零耦合），ReconX 单批次内有时间耦合（弱保证），但两者都不是几何保证。

**问 ③：加 3D 结构监督，就是为了修正"2D+时间轴"建模（而非"2D+相机轨迹"）保证不了 3D 一致性的缺陷？**

对，这是全文的核心诊断。视频扩散学的就是外观 × 时间，没人教它相机几何。3D 结构条件的作用是给生成装一个**几何锚**：DUSt3R 点云编码成骨架摘要卡 $\mathcal{F}(\mathcal{P})$，每一帧生成都查这张卡（Eq.11 的 cross-attention）——所有帧被要求"贴着同一副骨架走"，帧间一致从统计耦合升级为共享几何约束。消融里这是单项贡献最大的组件（+3.2 dB，§6.4）。

</details>

## 4. 核心机制完整推导

**整章一句话**：给视频扩散模型装上一张「场景的 3D 骨架图」，让它画出的每一帧都贴着骨架走。四节各回答一个问题，建议带着问题读：

| 节 | 问题 | 一句话答案 |
|---|---|---|
| 4.1 | 装骨架**凭什么值得试**？ | 多喂一份信息，最好情况白赚、最坏情况模型学会无视它（理论只保证不亏） |
| 4.2 | 骨架图**怎么造**？ | 两步：多张局部草图拼成一张全局点云地图 → 浓缩成一张定长的「摘要卡」 |
| 4.3 | 骨架**怎么装进模型而不毁旧能力**？ | 并联不串联：旧「照片接口」照常，旁边加一条带可调音量的「骨架接口」 |
| 4.4 | 画出的帧仍有小矛盾，**怎么收尾**？ | 3DGS 按每帧每像素的可信度掂量着信，可信度直接复用 DUSt3R 的副产品 |

（每节先读白话框架再看公式；Prop.1 的证明细节可跳过，记住「嵌套模型类只增不减」的骨架即可。）

### 4.1 Prop.1：加 3D 条件只赚不赔（及其正确读法）

**白话版**：想象两个班级比赛「画得像真实照片分布」——A 班只发参考照片（图像条件），B 班发参考照片**+场景 3D 骨架图**（3D 条件）。关键观察：**B 班学生完全可以无视骨架图**（白拿参考照片的自由还在），所以 B 班的最优成绩**至少**不低于 A 班；若骨架里有照片读不出的信息（如「墙角往哪边拐」），真用上就能严格更好。这就是 Prop.1 全部内容——先有白话，再读数学。

论文先给一个理论结果为 3D 条件铺路。设渲染数据分布 $q(x)$，扩散模型族 $p_{\theta,\psi}(x)$（$\theta$ 主干参数，$\psi$ 条件嵌入函数），目标是 $\min_{\theta,\psi}\mathcal{D}(q\|p_{\theta,\psi})$（Eq.8）。纯图像条件的方案 $\psi^*=g^*$（CLIP 图像编码），加 3D 先验的方案 $\tilde\psi^*=\{g^*,\mathcal{F}^*\}$。

> **Proposition 1**　设 $\mathcal{D}$ 凸、$\Psi$ 包含所有可测函数，则 $\mathcal{D}(q\|p_{\tilde\theta^*,\tilde\psi^*})<\mathcal{D}(q\|p_{\theta^*,\psi^*})$。

**证明骨架（附录 VII-A，三步黑话先翻译）**：「散度 $\mathcal{D}$」= 两个分布差多远（越接近越好）；「混合分布」= 多个场景的图混在一起的大杂烩分布；「嵌套函数空间」= 一个方案是另一个方案的特例（B 方案能做的事 ⊇ A 方案能做的事）。三步：① **Jensen 不等式**：$\mathcal{D}(\mathbb{E}_s q\|\mathbb{E}_s p)\le\mathbb{E}_s\mathcal{D}(q(x|s)\|p(x|s))$（Eq.15）——逼近似「大杂烩」不难于逼近似「每个场景」的平均（拆开学不会更差）；② **逐场景喂条件**：$\{g,\mathcal{F}\}$ 方案的最优值可写成 $\min_\theta\mathbb{E}_s\min_{g(s),\mathcal{F}(s)}\mathcal{D}$（Eq.16）——3D 条件允许每个场景配自己的骨架（这正是骨架图的本义：场景 $s$ 的骨架只描述 $s$）；③ **特例嵌入**：纯图像方案 = 3D 编码器喂空集 $E(\varnothing)$ 的 3D 条件方案（B 班学生撕掉骨架图就是 A 班）——大方案包含小方案，$\le$ 直接得到；严格号 $<$ 的论证是定性的（逐场景逼近 $q(x|s)$ 比逼近混合的 $q(x)$ 容易）。

**我的读法（两点保留 + 一点真金）**：保留一：$\Psi$ 含一切可测函数 + $\mathcal{D}$ 凸是强假设，且论证的是**最优值**不劣——不保证有限步训练、有限容量下兑现。保留二：严格不等号的论证是直觉性的，不是构造性反例。真金在于：**嵌套模型类的最优值单调性**这个骨架是硬的——3D 条件方案的最优解空间真包含图像条件方案（把 $\mathcal{F}$ 饿死即可退化回去），这与"条件信息只增不减则互信息单调不减"（VG 09 对齐篇会再遇到）是同一族论证。论文用 Prop.1 说明"为什么值得把点云塞进 cross-attention"，而非"塞了必然好"——后者要靠实验和消融说话。

### 4.2 3D 结构条件的构造：从点云到 cross-attention 的 key/value

**白话版**：骨架图分两步造。**第一步拼图**：DUSt3R 每次只能看两张图、各画各的局部草图（坐标系还不统一——你画的原点在门口、我画的在房间中央），Eq.9 把所有草图拼到同一张地图上，拼的时候**只信两边都指认清楚的位置**。**第二步浓缩**：拼好的点云几十万个点，直接用太贵（注意力是平方账，VG 02 §2.3），Eq.10 把它压成一张**定长的摘要卡**：先选 1/8 的代表点，代表点回头向全部点要信息，汇总成 $\mathcal{F}(\mathcal{P})$——之后模型每一帧的生成都要查这张卡。

**全局点云（Eq.9）**：DUSt3R 逐对预测 pointmap 后，在共享坐标系里做全局对齐——每对 $e$ 配变换 $T_e$（旋转平移，把这对图的坐标系摆正）、尺度 $\sigma_e$（对齐大小），置信度加权最小二乘（置信度 = DUSt3R 对「这个点两图都匹配稳了」的打分，分数低的位置在拼图时少听）：

$$
\mathcal{P}^*=\arg\min_{\mathcal{P},T,\sigma}\sum_{e\in\mathcal{E}}\sum_{v\in e}\sum_{i=1}^{HW}\mathcal{C}_i^{v,e}\big\|\mathcal{P}_i^v-\sigma_eT_eP_i^{v,e}\big\|. \tag{9}
$$

**编码器（Eq.10）**：点云 $\mathcal{P}$ → 紧凑 3D 上下文表征 $\mathcal{F}(\mathcal{P})$：

$$
\mathcal{F}(\mathcal{P})=\text{FFN}\big(\text{CrossAttn}(\text{PosEmb}(\tilde{\mathcal{P}}),\ \text{PosEmb}(\mathcal{P}))\big), \tag{10}
$$

其中 $\tilde{\mathcal{P}}$ 是 FPS（最远点采样）降到 1/8 的锚点集——FPS 的选法：每轮选**离已选点最远**的那个点，保证代表点均匀铺开、不扎堆。降采样点当 query（提问者）、原点云当 key/value（信息库）——每个锚点「回头问全量点：这一片的结构是什么」，汇总后把任意大小的点云压成定长表征。PosEmb = 3D 正弦位置编码（多频 $\sin(2^k\pi p)$）+ 可学习 MLP——给每个 3D 坐标注上「位置标签」，注意力才知道谁挨着谁。编码器不加载任何预训练权重，与视频扩散端到端联训——专门适配 DUSt3R 点云的分布特性。

### 4.3 双通道注入：Eq.11 与多条件 CFG

**白话版**：难点是「模型已经会用参考照片画画（预训练能力），怎么加骨架而不毁旧能力」。答案：**并联，不串联**——原有「照片接口」照常工作，旁边加一条新通路。每个注意力层做两次查询：查照片（「这两个参考帧长什么样」）+ 查骨架摘要卡（「场景结构允许什么」），两项相加，配比 $\lambda_\mathcal{F}$ 是**可学习的音量旋钮**（训练自己学会骨架声音开多大）。公式即这句话：

$$
F_{\text{out}}=\text{Softmax}\Big(\frac{QK_g^T}{\sqrt d}\Big)V_g+\lambda_{\mathcal{F}}\cdot\text{Softmax}\Big(\frac{QK_{\mathcal{F}}^T}{\sqrt d}\Big)V_{\mathcal{F}}, \tag{11}
$$

$K_g,V_g$ 来自图像条件嵌入 $g(I_{\text{ref}})$（预训练通道，训练时先做 2000 步预热微调——§6.1），$K_\mathcal{F},V_\mathcal{F}$ 来自 3D 结构条件 $\mathcal{F}(\mathcal{P})$（新通道，独立投影矩阵 $W'_K,W'_V$）。$\lambda_\mathcal{F}$ 用 **tanh 门控自适应学习**（沿用 DynamiCrafter 的技巧；tanh 限制在 $(-1,1)$——音量旋钮拧不出爆炸音）。训练目标（Eq.12）仍是标准扩散损失（VG 01 的 $\mathcal L=\mathbb E\|\epsilon-\epsilon_\theta\|^2$，什么都没改），条件从单通道变 $(c_{\text{view}},c_{\text{struc}})$ 双通道，推理用多条件 CFG（VG 01 §5.2 的 CFG 推广到两条条件各配引导权重）。

**设计品味**：图像通道管"这两个参考帧长什么样"（像素级锚定），3D 通道管"场景骨架在哪"（几何级锚定）。两通道互补而非互替——消融表（§6.4）按「只差一项」的行对读：去掉结构条件掉 **3.2 dB**（25.13→28.31，单项最大），去掉 DUSt3R 初始化掉 1.2 dB，四件全在才到 28.31。

### 4.4 置信度感知 3DGS：Eq.13–14 的两步论证

**白话版**：32 帧虽有骨架锚定，仍可能轻微互相矛盾（这帧说墙是米色、下帧说浅灰）——3DGS 若拿它们当「真照片」无差别地信，会被带偏。理想做法：给每帧每像素标一个「有多不可靠」，拟合时不可靠的少信。妙处在这个「不可靠分数」**不用新训任何东西**：DUSt3R 本来就给「两张图匹配得稳不稳」打分，对生成帧两两跑一遍，副产品直接当权重——**一个预训练模型的边角料，免费当另一个模型的质检员**。

**问题（准确版）**：3DGS 假设训练照片是"带标定相机的真实观测"；生成帧是无约束图像，残余不一致会污染优化。

**第一步（Eq.13）：把每帧像素建成高斯，方差 = 不确定度**（把「少信一点」写成公式：权重 = $\frac{1}{\sigma^2}$，越不可靠 $\sigma$ 越大、发言权越小）。对帧 $i$，预测色 $\hat C_i$、生成色 $C_i$，负对数似然

$$
\mathcal{L}_{I_i}=-\log\Big(\frac{1}{\sqrt{2\pi\sigma_i^2}}\exp\big(-\frac{\|\hat C_i-C_i'\|^2}{2\sigma^2}\big)\Big),\qquad C_i'=\mathcal{A}(C_i,\{C_j\}_{j\ne i}), \tag{13}
$$

$\mathcal{A}$ 是全局对齐函数（用其他帧校准本帧）。**第二步：DUSt3R 置信度恰好就是这个 $\sigma_i$ 的现成估计**——DUSt3R 的置信度图本来就是"像素匹配可靠度"，训练时天然给错配区域低分；对生成帧两两跑 DUSt3R，逐对匹配同时完成全局对齐 $\mathcal{A}$。于是**一个预训练模型的副产品被重新解释为另一个模型损失的权重**——这是全文最经济的一步棋。

最终损失（Eq.14）：

$$
\mathcal{L}_{\text{conf}}=\sum_{i=1}^{K'}\mathcal{C}_i\big(\lambda_{\text{rgb}}\mathcal{L}_1+\lambda_{\text{ssim}}\mathcal{L}_{\text{ssim}}+\lambda_{\text{lpips}}\mathcal{L}_{\text{lpips}}\big)(\hat{\boldsymbol{I}}^i,\boldsymbol{I}^i), \tag{14}
$$

$\lambda$ 取 0.8/0.2/0.5。整条损失一句话读法：**每帧的重建误差 ×（L1+SSIM 管像素与结构 + LPIPS 管感知语义）× 该帧该像素的可信度**——错得离谱的帧自动少发言权；LPIPS 单独要（去生成伪影），因为 L1/SSIM 只看像素数值、对「像不像真的」不敏感。

## 5. toy 实验：线性高斯世界的"生成造观测"

论文消融是端到端的（整条 pipeline 换组件看 PSNR）；为了把**三个机制（先验进场方式 / 3D 锚定 / 置信度加权）**拆开看清楚，构造线性版本（numpy，2000 场景）：

- **场景** $z\in\mathbb{R}^{48}$，前 16 维被两张视图精确观测，**后 32 维完全未见**（欠定的来源）。
- **DUSt3R 点云**：可见维准确；未见维 $= z+\eta$，$\eta\sim N(0,0.45^2)$——单目几何先验给了未见区域**部分**信息（这是点云条件的真实价值：它不是两张视图的无损重编码）。
- **图像条件生成**：未见内容每帧独立采样 $0.4z+\sqrt{1-0.4^2}\,\epsilon_t$——通用场景统计与真实内容相关度 0.4，但**帧间无锚**（没有 3D 条件时各帧各想各的）。
- **3D 条件生成**：未见内容 = 点云的贝叶斯最优猜测 $\kappa z_{\text{pc}}$（$\kappa=1/(1+\sigma_{pc}^2)\approx0.83$）**帧间共享** + 小噪声 0.15。
- **坏帧**：25% 的帧加上本场景共享的偏置向量（模 ≈ 2）——模拟"系统性错误的替代内容"（如生成器把某面墙画成另一个样子：错得自洽、错得一致，不是零均值噪声）。
- **线性 3DGS**：可见维由视图定，未见维 = 帧的加权平均。

| 方案 | 重建误差 ↓ | 帧间不一致度 ↓ |
|---|---|---|
| **A 两视图 3DGS**（无生成） | 0.813 | — |
| **B + 视频生成·仅图像条件**（独立幻觉，均匀 LS） | 0.662 | 1.19 |
| **C + 视频生成·3D 结构条件**（无坏帧·上限） | **0.339** | **0.15** |
| **D = 3D 条件 + 25% 系统性坏帧，均匀 LS** | 0.534 | 0.70 |
| **E = D + 置信度加权**（完整 ReconX） | **0.357** | 0.71 |

四条机制读法：

- **A→B**：通用先验（相关度 0.4）单独进场也有收益（0.813→0.662）——生成器确实"知道场景长什么样"。对应论文消融 17.34→19.70。
- **B→C 的差距是一篇论文的差距**：0.662→0.339，来源有两个——**一致性**（帧间不一致 1.19→0.15：共享锚定 vs 独立幻觉）和**信息**（DUSt3R 单目先验的相关度 0.83 > 通用统计的 0.4）。注意 LS 平均会部分抵消 B 的独立幻觉（均值趋近先验均值），**真实 3DGS 不是平均机**——不一致帧会变成 floater 拉扯优化，线性世界反而低估了 B 的病。
- **C→D**：25% 系统性坏帧把均匀 LS 拖回 0.534（≈B 水平）——好条件生成的好数据会被脏帧稀释。
- **D→E**：置信度加权收回几乎全部损失（0.357 ≈ 上限 0.339）。**诚实标注**：toy 的坏帧（25%、模 2 的系统性偏置）比现实悲观，且论文消融里置信度项只有 +0.5 dB（27.83→28.31）——线性世界里零均值噪声对均匀 LS 本来就无害，置信度加权的真正收益全部来自"系统性偏置"这一部分；现实 3DGS 的非线性病态（floater、局部极小）会把更多误差变成"事实上的偏置"，这是 toy 无法直接量化的部分。

### 6.5 外推能力与增量式 360° 重建

把条件帧从"首末"挪到"首 + 中间"（论文为此专门微调了一版模型：只把末帧条件的位置挪到中间帧），同一条生成链前半段是插值、后半段是**外推**（生成输入里不存在的内容）。更有想象力的是**滑窗增量生成**（Fig.8）：每次从上一步的插值/外推段各选一帧组成新条件对，自回归推进，最后一步用原始首图收口——**仅两张输入图转出一圈 360° 场景**。这是"生成即观测"逻辑的极致推演：观测不够，就一直生成下去。

- **VG 04（Make-Your-3D）**：同一课题组的两面。VG 04 是**主体个性化**（分布调和：两个模型互喂数据），本篇是**场景补全**（生成与重建互喂数据：生成器给重建器造观测，重建器的点云给生成器当条件）。两篇共享"不动预训练模型大架构、只加条件通路"的工程哲学——VG 04 加 image cross-attn 的微调，本篇加 3D 条件的并联 cross-attn（Eq.11 的 $\lambda_\mathcal{F}$ 门控与 VG 04 Eq.6 的参数保持项，都是"新通路不许毁掉旧能力"的安全带）。
- **VG 01（CFG）**：Eq.11 的双通道 + 多条件 CFG 是条件扩散工程的标准收尾；本篇的增量是**条件本身第一次是 3D 的**（点云表征而非文本/图像嵌入）。

**系列外**：

- **CAT3D / ReconFusion**（Google）：同范式的开创者（生成观测解决稀疏重建）；CAT3D 用多视图扩散（一次前向生成一小批视角一致的图，但跨批次无耦合——拼 360° 时批次间一致性没有结构性保证），ReconX 用**视频扩散的时间轴**（一次生成一串连贯帧）+ 3D 结构条件——视频扩散的连贯性红利换来了帧间一致，代价是相机轨迹被绑在"视频式运动"上。
- **DUSt3R / InstantSplat**：DUSt3R 一鱼两吃（初始化 + 置信度）；InstantSplat 是"只用 DUSt3R 能到达的"上限——本篇等于 InstantSplat + 生成器补未见区域。
- **VG 06 预告（VideoScene）**：本篇 32 帧视频扩散采样是主要推理开销；下一篇讲怎么把它蒸馏到一步。

## 8. 局限与思考

**论文未明说的前提**：视频扩散的时间轴 ≈ 相机轨迹，这依赖训练数据的性质（房产/风景 walkthrough 视频）；对时间轴上内容会变的场景（人走动、光影变化）没有保障——I2V 模型会"想要"生成动态，ReconX 需要它只生成相机运动。

**我的补充思考**：

1. **Prop.1 的承诺与兑现**：嵌套函数空间的单调性是"值得试"的论证，不是"必然好"的保证——兑现靠的是 DUSt3R 点云真的携带两张视图之外的信息（单目先验）。toy 的 B→C 差距里，一致性与信息增量两笔账混在一起；若点云对未见区域不含新信息（$\sigma_{pc}\to\infty$，即它只是两张视图的换装重编码），C 的收益只剩一致性一项。**"条件工程"的本质是往条件里塞新信息，而非换一种方式塞旧信息**。
2. **置信度信号的自举风险**：DUSt3R 置信度度量的是"像素匹配可靠度"，不是"生成内容正确度"——生成器可以错得非常"可匹配"（一致地错，如 toy 的坏帧共享偏置 $\mathcal{C}$ 反而高）。论文的消融证明现置信度净收益为正，但"系统性一致错误"是这个置信度方案的盲区（toy 里我让它恰好检测到坏帧，是理想化）。
3. **评估的隐性偏置**：稀疏重建的 PSNR 主要由未见区域决定，而未见区域的"真值"由稠密采集提供——生成先验填的内容若与采集视角的实拍一致则得分。这实际上把 NVS 基准变成了"单场景似然 + 场景先验"的混合测试，OOD Cross Set 的高分（21.05 vs 11.60）到底是重建还是"画得像"，PSNR 分不清，LPIPS 列（0.178 vs 0.425）也只部分回答。这为 VG 09（对齐/评估）埋下伏笔：**当生成器参与重建，重建指标开始衡量生成器的先验质量**。
4. **效率的接力棒**：训练 8×A800 两天换一个场景无关的前向系统；推理时 32 帧 DDIM 采样是主要开销。VG 06 将看到这条 pipeline 的蒸馏版本——一步生成多视图，快两个数量级。

## 附录 A：toy 实验设定

线性高斯世界（`numpy`，2000 场景，seed 固定）：$z\in\mathbb{R}^{48}$，前 16 维两视图可见；DUSt3R 点云未见维 $=z+N(0,0.45^2)$（单目先验相关度 $\kappa\approx0.83$）；图像条件生成 $=0.4z+\sqrt{1-0.4^2}\,\epsilon_t$ 逐帧独立；3D 条件生成 $=\kappa z_{\text{pc}}$ 帧间共享 + 0.15 噪声；坏帧 25%、共享偏置模 2（系统性错误内容）、置信度 0.2；线性 3DGS = 可见维取视图、未见维置信度加权平均。指标：重建误差 $\|\hat z-z\|/\|z\|$；帧间不一致度 = 未见维跨帧逐维标准差均值（信号方差为 1）。
