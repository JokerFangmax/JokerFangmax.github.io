# 为什么要复现一篇 2018 年的穿衣论文

[Learning to Dress](https://doi.org/10.1145/3272127.3275048)（Clegg, Yu, Tan, Liu, Turk; *ACM TOG* 37(6), 2018 — SIGGRAPH Asia）是"角色自主穿衣服"方向的奠基工作：一个 22 自由度的上半身人形，学会把夹克/T恤穿到自己身上。它的核心贡献不是某个网络结构，而是一组**机制设计**——

- 观测五元组 $O = [O_p, O_f, O_h, O_s, O_t]$：本体感受、服装特征环、触觉（21 个 haptic 传感器）、接触面里/外符号、任务方向向量；
- 五项加权奖励 $r = w_1 r_p + w_2 r_d + w_3 r_g + w_4 r_t + w_5 r_r$（进度、形变惩罚、测地接触、任务位移、目标姿态）;
- 以**特征平面穿越**定义穿衣进度：手臂沿轴穿过服装开口的几何事件，而不是模糊的"穿了多少"。

2018 年之后这个方向沉寂了相当长时间——一个常见猜测是：**这条路线对工程细节的依赖太重，外人难以复现**。原文的 DART + 旧版 PhysX PBD 布料栈早已无法在现代机器上原样复现。

所以本项目的问题不是"能不能超过它"，而是把它当成一面镜子：

> **What exactly did Learning to Dress need in order to succeed?**
> —— 到底是什么让 Learning to Dress 成功了？是算法、是观测设计、是奖励塑形，还是仿真器的隐性馈赠？

要回答这个问题,不能上来就写新方法。整个项目由一份 **20 节 spec 驱动**,带三条不可逾越的红线:

1. **先建可信的 2018 风格基线,再谈新方法**——不直接复现新提出的方法;
2. **不直接上全 T 恤穿衣**——先单袖、再夹克、最后 T 恤;
3. **论文没写的细节一律记为显式假设(A1–A17),不静默编造**。

# 最小场景模拟器选型:一段 20 次运行的调试考古

## 为什么需要选型测试

2018 技术栈无法原样复现,唯一可用的候选是 Isaac Sim 4.5.0 / Isaac Lab 2.1.1 的 PhysX 5 FEM deformables。**单候选不等于免考**——spec 要求按 10 项判据(接触稳定性、自碰撞、开口保持、摩擦响应、拉伸控制、重置可靠性、速度、向量化 RL 兼容、接触力可用性、种子可复现)用**实测行为**给出"采用/不采用 + 已知偏差清单",不允许按功能表打勾。

最小场景刻意做得比论文小:一根竖直手臂 capsule + 一个厚壁布质袖管(内径 0.048 m、壁厚 0.025 m、长 0.30 m、$E=10^5$ Pa、$\nu=0.3$、$\rho=150\ \mathrm{kg/m^3}$),摩擦扫 $\mu \in \{0.1, 0.5, 1.0\}$。三个探针:P1 手臂下插穿袖、P2 双侧 pad 挤压(自碰撞)、P3 双生环境确定性对比。

## 四个静默失败模式

这段调试最有价值的产出不是"选型结论",而是**四个每一个都会悄悄毁掉 RL 数据的坑**。它们共同的特点是:不报错、不崩溃、指标看起来"合理",只有交叉验证物理直觉才会现形。

**① 变形体不能 mid-episode 重置**(run17)。`write_nodal_state_to_sim` 把节点位置恢复得分毫不差(与 `default_nodal_state_w` 差值 0.0000),但 kinematic-vs-FEM 的接触对随后失效——袖子从它挂着的手臂上直接穿过去,落在地上(而 static 接触幸存:它确实停在了地面上)。`DeformableObject.reset()` 在 Isaac Lab 2.1.1 里字面意义上是 `pass`。对 RL 这是釜底抽薪:**episode 不能靠写状态重置**,只能 fresh spawn。

**② 侧向挤压杆刺穿袖管**(run18)。长 0.30 m 的 capsule 放在 ±0.15 m 处,半长 0.19 m > 0.15 m——每根都越过中轴 4 cm,把每个袖管的壁刺穿。此前所有"袖子挂在手臂上"的实验,其实是被刺穿的;那次"发现"(摩擦干涉挂住可行)是假的。判据受污染的教训:**每个肯定性结论都要有独立证据链**(这个 bug 同时解释了三件"怪事":3–5× 的元素拉伸、1.4 m/s 的持续振动、摩擦系数无差别)。

**③ PhysX 忽略 kinematic actor 的速度写入**(run19)。`set_velocities` 对 kinematic body 是经典 no-op——Isaac Lab 的 `write_root_velocity_to_sim` 底层走的就是它。这意味着 **run16–19 里所有"插入/挤压"实验其实全是静态场景**:手臂从未动过(insert_frac 恒为 0),摩擦系数当然"没有效应"。kinematic 体唯一可靠的驱动方式是在脚本里积分速度、每步 `write_root_pose_to_sim` 写位姿。这是整个选型测试里代价最高的一个坑,也是 R0 动作接口的直接设计约束。

**④ 对比忘了减环境原点**(run19)。双生环境确定性对比直接拿两个 env 的节点位置相减——而两个 env 在网格里相差 0.6 m。修正后,真实的 rollout 差异是 **1e-4 m 量级**,不是 0.6 m。

顺带一提还有一类低成本但阴险的 USD/工具链坑:默认 prim 必须在根层级、四元数 $-90°$ 而非 $+90°$ 才把 +X 转到 +Z(符号错了袖子静默地头朝下生成,靠 mean-z 告警指标才查出来)、shape spawner 不设 `collision_props` 就不是 collider(袖子曾因此穿过手臂自由落体)。

## 最终判据结果(run20,9 envs,hex 12)

run20 是第一个"真动了"的判据运行:手臂靠位姿积分真实下滑 0.125 m 穿过袖管,pad 真实合拢 0.08 m。

| 判据 | 结果 | 关键数字 |
|---|---|---|
| 接触稳定性 | **PASS** | 全程 finite,$v_{\max}$ 0.12 m/s(滑动中),无翻转 |
| 自碰撞 | **PASS** | 对壁间距 0.049 → 0.005–0.010 m 单调收敛,**未穿透** |
| 开口保持 | **PASS** | 顶部开口半径 0.0297 m 滑动+挤压全程恒定 |
| 摩擦 | 绑定已验证;**过盈配合 μ 饱和** | 见下 |
| 拉伸控制 | **PASS** | 静挂 1.32 / 挤压 1.87,远低于 $r_d$ 饱和区($w_{mid}=25$) |
| 重置 | **FAIL** | workaround: fresh-spawn episodes |
| 速度 | **PASS** | 147 steps/s @ 9 envs(hex 12;cooking 是瓶颈) |
| 向量化 | **PASS** | batched GPU tensors;逐 env 材质 9/9 回读正确 |
| 接触力 | **GAP + 已验证 workaround** | ContactSensor 对 FEM 接触恒读 0;动量差分 $F = m(\bar a + g)$ 实测 4.20 N vs 解析 4.195 N,<0.5% 误差 |
| 确定性 | RL 可用,非 bitwise | 双生环境(原点校正)7.6e-5 – 1.8e-4 m / 400 步 |

两个值得单独展开的发现:

**μ 饱和**。手臂直径比袖管内径大 5 mm 时,袖子在 $\mu = 0.1$ 与 $\mu = 1.0$ 下**都**纹丝不动地挂着(支撑力恰等于重量 4.2 N)。这不是 bug 而是物理:过盈配合的法向力(毫米级弹性压缩 × $10^5$ Pa 量级模量)比 $\mu=0.1$ 维持 4.2 N 所需大几个数量级。结论:**摩擦只有在"间隙尺度"接触下才是一个活的机制**——这恰好是论文的场景(服装留间隙、被夹持、被肢体拖动)。R0 必须按 A11 留间隙,并在冻结材质参数前标定间隙尺度的摩擦响应。

**FEM 接触力盲区**。Isaac Lab 的 ContactSensor 走刚体 contact-reporter 通道,rigid-vs-FEM 接触完全绕开它(30 个 soft-body-view 方法里没有任何 contact 查询)。论文的触觉观测 $O_h$ 恰恰建立在这些力上。可行的替代:动量差分给出**总量**(已验证),R0 的 21 传感器 $O_h$ 用**逐节点接触冲量**按最近传感器 binning 重建——从"传感器读数"变成"重建量",是假设层面的偏差,记入 A5 并纳入 A0–A5 消融审计(重建噪声比原生传感器大,必须做 O_h 噪声检查)。

## 决定

**采用 Isaac Lab 2.1.1 FEM 进入 R0**,附六条显式 caveat(voxel 指标 vs authored 碰撞几何的分辨率耦合、μ 饱和→必须留间隙、kinematic 只能位姿驱动、无 mid-episode 重置、$O_h$ 重建、非 bitwise 确定性→所有对比必须跨种子聚合)。整个复现的审计结构(B0 开环回放、A0–A5 消融、扰动门)存在的意义,恰恰就是检测"结论哪些部分是求解器相关的"——这六条 caveat 会直接喂进那个审计。

# 下一步:R0 单袖环境(设计待确认)

按 spec 优先级 4,R0 是最小可训练环境:最小 DoF 手臂 + 单袖。基于 shootout 的教训,设计要点是:

1. 袖子按 **A11 留 clearance**(摩擦成为活机制的前提);
2. $O_h$ 用**节点冲量重建** 21 传感器(A5 偏差入档);
3. **fresh-spawn episode 协议**(放弃 mid-episode 重置);
4. 手臂动作用**位姿积分**接口;
5. feature loop + 进度 metric 同时接 reward 与 eval,rollout 全程可视化。

RL 算法(TRPO vs PPO)按 A12 的规则决定:在刚体 sanity 任务上比较学习曲线与方差,先跑协议再开 B1 训练——这也是"可信基线"哲学的一部分:算法替换本身也要有依据,不能因为"现代"就默认更好。
