# WM 06：HyDRA——静态画布假设的破口与混合记忆

> 📖 本篇是视觉记忆工程线（[WM 02 VMem](../WM_02_vmem/) → [WM 03 Memory Forcing](../WM_03_memory_forcing/) → [WM 04 RELIC](../WM_04_relic/) / [WM 05 WorldPlay](../WM_05_worldplay/)）的终点，也是它的**自我否定**：前四篇把「记住静态世界」做到了实时，本篇承认世界里**有会自己走的主体**——纯回放从此不够用了。

## 1. 这篇论文解决什么问题

### 1.1 静态画布假设：工程线的公共前提，以及它的破口

先把 WM 02–05 的公共前提摆上桌——**四篇论文的记忆，全都假设世界是一块不动的画布**：

| 篇 | 记忆机制 | 隐含假设 |
|---|---------|---------|
| [WM 02](../WM_02_vmem/) VMem | surfel 几何索引检索过去视图 | 重访 = 回放存过的画面 |
| [WM 03](../WM_03_memory_forcing/) | 几何索引空间记忆 + 训练协议 | 同上（Minecraft 方块世界） |
| [WM 04](../WM_04_relic/) RELIC | KV cache 压缩历史 token | 静态场景一致性，蒸馏出实时 |
| [WM 05](../WM_05_worldplay/) WorldPlay | temporal reframing + Context Forcing | 长程**几何**一致性 |

这个假设下「记忆 = 忠实回放」是最优解（[WM 01](../WM_01_why_memory/) toy 的静态格：检索式停在观测噪声地板）。破口在论文摘要的第一句话里：**物理世界不是画布，是一个住着会自己动的主体的舞台**。行人、动物有自己的运动逻辑；当主体走出相机视野，静态画布式记忆对它无能为力。论文观察到三种具体失败：

| 失败模式 | 症状 | 记忆机制根源 |
|---------|------|-------------|
| **冻结雕像**（frozen statues） | 主体回来时停在出画时刻的姿态 | 记忆只存了出画时刻的快照，回放 |
| **扭曲幻影**（distorted phantoms） | 主体回来但外观/动作变形 | 静态特征与主体特征在 latent 里纠缠，检索历史时无法分离 |
| **凭空消失**（vanishing） | 主体再也不出现 | 检索根本没取回含主体的帧（空镜头） |

### 1.2 Hybrid Memory：档案员 + 追踪者

论文给出的范式定义（**Hybrid Memory**，混合记忆）：模型要同时扮演两个角色——

- **精确的档案员**（precise archivist）：静态背景（建筑、道路）的视角级重建，重访长得一样——这是 WM 02–05 已经解决的静态一致性；
- **警觉的追踪者**（vigilant tracker）：动态主体（行人、奔跑的狗）的**身份与运动**，尤其是出画期间——模型必须「心里推演」看不见的轨迹，保证重入帧时外观连贯、位置合理、运动连续。

用 [WM 01](../WM_01_why_memory/) 的语言：档案员近似 $p(s \mid \text{最近看得见的部分})$，追踪者要近似 $p(s \mid \text{看不见但该继续演化的部分})$——后者正是开篇说的「知道」，需要动力学模型的外推。

论文把难点拆成三条（§3.1），每条都对应后面一个设计：

| 难点 | 内容 | HyDRA 的对应设计 |
|------|------|-----------------|
| **时空解耦** | 相机自运动与主体独立轨迹必须分开算——静态记忆只需「位姿 → 固定 3D 空间」的映射，混合记忆要解缠两者 | 相机位姿显式注入（Eq. 2）；主体轨迹留给记忆与生成先验 |
| **出画外推** | 主体出画后失去全部视觉证据，只能在隐空间隐式模拟其运动 | 亲和检索取回出画侧的关键帧（§4.3）+ 生成先验外推 |
| **特征纠缠** | 扩散 latent 里背景特征与主体特征高度耦合，不分离就检索，主体会「冻进背景」或扭曲 | 3D 卷积记忆分词器造运动感知 token（§4.2） |

一句话：**这篇论文 = 静态画布时代的收官 + 「出画-入画」问题的第一次系统化（数据集 + 指标 + 方法三件套）**。它与 [WM 07 StEvo-Bench](../WM_07_stevo_bench/)、[WM 10 LiveWorld](../WM_10_liveworld/) 同属 2026.03 转折月——问题、评测、解法在同一个月被三篇论文分别立起。

## 3. 方法总览：数据集 + 架构双件套

论文的贡献是三件套：范式定义（§1）+ 数据集 HM-World + 方法 HyDRA。后两者互为表里——**没有出画-入画数据，检索再聪明也学不到重入该长什么样**。

### 3.1 HM-World：第一个混合记忆数据集

**为什么必须自建**：互联网视频中「主体完整出画再入画、且相机轨迹可控」的片段极其稀缺；而且评测需要出画/入画的精确时间戳与主体逐帧位置——自然视频不可能有。于是论文用 Unreal Engine 5 搭了一条**程序化渲染管线**，沿四个维度做组合：

| 维度 | 数量 | 说明 |
|------|------|------|
| 场景 | 17 | 风格多样（对应论文 Fig. 3a） |
| 主体 | 49 | 各种外观的人 + 多种动物，1–3 只一组程序化放置 |
| 主体轨迹 | 10 | 每个主体绑定自己的运动动画，从 10 种预设路径中随机选 |
| 相机轨迹 | 28 | **刻意设计「先左移后右移」等往返运动**，主动制造出画-入画；每条轨迹配多个初始位姿 |

四维组合后**过滤掉不含出画-入画事件的片段**，得到 **59,225 条高保真片段**。每条样本的标注包括：渲染视频、MiniCPM-V 生成的描述文本、相机位姿序列、**所有主体的逐帧位置**、**每个主体的出画与入画精确时间戳**。

与既有数据集的对照（论文 Table 1）：

| 数据集 | 动态主体 | 出画-入画事件 | 主体 3D 位姿 | 相机可动 | 规模 |
|--------|:--:|:--:|:--:|:--:|--|
| WorldScore（ICCV 25） | ✓ | ✗ | ✗ | ✓ | 3K |
| Context-as-Memory（SIGGRAPH Asia 25） | ✗ | ✗ | ✗ | ✓ | 10K |
| Multi-Cam Video（ICCV 25） | ✓（原地动作） | ✗ | ✗ | ✓ | 136K |
| 360°-Motion（ICLR 25） | ✓ | ✗ | ✓ | ✗（相机固定，主体永不出视野） | 5.4K |
| **HM-World（本篇）** | ✓ | ✓ | ✓ | ✓ | **59K** |

读法：前三者要么静态、要么主体原地动；360°-Motion 有主体位姿但相机不动，主体永远在画面里——**出画-入画这一列在此前所有数据集里都是 ✗**。这就是「第一个混合记忆数据集」的实际含义。

### 3.2 HyDRA：分词 + 亲和检索

**文字版流程图**（输入到输出）：

1. **编码**：上下文帧（77 帧）经因果 3D VAE 编码为 latent（时间维 4× 下采样），得到记忆 latent $Z_{\text{mem}}$；目标帧的带噪 latent 由 flow matching 插值构造（§4.1）；
2. **相机注入**：相机位姿序列展平成每帧 12 维向量，经 MLP 编码后空间广播、逐元素加到 DiT 输入特征上（§4.1）；
3. **记忆分词**：记忆 latent 过 **Memory Tokenizer**——一个 3D 卷积（核 2×4×4），把 $Z_{\text{mem}}$ 压成时空感知的记忆 token $M$（§4.2）；
4. **亲和检索**：DiT 的每个 block 里，用**动态检索注意力**（Dynamic Retrieval Attention）替代标准 3D 自注意力——目标帧的 query 与记忆 token 的 key 算逐对亲和度（§4.3），取 top-K（K=10）个 token 的 key/value，与目标序列的**局部窗口**（5 帧）拼接后做标准注意力（§4.4）；
5. **解码**：去噪完成后由 3D VAE 解码出目标帧。

一个容易错过的细节：**检索发生在每一个 DiT 层、每一个去噪步**，且各层选中的 token 不同（补充材料 Fig. 4：亲和检索的选中分布随层与步动态变化，而 FOV 检索全程固定）——检索不是一次性的预处理，而是深度计算图里反复进行的「查档案」动作。

## 4. 核心原理完整推导

### 4.1 训练目标与相机注入

底座是全序列视频扩散：因果 3D VAE + DiT，flow matching 训练。视频 $x$ 编码为干净 latent $z_0$，与高斯噪声 $z_1 \sim \mathcal{N}(0, I)$ 做线性插值得 $z_t$，网络 $u$ 学预测速度 $v_t = z_0 - z_1$：

$$
\mathcal{L}_{\theta}=\mathbb{E}_{z_0,\,z_1,\,t}\big\|\,u(z_t,\,t;\theta)-v_t\,\big\|^2
\tag{Eq. 1}
$$

<details>
<summary><b>速度约定：为什么 v = z₀ − z₁（以及它和推理方向的关系）</b></summary>

论文的插值约定是 $z_t = (1-t)\,z_1 + t\,z_0$：$t=0$ 时纯噪声、$t=1$ 时干净信号。对 $t$ 求导即得瞬时速度

$$
\frac{d z_t}{d t} = z_0 - z_1 = v_t
$$

所以 $v_t$ 指向**干净方向**。推理时从 $z_1$（纯噪声）出发，把学到的速度场 $u$ 从 $t=0$ 积分到 $t=1$，终点即生成 latent。这与 [VG 01](../../video_generation/VG_01_diffusion_basics/) §4.3 的 flow matching 一致——「换坐标把扩散写成 ODE」：损失（Eq. 1）就是**回归**，没有对抗、没有平衡技巧，DDPM 的三件套（$\tilde\mu_t$、ELBO、score 换算）在这里全部塌缩成一条直线。

注意各论文的 $t$ 方向约定不同（有的 $t=1$ 是噪声），读代码时先确认插值方向再对照公式——本篇按论文原文的 $v_t = z_0 - z_1$ 约定书写。

</details>

相机条件：位姿序列 $P = \{(R_i, t_i)\}_{i=1}^{f}$（旋转 9 维 + 平移 3 维）展平拼接为 $c_{\text{cam}} \in \mathbb{R}^{f \times 12}$，经 MLP 编码器 $\mathcal{E}_{\text{cam}}$（沿用 ReCamMaster 的做法），空间广播后逐元素相加：

$$
H_{\text{out}} = H_{\text{in}} + \mathcal{E}_{\text{cam}}(c_{\text{cam}})
\tag{Eq. 2}
$$

**为什么是加性注入而不是 cross-attention**：相机位姿是逐帧对齐的稠密条件（每一帧都有、且只作用于自己的 token），加性调制让「这一帧从哪里看」成为每个 token 的出厂属性——这正对应 [WM 01](../WM_01_why_memory/) 观测方程里的 $c_t$：相机只该改变看到什么，不该改变世界是什么样。**相机走显式通道，主体走记忆通道**——这就是难点表里「时空解耦」在架构上的落点。

### 4.2 记忆分词：为什么检索前要先过 3D 卷积

朴素做法是把整个记忆 latent $Z_{\text{mem}}$ 直接塞进注意力。论文给出两个反对理由：算力，以及**无关信息洪泛**——大量与当前目标无关的历史会把模型的推理路径带偏，产生时空不一致的生成。所以需要一个检索机制；但**在原始 latent 上直接检索是次优的**：raw latent 的静态背景特征与主体运动特征高度纠缠（难点三），既没有表达力、也没有分离度来支撑「找回出画主体」这个查询。

于是引入 3D 卷积记忆分词器 $\mathcal{T}_{\text{mem}}$：

$$
M = \mathcal{T}_{\text{mem}}(Z_{\text{mem}}), \quad M \in \mathbb{R}^{C' \times f'_{\text{mem}} \times h \times w}
\tag{Eq. 3}
$$

3D 卷积（核 2×4×4）**同时在时间与空间维上扩感受野**：一个 token 聚合多帧、多位置的信息——论文称之为「运动感知」（motion-aware）表示。消融会证明时间维是关键（§6.3：$T{=}1$ 掉 1.281 PSNR）。直觉：主体的「运动」是跨帧差分量，2D 分词器（逐帧压缩）看不见它；要检索「这个主体刚才怎么走的」，token 里必须先有运动信息。

### 4.3 亲和度：内容检索的打分函数

目标 latent $Z_{\text{tgt}} \in \mathbb{R}^{C' \times f_{\text{tgt}} \times H' \times W'}$ 投影出 query，记忆 token $M$ 投影出 key/value。逐目标帧 $i$ 处理：先把 $q_i$ 空间池化到与记忆 token 相同的分辨率 $h \times w$（记 $\tilde{q}_i$），然后与每个记忆时间片 $k_{\text{mem},j}$ 算亲和度：

$$
S_{i,j} = \frac{1}{\sqrt{d}} \sum_{y=1}^{h} \sum_{x=1}^{w} \Big\langle \tilde{q}_i(x,y),\; k_{\text{mem},j}(x,y) \Big\rangle
\tag{Eq. 4}
$$

其中 $\langle \cdot, \cdot \rangle$ 是通道内积，$d$ 为通道数。

<details>
<summary><b>Eq. 4 的读法：一个「帧对级」的全局注意力分数</b></summary>

标准注意力的 logit 是**单 token 对**的内积 $\langle q, k \rangle / \sqrt{d}$。Eq. 4 把它升级一层：$q$ 和 $k$ 不再是向量而是**特征图**（$C' \times h \times w$），Eq. 4 把 $h \times w$ 个空间位置上的通道内积**求和**——即「帧 $i$ 与记忆片 $j$ 的相似度 = 两者在所有空间位置上的逐点相似度之和」。

它有三个值得注意的性质：

1. **内容驱动**：$S_{i,j}$ 只依赖特征相关性，不依赖任何相机几何——一个空镜头（无主体）与「想画主体」的 query 亲和度天然低，这就是它能避开 FOV 检索取回空镜头的机制根源；
2. **分辨率对齐靠池化**：目标 latent 与记忆 token 分辨率不同（$H' \times W'$ vs $h \times w$），池化 $\tilde{q}_i$ 是廉价的对齐手段——粗粒度匹配够用于「选哪些 token」，精细信息留给后续注意力；
3. **它本身就是注意力的低成本预筛**：如果没有 top-K，直接对全部记忆 token 做全分辨率注意力就是标准 cross-attention；Eq. 4 相当于用 $1/h^2$ 的代价先算一遍「该看哪里」，再对选中的少数 token 做贵的计算——**检索 = 注意力的两级稀疏化**。

</details>

### 4.4 Top-K 检索 + 局部窗口：长程与短程的分工

按亲和度取 top-K 个记忆 token（$K=10$）：

$$
\mathcal{I}_i = \text{TopK}(S_i,\, K), \quad K_{\text{sel}} = \{ k_{\text{mem},j} \mid j \in \mathcal{I}_i \}, \quad V_{\text{sel}} = \{ v_{\text{mem},j} \mid j \in \mathcal{I}_i \}
\tag{Eq. 5}
$$

同时，目标序列中以帧 $i$ 为中心的**局部窗口** $W_i$（5 帧）的 key/value 被强制并入：

$$
K'_i = [K_{\text{sel}},\, K_{\text{loc}}], \quad V'_i = [V_{\text{sel}},\, V_{\text{loc}}]
$$

$$
\text{Attention}(q_i,\, K'_i,\, V'_i) = \text{Softmax}\Big( \frac{q_i (K'_i)^{\top}}{\sqrt{d}} \Big) V'_i
\tag{Eq. 6}
$$

**为什么局部窗口必须强制保留**：检索负责长程（出画主体的下落），但去噪的**局部稳定性**靠邻近帧的互相注视——目标片段内部的运动连续性如果也交给检索，top-K 一旦没选中近邻，帧间运动就断了。论文的表述是「保持原自注意力的结构完整性」。用 [WM 01](../WM_01_why_memory/) 的话说：局部窗口管 $\Delta \approx 0$ 的「现在时」，检索管 $\Delta$ 大的「过去时」——**记忆机制天然是按离开时长分层的**（本篇 toy §7 会把 $\Delta$ 拎出来当横轴）。

### 4.5 评测指标 DSC：把「重入主体」单独拎出来量

PSNR/SSIM/LPIPS 量整体重建，VBench 的 Subject/Background Consistency 量帧级连贯，但都不专门针对「出画后重入的主体」。论文提出 **DSC**（Dynamic Subject Consistency）：用 YOLOv11 检出三段视频（预测/真值/上下文）里运动主体的包围盒，裁出主体区域，过 CLIP 提特征，空间对齐 + 时间归一化后算余弦相似度：

$$
\text{DSC}_{GT} = \text{sim}\big(F^{\text{pred}}, F^{gt}\big), \quad \text{DSC}_{ctx} = \text{sim}\big(F^{\text{pred}}, F^{ctx}\big)
\tag{Eq. 7}
$$

两个分数各拴住一头：$\text{DSC}_{ctx}$ 问「重入的主体像不像出画前的那个」（**身份/历史对齐**——回到过去），$\text{DSC}_{GT}$ 问「重入的主体位置与状态对不对」（**演化保真**——推进过去）。这一对正好对应 [WM 01](../WM_01_why_memory/) 静态一致性/状态演化失败的二分，也预告了 [WM 07](../WM_07_stevo_bench/)–[09](../WM_09_memobench/) 诊断三连的核心关切。

<details>
<summary><b>评测循环性：DSC 的工具链依赖</b></summary>

DSC 的链条是「YOLOv11 检测 + CLIP 特征 + 余弦相似度」——用视觉基础模型给视频世界模型打分。[WM 01](../WM_01_why_memory/) §7 把「评测循环性」列为系列的五个开放问题之一：自动指标与 VQA 的增益里有多少是工具自我兑现？本篇的做法值得注意的两点：

- DSC 只做**检测与特征比对**，不生成内容——比「用 LLM 判 LLM」的循环弱一层；
- 但 CLIP 特征对**位置**不敏感（它管外观与语义）——Eq. 7 量的是「像不像」，不是「在不在正确的位置」。论文正文没有按离场时长 $D$ 分桶报告 DSC（本篇 toy §7 补上这个维度）；位置保真最终要靠 HM-World 的逐帧主体位置标注——这部分标注在正文指标里其实没有被直接使用。

</details>

## 6. 实验与消融

### 6.1 主结果：全面但幅度温和

| 方法 | PSNR↑ | SSIM↑ | LPIPS↓ | DSC_ctx↑ | DSC_GT↑ | 主体一致↑ | 背景一致↑ |
|------|------|------|--------|---------|---------|-----------|-----------|
| Baseline（Wan 1.3B + 相机编码器，上下文直接拼接） | 18.696 | 0.517 | 0.356 | 0.812 | 0.837 | 0.903 | 0.925 |
| DFoT（ICML 25，邻居上下文窗口） | 17.693 | 0.482 | 0.410 | 0.803 | 0.826 | 0.893 | 0.913 |
| Context-as-Memory（FOV 检索） | 18.921 | 0.530 | 0.342 | 0.816 | 0.839 | 0.911 | 0.922 |
| **HyDRA** | **20.357** | **0.606** | **0.289** | **0.827** | **0.849** | **0.926** | **0.932** |

三个值得停下来看的读数：

1. **Baseline 输给所有带记忆机制的对手**——把全部上下文无差别拼进输入（77 帧洪泛）连「检索一部分」都不如，呼应 §4.2 的「无关信息洪泛」论证：记忆的价值一半在**存**，一半在**不取回什么**；
2. **DFoT 垫底**：邻居窗口只有时间局部性，重访/重入需要的长程信息根本没有通道——时间近邻 ≠ 内容相关（[WM 02](../WM_02_vmem/) VMem 的老论点在动态主体上重演）；
3. **HyDRA 对 Context-as-Memory 的 +1.436 PSNR** 是本篇最干净的对照：两者都是「检索式记忆」，唯一区别是**打分函数**（FOV 几何重叠 vs Eq. 4 内容亲和）与**检索单元**（帧 vs 运动感知 token）——§6.3 的消融会把这两个变量拆开。

### 6.2 对照商业模型：WorldPlay 零样本

| 方法 | PSNR | LPIPS | DSC_ctx | DSC_GT |
|------|------|-------|---------|--------|
| WorldPlay（零样本，未微调） | 14.855 | 0.500 | 0.822 | 0.832 |
| HyDRA | 20.357 | 0.289 | 0.827 | 0.849 |

PSNR 差 5.502——但这个对照的**公平性有限**（WorldPlay 没在 HM-World 上微调，域分布差距直接砸在像素级指标上）。论文自己点出了真正有趣的读数：WorldPlay 的 $\text{DSC}_{ctx}$ 高达 0.822（几乎追平 HyDRA 的 0.827）——**大规模训练出来的商用模型对「重入主体像不像出画前」有一定的鲁棒性**，弱在 $\text{DSC}_{GT}$（重入状态对不对）。这条观察既佐证了 DSC 指标测的东西真实存在，也预告了 [WM 08 WRBench](../WM_08_wrbench/) 的 scaling 证据：规模买得到外观连贯，买不到状态演化。

### 6.3 三个消融：时间维、token 预算、检索方式

**消融一：分词器核大小**（核 $T \times H \times W$；空间维从 4×4 改 2×2 或 8×8，PSNR 只降 0.244 / 0.127——空间维稳健；**时间维砍掉（$T{=}1$）PSNR 掉 1.281（20.357 → 19.076），主体一致性 0.926 → 0.912**）。分词器的时间交互是运动信息的来源——这直接验证 §4.2 的「运动是跨帧差分量」论证。

> 勘误一条：论文正文写 $T{=}1$ 导致「1.281 的 PSNR 与 0.014 的 DSC_GT 下降」，但按其 Table 4，DSC_GT 是 0.849 → 0.841（−0.008），0.014 实际对应**主体一致性**（0.926 → 0.912）。正文疑似笔误，本篇按表格数字书写。

**消融二：检索 token 数**（$K$=5 → PSNR 19.309，$K$=10 → 20.357，$K$=15 → 20.333）。$K{=}5$ 时信息损失严重——补充材料的定性结果是模型把一只长颈鹿幻视成两只；$K{\geq}10$ 后饱和。**记忆太少丢主体，记忆够了再加只是噪音**——检索预算存在一个阈值，不是越多越好。

**消融三：检索方式**（这是全篇最关键的消融，对应 §6.1 读数 3）：

| 检索 | PSNR | DSC_ctx | DSC_GT | 主体一致性 |
|------|------|---------|--------|-----------|
| FOV 重叠（用源帧相机位姿均值算几何重叠） | 19.776 | 0.820 | 0.844 | 0.908 |
| 动态亲和（Eq. 4） | **20.357** | **0.827** | **0.849** | **0.926** |

补充材料 Fig. 3 给出失败机制：长相机运动中 FOV 检索**只选中位姿最近的帧——恰好是主体出画后的空镜头**，外观信息整段丢失，重入生成不一致。而亲和检索按特征相关性选中**含主体的关键帧**。Fig. 4 进一步显示：FOV 的选中集合在整个推理阶段**固定不变**（静态几何决定），亲和检索的选中分布**随去噪步与 DiT 层动态变化**——检索本身是个随计算深化的迭代过程。

### 6.4 一个论文没做的切面

主表与消融都是**总体均值**——没有按「主体离场时长 $D$」分桶报告 DSC。但混合记忆的全部难点都集中在长离场：$D$ 小时任何方法都能靠上下文窗口糊过去，$D$ 大时才有「冻结/扭曲/消失」的分化。§7 的 toy 实验补上这个维度。

## 7. toy 实验：检索修复的是锚点，不是演化

把 §6.3 消融三的机制做成最小可复现实验，并补上 §6.4 缺的 $D$ 轴。

### 7.1 设定

- **世界**：64 格环形走廊，一个主体以速率 $v$（$|v| \sim U(0.2, 0.8)$，方向随机）持续绕环走——**不管看不看得见都在走**；
- **相机**：宽 16 格的视窗沿 $[0, 48]$ 做三角波往返平移（1 格/步）——「先左移后右移」，正是 HM-World 相机轨迹的设计原则，天然制造出画-入画事件；
- **记忆**：完美写入端——每步都存（含空镜头；主体可见时附带 $\sigma_{\text{obs}}=0.3$ 的带噪位置观测）；
- **查询**：只在主体**重新进入视窗**的时刻（DSC 时刻）。检索取回 $K{=}5$ 帧记忆，锚点帧 + 学到的主体速率外推当前位置。

三种检索（**共享同一外推机制** $\hat{v} = v + \mathcal{N}(0, 0.05^2)$，隔离「取回什么」这一个变量——对应论文消融三）：

| 方法 | 取回规则 | 对应 |
|------|---------|------|
| **FOV** | 位姿距当前最近的 top-5（位姿重合 = FOV 重叠最大；取回的可能是空镜头或陈旧镜头） | Context-as-Memory / 消融三上排 |
| **Affinity** | 最近的主体可见帧（内容检索的理想化） | HyDRA / 消融三下排 |
| **Oracle** | 同 Affinity 但 $\hat{v} = v$（完美动力学） | 动力学知识上限 |

计分：命中（取回集合含主体帧）→ 预测 = $x_{\text{obs}}(\tau) + \hat{v}\,(t-\tau)$；全空 → 主体信息缺失，预测 = 视窗中心（均匀先验的最优点估计，对应「消失/错位」失败）。误差 = 环上距离，按**离场时长** $D = t_{\text{重入}} - t_{\text{出画}}$ 分桶（40 episodes，2523 个重入事件）。

### 7.2 结果

| $D$ 区间 | $\bar{D}$ | n | FOV 命中率 | FOV 锚点年龄 | FOV MAE | Affinity MAE | Oracle MAE |
|---|---|---|---|---|---|---|---|
| 1–20 | 10 | 443 | 84.4% | 228.7 | 8.59 | 0.52 | **0.23** |
| 20–40 | 30 | 1032 | 75.9% | 243.1 | 8.47 | 1.31 | **0.24** |
| 40–80 | 54 | 532 | 79.9% | 270.5 | 9.67 | 2.08 | **0.24** |
| 80–160 | 97 | 516 | 76.2% | 277.1 | 9.45 | 3.92 | **0.25** |
| 斜率（$D \in [1, 320]$ 最小二乘） | | | | | **0.012** | **0.039** | **0.000** |

### 7.3 三个结论

**结论一：几何检索的误差由锚点年龄决定，与离场时长无关。** FOV 的 MAE 平坦在 8.5–9.7（斜率 0.012），因为它取回的位姿重合帧来自 2–3 个相机周期之前（锚点年龄 ~230–277，不随 $D$ 变化）——外推距离被放大到锚点年龄，动力学误差 $\sigma_v \times 240 \approx 9.6$ 格；另有 16–24% 的查询取回全空镜头（命中率与 $D$ 无关），主体信息整体丢失（误差 ≈ 半视窗 8 格）。**论文补充材料 Fig. 3 的「FOV 取回空镜头」在这里有了定量版：几何检索的失败是结构性的，不是离场太久才发生。**

<details>
<summary><b>数字走查：FOV 每桶 MAE 的两项分解</b></summary>

FOV 的误差只有一个两项公式：$\text{MAE} \approx \text{hit率} \times \mathbb{E}\big|\mathcal{N}\big(0,\, \sqrt{\sigma_{\text{obs}}^2 + (\sigma_v \cdot \text{锚龄})^2}\big)\big| + (1 - \text{hit率}) \times 8$——命中项是「观测噪声 + 动力学误差 × 锚龄」的联合高斯绝对值期望，miss 项是半视窗惩罚。用桶内平均锚龄代入（$\mathbb{E}|N(0,s)| = s\sqrt{2/\pi} \approx 0.798\,s$）：

| 桶 | hit 率 | 平均锚龄 | 命中项误差 | 分解值 | 实测 |
|---|---|---|---|---|---|
| 1–20 | 84.4% | 229 | 9.13 | 8.95 | 8.59 |
| 20–40 | 75.9% | 243 | 9.70 | 9.29 | 8.47 |
| 40–80 | 79.9% | 270 | 10.79 | 10.23 | 9.67 |
| 80–160 | 76.2% | 277 | 11.06 | 10.33 | 9.45 |

分解值比实测高 4–9%——偏差来源：桶内锚龄分布右偏（较新的锚更可能含主体），平均锚龄高估了典型外推距离。但量级与形态（平坦、由锚龄而非 $D$ 决定）完全吻合。**注意命中项误差 9–11 格全部来自 $\sigma_v \times$ 锚龄**——动力学误差 $\sigma_v = 0.05$ 本身很小，是「陈旧锚点把它放大了 240 倍」。

</details>

**结论二：内容检索把误差改写成离场时长的函数。** Affinity 锚定在出画帧，误差 = $0.039 \times D$——斜率精确等于动力学学习误差 $\mathbb{E}|\mathcal{N}(0, \sigma_v)| = 0.0399$。[WM 01](../WM_01_why_memory/) 的「误差斜率 = 对动力学的无知程度」在本篇复现：短离场（$\bar{D}=10$）时 Affinity 比 FOV 好 **16 倍**（0.52 vs 8.59）——锚点对了，剩下的误差只从演化来。

**结论三：检索修复锚点，不修复演化。** Oracle（同锚点 + 完美动力学）把误差打回 0.24 的观测噪声地板，斜率 0.000。Affinity 与 Oracle 的差距随 $D$ 线性拉大（$\bar{D}=97$ 时 3.92 vs 0.25，约 16 倍）——**这根斜率是内容检索原理上压不掉的**：检索再准，取回的也只是出画时刻的状态；出画之后的演化只能靠生成先验去猜。压掉这根斜率要换武器：显式动力学（[WM 10](../WM_10_liveworld/) LiveWorld 的 monitor 快进）或结构先验（[WM 15](../WM_15_causal_jepa/) / [WM 16](../WM_16_flowm/)）。

把结论二和三合起来，就是本篇在系列叙事里的位置：**HyDRA 把「取回什么」做到了内容级（锚点修复），「看不见时怎么演化」仍然停在隐式外推**——它是视觉记忆工程线能走到的地方，也是状态内核范式（WM 10–14）的起跳板。

> 脚本：`scripts/world_memory_experiments/wm06_toy.py`（含全部参数）。脚本教训一条：首版把「事件原料」（时刻、记忆数组）先存起来打算事后评估，却发现**没存主体真值位置**——评估时刻需要的观测量必须在模拟循环里就地记。重写为「事件发生当场评估」后一次跑通。写 toy 先列「评估时刻需要什么」，再设计累积器。

### 8.2 局限

**论文自认的**：三个以上主体或严重遮挡时性能下降；未来工作指向多主体动力学与真实世界场景。

**本篇补充的四条**：

1. **外推被数据分布封顶**：HM-World 的主体轨迹只有 10 种预设路径——生成先验学到的「出画后怎么走」被这 10 种封了顶。真实世界的主体会加速、转弯、被遮挡、互动；分布外的离场运动如何泛化，论文没有测（toy 结论三说明这恰是误差主项）；
2. **合成域**：UE5 渲染的「高保真」与真实视频仍有域差；开域实验（互联网视频 + 往复相机运动）只有定性结果；
3. **DSC 的位置盲区**：CLIP 特征量外观与语义相似，不敏感于精确位置（§4.5 折叠块）——HM-World 标注了逐帧主体位置，指标却没用上它；
4. **10K 迭代微调的对照公平性**：HyDRA 在 HM-World 上微调而 WorldPlay 零样本——6.2 的主对照只能说「微调过的检索架构零样本商用模型」，混合记忆能力的**来源**（架构 vs 数据）没有被拆开消融。

### 8.3 面试可能被问的点

- **为什么检索前要过 3D 卷积，而不是直接在 latent 上检索？**——特征纠缠（背景/主体耦合）+ 表达力（运动是跨帧差分量；$T{=}1$ 消融掉 1.281 PSNR）；
- **top-K 检索与标准注意力的关系？**——Eq. 4 是帧对级的低成本预筛 logit，top-K 是注意力的两级稀疏化（§4.3 折叠块性质 3）；
- **局部窗口为什么强制保留？**——长程检索与短程稳定分工；把局部连续性交给检索会在 top-K 漏选时断帧；
- **HyDRA 解决了 out-of-sight dynamics 吗？**——没有，它解决的是 out-of-sight **identity/appearance**；状态演化仍是隐式外推（toy 结论三），这正是 WM 10–14 的出发点。
