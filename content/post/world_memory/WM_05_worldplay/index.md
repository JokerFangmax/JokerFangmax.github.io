# WM 05：WorldPlay——Temporal Reframing 对抗长程注意力衰减

> 📖 **WorldPlay: Towards Long-Term Geometric Consistency for Real-Time Interactive World Modeling**（Sun, Zhang, Wang 等，HKUST + Beihang + Tencent Hunyuan，arXiv:2512.14614，**ICML 2026**, PMLR 306）。720p、24 FPS、8×H800，单图或文本起步。

## 1. 这一篇解决什么问题

把 [WM 04](../WM_04_relic/) 的三难（实时 + 长程记忆 + 精确控制）原样搬来，WorldPlay 换了一个病灶诊断：

> 长程一致性失败的直接机制不在「记没记住」，而在**Transformer 的长程衰减**——即使关键的过去帧完好地躺在上下文里，随着相对距离增长，它对当前预测的影响力也在持续走弱，直到超出 RoPE 的训练插值范围。

一句话：**远处的记忆不是丢了，是被位置编码摁住了嗓门。**（论文原文：the fading influence of distant tokens in Transformers。）

对应的三个组件：

| 组件 | 攻哪个问题 | 一句话机制 |
|------|-----------|-----------|
| **Dual Action Representation** 双重动作表示 | 精确控制 + 记忆定位 | 离散按键与连续位姿**同时**注入，各取所长 |
| **Reconstituted Context Memory** 重构式上下文记忆（含 **Temporal Reframing**） | 长程几何一致性 | 每个新 chunk 动态重建记忆集，并**重写位置编码**把远期关键帧「拉近」 |
| **Context Forcing** 上下文强制 | 实时 + 抗误差累积 | 蒸馏时对齐教师与学生的**记忆上下文**，否则分布匹配必然失配 |

结果口径：720p / 24 FPS 流式生成，长程（≥250 帧）PSNR **18.94**、3D 结构一致性 MEt3R **0.133**、WorldScore **79.74**，全部第一；蒸馏后 4 步去噪反超蒸馏前 100 步的学生模型。

## 2. 背景最小集

**任务形态**：next-chunk 预测——把视频 latent 按每 4 个 latent（16 帧）分 chunk，因果地逐 chunk 生成，条件是过去观测、动作序列与文本/图像。底座是 Wan / HunyuanVideo 一类的 DiT 视频扩散模型（flow matching 训练，[VG 01](../../video_generation/VG_01_diffusion_basics/)）。

**两类既有解法与各自的死穴**（论文 Table 1 的骨架）：

| 路线 | 代表 | 死穴 |
|------|------|------|
| 保速度弃记忆 | Oasis、Genie 2、Matrix-Game 2.0 | 重访即变样；且蒸馏很难事后补记忆 |
| 保记忆弃速度 | VMem（显式 3D 检索）、Gen3C（显式 3D 表示）、WorldMem / Context-as-Memory（隐式检索） | 记忆机制让蒸馏变得非平凡——这是本文攻击的核心缝隙 |

第三行值得展开：**为什么「有记忆的模型」难蒸馏**？蒸馏是把学生分布对齐教师分布；标准教师是短片段训练的、无记忆的双向模型，学生却带着自己的记忆上下文做因果生成——两边条件分布 $p(x \mid C)$ 根本不同，分布匹配失去共同基准。§4.3 的 Context Forcing 就是冲这个来的。

**RoPE 长程衰减**：旋转位置编码（RoPE）让注意力权重随相对距离衰减；且预训练模型的插值范围有限（Wan 底座 5 s 视界），超出后外推失真。长程记忆帧的时间距离无界增长，**必然**撞上这两堵墙——这是 Temporal Reframing 的靶子。

## 3. 方法总览

```
用户输入（离散按键 + 连续位姿，可互转）
        │
        ├─ 离散键 → PE + 零初始化 MLP ─→ 时间嵌入（调制 DiT 块）      ← Dual Action
        └─ 连续位姿 → PRoPE ─→ 自注意力（Attn1 + zero-init(Attn2)）    Representation
        │
新 chunk 生成前：从历史 chunk 重建记忆上下文 C_t
        ├─ 时间记忆 C_T: 最近 L=3 个 chunk（运动平滑）
        ├─ 空间记忆 C_S: 非相邻帧中按 FOV 重叠 + 相机距离选出 1 chunk   ← Reconstituted
        └─ 首 chunk 永久保留（attention sink，抗误差累积）               Context Memory
        │
对所有记忆帧: 丢弃绝对时间索引 → 重赋固定小相对距离位置编码            ← Temporal Reframing
        │
训练: 三阶段（动作控制 → 记忆 → Context Forcing 蒸馏）                ← Context Forcing
```

与 RELIC 的分野在记忆的用法：RELIC **全都要**（压缩后全部历史进 cache），WorldPlay **挑着要**（每个 chunk 只重建一个小记忆集），但给选中的帧解除位置编码的封印。一个是压 token，一个是改坐标。

## 4. 核心原理

### 4.1 Dual Action Representation：一个输入，两种坐标

先看两种动作表示各自的死穴（论文消融 Table 5 的定性版）：

| 表示 | 优点 | 死穴 |
|------|------|------|
| 离散按键（W/A/S/D…） | 跨场景尺度自适应，训练稳 | 说不出「走了多远」——记忆检索拿不到精确位置 |
| 连续位姿 $(R, T)$ | 精确定位，记忆检索的天然索引 | 训练数据场景尺度方差大 → 训练不稳 |

解法是**双路同注**：

- **离散键**：位置编码（PE）+ **零初始化** MLP 编码，并入去噪时间步嵌入，调制 DiT 块。零初始化保证训练开始时新通路不扰动预训练权重；
- **连续位姿**：走 **PRoPE**（Pose-aware RoPE）注入自注意力。原注意力已经是 3D RoPE 的旋转调制（$R$ 为 latent 的 3D 旋转位置编码）：

$$
\mathrm{Attn}_1 = \mathrm{Attn}(R^{\top} \odot Q,\; R^{-1} \odot K,\; V)
\tag{Eq. 2}
$$

再叠加一路由相机内外参构造的投影矩阵 $D_{\text{proj}} = \begin{pmatrix} K & 0 \\ 0 & 1 \end{pmatrix} T^{cw}$ 驱动的注意力，编码相机视锥（frustum）间的几何关系：

$$
\mathrm{Attn}_2 = D_{\text{proj}} \odot \mathrm{Attn}\big((D_{\text{proj}})^{\top} \odot Q,\; (D_{\text{proj}})^{-1} \odot K,\; (D_{\text{proj}})^{-1} \odot V\big)
\tag{Eq. 3}
$$

每个自注意力块的输出是 $\mathrm{Attn}_1 + \mathrm{zero\_init}(\mathrm{Attn}_2)$——几何通路同样零初始化渐入。

注意与 RELIC 的同构性：那边「绝对位姿进 Q/K 当检索路标」，这边「PRoPE 让 Q·K 内积携带视锥几何」——**两边都把「从哪里看」直接写进注意力的打分函数**，这是位置 ② 记忆能被找到的共同前提。

### 4.2 Reconstituted Context Memory + Temporal Reframing

**重建（reconstitute）**：对每个新 chunk $x_t$，从历史 $O_{t-1}$ 重建记忆上下文 $C_t$，三部分：

1. **时间记忆** $C^T_t$：最近 $L=3$ 个 chunk——短期运动平滑；
2. **空间记忆** $C^S_t \subseteq O_{t-1} - C^T_t$：从**非相邻**过去帧中按几何相关性得分（FOV 重叠 + 相机距离）采样 1 个 chunk——长程几何防漂移的锚；
3. **首 chunk 永久保留**：attention sink（借鉴 Streaming LLM）——锚定全局风格，进一步抗误差累积。

**重赋帧（reframing）——本篇的核心一步**。记忆集建好后，问题变成「怎么让模型用得上」。标准 RoPE 下，当前 chunk 与历史记忆的相对距离随时间无界增长：(i) 影响力衰减，空间记忆的嗓门越来越小；(ii) 距离最终超出训练插值范围，外推失真。Temporal Reframing 的操作：

> **丢弃绝对时间索引，对所有上下文帧动态重赋位置编码，使它们与当前 chunk 之间保持固定的、小的相对距离——与真实时间差无关。**

效果上等于把几何上重要的过去帧「拉到眼前」，强制模型把它当近邻对待。这是对 §1 病灶的精准手术：不增加任何参数、不改变记忆内容，只改「模型感知到的距离」。

<details>
<summary><b>为什么这样做是合法的（以及代价是什么）</b></summary>

一个自然的疑问：抹掉真实时间差，模型不会把 10 分钟前的帧当成 1 秒前的帧、从而在「这段时间里世界该变了吗」上犯错吗？

合法性的来源是任务语义：WorldPlay 的世界以**静态场景**为主（导航探索），一致性要求的是「同一地点同一长相」——几何身份，不是时间演化。对几何身份而言，帧的可用性只取决于「它看到的地点是否相关」，与它是多久前看的无关；真实时间差反而是噪声。所以重赋固定小距离恰好保留了任务需要的那个变量（几何相关性，由 §4.1 的 PRoPE 与检索得分携带），删掉的是任务不需要的变量（绝对时间）。

代价在动态世界显形：一旦场景里有会随时间变化的对象，「时间差无关」的假设就错了——这正是 [WM 01](../WM_01_why_memory/) 两条方程里 $f$（演化）被显式丢弃的又一种方式。WorldPlay 的 promptable event（文本中途触发的气球、彩虹）走的是**文本条件**通道改内容，不经过记忆的时间语义，所以不与此冲突。这条边界要到 [WM 06（HyDRA）](../WM_06_hydra/)的动态主体才开始松动。

</details>

### 4.3 Context Forcing：先对齐条件，再做分布匹配

蒸馏目标（DMD 家族，[VG 06](../../video_generation/VG_06_videoscene/)）：

$$
\nabla_\theta \mathcal{L}_{\mathrm{DMD}} = \mathbb{E}_k\big(\nabla_\theta \mathrm{KL}(p_\theta(x_{0:t}) \,\|\, p_{\text{data}}(x_{0:t}))\big)
\tag{Eq. 4}
$$

问题：反向 KL 的梯度由教师的分数函数近似，而**条件**分布两边不同——学生 $p_\theta(x_{j:j+3} \mid x_{0:j-1})$ 带着自己的记忆上下文做因果自 rollout；标准教师是双向、无记忆、短片段训练的。条件不对齐，分布匹配没有共同基准。

Context Forcing 的构造（论文 Eq. 5）：教师 $V_\beta$ 也是**增强了记忆的双向模型**，其条件取「学生的记忆上下文 **减去** 学生正在生成的那些 chunk」：

$$
p_{\text{data}}(x_{j:j+3} \mid x_{0:j-1}) = p_\beta\big(x_{j:j+3} \,\big|\, C_{j:j+3} - x_{j:j+3}\big)
\tag{Eq. 5}
$$

其中 $C_{j:j+3}$ 是学生自 rollout $x_{j:j+3}$ 对应的全部记忆上下文 chunk。两边条件严格同源——教师是在「学生看到的世界」里给生成段打分的双向模型。

三点设计余味：

- **教师不必在长视频上训练**：$C_{j:j+3} - x_{j:j+3}$ 是变长上下文而非全历史，教师仍然只学短片段的条件分布，只是带着记忆条件——「避免在长视频与冗余上下文上训练 $V_\beta$」；
- **消融把反面做成了标本**（论文 Fig. 8）：教师记忆按 latent 级而非 chunk 级选取 → 上下文错位 → **蒸馏直接崩溃**（输出塌缩）；无记忆教师 → 分布错配 → 长程一致性显著受损；用学生自 rollout 的历史当教师上下文 → 教师在自己没见过的（生成）分布上估分数 → 伪影；**从真实视频采样历史 chunk 作教师上下文**最优；
- **渐进蒸馏**：自 rollout 的 latent 数逐步拉长（与 RELIC 的蒸馏课程同构）。

<details>
<summary><b>Context Forcing 与 Self-Forcing 的谱系</b></summary>

Self-forcing（[WM 03](../WM_03_memory_forcing/) 有梳理）解决的是「学生 rollout 的历史 vs 教师见过的干净历史」这一错配——让学生在自己生成的历史上训练。Context Forcing 解决的是**记忆维度上的同一类错配**：记忆增强的学生，其蒸馏教师也必须带着**同一个**记忆上下文。可以这样排：

| 方法 | 对齐了什么 |
|------|-----------|
| CausVid | 因果性：双向教师 → 因果学生（对齐架构方向） |
| Self-Forcing | 历史：学生用自己的 rollout 历史（对齐历史分布） |
| **Context Forcing** | 记忆：教师条件 = 学生记忆 − 生成段（对齐记忆上下文） |

每往记忆这边走一层，就多一个「教师看到的世界必须与学生一致」的约束。这个谱系下一站的问题：如果记忆里存的不是帧而是**状态**（系列第三组），教师要对齐的就不是上下文而是状态演化规则了。

</details>

### 4.4 toy 实验：注意力饥饿的三张标本

Temporal Reframing 的机制主张可以写成一行：**预测 = 记忆条目的 softmax 加权平均 + 生成噪声**，其中空间记忆（几何相关的锚，affinity 优势 $\beta$）与时间记忆（最近 3 chunk）竞争权重，而 RoPE 距离惩罚压在空间记忆头上——绝对索引下它的距离无界增长，reframing 后距离恒定。`scripts/world_memory_experiments/wm05_toy.py` 把这行写出来跑了三个测量（$D_{\max}=21$ chunk 是 5 s 训练视界，超过后惩罚切换为二次项——外推失真的代理；公共随机数消除抽样方差）。

**标本 1：空间记忆的注意力权重 $w_{sp}$ 随真实时间差的衰减**

| Δ（chunk） | 1 | 4 | 8 | 16 | 21 | 30 | 40+ |
|---|---|---|---|---|---|---|---|
| absolute $w_{sp}$ | 0.8853 | 0.8312 | 0.7299 | 0.4487 | 0.2777 | 0.0067 | **0.0000** |
| reframed $w_{sp}$ | 0.8312 | 0.8312 | 0.8312 | 0.8312 | 0.8312 | 0.8312 | **0.8312** |

**绝对索引下空间记忆在 Δ≈30 后完全失声**——锚好好地存着，softmax 里它的票数是零。reframing 恒定 0.8312。

**标本 2：长驻漂移**（一直停在锚点 600 chunk，生成值 RMS 误差）：

| chunk | 50 | 100 | 200 | 400 | 600 |
|---|---|---|---|---|---|
| absolute | 0.238 | 0.371 | 0.580 | 0.864 | **1.104** |
| reframed | 0.115 | 0.116 | 0.127 | 0.126 | **0.128** |

锚失效后，生成只能抄时间记忆里自己的漂移值——误差随机游走无界增长；reframing 下是 AR(1) 被锚拉住、进入稳态。**「不动也会漂」的机制解释**：漂移不是生成质量差，是锚在注意力里饿死了。

**标本 3：重访误差 vs 离开间隔 Δ**（离开期间时间记忆装的是途中别的场景）：

| Δ | 4 | 8 | 16 | 32 | 64 | 128 | 256 |
|---|---|---|---|---|---|---|---|
| absolute MAE | 0.125 | 0.164 | 0.262 | 0.466 | 0.469 | 0.465 | 0.472 |
| reframed MAE | 0.125 | 0.125 | 0.122 | 0.120 | 0.123 | 0.129 | 0.113 |

absolute 在 Δ≈32 后**饱和到场景散布水平**（时间记忆里全是无关场景的内容，≈随机内容 MAE 0.47）——注意这不是线性增长，是**断崖后躺平**：锚彻底出局后误差由噪声源决定、与 Δ 无关。reframed 全程平坦在 0.12。

> 论文里的对应证据是消融 Table 6（长程测试）：标准 RoPE PSNR 14.03 / Rdist 0.805 / Tdist 1.341 → Reframed RoPE **16.27 / 0.611 / 0.991**——视觉指标涨幅最大，与 toy 标本 1「影响力衰减主要压视觉一致性」一致。toy 把这个差距拆成了三个可单独指认的机制。

## 5. 训练与推理细节

### 5.1 数据：320K 片段的四象限拼盘

| 类别 | 来源 | 标注（离散, 连续） | 片段数 | 占比 |
|------|------|------------------|--------|------|
| 真实动态 | Sekai | （✗, ✗） | 40K | 12.5% |
| 真实 3D 场景 | DL3DV | （✔, ✔） | 60K | 18.75% |
| 合成 3D 场景 | UE 渲染 | （✗, ✔） | 50K | 15.6% |
| 模拟动态 | 游戏录像（自建平台，玩家录制） | （✔, ✗） | 170K | 53.1% |

与 RELIC 的 1600 分钟纯 UE 语料对照鲜明：WorldPlay 走「四象限互补」——真实/合成 × 静态/动态，标注完备性四角对齐（哪类数据缺哪种标注，就用另一路动作表示补）。处理链的三个要点：DL3DV 走「3D 重建 → 定制轨迹渲染 → 质量过滤 → Difix3D+ 修复」造出**带精确双标注且刻意含重访轨迹**的 60K 片段（记忆监督的来源与 RELIC 的 UE 重访轨迹同一意图，但造在真实场景上）；VIPE 估位姿后用**峰中值比 PMR > 5.0 过滤位姿塌缩**的片段；长视频切 30–40 s、VLM 配文。

### 5.2 三阶段训练（论文附录 A）

| 阶段 | 内容 | 关键量 |
|------|------|--------|
| ① 动作控制 | 双向动作模型 30K iter → 换块因果注意力再 30K iter | 61 帧（4 chunk），lr 1e-5，batch 64 |
| ② 记忆 | 双向 + AR 模型各带记忆上下文训练；教师侧生成序列 4 chunk、记忆上下文 $C_{j:j+3} - x_{j:j+3}$ 加 $[0, 0.2]$ 均匀噪声（鲁棒条件化），损失只算生成序列 | 最长 **160 latents（637 帧）** |
| ③ Context Forcing | 蒸馏，渐进拉长 rollout | 2K iter；学生 lr 1e-6，假分数模型 lr 2e-7 |

阶段②的「记忆上下文加轻噪声」值得记一笔：**记忆本身也是模型链路的一部分，也要做鲁棒性训练**——与 diffusion forcing 给历史加噪是同一思想，只是加在检索来的上下文上。

### 5.3 推理：24 FPS 的拼装

DiT 与 VAE 混合并行（序列并行 + 注意力并行，按 chunk 内 token 分片而非复制模型）；Triton 流式部署 + **渐进 VAE 解码**（小批量边解边播，压首帧时间）；SageAttention、浮点与矩阵乘量化；KV cache + **promptable event 的 KV-recache**（改文本时刷新缓存 KV，抹掉旧 prompt 残留、保住运动线索）。消融（Table 4）：DiT 并行+量化 2.80→16.0 FPS，再加流式解码 **24.0 FPS**（累计 8.57×）。

## 8. 局限与思考

**论文自认的四条**：~30 秒量级，分钟/小时级扩展仍是挑战；蒸馏只能**缓解**不能根除 AR 误差累积；动作类型待扩（多智能体、复杂物理）；FOV 检索在严重遮挡下会失灵（看不见的地方检索不到记忆）。

**顺着系列主线的三条**：

1. **Reframing 是「静态世界豁免权」下的最优解**。它删掉绝对时间差，等于宣告「记忆的效用与时间无关」——对几何一致性成立，对状态演化不成立（§4.2 折叠块的论证）。toy 标本 3 里 reframed 的平坦曲线，前提是锚的存储值 $v_{sp}$ 在离开期间**没有变化**；一旦狗在吃食、水位在涨，平坦就意味着「精确恢复离开时刻」——[WM 01](../WM_01_why_memory/) 结论一的下界换个位置重现。**位置 ② 记忆的两种失败（检索不到 / 演化不了）在这两篇里被分工解决了前者**。
2. **蒸馏与记忆的适配是个一般性命题，不止于此文**。Context Forcing 的教训可以推广：**给任何带状态的模型做蒸馏，教师必须复现学生的状态**——否则分布匹配在对齐两个不同的条件分布。系列往后会反复遇到这个形状：蒸馏 LLM 化的世界模型（WM 12/13）、蒸馏带程序内核的渲染器（WM 14），每一步都要回答「教师的世界状态从哪来」。
3. **两个平行方案没有分出胜负，但给出了可组合性**。RELIC 压 token、WorldPlay 改索引，理论上可以同时做（压缩记忆 + reframed 位置编码）。真正阻止组合的不是技术而是**证据缺失**：两篇都没有「压缩损失 × 衰减曲线」的联合测量——压缩后的 token 在注意力里的衰减特性是否与全分辨率 token 相同，schedule 里 1×/2×/4× 的交错是否本身就是一种频响均衡（偶尔给远处记忆一张全分辨率票）。这个问题留给系列的总结篇（WM 17）。
