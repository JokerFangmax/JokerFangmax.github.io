## 1. 这一篇解决什么问题

### 1.1 快照记忆的盲区：存了状态，没存变化

VLA 组前几篇的记忆都是**快照式**的：MemoryVLA 存感知/认知 token（[WM 23](../WM_23_memoryvla/)），MemoryWAM 存近帧 + 事件锚帧 + gist（[WM 25](../WM_25_memorywam/)），AtlasVLA 存体素地图（[WM 26](../WM_26_atlasvla/)）。论文 Figure 1(a) 点出它们的共同盲区：**任务相关的变化在存储的历史里是隐式的**——策略拿到一堆稀疏状态，还得自己推断「这两帧之间发生了什么、做到哪一步了」。

最干净的例子是 RMBench 的 Press Button：指令要求按九次左键、一次中键、再按终止键。每次按压前后画面**几乎相同**（按钮按下去会弹回来），当前观测完全无法区分「按了三次」和「按了七次」。论文 Figure 4 的失败轨迹很形象：去掉 delta token 的变体走错轨迹回到左键；朴素特征差变体到了中键却反复按、不知道该去按终止键。

### 1.2 答案的一句话版

**把「观测到的变化」本身做成记忆单元**：条件化 delta 分词把有序帧对 $(I_u, I_v)$（$u \le v$）压成**一个**方向性、源条件的变化 token，与对应的状态证据按时间序并排摆放——记忆同时回答「看到过什么」和「它怎么变的」。策略不再从稀疏快照反推进度，而是直接读取变化证据。

## 2. 最小背景

- **[WM 01](../WM_01_why_memory/)**：演化式 vs 回放式记忆的分野。本篇的立场微妙：它**不是**在观测端外推（StEvo 意义上的演化），而是把「已经观测到的演化」显式存进上下文——详见 §8 的辨析；
- **[WM 07（StEvo-Bench）](../WM_07_stevo_bench/)**：状态演化能否与观测解耦——本篇是操纵场景里对这个问题的一次正面回应（答案：先把可见的演化存好）；
- **[WM 09（MemoBench）](../WM_09_memobench/)**：消失-重现 + 状态变化范式——Press Button 的重复按压正是「状态变化」支柱的操纵版；
- **DeltaTok**（Kerssies et al. 2026）：视频条件特征压缩——给定源帧特征，把目标帧里**源解释不了的信息**压进单个 token。EvoMem-VLA 把它从视频领域搬进 VLA 记忆；
- **[WM 25（MemoryWAM）](../WM_25_memorywam/)**：近帧 + 事件锚帧 + gist 的混合记忆——本篇的记忆布局（初始帧 + 近三帧 + 关键帧）与 EventVLA（Yang et al. 2026a）一脉相承，并在每个状态旁边多放一个变化 token。

## 3. 方法总览

EvoMem-VLA 的推理循环（文字版流水线）：

1. **Delta Tokenizer（离线预训练，部署时冻结）**：冻结 DINOv3 提源/目标帧 patch 特征，编码器 $g_\Delta$ 配一个可学习查询把「目标帧中源帧解释不了的信息」压成单 token，解码器只用于预训练期的重建监督，用完即弃；
2. **组装多尺度状态演化记忆**：固定锚（第 0 帧、$t-30$、$t-15$、$t$ 的视觉 token）+ 三组近期 delta token（帧对 $(t-45, t-30)$、$(t-30, t-15)$、$(t-15, t)$，每组每相机流一个 token）+ 事件状态银行（Keyframe Head 在线选中的关键帧，每个配一个 event-local delta token）；
3. **任务自适应路由**：同一 VLM 主干，普通长时程任务直接出动作（direct route）；多阶段任务先生成一段可执行子任务文本、拼回上下文再出动作（subtask route）——路由由任务级配置指定，不学分类器；
4. **动作生成**：动作查询 token 过共享主干，残差 MLP 动作头输出动作块；Keyframe Head 同时从动作查询状态预测「未来哪个偏移值得记录」。

论文反复强调一条诚实边界：**每个 token 只代表它实际编码的有序帧对**——模型不从远距关键帧之间推断转移，也不重建未观测的中间状态。

## 4. 核心原理完整推导

### 4.1 基线：reactive VLA 的动作路径

$$
Z^A_t = F_\theta\big([X_t;\, Q^A]\big)_{Q^A}, \qquad \hat{A}_t = G_\psi(Z^A_t),
\tag{Eq. 1}
$$

$X_t = [V_t; L]$ 是当前视觉 token 与指令嵌入，$Q^A$ 是 $H$ 个动作查询 token，$F_\theta$ 是 VLM 主干（Qwen3-VL-4B-Instruct 初始化），$G_\psi$ 是残差 MLP 动作头；动作损失 $\mathcal{L}_{act} = \|\hat{A}_t - A_t\|_1 / (H d_a)$。EvoMem-VLA 做的事就是把 $X_t$ 里的 reactive 视觉上下文换成下面的结构化历史。

### 4.2 条件化 delta 分词：单 token 瓶颈（核心机制）

$$
z_{u \to v} = g_\Delta(f_u, f_v;\, q_\Delta),
\tag{Eq. 2}
$$

$f_u = \phi(I_u)$、$f_v = \phi(I_v)$ 是冻结 DINOv3 的 patch 特征，$q_\Delta$ 是可学习查询。预训练目标：解码器 $\hat{f}_v = h_\Delta(f_u, z_{u\to v})$ 从**源帧特征 + 单个 delta token** 重建目标帧特征，损失 $\mathcal{L}_\Delta$ 为逐 patch、逐维平均的 log-cosh。

**直觉**：瓶颈的精髓在条件——解码器手里已有 $f_u$，所以 $z_{u\to v}$ 里**只需装下 $f_u$ 解释不了的剩余信息**。梯度会自动把「两张帧共有的静态背景」推给 $f_u$ 那条免费通路，把「变化的部分」挤进这一个 token。论文特意强调产物**不是**像素差、不是光流场、也不是动作码——它是方向性（$z_{u\to v} \ne z_{v\to u}$）、源条件的变化表示。预训练完成后 $h_\Delta$ 直接丢弃，VLA 只用 token。

### 4.3 多尺度状态演化记忆的布局

$$
M_t = \Big[\underbrace{V_0;\; d^{(3)}_t;\; V_{t-30};\; d^{(2)}_t;\; V_{t-15};\; d^{(1)}_t;\; V_t}_{M^{anc}_t\text{（固定锚 + 近期链）}};\; \big\{d^e_i;\; V_{\kappa_i}\big\}_{i=1}^{m_t}\Big],
\tag{Eq. 3}
$$

近期三组 $d^{(1)}, d^{(2)}, d^{(3)}$（新到旧）分别编码帧对 $(t-15, t)$、$(t-30, t-15)$、$(t-45, t-30)$；事件条目按捕获顺序排列，每个 event-local delta token $d^e_i$ **紧贴在它的目标状态 $V_{\kappa_i}$ 前面**——变化与状态证据成对入场。负索引钳到 0（回合开头复用初始帧），只当分词器源的帧不额外占 RGB 记忆位。

**直觉**：两套时间尺度分工——近期链每步刷新，供给「执行中正在发生什么」；事件银行（Keyframe Head 选中）把「已经离开近期窗口的早期证据」连同其变化存档。初始帧锚则承担「可能消失的信息」（演示的顺序、物体的初始位置）。

### 4.4 Keyframe Head：预测何时记录，而非记录什么

$$
\hat{p}_t = \sigma\big(k_\omega(Z^A_t)\big) \in [0,1]^H.
\tag{Eq. 4}
$$

从动作查询状态出发，小头 $k_\omega$ 对动作窗口内每个偏移 $j = 0, \ldots, H-1$ 预测一个记录概率；只有当最高分的未来偏移概率超过阈值（RoboMME 0.55）才**调度**一次记录，且观测真正到达该时刻才提交入库，容量溢出删最旧。**直觉**：这沿袭 EventVLA 的「事件触发」思想——何时值得记是策略自己学的（正类稀少，训练用正类权重 7 的加权 BCE），但**记什么不由模型编造**，到点存真实观测。

### 4.5 任务自适应路由

$$
\hat{s}_t = \text{Decode}_\theta(C_t), \qquad \hat{A}_t = \Pi_{\theta,\psi}\big([C_t;\, E_\ell(\hat{s}_t)]\big),
\qquad C_t = [M_t;\, L;\, E_\ell(R_t)].
\tag{Eq. 5}
$$

多阶段任务（有子任务标注的）先让共享主干用语言建模头生成一段**可执行子任务**文本，拼回同一份「状态-变化」上下文做第二次前向后出动作；$R_t$ 是先前子任务历史（训练用标注，部署用生成文本累积，回合间清零）。普通任务走 direct route（$R_t$ 空，直接 $\hat{A}_t = \Pi_{\theta,\psi}(C_t)$）。两条路由共享全部参数，只是条件路径不同——**路由是配置出来的，不是学出来的**。

### 4.6 两阶段训练

$$
\mathcal{L} = \mathcal{L}_{act} + \lambda_{lang} \mathcal{L}_{lang} + \lambda_{kf} \mathcal{L}_{kf}.
\tag{Eq. 6}
$$

**阶段一**只训 Delta Tokenizer（$g_\Delta, h_\Delta$，DINOv3 冻结）；**阶段二**冻结 $\phi$ 与 $g_\Delta$，训 VLA、动作头、delta 投影层与 Keyframe Head。$\mathcal{L}_{lang}$ 是子任务文本的 token 级交叉熵（视觉/提示/动作查询全掩码，direct 路由样本贡献零）；$\mathcal{L}_{kf}$ 是加权 BCE（无关键帧监督则为零）。训练时动作用**标注**子任务、部署用**生成**子任务——一处标准的训练-部署错配，论文如实注明。

<details><summary><b>展开：为什么朴素特征差会输给「不存变化」——信息论视角</b></summary>

消融（Table 3）里最反直觉的一行：把学习型 $g_\Delta$ 换成 $f_v - f_u$（DINOv3 特征直接相减再投影），总分 47.1%——**低于**完全去掉 delta token 的 52.3%。特征差为什么更糟？

两个独立的原因。**其一（信噪比）**：DINOv3 特征维度的观测噪声在相减时不衰减（方差翻倍 $\times 2$），而两张高度相似帧的「真实变化」只占特征的很小一部分——相减产出的向量里噪声占比反而更高。**其二（表示错位）**：逐维特征差是**对称**的（$f_v - f_u = -(f_u - f_v)$），丢掉了方向；而条件化 token 的信息瓶颈会主动丢弃源帧能解释的成分、只保留「变化」所在的子空间，并且天然有向。toy 实验（§6.5）把第一点单独量化：lag-1 帧差的速率估计噪声是 $\sigma\sqrt{2}$，拉长差分基线到 $L$ 步才压到 $\sigma\sqrt{2}/L$。

论文的判词：exposing feature differences alone is insufficient——**「看得见差异」不等于「存得下变化」**。

</details>

## 6. 实验：只有核对过的数字

### 6.1 RMBench：M(n) 的提升是主菜（Table 1）

| 方法 | M(1) 平均 | M(n) 平均 | 总分 |
|------|-----------|-----------|------|
| QwenOFT（无记忆底座） | 0.0 | 12.8 | 5.7 |
| MemoryVLA (QwenOFT) | 44.2 | 38.8 | 41.7 |
| Mem-0 | 52.8 | 28.5 | 42.0 |
| EventVLA | 79.0 | 54.0 | 67.8 |
| **EvoMem-VLA** | **84.0** | **76.5** | **80.7** |

单一联合训练策略横跨九个双臂任务。M(1)（只需记住一次过去观测）84.0 领先 5.0；**M(n)（需要多次过去观测）76.5 领先 EventVLA 22.5 个点**——变化证据的收益集中在多阶段交互上。任务级亮点：Rearrange Blocks / Swap Blocks / Swap T 全 100.0，Put Back Block 92.0，Press Button 从 EventVLA 的 3.0 拉到 **70.0**（+67，最大单项增益——正是那个「按九次左键」的计数任务）。最弱项 Observe & Pick Up 28.0（仍是第一，EventVLA 21.0）：这个任务靠单次观测记忆，delta 帮不上忙——变化证据不是万能药（见 §8）。

### 6.2 RoboMME 与真机（Table 2 + Figure 3）

| 评测 | EvoMem-VLA | 最强基线 |
|------|-----------|---------|
| RoboMME 总分（16 任务） | **82.0** | FrameSamp 44.5；MemER 42.4 |
| ——计数 / 持久性 / 参考 / 模仿 | 86.5 / 88.5 / 74.5 / 78.5 | 各类别均第一 |
| 真机四任务（双平台平均） | **83.8** | πMEM 30.0；π0.5 5.0 |

真机四任务各有考点：Lift Cup 85.0（卡片示数 3–10 次的重复计数——当前杯位不告诉你还剩几次）、Cover Ducks 90.0（遮盖后的鸭子身份记忆）、Route Recall 75.0（人指认顺序 3–6 步含重复的空间序列复现）、Put Back Cup 85.0（杯子中转后回忆初始盒子）。四类考点分别对应 RoboMME 的计数/持久性/参考/模仿四大记忆类别——仿真与真机的考察面是对齐的。

### 6.3 消融：2×2 因子分解 + 朴素帧差的教训（Table 3）

| 变体 | M(1) | M(n) | 总分 |
|------|------|------|------|
| **EvoMem-VLA（完整）** | **84.0** | **76.5** | **80.7** |
| w/ 朴素特征差（$f_v - f_u$ 相减） | 52.0 | 41.0 | **47.1** |
| w/o delta token | 59.0 | 44.0 | 52.3 |
| w/o 子任务路由 | 84.0 | 33.0 | 61.3 |
| w/o 两者（纯状态记忆） | 55.0 | 31.0 | 44.3 |

四条读数：

1. **朴素特征差 47.1 < 不用 delta 52.3**：把噪声当成变化比不演化更糟（§4.2 折叠块的信息论解释）——完整模型对朴素差的优势高达 33.6 个点；
2. **delta 的贡献大于路由**（80.7 − 52.3 = 28.4 vs 80.7 − 61.3 = 19.4）；从纯状态变体（44.3）出发，只恢复 delta +17.0，只恢复路由 +8.0；
3. **两者互补且分工明确**：去掉路由只伤 M(n)（76.5 → 33.0），M(1) 纹丝不动——子任务文本是**多阶段执行**的进度外挂，与单阶段记忆无关；
4. 消融全部在同一框架、同数据、同 80k 步预算下重训（附录 C.1）——不是「各自论文数字拼桌」。

### 6.4 与诊断三连的回环

[WM 08（WRBench）](../WM_08_wrbench/) 证明视频世界模型的记忆失败 scaling 不修复；[WM 09（MemoBench）](../WM_09_memobench/) 把「消失-重现 + 状态变化」立为诊断支柱。EvoMem-VLA 的 Press Button 3.0→70.0 正是「状态变化」支柱在操纵里的可解版——**前提是给变化留出显式的表示位**。反过来看，朴素特征差 47.1 也说明：这个表示位不能随便拿差分填充，瓶颈式的条件压缩是必要的。

### 6.5 toy 实验：误差斜率的操纵版四级台阶

`scripts/world_memory_experiments/wm27_toy.py`：12 个「过程量」对象（液位/计数类状态，恒定速率 $r \sim U(0.15, 0.45)$/步持续变化），各自交替「可见块」（4–12 步）与「遮挡块」（2–60 步对数均匀），可见时得观测 $o = s + \mathcal{N}(0, \sigma)$，$\sigma = 0.45$。四种记忆共享同一观测流，只比「出视野后怎么演化」：**Frozen**（存最后一次观测 = WM 01 Replay 的操纵版）、**SlideWin**（最近 8 次观测平均）、**NaiveDiff**（lag-1 帧差当速率）、**EvoMem**（最长基线 ≤45 步的两点差分估速率，模仿 Delta Tokenizer 的源条件差分）。

**状态误差按遮挡时长分桶**：

| 遮挡时长 | Frozen | SlideWin | NaiveDiff | EvoMem |
|----------|--------|----------|-----------|--------|
| 1–5 步 | 0.894 | 2.448 | 1.734 | **0.425** |
| 6–15 步 | 2.978 | 4.585 | 5.465 | **0.620** |
| 16–35 步 | 7.157 | 8.836 | 12.586 | **1.044** |
| 36–60 步 | 12.810 | 14.431 | 21.982 | **1.637** |

**误差-遮挡时长 OLS 斜率**：Frozen 0.291 ≈ 速率均值 $\bar{r} = 0.30$；SlideWin 0.277；NaiveDiff **0.509 ≈ 0.8σ√2 = 0.51**；EvoMem 0.030。**速率估计 RMSE vs 差分基线长度 $L$**：L=1/2/5/15/45 → 0.6365 / 0.3181 / 0.1274 / 0.0418 / 0.0143，与理论 $\sigma\sqrt{2}/L$（0.6364 / 0.3182 / 0.1273 / 0.0424 / 0.0141）几乎重合。

四条结论，每条对回论文：

1. **冻结的斜率 = 速率均值**：WM 01 的「误差斜率 = 对动力学的无知程度」在操纵版原样成立（0.291 vs $\bar r$ 0.30）；
2. **朴素帧差斜率 0.51 > 冻结 0.30**：噪声被当成了变化，外推越久错得越快——toy 里 NaiveDiff 在长遮挡桶垫底（21.98），正是论文 naive 47.1 < w/o delta 52.3 的机制级复现；
3. **滑窗对单调过程量反而更差**（短遮挡 2.448 vs Frozen 0.894）：窗口平均给不出速率，只引入约 $3.5\bar r$ 的滞后偏移——「多存几帧」不等于「存了变化」；
4. **差分基线长度是关键旋钮**：速率噪声 $\sigma\sqrt{2}/L$ 随基线线性下降——论文把 source-target 间隔定为 **15 步**（Table 4）而不是相邻帧，面板（3）给出量化理由：L=15 时速率估计 RMSE 0.0418，比 lag-1 帧差低 15 倍。代价是隐含假设「15 步内速率近似恒定」——对突变式交互（抓取瞬间）这个假设会破。

## 8. 局限、个人评价与第二辑收束

### 8.1 论文的边界与含糊处

1. **「状态演化」存的是观测到的演化**：模型不从关键帧之间推断转移、不重建未观测中间状态（论文自己的声明）。遮挡期间的状态外推——StEvo 意义上的真演化——仍然缺席：遮挡 60 步的对象回来时，记忆里只有 60 步前的证据。WM 01 主线的最后一格（看不见时的外推）在操纵版依旧空着；
2. **多尺度是手工的**：锚点 0/t−30/t−15/t、间隔 15 步、三组近期 delta 全是超参，不学习也不自适应任务节奏；
3. **评测协议不完全对齐**（论文如实注明）：RoboMME 基线为 50 回合 × 3 seed × 3 checkpoint 平均，EvoMem-VLA 是 100 回合；基线分数取自发表报告未重训——82.0 vs 44.5 的量级差不受影响，但个位数差距需要打折看；
4. **Keyframe Head 的正类权重 7** 暗示正样本高度稀少；阈值 0.55 的敏感性没有消融；
5. **Observe & Pick Up 28.0**（全场最弱）：单次观测记忆任务上 delta 无从发力——变化证据的价值以「重复交互」为前提。

### 8.2 个人评价

这是 VLA 组里**概念上最贴主线的一篇**：它把「记忆该存什么」从状态（快照）推到变化（delta），并用一个几乎工程洁癖的设计实现——预训练完就丢解码器、冻结一切可冻结的、每个 token 只代表真实观测过的帧对。最值得记住的消融是朴素特征差 47.1 < 不用 delta 52.3：**表示学习在这里不是锦上添花，是把「变化」从噪声里分离出来的唯一途径**。局限同样清晰：它解决的是「记不住发生了什么」，不是「看不见时在发生什么」——后者要等动力学模型（[WM 24](../WM_24_mem_world/) 一脉）或真正的外推机制。

### 8.3 第二辑收束（WM 18–27）

[WM 17](../WM_17_summary/) 收束第一辑时立了三轴地图（存哪 × 存什么 × 看不见时怎么演化）。第二辑十篇在上面添的格：

| 组 | 篇 | 三轴上的新格 |
|----|----|--------------|
| 视频组 18–22 | [GEN3C](../WM_18_gen3c/) / [空间记忆](../WM_19_spatial_memory/) / [Context as Memory](../WM_20_context_memory/) / [WorldPack](../WM_21_worldpack/) / [World-T3](../WM_22_world_t3/) | 「存哪」轴五个新值：3D 点云缓存、TSDF 锚定分层记忆、检索式交互上下文、动态帧压缩、**参数即记忆**（TTT——把记忆从上下文搬进权重） |
| VLA 组 23–27 | [MemoryVLA](../WM_23_memoryvla/) / [Mem-World](../WM_24_mem_world/) / [MemoryWAM](../WM_25_memorywam/) / [AtlasVLA](../WM_26_atlasvla/) / 本篇 | 「怎么演化」轴的操纵答案梯度：检索回放（23）→ 动作条件世界模型外推（24）→ 事件锚帧混合（25）→ 几何锚 + 覆盖更新（26）→ **变化证据**（27） |

两条跨辑的主线观察：

1. **「看不见时怎么演化」的两辑合账**：第一辑给出的答案梯度（冻结 → 隐式 → monitor → 编排 → 引擎 → 程序 → 等变）在第二辑增加了三个新格——**参数**（TTT，22）、**几何覆盖**（AtlasVLA，26）、**变化证据**（本篇）。但两辑共同留下的空格只有一个：**观测中断期间的外推**——视频侧靠生成先验硬猜（MemoBench 证明猜不准），操纵侧靠世界模型（Mem-World）或干脆存证据（本篇）绕开。把这一格填上的那篇论文，会是第三辑的头条；
2. **操纵版给记忆问题加了一个视频版没有的约束**：动作。视频世界模型的记忆只需服务渲染；VLA 的记忆还要服务**控制**——所以「任务相关性」变成了第一公民（AtlasVLA 的意图查询、本篇的子任务路由、MemoryVLA 的认知流）。三轴地图或许该加第四轴：**记忆为谁服务**（渲染 vs 规划 vs 控制）。

第一辑的五个开放问题（[WM 17](../WM_17_summary/) §开放问题）状态更新，如实汇报：开放域类型系统——未解决；隐式/显式切换器——AtlasVLA 的任务级配置路由是最接近的雏形（但不是学的）；评测地面真值——RMBench/RoboMME 延续了「用基准测基准」的循环性（WM_07 已辨析）；写入端主动视觉——Keyframe Head 的「预测何时记录」是这一格的第一个学习式答案；可学性统一定理——两辑 26 个 toy 的斜率表仍在等一个统一表述。
