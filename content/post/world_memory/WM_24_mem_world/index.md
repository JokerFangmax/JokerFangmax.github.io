# WM 24：Mem-World——腕部视角的 4D surfel 记忆与抓取中的持久世界

> 📖 本篇精读 **Mem-World: Memory-Augmented Action-Conditioned World Models for Persistent Robot Manipulation**（Zirui Zheng, Jiaqian Yu, Xiongfeng Peng 等；大连理工大学 + Samsung R&D Institute China-Beijing；arXiv:2606.18960v3，2026.09）。VLA / 机器人组（WM 23–27）第二篇：把系列一直讨论的「遮挡持久性」搬进真实抓取流程——腕部相机频繁被夹爪遮挡、快速自运动，世界模型必须在**证据时有时无**的条件下保持场景。

## 1. 这一篇解决什么问题

### 1.1 腕部视角的两面性

操作型世界模型通常用多视角：第三方相机给全局场景，腕部相机给细粒度的手-物交互。问题在于**腕部视角既高度 informative 又高度 unstable**：相机随末端执行器运动，自运动快；末端与被操纵物体频繁遮挡视野。结果是「当前观测常常只包含场景状态的部分证据」——自回归世界模型因此**遗忘或幻觉早先帧里看过的物体**，长程 rollout 尤其严重。

用 [WM 01](../WM_01_why_memory/) 的语言：观测方程 $o_t = r(s_t, c_t)$ 里，腕部相机的 $c_t$ 剧烈变化且常被遮挡，$o_t$ 对 $s_t$ 的覆盖时断时续——**记忆必须回答「上次看到这块区域是什么时候、从哪个视角」**，而不能只依赖最近几帧。

### 1.2 现有检索策略为什么不够

| 方案 | 做法 | 失效原因 |
|------|------|---------|
| Interactive World Simulator | 调大条件窗口，用最近 $N$ 帧相邻历史 | 扩窗口不解决本质：旧的干净证据早被挤出 |
| Ctrl-World / EVAC-AC | 全历史按固定步长采样 + **关节位姿相似度**加权 | 关节相似只是上下文相关性的**间接代理**：既捕捉不到末端遮挡引入的可见性约束，也无法优先「覆盖更全」的视角（如高位腕部俯视） |
| 导航式 FOV 检索（WorldMem / Context-as-Memory） | 相机 FOV 重叠或静态 3D 锚点检索 | 假设**静态场景**；抓取违反之——场景部分动态，机械臂本身造成结构化遮挡 |
| VMem（[WM 02](../WM_02_vmem/)） | surfel 索引的视图记忆 | 假设相机位姿直接可得、不区分时变元素——静态第一人称场景的设定 |

### 1.3 答案的一句话版

**W-VMem**：把 VMem 的静态 3D surfel 升级成 **4D（带时间属性）的腕部视角中心 surfel 记忆**——每个 surfel 记住自己「何时被创建/更新、是否属于被操纵物体」；生成前，由未来动作序列经正运动学算出**平均未来腕部位姿**，从它出发**逐时间步**渲染 surfel、按「几何可见性 × 任务相关性 × 时间衰减」打分，NMS 去冗余后取 top-K 历史帧作为世界模型的条件。

## 2. 最小背景

**动作条件世界模型**（action-conditioned world model）：在预训练视频扩散底座上加入低层动作条件，生成动作一致的机器人视频 rollout，可充当策略评估与训练的虚拟环境。谱系：IRASim（轨迹到视频的帧级动作条件）→ Ctrl-World（多视角：两个第三方 + 一个腕部，本篇底座）→ Interactive World Simulator（头视角 + 一致性模型实时闭环）。

**VMem 的 surfel 记忆**（[WM 02](../WM_02_vmem/)，本篇的直接前身）：每个 surfel $s_k = (p_k, n_k, r_k, I_k)$ 存 3D 位置、法向、半径、以及**观测过它的帧索引集** $I_k$。给定未来相机位姿，渲染可见 surfel、聚合其 $I_k$，检索覆盖比例最大的历史帧作为生成条件；预测帧再转成 surfel 合并回记忆。局限：假设场景静态（所有 surfel 联合渲染）、相机位姿已知、不区分时变元素。

**位姿从哪来**：导航世界模型里相机位姿是输入；机器人场景里输入的是**关节空间动作**——需要正运动学（forward kinematics）把动作变成未来腕部位姿。这是本篇必须补的第一块砖。

## 3. 方法总览

Mem-World = W-VMem 记忆模块 + 多视角动作条件世界模型（Ctrl-World 底座），rollout 时循环执行（论文 Algorithm 1）：

1. **初始化**：用离点图估计器（Depth Anything 3）从**首帧三个视角**构建初始 surfel 集——首帧三视角提供场景的完整观测；
2. **动作到位姿**：拿到未来动作 chunk，正运动学 + 腕部相机与末端的固定安装变换，得到未来各腕部位姿（转到点云参考系），取**平均未来腕部位姿** $\bar{c}_w$；
3. **检索**：对每个历史时间步，把「截至该时刻的 surfel 集」从 $\bar{c}_w$ 渲染一遍、算 surfel 分数，对候选帧做 NMS，取 top-K 历史帧 $H_t$；
4. **生成**：世界模型以当前观测、检索帧 $H_t$、动作 chunk 为条件，预测未来多视角观测；
5. **更新**：**只用腕部视角的预测帧**更新 surfel（新增/刷新时间戳），回到 2。

设计里最值得咀嚼的是两个「不对称」：初始化用三视角、更新只用腕视角（§4.3）；渲染打分逐时间步做、而 VMem 是全记忆联合渲染（§4.4）。

## 4. 核心原理完整推导

### 4.1 问题形式化

标准动作条件世界模型预测 $\hat{o}_{t+1:t+H} \sim \mathcal{W}(\cdot \mid \hat{o}_t, a_{t+1:t+H})$；Mem-World 在条件里加上检索到的历史帧集 $H_t = \{o_{g_1}, \ldots, o_{g_K}\}$（$g_i$ 为选中的历史时间步）：

$$
\hat{o}_{t+1:t+H} \sim \mathcal{W}\big(\cdot \,\big|\, \hat{o}_t,\, H_t,\, a_{t+1:t+H}\big).
\tag{Eq. 1}
$$

（注意符号碰撞：$H$ 在 Eq. 1 里是动作时域，在 Eq. 2 里又是时间半衰期——论文自己复用了这个字母，读时小心。）

**从动作到未来腕位姿**：第三方相机全程固定，位姿估计只需对腕部相机做。腕部相机与末端刚性安装 → 固定变换；动作 chunk 经正运动学得末端位姿序列，再经固定变换得腕部相机位姿（机器人基座系），最后用已知的第三方相机外参转到点云参考系。这一步是纯几何，无学习。

### 4.2 时间感知的 surfel 定义

VMem 的 surfel 是纯空间对象；抓取场景里机械臂和物体在动，W-VMem 给每个 surfel 加时间与任务属性：

$$
s_k = (p_k,\, n_k,\, r_k,\, t_k,\, m_k),
$$

- $t_k$：surfel 被创建与更新的**时间步集合**——4D 的「第四维」，让表示能携带时间动态；
- $m_k \in \{0, 1\}$：是否属于**被操纵物体**。由 VLM（Qwen3）从文本指令与初始观测分析出任务相关物体类别，再由分割模型（RoboEngine）在图像中分割、给对应 surfel 打标志。

对比 VMem 的 $(p_k, n_k, r_k, I_k)$：$I_k$（观测索引集）被 $t_k$（时间步集）取代——从「哪些帧看过我」变成「**何时**被看过」，时间信息从检索的副产品升级为一等公民。

### 4.3 只用腕部视角更新：一个反直觉但必要的选择

初始化用三视角（要完整场景），更新却**只用腕部视角的帧**。论文给两条理由，第二条尤其重要：

1. 腕部视角是**最操作中心的观测**：主动交互区域里的物体几何、纹理、接触状态、细粒度变化都看得最清；
2. **时间戳的语义依赖视角**：如果用第三方视角更新，其全局视野会让大多数可见 surfel 被反复刷新、带上几乎全部时间戳——$t_k$ 不再表示「何时被**移动的腕部相机**观测」，surfel 与历史腕部观测的关联就被冲掉了。限制更新来源，正是为了保住「这块区域何时被腕视角看过」这条检索线索。

（第三方视角的预测帧仍参与世界模型的生成与 loss，只是不进 surfel 更新。）

### 4.4 检索打分：几何 × 任务 × 时间

生成前，从平均未来腕位姿 $\bar{c}_w$ 出发，对每个历史时间步 $\tau$ **单独**渲染当时的 surfel 集 $S_\tau$——而不是像 VMem 那样把全部 surfel 联合渲染。理由：不同时间步观测到的 surfel 对应**不同交互阶段**（抓取前/后的同一物体是不同的 surfel 状态），联合渲染会糊掉时间线索。每个渲染出的 surfel $s$ 获得分数：

$$
\text{score}(s, t) = \frac{\langle n_s, \bar{v}_w \rangle}{1 + d_s} \cdot \ln(e + m_s) \cdot \Big[ \lambda_{\min} + (1 - \lambda_{\min})\, 2^{-\frac{T - t}{H}} \Big],
\tag{Eq. 2}
$$

三个因子各管一件事：

| 因子 | 形式 | 直觉 |
|------|------|------|
| 几何可见性 | $\langle n_s, \bar{v}_w \rangle / (1 + d_s)$：法向与平均未来视线方向的内积，除以 1 + 深度 | 正对相机、离得近的 surfel 证据质量高——呼应腕部观测噪声随距离增大 |
| 任务相关性 | $\ln(e + m_s)$：$m_s = 0$ 时为 1，$m_s = 1$ 时为 $\ln(e+1) \approx 1.31$ | 被操纵物体的证据温和加权（对数压缩，避免压倒几何项） |
| 时间衰减 | $\lambda_{\min} + (1-\lambda_{\min})\, 2^{-(T-t)/H}$ | $T$ 为当前时间步，半衰期 $H$（论文取 $0.3 \times T_{\max}$），底 $\lambda_{\min} = 0.1$ 保证老帧不被清零——**静态场景靠几何项翻旧账，动态物体靠衰减项追新值** |

每个候选时间步的帧分数 = 该步渲染 surfel 的分数聚合；随后做**非极大值抑制**（NMS）：腕部相机在抓取时会在物体上方徘徊，相邻时间步的帧高度冗余，NMS 强制选出的 top-K 覆盖不同区域。

<details><summary><b>展开：Algorithm 1（rollout 全流程伪代码）</b></summary>

输入：初始多视角观测 $o_{t=0}$、世界模型 $\mathcal{W}$、top-K、动作时域 $H$、交互步数 $T$。

```
S ← INITSURFELS(o_0);  O ← {o_0}
for t = 0 .. T−1:
    取动作 chunk a_{t+1:t+H}（来自策略或重放轨迹）
    c̄_w ← AVGWRISTPOSE(a_{t+1:t+H})          # FK + 固定变换 + 取平均
    对每个历史步 τ: score_τ ← SCORE(RENDER(S_τ, c̄_w))
    H_t ← TOPK-NMS({score_τ}, K)
    ô_{t+1:t+H} ← W(ô_t, H_t, a_{t+1:t+H})
    O ← O ∪ {ô_{t+1:t+H}}
    S ← UPDATESURFELS(S, ô^w_{t+1:t+H})       # 只用腕部视角
```

值得注意的闭环细节：喂给记忆更新的不是真值而是**世界模型自己的预测帧**——记忆的误差会随 rollout 复利，这正是评测要盯「重放一致性」的原因。

</details>

## 5. 训练与推理细节

<details><summary><b>展开：训练配方（数字标本）</b></summary>

- **底座与数据**：世界模型建立在 Ctrl-World 之上（两个第三方视角 + 一个腕视角的多视角动作条件模型）；主数据源 DROID（95,599 条轨迹，腕部相机运动多样）。硬件为 Franka Emika Panda + 2 自由度夹爪，1 腕部相机 + 2 第三方相机。
- **训练 clip 构造**：从 DROID 采 11K 条轨迹，把原本「时间相邻」的条件上下文**替换为 training-free W-VMem 检索出的几何相关上下文**——即先用不训练的 W-VMem 跑检索，再造训练样本，让模型在训练时就见到「推理时会遇到的条件分布」。这是一个与 [WM 03](../WM_03_memory_forcing/)「训练协议教模型分场合用记忆」同向的设计。
- **微调范围**：只微调世界模型的**时间注意力层**；8×H100、总 batch 32、约 2 天。
- **打分参数**（Eq. 2）：$\lambda_{\min} = 0.1$，时间半衰期 $H = 0.3 \times T_{\max}$。（原文此句有排版断错：「the λmin in Eq. (2) is set to 0.1, the temporal half-life H is set to 0.3 × Tmax」——语义可复原，但 $H$ 与 Eq. 1 的动作时域撞符号，论文未消歧。）
- **损失加权**：考虑到腕视角的重要性，腕视角预测的损失项上权。

**一个如实说明**：正文提到 W-VMem 的参数消融、检索时间开销分析与 150 条随机轨迹的泛化评测「见补充材料」，但 v3 的正文与参考文献里没有这些数字——本篇不引用未核实的补充材料内容。

</details>

<details><summary><b>展开：评测协议与五个策略评估任务</b></summary>

**一致性评测**：从 DROID 精选 34 条重放轨迹，每条至少满足其一：(1) 被操纵物体在腕视角被夹爪暂时遮挡、之后重新出现；(2) 腕部相机大幅往返运动。rollout 20 步生成 20 秒轨迹；指标为对 GT 的 PSNR / SSIM / LPIPS（计算类）+ SAM3 分割被操纵物体后的 DINOv2 特征相似度（模型类，Obj. Con.）。

**策略评估任务**（5 个，时序复杂度递增）：短程 2 个（pick cube to the plate、wipe table——单次抓放或单向运动）；长程 3 个（pick 1 object to 2 targets、pick 2 objects to 1 target、pick 2 objects to 2 targets——两个串行子任务、大幅环状腕部运动，逐步考验重访时保持物体与目标、跟随策略动作、跨复杂物体-目标配置的长期一致）。自定义环境 + 2 自由度夹爪对策略与世界模型都是分布外，故每任务采 50 episode 做后训练：$\pi_0$ / $\pi_{0.5}$ 微调 20K 步（4×H100），世界模型微调 5K 步以适配视觉域移。

**策略训练**：以 $\pi_{0.5}$ 为基础策略在未见过的初始布置上 rollout，每任务生成 200 条轨迹，按人工成功标注保留 20–30 条高质量的，用它们做后训练。

</details>

## 6. 实验与消融

### 6.1 世界模型一致性（论文 Table 1，34 条记忆压力重放轨迹）

| 相机 | 方法 | PSNR ↑ | SSIM ↑ | LPIPS ↓ | Obj. Con. ↑ |
|------|------|--------|--------|---------|------------|
| 第三方 | Cosmos Predict 2.5 | 22.80 | 0.819 | 0.089 | 0.579 |
| 第三方 | Ctrl-World | 23.17 | 0.828 | 0.076 | 0.573 |
| 第三方 | **Mem-World** | **25.30** | **0.878** | **0.054** | **0.619** |
| 腕部 | Ctrl-World | 17.34 | 0.623 | 0.281 | 0.476 |
| 腕部 | **Mem-World** | **19.21** | **0.691** | **0.236** | **0.524** |

（Cosmos Predict 2.5 只做单视角微调，未扩到多视角——算力原因，论文如实注明。）增益在**腕视角**上最显著——正是快速自运动 + 末端遮挡最集中的视角；定性结果里，盖子在被夹爪暂时遮挡后仍可恢复、黑色零食在往返相机运动后仍被一致地重新生成，而基线出现物体扭曲/消失。

### 6.2 检索策略消融（论文 Table 2）

在「条件于随机采样上下文训练的同一底座」上公平比较三种检索（隔离检索质量这一个变量——与本系列 toy 的控制方式一致）：

| 相机 | 检索策略 | PSNR ↑ | SSIM ↑ | LPIPS ↓ | Obj. Con. ↑ |
|------|---------|--------|--------|---------|------------|
| 第三方 | Short-term（最近 $N$ 帧） | 21.25 | 0.802 | 0.082 | 0.526 |
| 第三方 | Stride（固定步长采样） | 22.58 | 0.814 | 0.079 | 0.544 |
| 第三方 | **W-VMem** | **24.78** | **0.869** | **0.062** | **0.597** |
| 腕部 | Short-term | 15.04 | 0.526 | 0.353 | 0.401 |
| 腕部 | Stride | 17.06 | 0.614 | 0.295 | 0.463 |
| 腕部 | **W-VMem** | **18.97** | **0.680** | **0.248** | **0.502** |

腕视角上 W-VMem 对 Short-term 的 PSNR 差距接近 **+4 dB**。定性消融（论文 Fig. 3）：Short-term 与 Stride 给出的上下文不够 informative，rollout 中勺子扭曲、消失；W-VMem 检索到几何相关的历史帧，物体外观得以保持。

### 6.3 世界模型当模拟器：策略评估的保真度

五个任务上，从相同初始观测出发，比较策略在**真机**与**世界模型 rollout** 中的成功率：Mem-World 的想象成功率与真机高度相关（**$r = 0.97$，$p < 0.001$**），Ctrl-World 为 $r = 0.85$（$p < 0.01$）——**Pearson 相关提升 14.5%**。Ctrl-World 的偏差主要来自长程任务的显著掉分：stride 记忆撑不住长程场景一致性（定性案例：pick 2 objects to 1 target 里叉子被严重扭曲，后续抓取无法完成）。Mem-World 的绝对成功率整体低于真机但**差距跨任务均匀、无离群点**——线性对应关系成立，这正是「当排名器用」所需要的性质。

### 6.4 世界模型当数据引擎：策略训练

用 $\pi_{0.5}$ 在 Mem-World 里从未见过的初始布置 rollout、筛成功轨迹做后训练：三个长程任务的平均真机成功率从 **58% 提升到 72%**。记忆一致性 → 合成数据质量 → 策略性能的链条在这里闭合。

### 6.5 toy 实验：遮挡持久性——检索质量 vs 证据年龄

`scripts/world_memory_experiments/wm24_toy.py`：100×100 工作区，14 个静态物体 + 4 个被操纵物体（抓取瞬间状态改变 $\pm 4 \sim 10$）。末端执行器带窄 FOV 腕部相机（半角 22°、距离 45），距夹爪 14 以内的物体被遮挡；观测噪声 $\sigma(d) = 0.4 + 0.06d$（越近越清）。轨迹为脚本化抓取流程（2 轮 × 4 物体：接近 22 步 → 驻留 10 步〔目标被遮挡，第 5 步状态改变〕→ 后撤 16 步〔第 4–10 步相机回看目标，产生改变后的较远观测〕→ 游走 20 步）。每步由已知动作序列取平均未来腕位姿，只评估未来视野内的物体；四种策略各取 K=4 帧历史，证据读取理想化（检索帧中该物体的最优证据；无证据 → 先验误差 $E|N(0,10)| \approx 7.98$），按 $\Delta$ = 距上次干净观测的时长分桶（12 个 episode）：

| $\Delta$ 区间 | ShortTerm | Stride | WVMem | WVMem-noDecay |
|---|---|---|---|---|
| 0–4 | 2.408 | 2.608 | **2.189** | 2.357 |
| 4–8 | 7.979 | 6.757 | **1.977** | 1.925 |
| 8–16 | 7.979 | 6.754 | **2.086** | 2.173 |
| 16–32 | 7.979 | 6.914 | **2.227** | 2.570 |
| 32–64 | 7.979 | 7.210 | **1.595** | 1.962 |
| 64–128 | 7.979 | 7.280 | **1.698** | 1.884 |
| 128 步以上 | 7.979 | 6.918 | **1.629** | 1.681 |

被操纵物体上的两种失败模式分开统计（检索到改变前旧帧 = 过期证据；检索帧里根本没有该物体 = 无证据）：

| 策略 | 过期证据率 | 无证据率 |
|------|-----------|---------|
| ShortTerm | 0.066 | **0.451** |
| Stride | 0.079 | 0.433 |
| WVMem | **0.120** | 0.213 |
| WVMem-noDecay | 0.183 | 0.329 |

四个读数：

1. **ShortTerm 是悬崖型记忆**：$\Delta \le 4$ 时还行（2.4），一旦物体离开最近几帧就整段退回先验误差 7.98——WM 01 里 Replay 斜率故事的「窗口版」。
2. **Stride ≈ 先验 + 零星命中**：固定步长偶尔砸中物体可见的旧帧（6.7–7.3），但不看几何——它不知道「这一步要预测的区域里有什么」。
3. **WVMem 全程 1.6–2.2**：几何打分让它总是找回「这个区域看得最清楚的那几帧」，且**无证据率从 45% 压到 21%**——几何检索的主要收益是覆盖率，而不是单帧精度。
4. **过期与缺失是两种不同的失败**：WVMem 的过期证据率（12%）反而高于 ShortTerm（6.6%）——因为 ShortTerm 压根没有证据（45% 缺失）。「缺失」是随机灾难，「过期」是系统性偏差；时间衰减项（Eq. 2 第三因子）做的事就是把后者再压一半（noDecay 18.3% → 12.0%，同时缺失率 32.9% → 21.3%）。衰减项救不回的 12% 残余，就是「检索式记忆对已变化状态无能为力」的残余——与 WM 01 结论一同构。

> **脚本教训**（wm01 的教训原样重演）：分桶计数器 initially 放在了策略循环内——每个「物体-查询」被重复计 4 次，**所有 MAE 被静默除以 4**。暴露它的不是报错而是反常的常数：ShortTerm 在所有 $\Delta \ge 4$ 的桶里纹丝不动地钉在 1.995 = 7.98/4——「误差恰好等于先验误差的整数分之一」这种完美常数,恰是统计代码坏掉的指纹。多策略共享分母的代码,先手算一格再信输出。

## 8. 局限与个人评价

论文自列两条，我加三条：

1. **（论文）初始腕部帧的信息量依赖**：rollout 质量受首帧腕部观测影响；若首帧本身被遮挡或视野受限，后续预测缺乏足够的视觉证据。多视角一致性是值得做的补救。
2. **（论文）不显式施加物理约束**：抓球时即使夹爪没有建立对跖接触，世界模型仍可能预测成功抓取——需要接触/力等物理信号提高想象 rollout 的物理保真。
3. **（我的）检索式记忆的天花板在 toy 里可见**：WVMem 对已变化物体仍有 12% 的过期证据率（§6.5）——时间衰减是软偏置，不是状态更新。物体在遮挡期间的变化（被捏变形、被移动）没有动力学模型可依赖，「消失-重现后以更新状态回归」只能靠运气好的近期帧。这与 WM 01 的结论一完全一致：检索的误差下界 = 存储时刻与查询时刻之间的演化量。
4. **（我的）组件误差链**：W-VMem 依赖点图估计（Depth Anything 3）、VLM 任务物体识别（Qwen3）、分割（RoboEngine）与 FK 位姿——每一环的误差都会错位「surfel → 帧」的关联。论文没有报告这些组件失效时的鲁棒性。
5. **（我的）证据理想化**：正文所有一致性数字建立在「检索帧喂给世界模型」的端到端评测上，但**检索质量与生成利用程度没有分离**（toy 用理想化读取做了分离，论文没有）——r=0.97 的策略评估保真度里，多少来自检索、多少来自 Ctrl-World 底座本身的能力，无法从正文拆出。

个人评价：这是「把记忆工程搬到真机器人上」的一篇务实工作——机制上没有发明新东西（surfel 检索是 VMem 的、时间衰减是常规设计），但它对**操作场景特有约束**的三个回答都是对的：动作 → 未来位姿让检索可以**面向预测目标**（检索「马上要看的区域」的证据，而不是「刚看过什么」）；只用腕视角更新保住了时间戳的语义；逐时间步渲染 + NMS 处理了交互阶段与冗余。最有长期价值的数字反而是 r = 0.97：**世界模型要当策略评估器用，记忆一致性不是锦上添花，是排名正确性的瓶颈**——Ctrl-World 的 r = 0.85 崩在哪里？崩在长程任务，崩在物体扭曲。与 [WM 22](../WM_22_world_t3/) 合看，第二辑给出的两条路线（参数容量 / 几何结构）在机器人组都还有很长的路：真正的下一步是给检索记忆补上「物体在遮挡期间如何变化」的模型——那正是 [WM 27](../WM_27_evomem_vla/) 要谈的演化式记忆。
