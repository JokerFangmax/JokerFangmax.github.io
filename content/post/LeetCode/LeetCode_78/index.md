# LeetCode 78. 子集

> 题目链接：[https://leetcode.cn/problems/subsets/](https://leetcode.cn/problems/subsets/)  
> 难度：中等  
> 标签：位运算、数组、回溯

---

## 1. 题目描述

给定一个**不含重复元素**的整数数组 `nums`，返回该数组所有可能的子集（幂集）。

解集**不能包含重复的子集**，可以按任意顺序返回。注意空集 $\emptyset$ 与全集本身都算子集。

**数据范围：**

- $1 \le nums.length \le 10$
- $-10 \le nums[i] \le 10$
- `nums` 中的所有元素**互不相同**

**示例：**

```
输入：nums = [1,2,3]

输出：[[],[1],[2],[1,2],[3],[1,3],[2,3],[1,2,3]]

共 2^3 = 8 个子集。
```

---

## 2. 思路分析

### 2.1 暴力：从旧子集里逐个生长

从空集出发，每拿到一个新元素 `x`，就把它**拼到现有每个子集的后面**，生成一批新子集：

| 阶段 | 处理元素 | 已有子集 | 新增子集 |
|------|---------|----------|----------|
| 初始 | — | [] | — |
| 1 | 1 | [] | [1] |
| 2 | 2 | [], [1] | [2], [1,2] |
| 3 | 3 | [], [1], [2], [1,2] | [3], [1,3], [2,3], [1,2,3] |

每轮子集数翻倍，最终恰为 $2^n$ 个。这个「迭代生成」完全正确，也已经是 $O(n \cdot 2^n)$ 的最优量级。但它没有回答一个更根本的问题：**子集的总数为什么恰好是 $2^n$？** 回答了它，就能得到一行代码的解法。

### 2.2 关键观察：每个元素面临一次「进/不进」的独立决策

对 $n$ 个元素逐个发问：「你进不进这个子集？」每个元素 2 种回答，互相独立，组合起来 $2 \times 2 \times \cdots \times 2 = 2^n$ 种——**每个子集对应一个长度为 $n$ 的 0/1 决策串**。这个观察同时点亮两条路：

- **位运算**：把 0/1 决策串直接看成一个 $n$ 位二进制数 $mask \in [0, 2^n)$，第 $i$ 位为 1 就选 `nums[i]`。枚举 $mask$ 即枚举所有子集；
- **回溯**：决策串就是决策树的路径，第 $i$ 层决定「`nums[i]` 进还是不进」，每个节点都是一个完整答案（不止叶子）。

### 2.3 解法一：回溯（每个节点都收答案）

与全排列不同，子集**不要求选满 $n$ 个元素**——树中每个节点（含根代表的空集）都对应一个子集，因此「收答案」发生在**每个节点入口**而不是叶子处：

```
                    []            ← 收 []
            ┌───────┴───────┐
          不选1            选1
           []              [1]     ← 收 [1]
        ┌───┴───┐       ┌───┴───┐
      不选2    选2     不选2    选2
       []     [2]      [1]    [1,2]   ← 收 [2]、[1,2]
      ┌┴┐    ┌┴┐      ┌┴┐     ┌┴┐
     ...    ...      ...     ...      ← 第 3 层收 4 个，共 1+2+4 = 8
```

实现上通常不显式建「不选」分支：同层循环里依次**考虑选入 `nums[i..n-1]` 中的每个元素**，`start` 保证只向后看，天然消除 `[1,2]` 与 `[2,1]` 这类顺序性重复。

以 `nums = [1,2,3]` 走一遍（`start` 版）：

| 步骤 | 动作 | path |
|------|------|------|
| 进入 dfs(0) | 收答案 | [] |
| 选 1 → dfs(1) | 收答案 | [1] |
|   选 2 → dfs(2) | 收答案 | [1,2] |
|     选 3 → dfs(3) | 收答案 | [1,2,3]；返回，撤销 3 |
|   返回，撤销 2；选 3 → dfs(3) | 收答案 | [1,3]；返回，撤销 3 |
| 返回，撤销 1；选 2 → dfs(2) | 收答案 | [2] |
|   选 3 | 收答案 | [2,3] |
| 返回，撤销 2；选 3 | 收答案 | [3] |

8 个子集，一次不多一次不少。

### 2.4 解法二：位运算枚举（一行核心循环）

把 2.2 的对应关系写成代码：$mask$ 从 $0$ 到 $2^n - 1$，检查第 $i$ 位：

| $mask$ | 二进制 | 子集 |
|--------|--------|------|
| 0 | 000 | [] |
| 1 | 001 | [1] |
| 2 | 010 | [2] |
| 3 | 011 | [1,2] |
| 4 | 100 | [3] |
| 5 | 101 | [1,3] |
| 6 | 110 | [2,3] |
| 7 | 111 | [1,2,3] |

**同一个 $mask$ 的位模式，恰好是回溯树上一条根到叶的路径**——`mask & (1 << i)` 非零即「选 $i$」。回溯从上到下逐层确定每一位，位运算则是把所有路径横向摊开编号，两者在枚举同一棵隐式二叉树。

$n \le 10$ 意味着 $mask < 1024$，位运算是三行循环的最短实现；但它**依赖元素互异**（有重复元素时 90 题 子集 II 需要回溯 + 去重），也生成不出「按字典序」以外的定制顺序。两种解法都值得掌握。

## 3. 代码实现

```cpp
class Solution {
    vector<vector<int>> ans;
    vector<int> path;

    void dfs(vector<int>& nums, int start) {
        ans.push_back(path);                 // 每个节点都是一个子集（含根 = 空集）
        for (int i = start; i < (int)nums.size(); i++) {
            path.push_back(nums[i]);         // 选 nums[i]
            dfs(nums, i + 1);                // 只能向后看，保证组合不重
            path.pop_back();                 // 撤销，为不选 nums[i] 的分支清场
        }
    }
public:
    vector<vector<int>> subsets(vector<int>& nums) {
        dfs(nums, 0);
        return ans;
    }
};
```

实现要点：

1. **`ans.push_back(path)` 放在函数入口**而不是出口/叶子处——子集问题的答案遍布全树。这一行放在循环里或 `if` 里是最高频错误。
2. **`dfs(nums, i + 1)` 传 `i + 1` 而不是 `i`**：元素不能重复选自己；若可重复选（39 题 组合总和），才传 `i`。
3. **`path` 的拷贝发生在 `push_back(path)` 时**，后续 `pop_back` 不影响已收答案，无需手动复制。

位运算版（等价解，完整代码见第 6 节）核心只有三行：枚举 $mask \in [0, 2^n)$，对第 $i$ 位检查 `mask >> i & 1`，非零则选入 `nums[i]`。

两版复杂度完全相同；回溯版是 90（子集 II）、40（组合总和 II）等含重复/带约束变体的可扩展底座，位运算版是元素互异、求幂集时的最短直译。

## 4. 复杂度分析

- **时间复杂度**：$O(n \times 2^n)$。共 $2^n$ 个子集，构造每个子集平均 $O(n/2)$、最坏 $O(n)$（全集）；渐进上界 $O(n \cdot 2^n)$，且这已是输出规模的量级——答案本身含 $\Theta(n \cdot 2^n)$ 个整数，任何算法都不可能更快，两版解法同为最优。
- **空间复杂度**：$O(n)$（不算输出）。回溯递归深度至多 $n$、`path` 长 $\le n$；位运算版的临时 `cur` 同样 $\le n$。

对照排列：46 题是 $n! = O(2^{n\log n})$ 量级，所以 $n \le 6$；本题 $2^n$，$n \le 10$。**数据范围本身就是出题人给的复杂度提示**——见到 $n \le 10$ 优先想幂集枚举/状压，$n \le 20$ 想折半或回溯剪枝，$n \le 24$ 基本锁定折半枚举。

## 5. 常见疑问

**疑问一：为什么必须传 `start`，去掉它会怎样？**

去掉 `start`、每层都从 0 扫（不配 `used`），元素可被无限重复选，`[1,1,1]` 也会出现——那变成「可重复组合」而非子集。`start` 的语义是「**下标小于 `start` 的元素已经在更高层决策过了，本层不再回头**」，它把指数级的有序序列空间（$n^k$）裁剪成无序组合空间（$\binom{n}{k}$），是组合型回溯与排列型回溯的分水岭：**有序用 `used`，无序用 `start`**。

**疑问二：`1 << n` 会不会溢出？**

本题 $n \le 10$，`1 << 10 = 1024`，安全。但把同样写法搬到 $n = 31$ 时，`1 << 31` 在 `int` 上是未定义行为（符号位溢出），需要 `1LL << n` 或 `unsigned`。另一个隐蔽坑是「向右枚举」的写法 `mask = (mask - 1) & total`：位运算枚举子集内的子集时边界是 `mask` 而不是 `total`，手滑写错会凭空多出大量越界位。$n \le 10$ 的本题安全，但把位运算当模板记时要连着记边界。

**疑问三：输出顺序重要吗？空集要不要特判？**

题目允许任意顺序，两种解法顺序天然不同（回溯是「按字典序的前序遍历」，位运算是按 $mask$ 数值序），都能通过。空集也无需特判：回溯版根节点入口那次 `push_back` 收下的就是它；位运算版 `mask = 0` 的内层循环不执行、`cur` 为空。**「空集是所有集合的子集」在两种实现里都是代码结构的自然产物**，不需要任何 if。

## 6. 相关题目与模板

**位运算版完整实现**（幂集最短直译）：

```cpp
class Solution {
public:
    vector<vector<int>> subsets(vector<int>& nums) {
        int n = nums.size(), total = 1 << n;         // 2^n 个子集
        vector<vector<int>> ans;
        ans.reserve(total);
        for (int mask = 0; mask < total; mask++) {
            vector<int> cur;
            for (int i = 0; i < n; i++)
                if (mask >> i & 1)                    // 第 i 位为 1：选 nums[i]
                    cur.push_back(nums[i]);
            ans.push_back(move(cur));
        }
        return ans;
    }
};
```

**组合型回溯骨架**（与 46 题的排列骨架只差参数语义）：

```cpp
void backtrack(int start) {
    收答案;                       // 子集型：每个节点都收
    for (int i = start; i < n; i++) {
        if (剪枝) continue;
        path.push_back(nums[i]);  // 选
        backtrack(i + 1);         // 不回头（排列型此处改为全扫 + used）
        path.pop_back();          // 不选
    }
}
// 若为「恰好选 k 个」类，收答案改为 if (path.size() == k)。
```

**同类题目：**

- [LeetCode 90. 子集 II](https://leetcode.cn/problems/subsets-ii/)：含重复元素，排序后同层跳过相同值：`if (i > start && nums[i] == nums[i-1]) continue;`
- [LeetCode 46. 全排列](https://leetcode.cn/problems/permutations/)：排列型回溯，`used[]` 版决策树，与本题对照理解「`start` vs `used`」
- [LeetCode 77. 组合](https://leetcode.cn/problems/combinations/)：从 $n$ 个数里选 $k$ 个，本题加上叶子剪枝的特例
- [LeetCode 39. 组合总和](https://leetcode.cn/problems/combination-sum/)：候选无限复用，`backtrack(i)` 而非 `backtrack(i + 1)`
- [LeetCode 698. 划分为k个相等的子集](https://leetcode.cn/problems/partition-to-k-equal-sum-subsets/)：位运算枚举子集 + 状态压缩 DP 的进阶应用

**方法论总结**：「求所有子集」有两个互相映照的视角——**回溯视角**把它看成「每个元素进/不进」的决策树（答案在每个节点），**位运算视角**把它看成 $[0, 2^n)$ 的整数编号。元素互异、无附加约束时位运算最短；一旦出现重复元素、和的约束、字典序要求或需要剪枝，回到回溯骨架上做扩展。数据范围 $n \le 10$ 与 $n \le 20$ 是识别「指数枚举」类题目的最强信号。

**一句话总结**：幂集 = $n$ 次独立的「要或不要」——回溯把它竖成一棵二叉决策树，位运算把它摊成 $2^n$ 个编号，枚举的是同一个东西。
