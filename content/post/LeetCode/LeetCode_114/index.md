# LeetCode 114. 二叉树展开为链表

> 题目链接：[https://leetcode.cn/problems/flatten-binary-tree-to-linked-list/](https://leetcode.cn/problems/flatten-binary-tree-to-linked-list/)  
> 难度：中等  
> 标签：树、深度优先搜索、链表、二叉树

---

## 1. 题目描述

给你二叉树的根节点 `root`，请你将它展开为一个**链表**（用树的节点模拟，不用真正的链表节点）：

- 展开后的"链表"同样使用 `TreeNode`，其中 `right` 指针指向链表中下一个节点，而左子指针始终为 `nullptr`；
- 展开后的链表应该与二叉树的**前序遍历 (preorder traversal)** 顺序相同。

**要求原地 (in place) 展开**：过程不得创建新的树节点（可以改动节点间的连接关系）。函数没有返回值，直接修改 `root` 指向的树。

**数据范围：**

- 树中节点数目范围 $[1, 2000]$
- $-100 \le Node.val \le 100$

**示例：**

```
输入：
        1
       / \
      2   5
     / \   \
    3   4   6

输出（原地修改后）：
    1
     \
      2
       \
        3
         \
          4
           \
            5
             \
              6

即前序序列 1,2,3,4,5,6 组成的右链。
```

---

## 2. 思路分析

### 2.1 暴力：前序遍历存序列再串链

最直接的做法：前序遍历整棵树（递归或迭代），把节点指针依次存进数组；再扫一遍数组，`ans[i]->right = ans[i+1]`、`ans[i]->left = nullptr`。

正确且好写，代价是 $O(n)$ 时间 + $O(n)$ 辅助空间。但它完全没有利用"原地"的要求——**指针操作类题目，往往存在把辅助空间消掉的精巧做法**，本题正是训练这一点的好题。

### 2.2 观察：左子树插到根与右子树之间

前序遍历是"根 - 左 - 右"。所以对任意节点，展开后的结构必然是：

> `root -> (root 的左子树展开链) -> (root 的右子树展开链)`

即：**左子树整棵搬到右边、插在原右子树前面**。具体三步：

1. 找到左子树前序链的**末端**（左子树一路沿右指针走到底的节点）；
2. 把原右子树接到这个末端后面；
3. 整棵左子树挂到 `root->right`，`root->left` 置空。

用示例走一遍第一轮：

| 步骤 | 操作 | 树的状态 |
|------|------|---------|
| 初始 | — | 根 1，左 2-3-4，右 5-6 |
| 找末端 | 左子树根 2 沿右走：2 → 4 | 末端是 4 |
| 接右 | `4->right = 5` | 右链暂时为 2,3,4,5,6 |
| 搬左 | `1->right = 2`，`1->left = nullptr` | 根 1 只剩右链 |

此后 `root = 1->right = 2`，对 2 重复同样操作（2 的左是 3、右是 4；末端 3 接上 4，3 挂到右边）；节点 3、4、5、6 无左子树，直接跳过。全程每个节点只处理一次。

### 2.3 递归版：先展开后拼接，还是先拼接后展开

按 2.2 的规则可以自然写出**后序位置**干活的递归：先递归展开左右子树，回来后做"左搬右"拼接。递归版的难点在于"展开后的链头/链尾怎么拿"——头就是子树根本身，尾需要一路 `right` 走到底。

而 2.2 的三步操作其实**不需要递归**：它是纯指针搬运。由此得到著名的 **Morris 风格 $O(1)$ 空间迭代解**——对每个节点：

1. 有左子树：找前驱（左子树最右节点），接右链、搬左子树；
2. 移动到 `root->right`（可能是刚搬上来的原左孩子，也可能是原右孩子），重复。

关键在于：**搬完左子树后向右走一步，正好进入"刚接好的链"的下一个节点**，访问次序天然等于前序，不会漏也不会重。

### 2.4 为什么 $O(1)$ 空间是可能的：前驱节点就是现成的"回程票"

一般遍历需要栈，是因为进入左子树后**找不到回根的路**。但本题边走边拆：把左子树挂到右边之前，先让左子树的最右节点（它正是前序意义下左子树链的最后一个，也是即将"回到"原右子树的位置）接住原右子树——**回程路被铺在树里**，栈就可以省了。这与 Morris 遍历用"空闲右指针"回链的技巧一脉相承：树本身的空指针就是免费的存储。

| 方案 | 时间 | 空间 | 备注 |
|------|------|------|------|
| 前序存数组再串链 | $O(n)$ | $O(n)$ | 最直观，先保证正确 |
| 递归（后序拼接） | $O(n)$ | $O(h)$ | 逻辑清晰，面试可作为讲解跳板 |
| **迭代（Morris 风格）** | $O(n)$ | $O(1)$ | 每步找前驱看似费时，实则均摊 |

## 3. 代码实现

```cpp
class Solution {
public:
    void flatten(TreeNode* root) {
        while (root != nullptr) {
            if (root->left == nullptr) {
                root = root->right;         // 无左子树，直接沿右链下移
                continue;
            }
            // 1. 找左子树的最右节点：它将是原左链的末端
            TreeNode* pred = root->left;
            while (pred->right != nullptr)
                pred = pred->right;
            // 2. 原右子树接到左链末端之后
            pred->right = root->right;
            // 3. 左子树整棵搬到右边，左指针清空
            root->right = root->left;
            root->left = nullptr;
            // 4. 下移：进入刚搬上来的原左子树（前序的下一个节点）
            root = root->right;
        }
    }
};
```

等价的递归版（两版任选其一提交）：

```cpp
class Solution {
    // 展开以 root 为根的子树，返回展开后链的尾节点
    TreeNode* dfs(TreeNode* root) {
        if (root == nullptr) return nullptr;
        TreeNode* leftTail  = dfs(root->left);    // 先展开左子树
        TreeNode* rightTail = dfs(root->right);   // 再展开右子树
        TreeNode* tail = root;
        if (leftTail != nullptr) {                // 左链存在：搬右
            tail->right = root->left;
            tail = leftTail;
        }
        root->left = nullptr;
        if (rightTail != nullptr) {               // 原右链接在后
            tail->right = root->right;
            tail = rightTail;
        }
        return tail;
    }
public:
    void flatten(TreeNode* root) { dfs(root); }
};
```

几个实现细节：

1. **迭代版必须"先接右、再搬左"**。若先把 `root->left` 挂到 `root->right`，原右子树的指针就被覆盖丢了——顺序反了是本题最高发的 bug。
2. **`root->left = nullptr` 别忘**。前序链要求左指针全空，漏掉虽然多数判例不报错，但链表里留着左指针属于未完成展开。
3. **迭代版第 4 步下移后，新节点可能又有左子树**，外层 `while` 会继续处理——这正是"逐节点前序推进"的含义，不需要额外队列/栈。
4. 递归版中**叶子节点返回自身作为尾**，`nullptr` 返回 `nullptr`，用返回值把"链尾"逐层上传，避免了全局变量。

## 4. 复杂度分析

- **时间复杂度**：$O(n)$（迭代版均摊）。单看某个节点，找前驱最多走 $O(h)$ 步，似乎总和是 $O(nh)$；但换个记账角度——**每条边在整个算法中至多被"找前驱"这一步走过一次**：一旦某条路径被用作回程连接，它随即变成右链的一部分不再被搜索。更准确地说，每个节点作为"左子树最右链"成员至多被访问一次，加上外层 $n$ 次下移，总量 $O(n)$。递归版显然 $O(n)$（每节点访问一次）。
- **空间复杂度**：迭代版 $O(1)$，只用常数个指针；递归版 $O(h)$ 递归栈（树退化为链时 $O(n)$）。

对比三档：数组 $O(n)$ 空间 → 递归 $O(h)$ 空间 → 迭代 $O(1)$ 空间，是"逐步消除辅助结构"的经典阶梯。

## 5. 常见疑问

**疑问一：为什么展开顺序是前序而不是中序/后序？**

这是题目的规定，但规定得有道理：链表只有"右指针"一个前进方向，而树的"根 - 左 - 右"恰好映射到"自己 - 第一个后继链 - 第二个后继链"的单向拼接；2.2 的三步操作（左搬右、尾接右）正是前序结构的指针级翻译。若规定成中序，单靠改接指针无法原地完成（中序需要先深入左子树再回到根，缺少回程路），必须借助栈或线索化。

**疑问二：迭代版会不会把某些节点访问多遍、漏访问，或形成环？**

不会漏不会重：每轮循环恰好"定稿"一个节点（它的右指针此后不再被改，除非它作为别人左子树的尾端被接一次——发生在定稿之前）。不会成环：接右操作 `pred->right = root->right` 中，`pred` 是左子树内的节点而 `root->right` 在左子树之外，连接方向总是"子树内 → 子树外"，不可能绕回。找前驱的循环 `while (pred->right)` 若担心走到已接好的链上——不会，因为此时左子树尚未被搬动，其内部右指针还是原生的。

**疑问三：`flatten` 没有返回值，怎么确认"原地"改对了？**

判题机持有根指针，沿 `root->right` 逐个取值并断言 `left == nullptr`。所以自测时同样照此检查：前序值序列对、右指针贯通、左指针全空，三者缺一不可。常见的"假正确"是值序列对但部分节点 `left` 没清空（见 3 中细节 2），在严格判题下会挂。

## 6. 相关题目与模板

**可复用模板**（Morris 风格"前驱回程"骨架，把本题的"搬左"换成别的动作即可）：

```cpp
// O(1) 空间遍历/改造二叉树的通用相位
while (root != nullptr) {
    if (root->left == nullptr) {
        root = root->right;              // 无左子树：直接前进
    } else {
        TreeNode* pred = root->left;     // 找前驱（左子树最右节点）
        while (pred->right != nullptr) pred = pred->right;
        pred->right = root->right;       // 铺回程路
        // ... 对 root 做本题需要的指针改造 ...
        root = root->right;              // 沿"改造后"的路前进
    }
}
```

**方法论总结**：树的遍历要 $O(1)$ 空间，诀窍是**把辅助信息藏在树的空闲指针里**——Morris 遍历用空闲右指针暂存回程，本题用"前驱接右"直接把回程固化成结果结构。看到"原地修改树 + 顺序要求"的组合，优先想到这一族技巧。

**一句话总结**：前序展开的指针级翻译就是"**左子树搬到右边、左链尾端接住原右子树**"——递归 $O(h)$ 空间可解，而让前驱节点铺好回程路，就能做到原地 $O(1)$。
