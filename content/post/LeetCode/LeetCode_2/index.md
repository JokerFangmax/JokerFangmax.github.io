# LeetCode 2. 两数相加

> 题目链接：[https://leetcode.cn/problems/add-two-numbers/](https://leetcode.cn/problems/add-two-numbers/)  
> 难度：中等  
> 标签：递归、链表、数学

---

## 1. 题目描述

给你两个**非空**链表，表示两个非负整数。每位数字按照**逆序**方式存储，即链表头是数字的**最低位**（个位），每个节点只存一位数字。请你将这两个数相加，以同样的逆序链表形式返回表示和的链表。

除了数字 0 本身，两个数都**不含前导零**。

**数据范围：**

- 每个链表的节点数为 $[1, 100]$
- $0 \le Node.val \le 9$
- 题目保证链表表示的数字不含前导零

**示例：**

```
输入：l1 = [2,4,3], l2 = [5,6,4]
输出：[7,0,8]
解释：342 + 465 = 807

输入：l1 = [0], l2 = [0]
输出：[0]

输入：l1 = [9,9,9,9,9,9,9], l2 = [9,9,9,9]
输出：[8,9,9,9,0,0,0,1]
解释：9999999 + 9999 = 10009998
```

第三个示例是经典陷阱：两条链表长度不等，且最高位还要**再进一位**，结果比两条输入都长。

---

## 2. 思路分析

### 2.1 暴力：还原成整数再相加

最直白的想法：沿 `next` 把两条链表还原成两个整数，相加，再拆位建链表。

在本题的数据范围下这是**错误**做法：链表最长 100 位，而 C++ 的 `long long` 只有约 19 位十进制有效数字，直接溢出。即使用 Python 的大整数能过，这个解法也没有泛化能力——它把"逐位运算"这个本质问题偷换成了"语言是否自带大数"。面试中写下这个解法，下一个追问一定是"数字有一百万位怎么办"。

### 2.2 小学竖式：逐位相加，进位后传

正确姿势就是**竖式加法 (elementary addition)**：从最低位开始逐位相加，加上低位传来的进位 (carry)，当前位写入 $sum \bmod 10$，新的进位 $\lfloor sum / 10 \rfloor$ 传给下一位。

而这道题最妙的一点是：**链表逆序存储恰好就是竖式的运算顺序**。链表头是个位，`next` 指向十位、百位……而竖式加法正是从个位算起、进位沿着数位升高的方向传播——与 `next` 的方向完全一致。所以顺着链表走一遍，就是把竖式从下往上执行一遍，**不需要任何反转、不需要栈**。

逐位的运算规则只有一条：

$$digit = (d_1 + d_2 + carry_{in}) \bmod 10, \qquad carry_{out} = \left\lfloor \frac{d_1 + d_2 + carry_{in}}{10} \right\rfloor$$

其中 $d_1, d_2$ 是两条链表当前节点的数字，短的链表走完后按 $d = 0$ 处理。

### 2.3 用示例走一遍

`l1 = 2 -> 4 -> 3`（即 342），`l2 = 5 -> 6 -> 4`（即 465）：

| 位 | $d_1$ | $d_2$ | $carry_{in}$ | 本位和 | 写入 $digit$ | $carry_{out}$ |
|----|-------|-------|--------------|--------|--------------|---------------|
| 个位 | 2 | 5 | 0 | 7 | **7** | 0 |
| 十位 | 4 | 6 | 0 | 10 | **0** | 1 |
| 百位 | 3 | 4 | 1 | 8 | **8** | 0 |

结果链表 `7 -> 0 -> 8`，即 807，与 $342 + 465 = 807$ 一致。

再看进位击穿最高位的例子 `l1 = [5], l2 = [5]`：

| 位 | $d_1$ | $d_2$ | $carry_{in}$ | 本位和 | 写入 | $carry_{out}$ |
|----|-------|-------|--------------|--------|------|---------------|
| 个位 | 5 | 5 | 0 | 10 | **0** | 1 |
| 十位（双方都空） | 0 | 0 | 1 | 1 | **1** | 0 |

两条链表都空了但 $carry = 1$，还要**补一个节点**。这就是循环条件必须是 `while (l1 || l2 || carry)` 的原因——第三项专治这种 WA。

### 2.4 递归视角

逐位推进天然也是递归 (recursion)：定义 $add(l_1, l_2, carry)$ 处理当前位并返回"本位节点 + $add(\text{两条链表的 next}, \text{新 carry})$"。出口是两条链表都空且 $carry = 0$。递归深度 $\max(m, n) + 1$，本题最多 101 层，安全；但节点上万时仍应写迭代。

## 3. 代码实现

```cpp
class Solution {
public:
    ListNode* addTwoNumbers(ListNode* l1, ListNode* l2) {
        ListNode dummy(0);          // 哨兵节点：结果链表头不用特判
        ListNode* tail = &dummy;
        int carry = 0;

        // 三个条件缺一不可：进位可能比两条链表都长
        while (l1 || l2 || carry) {
            int sum = carry;
            if (l1) { sum += l1->val; l1 = l1->next; }
            if (l2) { sum += l2->val; l2 = l2->next; }
            carry = sum / 10;                     // 向高位的进位
            tail->next = new ListNode(sum % 10);  // 本位写入新节点
            tail = tail->next;
        }
        return dummy.next;
    }
};
```

与归并链表（LeetCode 21）不同，本题结果是一个**新数**，必须 `new` 新节点；短链表走空后按 $0$ 参与运算，靠两个 `if` 自然处理，不需要预先对齐长度。

## 4. 复杂度分析

- **时间复杂度**：$O(\max(m, n))$。循环次数等于 $\max(m, n)$（可能再多一次处理最终进位），每次 $O(1)$。
- **空间复杂度**：$O(1)$ 额外空间（哨兵 + 若干局部变量）；若把结果链表本身计入，则为 $O(\max(m, n) + 1)$ 个新节点。递归版另有 $O(\max(m, n))$ 的调用栈。

这是理论最优：输出本身就有 $\max(m, n)+1$ 位，任何算法至少要写这么多节点。

## 5. 常见疑问

**Q1：链表逆序存储，难道不应该先反转成正序再算吗？**

恰恰相反，逆序是出题人送你的礼物。竖式加法从最低位开始、进位向高位传播，而逆序链表的 `next` 方向正是"低位到高位"，运算顺序与遍历顺序天然一致。对比 [LeetCode 445. 两数相加 II](https://leetcode.cn/problems/add-two-numbers-ii/)（正序存储）：那里你才需要先反转链表或用栈把数位倒出来，最后还可能要再反转回去——做完 445 你会更感激 2 的逆序设计。

**Q2：最高位的进位什么时候产生、最容易怎么写丢？**

两链表同长且最高位和 $\ge 10$ 时（如 `[5]+[5]`、`[9,9]+[9,9]`）会产生超出两条链表长度的进位。最常见的 WA 写法是 `while (l1 || l2)`，循环结束后忘了检查 `carry`——正确做法就是把 `|| carry` 并进循环条件，让"补最高位节点"和普通位走同一套逻辑。

**Q3：进位最大能是多少，`sum` 会不会再加出进位？**

不会。每位输入 $d_1, d_2 \le 9$、$carry \le 1$，所以 $sum \le 19$，$carry_{out} \in \{0, 1\}$，归纳下去每一位都成立。这正是十进制竖式自洽的地方；换成二进制版本（[LeetCode 67. 二进制求和](https://leetcode.cn/problems/add-binary/)）只需把 $\bmod\ 10$ 换成 $\&\ 1$、$/$ 10 换成 $>> 1$。

## 6. 相关题目与模板

**可复用模板**（逐位模拟骨架，加法类题目通用）：

```cpp
// 逐位模拟加法：三条件循环 + carry 后传
int carry = 0;
while (a || b || carry) {
    int sum = carry;
    if (a) { sum += *a; a = a->next; }
    if (b) { sum += *b; b = b->next; }
    carry = sum / 10;
    append(sum % 10);
}
```

**方法论总结**：大数运算的通用姿势是**不还原成整数，直接在数位表示上模拟竖式**；核心不变量只有一条——"当前位的和 = 两条输入的当前数位 + 低位传来的进位"。链表、字符串、数组只是数位的容器不同。

- [LeetCode 67. 二进制求和](https://leetcode.cn/problems/add-binary/)：把进位基数从 10 换成 2

**一句话总结**：逆序链表就是一份从个位开始的竖式草稿——顺着 `next` 逐位加、进位后传，`while (l1 || l2 || carry)` 三个条件一个都不能少。
