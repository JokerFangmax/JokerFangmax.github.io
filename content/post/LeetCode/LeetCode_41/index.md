# LeetCode 41. 缺失的第一个正数

> 题目链接：[https://leetcode.cn/problems/first-missing-positive/](https://leetcode.cn/problems/first-missing-positive/)  
> 难度：困难  
> 标签：数组、哈希表

---

## 1. 题目描述

给定一个未排序的整数数组 `nums`，请找出**其中没有出现的最小的正整数**。

也就是说，从 $1, 2, 3, \ldots$ 开始逐个检查，第一个不在数组里的正整数就是答案。注意：负数、零和重复元素都不影响"正整数是否出现"的判断。

**进阶要求**：时间复杂度 $O(n)$，并且只使用常数级 $O(1)$ 的额外空间——这是本题被评为"困难"的核心原因。

**数据范围：**

- $1 \le nums.length \le 10^5$
- $-2^{31} \le nums[i] \le 2^{31} - 1$

**示例：**

```
输入：nums = [1,2,0]
输出：3      // 1、2 都在，缺 3

输入：nums = [3,4,-1,1]
输出：2      // 1 在，2 不在

输入：nums = [7,8,9,11,12]
输出：1      // 1 本身就没出现
```

---

## 2. 思路分析

### 2.1 暴力：从 1 开始逐个询问

最直接的做法：令答案 $ans$ 从 $1$ 开始，每轮线性扫描数组看 $ans$ 在不在，不在就返回。最坏 $O(n^2)$——例如 `[1,2,3,...,n]` 要问 $n+1$ 次，$10^5$ 规模下约 $10^{10}$ 次比较，必然超时。

两个常规优化都不满足进阶：

| 做法 | 时间 | 空间 | 短板 |
|------|------|------|------|
| 排序后从头扫 | $O(n \log n)$ | $O(\log n)$（快排栈） | 时间、空间都不达标 |
| 哈希集合存所有数 | $O(n)$ | $O(n)$ | 时间达标，空间超标 |
| 从 1 逐个询问 | $O(n^2)$ | $O(1)$ | 时间超标 |

进阶要求"线性时间 + 常数空间"同时成立，这逼着我们**把数组自己当成哈希表**。

### 2.2 关键观察：答案被限制在 $[1, n+1]$ 内

设 $n = nums.length$。由抽屉原理 (pigeonhole principle)：

- 如果 $[1, n]$ 这 $n$ 个正整数**全部**出现在数组里，答案只能是 $n + 1$；
- 否则 $[1, n]$ 中至少缺一个，答案就是缺失者中最小的那个，必然 $\le n$。

所以答案 $\in [1, n+1]$。这个观察有两个直接推论：

1. **值不在 $[1, n]$ 内的元素（负数、零、大于 $n$ 的数）对答案毫无贡献**，可以无视；
2. 我们只需要关心"值 $v \in [1, n]$ 是否出现"，这正是 $n$ 个槽位能记录的信息——**下标 $0 \sim n-1$ 天然对应值 $1 \sim n$**。

于是得到**原地哈希 (in-place hashing)** 的设计：让值 $v$ 归位到下标 $v - 1$，即整顿之后 ideally 有 $nums[i] = i + 1$。整顿结束后再扫一遍，第一个 $nums[i] \ne i + 1$ 的位置就报告答案 $i + 1$；全都就位则答案为 $n + 1$。

### 2.3 归位怎么做：交换的连锁反应

从左到右遍历，对每个位置 $i$：

- 若 $nums[i] \in [1, n]$ 且它**没**在正确位置上（即 $nums[nums[i] - 1] \ne nums[i]$），就把它换到家里去：`swap(nums[i], nums[nums[i] - 1])`；
- 换回来的新值可能也需要归位，所以用 `while` 而不是 `if`，在位置 $i$ 上持续处理，直到来的值"无家可归"（越界）或"已在家"（家里坐着的正是它自己，说明是重复值）。

以 `nums = [3,4,-1,1]`（$n = 4$）逐步走一遍，记「位置 i ← 值」：

| 步骤 | 操作 | 数组状态 | 说明 |
|------|------|----------------|------|
| $i=0$ | 3 应去下标 2，交换 | `[-1,4,3,1]` | 3 归位到下标 2 |
| | -1 越界，停 | `[-1,4,3,1]` | 位置 0 处理完毕 |
| $i=1$ | 4 应去下标 3，交换 | `[-1,1,3,4]` | 4 归位 |
| | 1 应去下标 0，交换 | `[1,-1,3,4]` | 1 归位 |
| | -1 越界，停 | `[1,-1,3,4]` | 位置 1 处理完毕 |
| $i=2$ | 3 已就位（$nums[2]=3$） | `[1,-1,3,4]` | 跳过 |
| $i=3$ | 4 已就位（$nums[3]=4$） | `[1,-1,3,4]` | 跳过 |

第二遍扫描：$nums[0] = 1$ ✓，$nums[1] = -1 \ne 2$ ✗ → 答案为 $2$。与示例一致。

## 3. 代码实现

```cpp
class Solution {
public:
    int firstMissingPositive(vector<int>& nums) {
        int n = nums.size();

        // 第一遍：原地哈希，把值 v in [1, n] 归位到下标 v-1
        for (int i = 0; i < n; i++) {
            // 值必须落在 [1, n]；家里坐的还不是自己，才需要交换
            // 条件写成 nums[nums[i]-1] != nums[i] 而非 nums[i] != i+1，
            // 否则遇到重复值会无限交换（见第 5 节）
            while (nums[i] >= 1 && nums[i] <= n
                   && nums[nums[i] - 1] != nums[i]) {
                swap(nums[i], nums[nums[i] - 1]);
            }
        }

        // 第二遍：第一个不满足 nums[i] == i+1 的位置给出答案
        for (int i = 0; i < n; i++) {
            if (nums[i] != i + 1) return i + 1;
        }
        return n + 1;   // [1, n] 全部就位，只能缺 n+1
    }
};
```

两个实现细节：

1. **内层是 `while` 不是 `if`**。换回来的值往往也需要归位，在原地继续处理才能把整条"交换链"走完。
2. **归位条件比较的是"家里的值"，不是"下标"**。`nums[nums[i] - 1] != nums[i]` 在值重复时天然终止，这是防死循环的关键。

## 4. 复杂度分析

- **时间复杂度**：$O(n)$。看似两层循环，但每一轮 `swap` 都**把一个值精确送回它的家**——一个位置一旦坐上正确的值就永远不再参与交换。$n$ 个位置至多发生 $n$ 次成功归位，`while` 的总执行次数因此是 $O(n)$，均摊到外层每轮 $O(1)$。这与单调队列、并查集路径压缩同属"均摊分析"的经典案例。
- **空间复杂度**：$O(1)$。所有信息都记录在 `nums` 自身，只用了常数个变量（不计输入数组）。

对照 2.1 节的表格：原地哈希同时做到了线性时间与常数空间，达到进阶要求。

## 5. 常见疑问

**疑问一：为什么答案不会超过 $n + 1$？**

数组只有 $n$ 个格子，最多容纳 $[1, n]$ 中每个正整数各一次。若 $[1, n]$ 全到齐，下一个候选正整数恰好是 $n + 1$；若没到齐，缺失者就在 $[1, n]$ 之中。两种情况答案都 $\le n + 1$，所以第二遍扫描最多看到下标 $n$ 就必有结论，`return n + 1` 兜底即可。

**疑问二：值有重复时为什么不会死循环？**

考察 `nums = [1, 1]`，$i = 1$ 时若条件写成 `nums[i] != i + 1`：$nums[1] = 1 \ne 2$，交换后两个 1 互换位置，数组不变，条件永远成立——无限循环。而条件写成 `nums[nums[i] - 1] != nums[i]` 时：家里（下标 0）坐的已经是同一个值 $1$，条件为假，循环终止。一句话：**判"家是否被同一个值占着"，而不是判"我是否在我家"**。

**疑问三：能不能用"打标记"代替交换？**

可以，思路是先把越界值统一改成某个哨兵（如 $n + 1$），再用**符号位**记录"值 $i+1$ 出现过"（把 $nums[i]$ 取负）。两次遍历、不打乱原值顺序（最后可恢复）。缺点是流程琐碎：要处理取绝对值、值域清洗、以及符号标记与原值符号的冲突。交换归位版逻辑更整一，两遍循环各司其职，是更推荐的写法。

**可复用模板**（原地哈希 / 归位骨架，适用于"值域 $[1, n]$、要求 $O(1)$ 空间"的数组题）：

```cpp
// 把值 v in [1, n] 换到下标 v-1；重复值自动安全终止
for (int i = 0; i < n; i++)
    while (nums[i] >= 1 && nums[i] <= n && nums[nums[i] - 1] != nums[i])
        swap(nums[i], nums[nums[i] - 1]);
// 整顿后：nums[i] == i+1 当且仅当值 i+1 出现过
```
