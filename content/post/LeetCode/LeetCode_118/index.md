# LeetCode 118. 杨辉三角

> 题目链接：[https://leetcode.cn/problems/pascals-triangle/](https://leetcode.cn/problems/pascals-triangle/)  
> 难度：简单  
> 标签：数组、动态规划

---

## 1. 题目描述

给定一个非负整数 `numRows`请生成杨辉三角的前 `numRows` 行。

杨辉三角中，每个数是它**左上方**和**右上方**的数之和；每行的两端永远是 1。第 $r$ 行（从 0 开始编号）有 $r + 1$ 个元素，第 $c$ 个元素正是组合数 $\binom{r}{c}$。

**数据范围：**

- $1 \le numRows \le 30$

**示例：**

```
输入：numRows = 5

输出：
[
     [1],
    [1,1],
   [1,2,1],
  [1,3,3,1],
 [1,4,6,4,1]
]
```

注意输出是「数组的数组」：第 $i$ 行是一个长度为 $i+1$ 的 `vector<int>`。

---

## 2. 思路分析

### 2.1 暴力：对每个位置独立计算组合数

既然第 $r$ 行第 $c$ 列就是 $\binom{r}{c}$，最直接的想法是对每个位置套组合数公式：

$$\binom{r}{c} = \frac{r!}{c!\,(r-c)!}$$

三重代价：阶乘要预处理或现算；$r = 29$ 时 $29! \approx 8.8 \times 10^{30}$ 远超 `long long`（上限约 $9.2 \times 10^{18}$），必须改用乘法递推 $\binom{r}{c} = \binom{r}{c-1} \cdot \frac{r-c+1}{c}$ 避免中间溢出；每个位置的答案彼此独立计算，完全没利用相邻元素的关系。

问题的本质是：**杨辉三角的元素之间天然带着递推关系**，逐项独立计算是把结构信息扔掉了。

### 2.2 递推（动态规划）：每个数只依赖上一行

杨辉三角的定义本身就是状态转移方程：

$$dp[r][c] = dp[r-1][c-1] + dp[r-1][c], \qquad \text{边界 } dp[r][0] = dp[r][r] = 1$$

即「每个数 = 左上 + 右上」。逐行从上往下构造，构造第 $r$ 行时第 $r-1$ 行已经就绪，直接查表相加即可——不需要任何乘除法，也没有溢出风险（$r \le 30$ 时最大元素 $\binom{30}{15} = 155117520$，`int` 装得下）。

这就是最简单形态的动态规划 (dynamic programming, DP)：**当前状态由已计算出的更小状态线性表出，按依赖顺序填表**。它和背包、打家劫舍是同一个骨架，只是转移方程恰好只有一行加法。

### 2.3 逐行走一遍（numRows = 5）

用「上一行 → 本行」演示构造过程，行首尾补 1，中间每位取上一行相邻两数之和：

| 行 $r$ | 上一行 | 构造过程 | 本行 |
|--------|--------|----------|------|
| 0 | — | 直接写 1 | `[1]` |
| 1 | `[1]` | 首尾补 1 | `[1,1]` |
| 2 | `[1,1]` | 首位 1；中间 $1+1=2$；末位 1 | `[1,2,1]` |
| 3 | `[1,2,1]` | 1；$1+2=3$；$2+1=3$；1 | `[1,3,3,1]` |
| 4 | `[1,3,3,1]` | 1；$1+3=4$；$3+3=6$；$3+1=4$；1 | `[1,4,6,4,1]` |

5 行恰好 15 个元素，每个中间元素恰好做了一次加法——没有任何重复计算。

一个小优化点：由对称性 $\binom{r}{c} = \binom{r}{r-c}$，每行只需算前一半，后一半镜像复制。$numRows \le 30$ 时纯属锦上添花，但这个对称性是组合数最重要的性质之一，值得记住。

## 3. 代码实现

```cpp
class Solution {
public:
    vector<vector<int>> generate(int numRows) {
        vector<vector<int>> dp(numRows);
        for (int r = 0; r < numRows; r++) {
            dp[r].assign(r + 1, 1);            // 首尾及所有位置先置 1（边界）
            for (int c = 1; c < r; c++) {      // 只填中间部分
                // 转移：左上 + 右上
                dp[r][c] = dp[r - 1][c - 1] + dp[r - 1][c];
            }
        }
        return dp;
    }
};
```

两个实现细节：

1. **`dp[r].assign(r + 1, 1)` 把整行初始化为 1**：首尾两个位置本来就是边界值 1，中间位置反正要被覆盖，这样写省去单独处理首尾的分类讨论，循环条件简化为 `1 <= c < r`。
2. **按行填充、按行申请空间**：第 $r$ 行长度固定为 $r+1$，直接 `assign` 一次到位，避免 `push_back` 反复扩容。

## 4. 复杂度分析

- **时间复杂度**：$O(numRows^2)$。输出的总元素个数是 $\sum_{r=0}^{n-1}(r+1) = \frac{n(n+1)}{2}$，每个中间元素只做一次加法，与输出规模同阶——已经是理论下界（答案本身就有这么多元素）。
- **空间复杂度**：$O(1)$（不计输出）。额外只用了常数个循环变量；若把返回的二维数组算进去则是 $O(numRows^2)$，但这部分是题目要求的输出，无法省略。

## 5. 常见疑问

**疑问一：为什么不用组合数公式，明明 $O(1)$ 就能算一个数？**

乘法递推 $\binom{r}{c} = \binom{r}{c-1} \cdot \frac{r-c+1}{c}$ 单个位置确实是 $O(1)$，但题目的输出是**整个三角形**、共 $\Theta(n^2)$ 个数，逐个算总时间仍是 $O(n^2)$，没有渐近收益；反而引入了除法和潜在的中间溢出问题（先乘后除的顺序错了就爆 `long long`）。递推版只做加法，简单且安全。

**疑问二：从第 0 行还是第 1 行开始编号？**

本文统一用 0 开始：第 0 行是 `[1]`，第 $r$ 行有 $r+1$ 个元素。写成代码时最容易错的差一 (off-by-one) 是循环边界：填中间列用 `for (int c = 1; c < r; c++)`——当 $r \le 1$ 时循环体不执行，整行都是 1，恰好正确。若写成 `c <= r` 就会把边界位也覆盖，访问 `dp[r-1][-1]` 直接越界。

**疑问三：能不能只申请一行空间滚动着算？**

可以（这正是 [LeetCode 119. 杨辉三角 II](https://leetcode.cn/problems/pascals-triangle-ii/) 的 $O(k)$ 空间要求），但要注意**滚动方向**：若原地更新一行，必须**从右往左**刷。从左往右会先用新值覆盖 $dp[c-1]$，接着算 $dp[c]$ 时取到的是本行的新值而不是上一行的旧值。本题不卡空间，直接开二维表最清晰。

## 6. 相关题目与模板

**可复用模板**（线性 DP 填表骨架，从打家劫舍到背包都是它的变体）：

```cpp
// 按「状态依赖」顺序填表：先算小的，再算大的
for (int r = 0; r < n; r++) {
    init(dp[r]);                    // 边界状态
    for (int c = 1; c < r; c++)
        dp[r][c] = dp[r-1][c-1] + dp[r-1][c];   // 转移方程
}
```

方法论一句话：**识别出「当前值 = 若干更小状态的函数」，按依赖顺序填表，暴力中的重复计算就全部消失了**。

**同类题目：**

- [LeetCode 119. 杨辉三角 II](https://leetcode.cn/problems/pascals-triangle-ii/)：只要第 $k$ 行，$O(k)$ 空间滚动数组（从右往左刷）
- [LeetCode 120. 三角形最小路径和](https://leetcode.cn/problems/triangle/)：同一张表，从「填值」变成「取 min 的路径 DP」
- [LeetCode 198. 打家劫舍](https://leetcode.cn/problems/house-robber/)：转移方程从「左上+右上」变成「max(不选, 选)」，见本系列 [LeetCode 198 题解](../LeetCode_198/)
- [LeetCode 1922. 素数个数统计](https://leetcode.cn/problems/count-good-numbers/)：组合计数思想的另一种应用

**一句话总结**：杨辉三角是最纯粹的动态规划——转移方程写在定义里，$\binom{r}{c} = \binom{r-1}{c-1} + \binom{r-1}{c}$，识别它、按行填表，剩下的只是小心边界。
