# LeetCode 152. 乘积最大子数组

> 题目链接：[https://leetcode.cn/problems/maximum-product-subarray/](https://leetcode.cn/problems/maximum-product-subarray/)  
> 难度：中等  
> 标签：数组、动态规划

---

## 1. 题目描述

给你一个整数数组 `nums`，请找出**乘积最大的非空连续子数组**（该子数组中至少包含一个数字），并返回该子数组对应的乘积。

**数据范围：**

- $1 \le nums.length \le 2 \times 10^4$
- $-10 \le nums[i] \le 10$
- 任意子数组的乘积都保证是 32 位整数范围内的整数

**示例：**

```
输入：nums = [2,3,-2,4]
输出：6
解释：子数组 [2,3] 有最大乘积 6。

输入：nums = [-2,0,-1]
输出：0
解释：结果不能为 2，因为 [-2,-1] 不是连续子数组。
```

---

## 2. 思路分析

### 2.1 暴力：枚举所有子数组

枚举左端点 $i$、右端点 $j$，边扩边乘，$O(n^2)$ 便能算出所有子数组的乘积。$n = 2 \times 10^4$ 时约 $2 \times 10^8$ 次乘法，C++ 勉强能过但毫无美感。我们的目标是线性。

### 2.2 借鉴"最大子数组和"？只维护最大值会翻车

做过 [LeetCode 53. 最大子数组和](https://leetcode.cn/problems/maximum-subarray/) 的第一反应是照搬 Kadane 算法：$dp[i]$ = 以 $i$ 结尾的最大乘积，$dp[i] = \max(nums[i],\ dp[i-1] \cdot nums[i])$。

对加法这成立，因为加法是"单调"的：接上一个大和只会更好。**乘法不单调，负数会翻转一切。** 看反例：

```
nums = [2, 3, -2, 4]

以 -2 结尾时：maxP = max(-2, 2*3*(-2)) = -2
以  4 结尾时：maxP = max(4, -2*4) = 4     ← 只维护最大值，得到 4
真实答案：[2,3] 的乘积 6，已在 -2 之前的
"2,3" 那段信息被 -2 污染后丢失了
```

问题出在：当前最大的 $dp[i-1]$ 若为负，遇到负数后反而变成候选最小；而当前**最小**的（很负的）值遇到负数后一跃成为最大。**"最差状态"是"最佳状态"的潜在跳板。**

### 2.3 同时维护最大与最小：$O(n)$

修正方案：定义

- $f_{\max}(i)$：以 $i$ 结尾的子数组乘积的**最大值**；
- $f_{\min}(i)$：以 $i$ 结尾的子数组乘积的**最小值**。

转移时三者取最（新起一段 / 接最大 / 接最小）：

$$f_{\max}(i) = \max\{nums[i],\ f_{\max}(i-1) \cdot nums[i],\ f_{\min}(i-1) \cdot nums[i]\}$$

$$f_{\min}(i) = \min\{nums[i],\ f_{\max}(i-1) \cdot nums[i],\ f_{\min}(i-1) \cdot nums[i]\}$$

以 `nums = [2,3,-2,4,-1]` 走一遍（注意它比示例多一个结尾的 -1，答案会变）：

| $i$ | $nums[i]$ | $f_{\max}$ | $f_{\min}$ | 当前最优 | 说明 |
|---|---|---|---|---|---|
| 0 | 2  | 2  | 2  | 2  | 单元素起步 |
| 1 | 3  | 6  | 3  | 6  | $[2,3]$ |
| 2 | -2 | -2 | -12 | 6 | 最大变最小、最小变最大，双通道都得留 |
| 3 | 4  | 4  | -48 | 6 | $-2 \times 4 = -8 < 4$，不如新起 |
| 4 | -1 | **48** | -4 | **48** | $-48 \times (-1) = 48$，第 3 步埋下的 $-48$ 爆发 |

答案 $48$，来自整个数组 $[2,3,-2,4,-1]$——两负相乘翻正，这正是"维护最小值"的价值：**$f_{\min}$ 是一张彩票，负数开奖。**

实现上两个变量滚动即可，注意必须先把旧值存下来再分别更新（两个转移互相引用对方的旧值）。

## 3. 代码实现

```cpp
class Solution {
public:
    int maxProduct(vector<int>& nums) {
        int curMax = nums[0];    // 以当前元素结尾的最大乘积
        int curMin = nums[0];    // 以当前元素结尾的最小乘积
        int ans = nums[0];
        for (int i = 1; i < (int)nums.size(); i++) {
            int x = nums[i];
            int preMax = curMax, preMin = curMin;   // 保存旧值，两转移互引
            curMax = max({x, preMax * x, preMin * x});
            curMin = min({x, preMax * x, preMin * x});
            ans = max(ans, curMax);
        }
        return ans;
    }
};
```

三个实现细节：

1. **`preMax` / `preMin` 必须先存副本**。若先更新 `curMax` 再用它更新 `curMin`，后者用到的是已被覆盖的新值，$f_{\min}$ 的转移就错了。
2. **`ans` 每轮都取 `curMax`**，而不是最后返回 `curMax`——最大乘积的子数组可能结束在任意位置，与 53 题同理。
3. 初始化用 `nums[0]` 而不是 1：$f_{\max}, f_{\min}$ 的定义是"以 $i$ 结尾"，第一个元素没有前驱，只能是自己。

## 4. 复杂度分析

- **时间复杂度**：$O(n)$。每个元素常数次比较与乘法。
- **空间复杂度**：$O(1)$。只用三个整型变量滚动。

对比：暴力 $O(n^2)$ → 双状态 DP $O(n)$。理论上乘积无法像和那样用前缀量 + 逆运算做区间查询（乘法在 0 处不可逆，负数需要额外记录符号个数），滚动双状态已是简洁的线性解。

## 5. 常见疑问

**疑问一：能不能像前缀和那样做"前缀积"，然后区间除回去？**

有两大障碍。其一，**0 不可逆**：一旦区间内含 0，除法会把整个计算毁掉，需要按 0 分段处理。其二，即便分段后无 0，负数乘积的符号问题也要单独统计——每段内还要维护负数个数的奇偶性才能知道"去掉前缀后符号是否翻转"。改来改去复杂度和代码量都不如双状态 DP，$O(1)$ 空间的两行转移它不香吗。

**疑问二：遇到 0 会自动处理吗？**

会。设当前 $x = 0$：$f_{\max}(i) = \max(0, \ldots) = 0$，$f_{\min}(i) = 0$，两个状态同时归零——语义上等价于"0 切断了所有历史，之后从 0 后面的元素重新起步"。由于候选里始终有"新起一段 $= x$"一项，0 后面的元素不会被迫乘上 0。例如 `[-2, 0, 3]`：状态依次为 $(-2,-2) \to (0,0) \to (3,0)$，答案 3，正确。

**疑问三：为什么题目保证答案在 32 位整数范围内，还不用 `long long`？**

题目明确"任意子数组的乘积都在 32 位范围内"，这是对数据的承诺（$|nums[i]| \le 10$ 且保证不溢出，意味着数组中绝对值大于 1 的元素很少连乘）。如果去掉这个保证（变体题常见），中间状态 $f_{\min} \cdot x$ 也可能溢出，稳妥起见用 `long long` 存状态、返回时比较即可。

## 6. 相关题目与模板

**可复用模板**（"最大/最小双状态"滚动 DP 骨架，凡遇到**负数或取反操作破坏单调性**的区间问题都可以套用）：

```cpp
// 以 i 结尾的最大 / 最小同时维护，候选 = {新起, 接max, 接min}
long long curMax = a[0], curMin = a[0], ans = a[0];
for (int i = 1; i < n; i++) {
    long long pMax = curMax * a[i], pMin = curMin * a[i];
    curMax = max({(long long)a[i], pMax, pMin});
    curMin = min({(long long)a[i], pMax, pMin});
    ans = max(ans, curMax);
}
```

**方法论对比**：一维"以 $i$ 结尾"型 DP 的三种形态——

| 题型 | 状态 | 转移候选 | 例题 |
|---|---|---|---|
| 最大子数组和 | 单状态 $f(i)$ | 新起 / 接上 | LeetCode 53 |
| 乘积最大子数组 | **双状态** $f_{\max}, f_{\min}$ | 新起 / 接 max / 接 min | 本题 |
| 打家劫舍 | 单状态（带约束） | 选 / 不选 | LeetCode 198 |

**同类题目：**

- [LeetCode 53. 最大子数组和](https://leetcode.cn/problems/maximum-subarray/)：本题的"加法版"，Kadane 单状态即可
- [LeetCode 1567. 乘积为正数的最长子数组长度](https://leetcode.cn/problems/maximum-length-of-subarray-with-positive-product/)：同样的正负翻转逻辑，把"乘积"改成"长度"
- [LeetCode 560. 和为 K 的子数组](https://leetcode.cn/problems/subarray-sum-equals-k/)：另一类子数组问题（计数）的标准解法，见[本题题解](../LeetCode_560/)
- [LeetCode 918. 环形子数组的最大和](https://leetcode.cn/problems/maximum-sum-circular-subarray/)：环形版 53 题，需要"最大和 + 最小和"双视角，思想与本题相通

**一句话总结**：乘法里**最小值是最大值的影子**——负数一来两者互换身份，所以两个都得维护。
