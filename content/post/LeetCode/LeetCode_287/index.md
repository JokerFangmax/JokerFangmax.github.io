# LeetCode 287. 寻找重复数

> 题目链接：[https://leetcode.cn/problems/find-the-duplicate-number/](https://leetcode.cn/problems/find-the-duplicate-number/)  
> 难度：中等  
> 标签：位运算、数组、双指针、二分查找

---

## 1. 题目描述

给定一个包含 $n + 1$ 个整数的数组 `nums`，其数字都在 $[1, n]$ 的范围内（$1$ 和 $n$ 都包括在内）。由鸽巢原理 (pigeonhole principle) 可知，至少存在一个重复的整数。

假设 `nums` 中**只有一个**重复的整数，返回这个重复的数。

**解决方案必须不修改**数组 `nums`，且只使用 $O(1)$ 的额外空间。

**数据范围：**

- $1 \le n \le 10^5$
- $nums.length = n + 1$
- $1 \le nums[i] \le n$
- `nums` 中只有一个重复的数字，但它**可能重复出现多次**（出现 $2$ 次及以上）

**示例：**

```
输入：nums = [1,3,4,2,2]
输出：2

输入：nums = [3,1,3,4,2]
输出：3

输入：nums = [3,3,3,3,3]
输出：3
```

注意最后一例：重复数可能占满整个数组。$n+1$ 个数塞进 $[1, n]$ 的值域，重复次数不定——这是它与 442 题（每个数最多出现两次）的关键区别，很多在其他题上可行的做法在这里会翻车。

## 2. 思路分析

### 2.1 常规武器为什么全部被禁

先盘点一排直觉解法，看它们各撞在哪堵墙上：

| 做法 | 时间 | 空间 | 是否修改数组 | 判定 |
|------|------|------|--------------|------|
| 暴力双重循环 | $O(n^2)$ | $O(1)$ | 否 | 超时（$10^5$ 下 $10^{10}$） |
| 排序后查相邻相等 | $O(n \log n)$ | $O(\log n)$ | **是** | 违反"不修改" |
| 哈希表 | $O(n)$ | **$O(n)$** | 否 | 违反 $O(1)$ 空间 |
| 原地交换（`nums[i]` 换到下标 `nums[i]`） | $O(n)$ | $O(1)$ | **是** | 违反"不修改" |

四条常规路被"不修改 + $O(1)$ 空间 + 准线性时间"三个约束逼到墙角。突破口必须来自题目中**额外的结构信息**：值域 $[1, n]$ 恰好比数组长度小 1。

### 2.2 二分答案：值域上的鸽巢

不再对下标做文章，改为**对答案的值域**二分。设一个判定问题：

> $cnt(x) = $ 数组中 $\le x$ 的元素个数。如果没有重复数（$[1,n]$ 每个恰好一次），必有 $cnt(x) \le x$ 对一切 $x$ 成立。

现在存在重复数 $t$（可能重复 $k \ge 2$ 次）。由鸽巢原理，$x \ge t$ 之后必有某个值被"挤多"，事实上可以证明：

- 若 $x < t$：$cnt(x) \le x$（下标 $1..x$ 最多"正常容纳"各一个，即使有别的数挤进来，$t$ 不在其中，总量仍守恒偏小）；
- 若 $x \ge t$：$cnt(x) \ge x + 1$（$t$ 出现至少两次，而 $[1,x]$ 除 $t$ 之外只有 $x-1$ 个不同的值，每个至多一次，合计已到 $x+1$；完整论证见疑问一）。

于是 $cnt(x) > x$ 是否成立，构成关于 $x$ 的单调分段：**前段全假、后段全真**，二分第一个"真"的 $x$ 就是答案 $t$。

用 `nums = [1,3,4,2,2]`（$n = 4$，值域 $[1,4]$）走一遍，$lo = 1, hi = 4$：

| 轮 | lo | hi | mid | cnt(≤mid) | 与 mid 比较 | 结论 | 新区间 |
|----|----|----|-----|-----------|-------------|------|--------|
| 1 | 1 | 4 | 2 | 3（1,2,2） | $3 > 2$ | $t \le 2$ | $[1,2]$ |
| 2 | 1 | 2 | 1 | 1（只有 1） | $1 \le 1$ | $t > 1$ | $[2,2]$ |
| 3 | 2 | 2 | — | 收敛 | — | $t = 2$ | — |

每轮"数一遍"花 $O(n)$，共 $O(\log n)$ 轮，总时间 $O(n \log n)$，空间 $O(1)$，数组原封不动——三个约束全部满足。

### 2.3 位运算：按比特投票

二分判定一次要数全部元素，能否一次扫描拿到更多信息？换一个统计口径——**逐比特**看。

对第 $b$ 位，统计数组中该位为 $1$ 的个数 $ones_b$，再统计**无重复基准**（值域 $[1,n]$ 每数各一次）中该位为 $1$ 的个数 $base_b$：

- 若 $ones_b > base_b$：重复数 $t$ 的第 $b$ 位是 $1$；
- 否则：$t$ 的第 $b$ 位是 $0$（严格论证见疑问三）。

$[1,n]$ 的位计数可以只循环 $n$ 次现场算，也可以 $O(\log n)$ 按位段规律算。整体时间 $O(n \log n)$、空间 $O(1)$。这是"二进制视角"的典型技巧，与只出现一次的数字系列一脉相承。

### 2.4 Floyd 判圈：把数组看成函数

最优雅的解法来自一个视角转换：定义函数 $f(i) = nums[i]$，从下标 $0$ 出发不断跳转 $i \to nums[i]$，得到链 $0 \to nums[0] \to nums[nums[0]] \to \dots$。

- 值域 $[1,n]$、下标 $0..n$：从 $0$ 出发的链条**永远跳不回 $0$**（没有任何 $nums[i] = 0$），而位置只有 $n+1$ 个，有限步内必然进入循环——**链一定有圈**；
- 圈的**入口**是谁？重复数 $t$ 出现 $\ge 2$ 次，即有 $\ge 2$ 个下标 $i$ 满足 $nums[i] = t$，也就是**有两个节点同时指向节点 $t$**——一个链要成圈，靠的正是这个"被指两次"的节点。因此**圈入口的编号就是 $t$**（严格说入口编号等于 $t$，见疑问二）。

于是问题变成"找链表的环入口"——[LeetCode 142. 环形链表 II](https://leetcode.cn/problems/linked-list-cycle-ii/) 的**Floyd 判圈算法 (Floyd's cycle detection)**：快慢指针第一次相遇后，一个指针回到起点，两者同速前进，再次相遇处即环入口。

对 `nums = [1,3,4,2,2]`（$n=4$），函数图像：$0\to1\to3\to2\to4\to2\to4\to\dots$，圈是 $2\to4\to2$，入口 $2$，重复数正是 $2$。指针推演：

| 阶段 | slow | fast | 说明 |
|------|------|------|------|
| 初值 | 0 | 0 | 相同起点 |
| 1 步 | $nums[0]=1$ | $nums[nums[0]]=nums[1]=3$ | fast 走两步 |
| 2 步 | $nums[1]=3$ | $nums[nums[3]]=nums[2]=4$ | |
| 3 步 | $nums[3]=2$ | $nums[nums[4]]=nums[2]=4$ | |
| 4 步 | $nums[2]=4$ | $nums[nums[4]]=nums[2]=4$ | **相遇于 4** |
| 回溯 | p=0, slow=4 | — | p 从起点出发 |
| +1 | $nums[0]=1$ | $nums[4]=2$ | 各走一步 |
| +2 | $nums[1]=3$ | $nums[2]=4$ | |
| +3 | $nums[3]=2$ | $nums[4]=2$ | **相遇于 2** → 答案 |

时间 $O(n)$（两圈以内必相遇），空间 $O(1)$，不修改数组——理论最优。

四种解法对比：

| 解法 | 时间 | 空间 | 难点 |
|------|------|------|------|
| 二分答案 | $O(n \log n)$ | $O(1)$ | 想到"对值域二分" |
| 位运算 | $O(n \log n)$ | $O(1)$ | 逐位比较的基准 |
| **Floyd 判圈** | $O(n)$ | $O(1)$ | 把数组看作链表的视角 |

## 3. 代码实现

```cpp
class Solution {
public:
    int findDuplicate(vector<int>& nums) {
        // Floyd 判圈：f(i) = nums[i)，从 0 出发必有环，环入口编号即重复数
        int slow = 0, fast = 0;
        do {
            slow = nums[slow];            // 慢指针一步
            fast = nums[nums[fast]];      // 快指针两步
        } while (slow != fast);

        int p = 0;                        // 一个指针回到起点
        while (p != slow) {
            p = nums[p];
            slow = nums[slow];            // 同速前进，相遇在环入口
        }
        return p;                         // 入口编号 = 重复的值
    }
};
```

若面试中被要求演示二分答案版（同样满足全部约束）：

```cpp
class Solution {
public:
    int findDuplicate(vector<int>& nums) {
        int n = nums.size() - 1;          // 值域 [1, n]
        int lo = 1, hi = n;
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            int cnt = 0;
            for (int x : nums) cnt += (x <= mid);   // 数一遍 <= mid 的个数
            if (cnt > mid) hi = mid;      // 重复数 <= mid：左半"超员"
            else           lo = mid + 1;  // 否则在右半
        }
        return lo;
    }
};
```

两个实现细节：

1. **判圈必须用 `do-while`**：初值 `slow == fast == 0`，用 `while` 判等会立刻退出，一个指针都没走。
2. **二分用 `mid = lo + (hi - lo) / 2`**：防溢出的习惯写法；本题 $n \le 10^5$ 不溢出，但值域版的二分骨架值得统一。

## 4. 复杂度分析

**Floyd 判圈：**

- **时间 $O(n)$**。设起点到环入口距离为 $a$、环长为 $b$。第一阶段快慢指针至多走 $2(a+b) \le 2n$ 步相遇；第二阶段两指针各走至多 $a + b$ 步。总计线性。
- **空间 $O(1)$**。两个（或三个）下标变量，数组只读。

**二分答案：**

- **时间 $O(n \log n)$**。$O(\log n)$ 轮二分，每轮线性扫描计数。
- **空间 $O(1)$**。只有 $lo, hi, mid, cnt$ 四个变量。

对比第 2.1 节被禁的四种做法：Floyd 是唯一同时做到线性时间、常数空间、不动数组的，代价是最高的思维门槛——视角从"数组"换成"隐式链表"。

## 5. 常见疑问

**疑问一：为什么"$x \ge t$ 时 $cnt(x) \ge x+1$"严格成立？（尤其重复数可能出现多次）**

把 $n+1$ 个元素按"值 $\le x$"和"$> x$"分成两桶。设 $t \le x$，$t$ 出现 $k \ge 2$ 次。

- 值域 $[1,x]$ 内除了 $t$ 还有 $x - 1$ 个不同的值，每个至多出现一次，这部分至多 $x-1$ 个元素；再加上 $t$ 的 $k \ge 2$ 次，得 $cnt(x) \ge (x-1) + 2 = x + 1$。
- 反之 $t > x$ 时，$[1,x]$ 共 $x$ 个值、每个至多一次，$cnt(x) \le x$。

两条合起来，$cnt(x) > x \iff x \ge t$，这就是二分判定单调性的完整证明——注意它**不依赖 $k$ 的具体大小**，所以重复多次不破坏结论。

**疑问二：为什么环入口的"编号"就等于重复数，而不是别的巧合？**

节点 $i$ 指向节点 $nums[i]$。环入口 $e$ 满足：链上第一次进入它之前，已经有节点指向它（否则成不了环）——即存在 $i \ne j$ 使 $nums[i] = nums[j] = e$，这正是"$e$ 被重复填入"。反过来，若 $t$ 是重复数，有两个下标指向节点 $t$，从 0 出发的链只要经过其中任意一个就会走进环，而环的入口恰是第一次被"第二次访问"的节点，编号即 $t$。一个更直接的核验：本题只有一个重复值，所以入口编号别无选择。

**疑问三：位运算法里，"某位多出来的 1"一定来自 $t$ 吗？缺失的数不会干扰吗？**

会干扰，但**方向是确定的**。设 $t$ 出现 $k$ 次（$k \ge 2$）。数组共 $n+1$ 个元素，其余 $n-1$ 个值各至多出现一次，由此可解出值域中**恰好有 $k-2$ 个值缺失**：由 $k + (n - 1 - (k-2)) = n + 1$ 成立。记缺失值集合为 $M$，$|M| = k-2$。对第 $b$ 位，把数组看作"基准 $[1,n]$ 各一份、多出 $(k-1)$ 份 $t$、缺失值各少一份"，有 $ones_b - base_b = (k-1) \cdot bit_b(t) - \sum_{m \in M} bit_b(m)$。

- 若 $bit_b(t) = 1$：差值 $\ge (k-1) - (k-2) = 1 > 0$——即使缺失值在第 $b$ 位**全部**为 $1$，也抵消不完多出的份数，判据 $ones_b > base_b$ 必然触发；
- 若 $bit_b(t) = 0$：差值 $= -\sum_{m \in M} bit_b(m) \le 0$，判据必然不触发。

两个方向都不被缺失值翻案，所以逐位判定的答案就是 $t$ 本身。不过这番推导确实绕，也是位运算法不如 Floyd 常用的原因——面试中给出 Floyd 或二分即可，位运算作为加分项了解。

## 6. 相关题目与模板

**可复用模板**（Floyd 判圈通用骨架，适用于一切"隐式链表找环"）：

```cpp
// 0 是链表头（不被任何节点指向的起点），f(i) 为下一步函数
int slow = START, fast = START;
do {
    slow = f(slow);
    fast = f(f(fast));      // 本题 f(i) = nums[i]
} while (slow != fast);
int p = START;
while (p != slow) { p = f(p); slow = f(slow); }
return p;                   // 环入口
```

**方法论总结**：当常规数据结构被约束（不许排序、不许哈希、不许改数组）逼死时，剩下两条路——**二分答案**（把"找值"变成"找满足单调判定的边界"，代价 $O(n \log n)$）和**视角转换**（把数组下标与值的映射看成图/链表，本题为最经典的隐式链表模型）。这两个套路分别对应"判定单调性"与"结构即算法"两种思维。

**同类题目：**

- [LeetCode 142. 环形链表 II](https://leetcode.cn/problems/linked-list-cycle-ii/)：显式链表版的环入口，Floyd 数学推导完全相同
- [LeetCode 442. 数组中重复的数据](https://leetcode.cn/problems/find-all-duplicates-in-an-array/)：值域条件类似，但允许修改数组，用"正负标记"做到 $O(n)$
- [LeetCode 448. 找到所有数组中消失的数字](https://leetcode.cn/problems/find-all-numbers-disappeared-in-an-array/)：同系列，正负标记找缺失值
- [LeetCode 645. 错误的集合](https://leetcode.cn/problems/set-mismatch/)：一个找"多出的"、一个同时找"多出的 + 缺失的"，可对照位运算/数学解法

**一句话总结**：$n+1$ 个值挤在 $[1,n]$ 的值域里，本身就构成一张带环的隐式链表——重复数就是环的入口，Floyd 判圈用两个指针把它走了出来。
