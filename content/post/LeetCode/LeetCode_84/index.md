# LeetCode 84. 柱状图中最大的矩形

> 题目链接：[https://leetcode.cn/problems/largest-rectangle-in-histogram/](https://leetcode.cn/problems/largest-rectangle-in-histogram/)  
> 难度：困难  
> 标签：栈、数组、单调栈

---

## 1. 题目描述

给定一个非负整数数组 `heights`，其中 `heights[i]` 表示第 `i` 根柱子的高度、每根柱子宽度均为 `1`，它们排成一排构成直方图。求**能框进直方图内的最大矩形面积**。

矩形必须完全落在直方图轮廓内部：选定一段**连续**的柱子 $[l, r]$，矩形高度只能取其中的最小高度 $\min_{l \le i \le r} heights[i]$，面积为该最小值乘以区间长度。

**数据范围：**

- $1 \le heights.length \le 10^5$
- $0 \le heights[i] \le 10^4$

**示例：**

```
输入：heights = [2,1,5,6,2,3]
输出：10

解释：取柱子下标 2 和 3（高度 5、6），最小高度 5，宽度 2，
     面积 5 × 2 = 10，是所有可行矩形中最大的。
```

---

## 2. 思路分析

### 2.1 暴力：枚举区间

最朴素的做法是枚举所有 $O(n^2)$ 个区间 $[l, r]$，同时维护区间最小值，面积 $= \min \times (r - l + 1)$，总代价 $O(n^2)$。$n = 10^5$ 时约 $10^{10}$ 次操作，超时。

换个枚举方式能好写一点：**枚举"谁是矩形中最矮的柱子"**。对每个 $i$，向两侧尽量扩展，直到碰到第一根严格更矮的柱子为止。设左侧第一个更矮者的下标为 $left[i]$、右侧为 $right[i]$（不存在记为 $-1$ 和 $n$），则柱子 $i$ 能撑起的最大矩形为：

$$
area(i) = heights[i] \times (right[i] - left[i] - 1)
$$

答案取 $\max_i area(i)$。逐柱双向扩展仍是 $O(n^2)$（单调递增的输入会退化为每次都扫到边界），但这个表述把问题**完全转化**成了求"两侧第一个更小元素"。

### 2.2 为什么会想到单调栈

"第一个更小元素"正是[LeetCode 739 每日温度](../LeetCode_739/)的对偶：739 求右侧第一个**更大**，这里求两侧第一个**更小**——把单调栈的弹栈条件反一个方向，维护**从栈底到栈顶递增**的栈即可。

关键观察：栈中柱子按高度递增排着队，当新来的柱子 $i$ 比**栈顶**矮时，栈顶柱子的"右侧第一个更小者"就出现了——正是 $i$，结算时机到了：

> 弹出栈顶 $t$，它的右边界是 $i$；左边界是弹出后**新的栈顶**（栈内递增，新栈顶是它左侧第一个更矮且还没被结算的柱子；若栈空则 $left = -1$）。

每根柱子入栈一次、出栈一次，$left$、$right$ 在弹栈瞬间同时确定，无需单独跑两遍。

### 2.3 用示例走一遍

`heights = [2,1,5,6,2,3]`，在末尾追加一个高度为 $0$ 的**哨兵 (sentinel)** 强制清栈（最后一根柱子右侧的"更矮者"需要有人来触发）。栈内用「下标(高度)」表示：

| i | 新高度 | 弹栈与结算 | 栈（下标） | 面积更新 |
|---|--------|-----------|-----------|----------|
| 0 | 2      | —         | 0(2)      | —        |
| 1 | 1      | 弹 0(2)：左 $-1$，宽 $1-(-1)-1=1$，面积 2 | 1(1) | $ans=2$ |
| 2 | 5      | —         | 1(1) 2(5) | —        |
| 3 | 6      | —         | 1(1) 2(5) 3(6) | —   |
| 4 | 2      | 弹 3(6)：左 2，宽 $4-2-1=1$，面积 6 | 1(1) 2(5) | $ans=6$ |
|   |        | 弹 2(5)：左 1，宽 $4-1-1=2$，面积 **10** | 1(1) 4(2) | $ans=10$ |
| 5 | 3      | —         | 1(1) 4(2) 5(3) | —   |
| 6 | 0(哨兵)| 弹 5(3)：左 4，宽 $1$，面积 3 | 1(1) 4(2) | — |
|   |        | 弹 4(2)：左 1，宽 $6-1-1=4$，面积 8 | 1(1) | — |
|   |        | 弹 1(1)：左 $-1$，宽 $6-(-1)-1=6$，面积 6 | 空 | — |

最大面积 $10$，与期望一致。注意下标 2 的柱子（高度 5）：它的右边界是下标 4 的柱子（高度 2），左边界是下标 1（高度 1），宽度 $4 - 1 - 1 = 2$，正是示例中"高度 5 × 宽度 2"的来源。

## 3. 代码实现

```cpp
class Solution {
public:
    int largestRectangleArea(vector<int>& heights) {
        int n = heights.size();
        stack<int> st;                  // 存下标，对应高度从栈底到栈顶递增
        int ans = 0;

        // 循环到 i == n：追加高度为 0 的哨兵，强制把栈清空
        for (int i = 0; i <= n; i++) {
            int h = (i == n) ? 0 : heights[i];
            while (!st.empty() && heights[st.top()] >= h) {
                int height = heights[st.top()];
                st.pop();
                // 左边界：弹出后的新栈顶（不存在则 -1）；右边界：i
                int left = st.empty() ? -1 : st.top();
                ans = max(ans, height * (i - left - 1));
            }
            st.push(i);
        }
        return ans;
    }
};
```

几个实现细节：

1. **哨兵代替显式清栈**。不加哨兵的话，循环结束后栈里还有柱子没结算（它们的右边界都是"数组尽头" $n$），要再写一段几乎相同的 while 循环。哨兵高度 $0$ 比谁都矮，天然触发全量弹栈，一份代码覆盖两种情况；$i = n$ 时循环结束，哨兵下标本身入不入栈都无所谓（循环即终止）。
2. **宽度公式 $(i - left - 1)$**。柱子 $t$ 被弹出时，区间 $(left, i)$ 开区间内的柱子都不比它矮，闭区间长度为 $i - left - 1$，两端的 $left$、$i$ 都是"第一个更矮者"，被排除在外。
3. **弹栈条件用 `>=`**。高度相等时也弹。直觉上等高柱子不该互相"截断"，但弹掉先来者只是**把它的宽度算小了**——后到的等高柱子会在自己的结算中把完整宽度补回来（两者中必有一个撑到全宽），最大值不受影响。用严格 `>` 也正确，两种写法只需自洽即可。

## 4. 复杂度分析

- **时间复杂度**：$O(n)$。每个下标入栈一次、出栈至多一次，总操作数不超过 $2n$，均摊每轮 $O(1)$（与 [739](../LeetCode_739/)、[239](../LeetCode_239/) 同款的均摊论证）。
- **空间复杂度**：$O(n)$。单调递增输入下所有下标同时在栈中。

对比：暴力 $O(n^2)$ → 单调栈 $O(n)$。另有分治做法（每次取区间最小值分治两侧，配线段树 $O(n \log n)$），既慢又难写，单调栈全面占优。

## 5. 常见疑问

**疑问一：为什么"枚举最矮柱子"不重不漏？**

任何最优矩形都有一个非空的"最矮柱子集合"，把矩形记到其中**任意一根**（比如下标最小的那根）名下，就完成了分类：矩形 $\Leftrightarrow$ (最矮柱子 $i$, 它横跨的区间)。每根柱子 $i$ 只需考察它能撑起的**最大**宽度（更窄的子区间面积不会更大），所以对每个 $i$ 取左右第一个更矮者作边界即可覆盖所有候选。这是"枚举关键元素 + 每个元素只算最优贡献"的经典计数化思路。

**疑问二：高度可以为 0，会出问题吗？**

不会。高度 $0$ 的柱子面积为 $0$，且它和哨兵一样会把栈中更高的柱子全部弹出来结算——$0$ 高柱子天然是别人的边界。真正要小心的是**别把哨兵值设成和合法高度冲突的数**：如果题目高度可以取 $0$，哨兵必须 $\le 0$（本解法哨兵就是 $0$，弹栈条件含等号，照样全部弹出）。

**疑问三：能不能正反两遍各求一次 left/right？**

可以。倒序扫一遍单调栈求 $right[i]$，正序扫一遍求 $left[i]$，再统一算面积，逻辑更"对齐"739 的模板。一遍扫 + 弹栈时同时定左右边界是等价且更紧凑的写法——因为**弹出 $t$ 的那个元素就是 $t$ 的右边界，而 $t$ 弹出后露出的新栈顶就是它的左边界**，两份信息在同一个瞬间同时可得。

## 6. 相关题目与模板

> 📚 系统整理见模板笔记：[单调队列：滑动窗口最值与决策单调性](../../algorithms/monotonic_queue/)——单调栈/单调队列同属"保强弃弱"家族，方向由问题决定。

**可复用模板**（"以每根柱子为最值求最大矩形"骨架，返回面积同时可得区间）：

```cpp
// heights 末尾视为有 0 高度的哨兵
stack<int> st;                          // 下标栈，高度递增
long long best = 0;
for (int i = 0; i <= n; i++) {
    int h = (i == n) ? 0 : heights[i];
    while (!st.empty() && heights[st.top()] >= h) {
        int cur = heights[st.top()]; st.pop();
        int left = st.empty() ? -1 : st.top();
        best = max(best, (long long)cur * (i - left - 1));
    }
    st.push(i);
}
```

求"以每根柱子为**最大值**的区间"（如最大矩形对偶问题）只需把弹栈条件改成 `<=` 维护递减栈。

**单调栈难题的常见组装方式：**

1. **两侧第一个更小/更大元素**：739 的直套模板；
2. **本题：枚举最矮者 → 两侧第一个更小 → 宽度**；
3. **矩形面积 × 计数/DP**：把 $area(i)$ 换成贡献和（LeetCode 907）或接上历史信息（LeetCode 85 逐行降维）。

**同类题目：**

- [LeetCode 85. 最大矩形](https://leetcode.cn/problems/maximal-rectangle/)：01 矩阵逐行做"柱状图高度"前缀累加，每行跑一遍本题代码，二维降一维
- [LeetCode 42. 接雨水](https://leetcode.cn/problems/trapping-rain-water/)：同是"按柱子结算"，但结算的是两侧最值围成的凹槽水量
- [LeetCode 907. 子数组的最小值之和](https://leetcode.cn/problems/sum-of-subarray-minimums/)：把"宽度"换成"以 $i$ 为最小值的子数组个数"，乘法原理求和
- [LeetCode 1793. 好子数组的最大分数](https://leetcode.cn/problems/maximum-score-of-a-good-subarray/)：本题加了"子数组必须包含下标 k"的限制
- [LeetCode 739. 每日温度](https://leetcode.cn/problems/daily-temperatures/)：单调栈入门，见[上一篇](../LeetCode_739/)

**一句话总结**：最大矩形 = **每根柱子 × 它能横跨的最大宽度**，而"能横跨到哪里"由两侧第一个更矮者决定——单调栈在 $O(n)$ 内把每根柱子的两侧边界一次问清。
