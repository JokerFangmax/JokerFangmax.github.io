# LeetCode 5. 最长回文子串

> 题目链接：[https://leetcode.cn/problems/longest-palindromic-substring/](https://leetcode.cn/problems/longest-palindromic-substring/)  
> 难度：中等  
> 标签：字符串、动态规划

---

## 1. 题目描述

给你一个字符串 `s`，找到 `s` 中**最长的回文子串 (palindromic substring)** 并返回它。若存在多个等长的最长回文子串，返回其中任意一个即可。

**回文 (palindrome)**：正读反读相同的字符串，如 `"aba"`、`"abba"`。**子串 (substring)** 必须连续（区别于可跳字符的子序列）。

**数据范围：**

- $1 \le s.length \le 1000$
- `s` 仅由数字和小写英文字母组成

**示例：**

```
输入：s = "babad"
输出："bab"
解释："aba" 同样是符合题意的答案。

输入：s = "cbbd"
输出："bb"
```

---

## 2. 思路分析

### 2.1 暴力：枚举所有子串

枚举 $O(n^2)$ 个子串，每个用双指针 $O(n)$ 验证回文，总计 $O(n^3)$。$n = 1000$ 时约 $10^9$ 次操作，超时。同样的病灶：**大量子串互相嵌套**——`"aba"` 和 `"xabax"` 的验证过程几乎重合，却被从头各验一遍。

关键突破口是回文的**自带递归结构**：

> $s[l..r]$ 是回文 $\iff$ $s[l] = s[r]$ **且** $s[l+1..r-1]$ 是回文。

即"长回文"天然包着一个"短回文"，验证过程完全可以复用。这就是本题主菜——动态规划 (dynamic programming) 或等价的中心扩展——的出发点。

### 2.2 思路一：区间 DP

顺着递归结构定义：

> $dp[l][r]$ = 子串 $s[l..r]$ 是否为回文。

转移：$dp[l][r] = (s[l] = s[r]) \wedge dp[l+1][r-1]$，边界是单字符（恒真）和双字符（$s[l] = s[l+1]$）。注意 $dp[l][r]$ 依赖 $dp[l+1][r-1]$——**左端点更大、右端点更小**的格子，所以必须**按长度从小到大**（或 $l$ 从大到小）遍历，否则用到还没算的格子。

枚举所有 $(l, r)$，维护最长的真值区间。时间 $O(n^2)$、空间 $O(n^2)$。能过，但有一个隐藏浪费：**我们只关心最长的那个回文，dp 表却把所有子串的答案都存了下来**——$10^6$ 个布尔值里，我们真正用到的信息少得可怜。

### 2.3 思路二：中心扩展——只算用得上的

换个方向利用递归结构：既然每个回文都由"中心 + 对称扩张"构成，不妨**枚举中心，向两边扩到不能扩为止**：

1. 长度为奇数的回文以某个字符为中心，如 `"aba"` 中心是 `b`；
2. 长度为偶数的回文以某两个字符的**间隙**为中心，如 `"abba"` 中心是两个 `b` 之间。

所以中心共有 $n + (n-1) = 2n - 1$ 个。每个中心最多向外扩 $O(n)$ 层，总时间 $O(n^2)$——与 DP 同阶，但**空间 $O(1)$**，且短回文的扩张结果隐式地被长回文复用（扩到第 $k$ 层顺带确认了第 $k-1$ 层），没有浪费在"存所有子串的答案"上。

### 2.4 用示例走一遍中心扩展

`s = "babad"`（下标 0..4），逐个中心扩张：

| 中心 | 类型 | 扩张过程 | 最长回文 | 长度 |
|---|---|---|---|---|
| `(0,0)` `b` | 奇 | 左出界，停 | `b` | 1 |
| `(0,1)` `b`a | 偶 | `b` ≠ `a`，零步 | — | 0 |
| `(1,1)` `a` | 奇 | `s[0]=b, s[2]=b` ✓ 再扩出界 | `bab` | **3** |
| `(1,2)` `a`b | 偶 | `a` ≠ `b` | — | 0 |
| `(2,2)` `b` | 奇 | `s[1]=a, s[3]=a` ✓ 再扩 `s[0]=b, s[4]=d` ✗ | `aba` | 3 |
| `(2,3)` `b`a | 偶 | `b` ≠ `a` | — | 0 |
| `(3,3)` `a` | 奇 | `s[2]=b, s[4]=d` ✗ | `a` | 1 |
| `(3,4)` `a`d | 偶 | ✗ | — | 0 |
| `(4,4)` `d` | 奇 | 两边出界 | `d` | 1 |

全程最长的是长度 3，中心 `(1,1)` 先到达，记录为 `bab`（中心 `(2,2)` 的 `aba` 同长，不更新）——输出 `"bab"`。

再验证偶数情形 `"cbbd"`：中心 `(2,2)` 的 `b` 扩张得 `s[1]=b ≠ s[3]=d`，只有 `b` 自己；间隙中心 `(1,2)` 处 `s[1]=b, s[2]=b` ✓ 再扩 `s[0]=c ≠ s[3]=d` ✗，得 `bb`（长 2）——正是答案。

### 2.5 更快的 Manacher？

存在 $O(n)$ 的 Manacher 算法：插入分隔符统一奇偶，再用"已有回文的对称性"跳过重复比较。它理论最优，但推导繁琐、面试中 $n \le 1000$ 根本用不上。**中心扩展是"难度/收益比"的最佳选择**；Manacher 作为知识边界，知道它存在、知道复杂度即可。

## 3. 代码实现

```cpp
class Solution {
    // 从 l、r 向两侧扩张，返回能形成的最长回文的 {起点, 长度}
    pair<int, int> expand(const string& s, int l, int r) {
        while (l >= 0 && r < (int)s.size() && s[l] == s[r]) {
            l--; r++;
        }
        // 退出循环时 s[l] != s[r]（或越界），真正有效的回文是 (l+1, r-1)
        return {l + 1, r - l - 1};
    }

public:
    string longestPalindrome(string s) {
        int bestL = 0, bestLen = 1;             // 题目保证 n >= 1，初始取 s[0]
        auto update = [&](pair<int, int> p) {
            if (p.second > bestLen) {           // 严格大于：等长时保留最早出现的
                bestLen = p.second;
                bestL = p.first;
            }
        };
        for (int i = 0; i < (int)s.size(); i++) {
            update(expand(s, i, i));            // 奇数长度：中心是字符 i
            update(expand(s, i, i + 1));        // 偶数长度：中心是 i 与 i+1 的间隙
        }
        return s.substr(bestL, bestLen);
    }
};
```

几个实现细节：

1. **`expand` 返回 `(起点, 长度)` 而不是终点**：长度由扩张结束位置一步算出 $r - l - 1$，避免在调用处做差一换算。
2. **循环退出时 `s[l] != s[r]` 或越界**，所以有效回文是 $(l+1, r-1)$——这一步的 `+1/-1` 是本题最容易错的地方，务必想清楚再写。
3. **等长不更新**（`>` 而非 `>=`）：保证返回最先出现的最长回文，与判题器的期望一致。
4. 奇偶中心共用同一个 `expand`：奇数传 `(i, i)`，偶数传 `(i, i+1)`，一个函数通吃，比写两份循环干净得多。

## 4. 复杂度分析

- **时间复杂度**：$O(n^2)$。$2n - 1$ 个中心，每个中心最多扩张 $\lceil n/2 \rceil$ 层。$n = 1000$ 时约 $10^6$ 次字符比较，轻松通过。最坏输入是全同字符串如 `"aaaa...a"`：每个中心都一路扩到底，达到平方级上界。
- **空间复杂度**：$O(1)$（不算返回的子串）。这是对区间 DP（$O(n^2)$ 表）的实质改进。

| 做法 | 时间 | 空间 | 备注 |
|---|---|---|---|
| 暴力枚举 | $O(n^3)$ | $O(1)$ | 超时 |
| 区间 DP | $O(n^2)$ | $O(n^2)$ | 表能把所有子串的答案都留下来 |
| **中心扩展** | $O(n^2)$ | $O(1)$ | **本题首选** |
| Manacher | $O(n)$ | $O(n)$ | 理论最优，推导重、性价比低 |

## 5. 常见疑问

**Q1：为什么中心是 $2n - 1$ 个而不是 $n$ 个？**

回文分奇偶两种长度：奇数回文有一个正中的字符，偶数回文的正中是两个字符之间的**间隙**。只枚举字符会漏掉所有偶数回文（`"cbbd"` 里答案 `"bb"` 正是偶数的）。$n$ 个字符中心 + $n - 1$ 个间隙中心 $= 2n - 1$。另一个思路（Manacher 采用的）是插 `#` 分隔符把两种长度统一成奇数，但对中心扩展法来说，直接枚举两类中心反而更简单。

**Q2：区间 DP 的遍历顺序为什么容易写错？**

$dp[l][r]$ 依赖 $dp[l+1][r-1]$：左端点**更大**、右端点**更小**。若按惯用的"外层 $l$ 从小到大"遍历，算 $dp[0][5]$ 时要用 $dp[1][4]$——还没算过。正确写法是**外层枚举长度**（2 到 $n$），或者外层 $l$ **从 $n-1$ 倒序到 0**。这道题成了"区间 DP 必须倒序/按长度"这一通用规则的经典教学案例，同样的坑在 [LeetCode 312. 戳气球](https://leetcode.cn/problems/burst-balloons/) 里还会再踩一次。

**Q3：滑动窗口能做吗？**

不能，而且"不能的理由"值得说清楚。滑动窗口要求窗口条件对扩张/收缩**单调**（参考本系列 [LeetCode 76](../LeetCode_76/) 的判据）：窗口越长、条件越容易/难满足。"去掉首尾两字符后是否回文"不具有这种单调性——加长窗口既可能让回文破坏（`"aba"` → `"xaba"`），也可能让回文成立（`"aba"` → `"xabax"`），且窗口右端移动后左端的最优位置**需要回退**。回文的对称结构决定了"中心"才是天然的锚点，而不是"左端点"。

## 6. 相关题目与模板

**可复用模板**（回文中心扩展，适用于一切"回文 + 枚举中心"题）：

```cpp
// 返回以 (l, r) 为种子向外扩张得到的最长回文的 {起点, 长度}
// 奇数中心调用 expand(s, i, i)，偶数中心调用 expand(s, i, i + 1)
pair<int, int> expand(const string& s, int l, int r) {
    while (l >= 0 && r < (int)s.size() && s[l] == s[r]) { l--; r++; }
    return {l + 1, r - l - 1};
}
```

- [LeetCode 647. 回文子串数](https://leetcode.cn/problems/palindromic-substrings/)：同一模板把"记录最长"改成"计数"，中心扩展一遍过

- [LeetCode 131. 分割回文串](https://leetcode.cn/problems/palindrome-partitioning/)：预处理一张区间 DP 回文表 + 回溯切割方案——Q2 的遍历顺序在那里是硬考点

**方法论总结**：字符串回文类题的决策树——问**子串**先想中心扩展（$O(n^2)$ / $O(1)$，够用）；要**所有子串的答案**或做**切割方案**再上区间 DP 表；只有 $n$ 到 $10^5$ 以上才请出 Manacher。

**一句话总结**：最长回文子串的最优性价比解法是中心扩展——把回文的递归结构反过来用，"枚举 $2n-1$ 个中心、向外扩到头"，用 $O(1)$ 空间换掉了区间 DP 整张 $O(n^2)$ 的表。
