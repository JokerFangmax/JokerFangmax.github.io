# LeetCode 53. 最大子数组和

> 题目链接：[https://leetcode.cn/problems/maximum-subarray/](https://leetcode.cn/problems/maximum-subarray/)  
> 难度：中等  
> 标签：数组、分治、动态规划

---

## 1. 题目描述

给你一个整数数组 `nums`，请找出**和最大的连续子数组**（子数组至少包含一个元素），返回其最大和。

注意两点：子数组必须是**连续**的一段；**至少选一个元素**——全负数组时答案是最小的那个负数的绝对值取负，而不是空段的 0。

**数据范围：**

- $1 \le nums.length \le 10^5$
- $-10^4 \le nums[i] \le 10^4$

**示例：**

```
输入：nums = [-2,1,-3,4,-1,2,1,-5,4]
输出：6
// 连续子数组 [4,-1,2,1] 的和最大，为 6

输入：nums = [-1]
输出：-1

输入：nums = [-3, -2, -5]
输出：-2     // 全负时取最大的单个元素
```

## 2. 思路分析

### 2.1 暴力：枚举所有子数组的和

子数组由 $(起点, 终点)$ 决定，共 $O(n^2)$ 个；枚举起点、向右扩展终点、边扩展边累加，总代价 $O(n^2)$。$n = 10^5$ 时约 $5 \times 10^9$ 次加法，超时。

也可以用前缀和把"任意子数组和"变成 $pre[r] - pre[l-1]$，但仍然要枚举 $O(n^2)$ 对端点，只是省掉了每次重加。

要突破 $O(n^2)$，得问：**这些子数组里，哪些根本不可能赢？**

### 2.2 关键观察：按右端点分类，无用的延展直接丢弃

把所有子数组按**右端点** $i$ 分类。设 $f(i)$ 为"以 $i$ 结尾的和最大的子数组的和"，则全局答案就是：

$$\text{ans} = \max_{0 \le i < n} f(i)$$

以 $i$ 结尾的子数组只有两类：**接在以 $i-1$ 结尾的最优子数组后面**，或者**单开一段只有 $nums[i]$ 自己**。而且这两个选择可以直接比较出优劣：

- 若 $f(i-1) > 0$，把它接到前面是纯赚：$f(i) = f(i-1) + nums[i]$；
- 若 $f(i-1) \le 0$，前面那段是**包袱**——无论它内部多优秀，只会拖累后面，扔掉重开：$f(i) = nums[i]$。

合并成一条转移方程：

$$f(i) = \max(f(i-1) + nums[i],\; nums[i])$$

这就是**动态规划 (dynamic programming)**：$f$ 只依赖 $f(i-1)$，滚掉一维就是 **Kadane 算法 (Kadane's algorithm)**。

直觉上再想一遍"为什么敢扔"：以 $i$ 结尾的子数组形如 $nums[j..i]$，若 $nums[j..i-1]$ 的和 $\le 0$，那么 $nums[j..i] \le nums[i]$（前者比后者多了个非正的前缀）——任何"开头一段和为负"的候选都被"砍掉开头"严格改进，最优解的开头永远不是负前缀。

### 2.3 操作流程（以示例演示）

`nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4]`，一行当前最优子段用 `[ ]` 标出：

| $i$ | $nums[i]$ | $f(i-1)$ | 决策 | $f(i)$ | 当前子段 | 全局答案 |
|---|---|---|---|---|---|---|
| 0 | -2 | —（视作 $-\infty$） | 单开 | $-2$ | `[-2]` | $-2$ |
| 1 | 1 | $-2 \le 0$ | 单开 | $1$ | `[1]` | $1$ |
| 2 | -3 | $1 > 0$ | 接上 | $-2$ | `[1,-3]` | $1$ |
| 3 | 4 | $-2 \le 0$ | 单开 | $4$ | `[4]` | $4$ |
| 4 | -1 | $4 > 0$ | 接上 | $3$ | `[4,-1]` | $4$ |
| 5 | 2 | $3 > 0$ | 接上 | $5$ | `[4,-1,2]` | $5$ |
| 6 | 1 | $5 > 0$ | 接上 | $6$ | `[4,-1,2,1]` | $6$ |
| 7 | -5 | $6 > 0$ | 接上 | $1$ | `[4,-1,2,1,-5]` | $6$ |
| 8 | 4 | $1 > 0$ | 接上 | $5$ | `[4,-1,2,1,-5,4]` | $6$ |

注意两处：$i=2$ 时 $f(1)=1>0$ 接上后 $f(2)=-2$ **变小了**——但 $f$ 是"以 $i$ 结尾"的局部最优，不要求单调，它只为 $i+1$ 的决策服务；$i=7$ 同理跌到 1 但全局答案仍守住 6。最终答案 $6$，对应子段 `[4,-1,2,1]`。

### 2.4 另一条路：分治

把数组从中间劈开，最大子数组和只可能出现在三处：

| 情况 | 递归形态 |
|------|---------|
| 完全在左半 | $\text{solve}(l, mid)$ |
| 完全在右半 | $\text{solve}(mid+1, r)$ |
| **横跨中点** | 左半"延伸到 mid 的最大后缀和" + 右半"从 mid+1 出发的最大前缀和" |

第三种情况 $O(\text{len})$ 直接扫出来，递归式 $T(n) = 2T(n/2) + O(n)$，由主定理解得 $O(n \log n)$。分治版看似更慢更绕，但它维护的四个量（区间总和、最大前缀和、最大后缀和、最大子段和）正是**线段树**节点的标准信息，能推广到"带点修改、查询任意区间的最大子段和"这类动态问题（经典如 SPOJ GSS1），这是 Kadane 做不到的。

## 3. 代码实现

```cpp
class Solution {
public:
    int maxSubArray(vector<int>& nums) {
        int cur = nums[0];       // f(i): 以 i 结尾的最大子数组和
        int best = nums[0];      // 全局答案
        for (int i = 1; i < nums.size(); i++) {
            cur = max(cur + nums[i], nums[i]);  // 接上 or 单开
            best = max(best, cur);
        }
        return best;
    }
};
```

几个实现细节：

1. **`cur` 和 `best` 用 `nums[0]` 初始化而不是 0**：子数组至少要有一个元素，全负数组时答案是非正数，用 0 初始化会错误地返回 0（空段）。这是本题第一大 WA 来源。
2. **`cur` 可以为负**：不要在循环里写 `if (cur < 0) cur = 0`——那同样是允许空段的做法。正确的语义是"负前缀在下一步比较时自然被丢弃"，丢弃发生在 `max(cur + x, x)` 里，不是当下清零。
3. **不需要数组存 $f$**：转移只依赖上一步，滚动变量即可，空间降到 $O(1)$。
4. `int` 不会溢出：$|f| \le 10^5 \times 10^4 = 10^9$，恰好在 `int` 边界内（$2.1 \times 10^9$）；若范围放宽一档就换 `long long`。

## 4. 复杂度分析

- **时间复杂度**：$O(n)$。一次线性扫描，每个元素一次比较一次加法。这是最优的——每个元素至少要看一眼，$\Omega(n)$ 是下界。
- **空间复杂度**：$O(1)$。两个滚动变量（分治版为 $O(\log n)$ 递归栈）。

三者对比：

| 做法 | 时间 | 空间 | 可扩展性 |
|------|------|------|---------|
| 暴力枚举 | $O(n^2)$ | $O(1)$ | — |
| 分治 | $O(n \log n)$ | $O(\log n)$ | 可上线段树，支持动态修改 |
| **Kadane (DP)** | $O(n)$ | $O(1)$ | 可推广到"环形""最多删一个"等变体 |

## 5. 常见疑问

**疑问一：为什么"前缀和 $\le 0$ 就扔"不会扔掉最优解？** 被扔掉的只是"以 $i-1$ 结尾"这个**局部**的最差延展方式，而扔的依据是比较了两种选择的大小——$\max(f(i-1)+x, x)$ 两种可能都覆盖了，不存在没考虑到的方案。换句话说，Kadane 不是贪心（不回头的猜测），而是把决策显式枚举后取 $\max$ 的 DP，天然完备。

**疑问二：如果允许"子数组为空"，答案怎么算？** 把 `best` 初始化为 0、允许 `cur` 清零即可（全负时答案 0）。LeetCode 这题**不允许空段**，所以两者写法不同，混用就是全负样例 WA。审题时先确认"子数组是否可空"。

**疑问三：要求输出具体的子数组而不仅是和？** 维护 `best` 时同步记 `(起点, 终点)`：当 `cur` 走到"单开"分支时更新临时起点，当 `cur > best` 时把临时起点抄进答案。表格里第三列的"当前子段"就是维护过程。

## 6. 相关题目与模板

**可复用模板**（线性 DP / Kadane 骨架）：

```cpp
// 最大子数组和；变体只需改"合并"与"初值"两处
int cur = /* 第一个元素或 0（允许空段）*/, best = cur;
for (int i = 1; i < n; i++) {
    cur = max(cur + a[i], a[i]);   // 亦可写成 max(cur, 0) + a[i]
    best = max(best, cur);
}
```

**Kadane 思想的常见变体**（都是"以 $i$ 结尾的局部最优 + 全局取 max"）：

- 最大子数组和的**乘积版**：维护"最大/最小"两个滚动量（负数乘最小变最大），转移多一个分支
- **环形**数组的最大子数组和：答案 = 普通最大子段和 或 总和 − 最小子段和，二者取大（全负时特判）
- **带冷却/至多一次交易**的股票题：本质同构的"以今天结尾的最优"

**同类题目：**

- [LeetCode 152. 乘积最大子数组](https://leetcode.cn/problems/maximum-product-subarray/)：乘法版，负负得正迫使我们同时维护最小值
- [LeetCode 918. 环形子数组的最大和](https://leetcode.cn/problems/maximum-sum-circular-subarray/)：环形版，"总和减最小子段"的转化很妙
- [LeetCode 560. 和为 K 的子数组](https://leetcode.cn/problems/subarray-sum-equals-k/)：同样是子数组和问题，但目标是"恰好等于 k"，要用前缀和 + 哈希（详见[我的题解](../LeetCode_560/)）
- [LeetCode 1186. 删除一次得到子数组最大和](https://leetcode.cn/problems/maximum-subarray-sum-with-one-deletion/)：多一维状态"是否已用过删除"

**一句话总结**：Kadane 的全部内容是一条转移 $f(i) = \max(f(i-1), 0) + nums[i]$——"负前缀是包袱"这一个观察，把 $O(n^2)$ 的枚举压成一次线性扫描。
