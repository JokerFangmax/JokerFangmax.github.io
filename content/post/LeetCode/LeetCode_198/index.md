# LeetCode 198. 打家劫舍

> 题目链接：[https://leetcode.cn/problems/house-robber/](https://leetcode.cn/problems/house-robber/)  
> 难度：中等  
> 标签：数组、动态规划

---

## 1. 题目描述

你是一个专业的小偷，计划偷窃沿街的一排房屋。每间房内藏有一定的现金，影响你偷窃的唯一制约因素是：**相邻的两间房屋不能同时偷**——它们装有相互连通的防盗系统，一旦两间相邻房屋同一晚被闯入，系统自动报警。

给定一个非负整数数组 `nums`，`nums[i]` 表示第 $i$ 间房屋的现金数，求**在不触发警报的前提下**能偷窃到的最高金额。

**数据范围：**

- $1 \le nums.length \le 100$
- $0 \le nums[i] \le 400$

**示例：**

```
输入：nums = [2,7,9,3,1]
输出：12
解释：偷第 0、2、4 间（2 + 9 + 1 = 12），跳过第 1、3 间。
```

```
输入：nums = [2,1,1,2]
输出：4
解释：偷第 0、3 间（2 + 2 = 4），优于偷第 0、2 间的 2 + 1 = 3。
```

---

## 2. 思路分析

### 2.1 暴力：枚举所有不相邻子集

每间房有「偷」和「不偷」两种选择，约束只是相邻不能同时偷。暴力递归：从第 0 间出发，每步要么跳过当前房（考虑下一间），要么偷当前房（必须跳过下一间）。最坏情况（金额全为 0，两种选择并驾齐驱）递归树有 $2^{100}$ 个节点，天文数字。

但仔细看递归树：**「从第 $i$ 间开始能偷到的最大值」这个子问题会被反复计算**——比如跳过 0、1 之后和偷 0 之后都会进入「从第 2 间开始」，却各自独立求解。重复子问题 + 最优子结构，正是动态规划 (dynamic programming) 的入场券。

### 2.2 贪心为什么不行

一个诱人的想法：哪间钱多偷哪间、隔开就行，或者隔一间偷一间。反例就在示例 2：

| 策略 | `nums = [2,1,1,2]` 上的选择 | 金额 |
|------|------------------------------|------|
| 隔一间偷一间（下标 0,2） | $2 + 1$ | 3 |
| 哪间多偷哪间（局部贪心） | 先偷 2，邻居不能偷，再看剩下的…… | 4 或更差 |
| **最优（下标 0,3）** | $2 + 2$ | **4** |

局部最优不蕴含全局最优：**当前偷不偷，影响的不只是眼前收益，还有后面所有房屋的可用性**。这种「决策有后效性」的场景，贪心失效，必须用 DP 把所有子状态的最优值都算出来。

### 2.3 状态设计与转移方程

定义 $dp[i]$ 为**只考虑前 $i+1$ 间房（下标 $0 \dots i$）时能偷到的最大金额**。对第 $i$ 间房只有两种决策：

- **不偷第 $i$ 间**：问题退化为前 $i-1$ 间的最优，即 $dp[i-1]$；
- **偷第 $i$ 间**：第 $i-1$ 间必须空着，之前的最优是 $dp[i-2]$，加上本轮收益 $nums[i]$。

两者取较大者：

$$dp[i] = \max(dp[i-1],\; dp[i-2] + nums[i])$$

边界：$dp[0] = nums[0]$，$dp[1] = \max(nums[0], nums[1])$。

### 2.4 逐步填表（nums = [2,7,9,3,1]）

| $i$ | $nums[i]$ | 不偷：$dp[i-1]$ | 偷：$dp[i-2]+nums[i]$ | $dp[i]$ | 决策 |
|-----|-----------|-----------------|------------------------|---------|------|
| 0 | 2 | — | — | 2 | 偷（边界） |
| 1 | 7 | — | — | 7 | 偷多的那间（边界） |
| 2 | 9 | 7 | $2+9=11$ | **11** | 偷第 2 间 |
| 3 | 3 | 11 | $7+3=10$ | **11** | 不偷，延续 $dp[2]$ |
| 4 | 1 | 11 | $11+1=12$ | **12** | 偷第 4 间 |

答案 $dp[4] = 12$，对应选择下标 $\{0, 2, 4\}$。注意第 3 步：$dp[2] = dp[3] = 11$，说明**最优解可以不包含最后一间房**——DP 表天然把「偷与不偷」的所有组合都囊括了。

### 2.5 滚动变量：空间压到 O(1)

转移只依赖 $dp[i-1]$ 和 $dp[i-2]$ 两项，用两个变量滚动即可，不必开数组：

```text
prev2 (dp[i-2])、prev1 (dp[i-1]) → cur = max(prev1, prev2 + nums[i])
然后 prev2 ← prev1，prev1 ← cur
```

## 3. 代码实现

```cpp
class Solution {
public:
    int rob(vector<int>& nums) {
        int n = nums.size();
        // prev2 = dp[i-2], prev1 = dp[i-1]
        int prev2 = 0, prev1 = 0;
        for (int i = 0; i < n; i++) {
            // 不偷第 i 间：prev1
            // 偷第 i 间：  prev2 + nums[i]
            int cur = max(prev1, prev2 + nums[i]);
            prev2 = prev1;      // 滚动前移
            prev1 = cur;
        }
        return prev1;           // dp[n-1]
    }
};
```

一个技巧：初始 `prev2 = prev1 = 0` 相当于虚拟出 $dp[-1] = dp[-2] = 0$ 两个边界，让 $i = 0$ 时 $cur = \max(0, 0 + nums[0]) = nums[0]$ 自动成立，省去对 $n = 1$ 的特判。

---

## 4. 复杂度分析

- **时间复杂度**：$O(n)$。一次线性扫描，每间房只处理一次，每步 $O(1)$。
- **空间复杂度**：$O(1)$。滚动数组只保留最近两个状态，与 $n$ 无关（版本上界 $n \le 100$，但即使 $10^6$ 间房也一样）。

对比：暴力 $O(2^n)$ → 记忆化递归 / 普通 DP $O(n)$ 空间 $O(n)$ → 滚动变量 $O(n)$ 时间 $O(1)$ 空间。

## 5. 常见疑问

**疑问一：为什么「偷第 $i$ 间」对应 $dp[i-2]$ 而不是 $dp[i-1] - nums[i-1]$？**

「偷第 $i$ 间」只要求**第 $i-1$ 间空着**，并不要求「第 $i-1$ 间一定被偷过再退掉」。$dp[i-2]$ 已经是「前 $i-2$ 间的最优」的完整信息，从它出发加 $nums[i]$ 即可。若写 $dp[i-1] - nums[i-1]$，隐含假设了第 $i-1$ 间被偷——但 $dp[i-1]$ 的最优解里第 $i-1$ 间可能根本没偷（比如 $nums[i-1] = 0$），减法就减多了。

**疑问二：`nums[i]` 可以为 0，会影响什么吗？**

不影响正确性，但会制造「偷与不偷金额相同」的并列最优。这也解释了为什么不能从 $dp$ 值反推出唯一方案——方案可能有多解，而题目只要最大金额。

**疑问三：环形排列（房屋围成一圈，首尾相邻）怎么办？**

那是 [LeetCode 213. 打家劫舍 II](https://leetcode.cn/problems/house-robber-ii/)。诀窍是拆成两个线性子问题：「不偷第 0 间，考虑 $1 \dots n-1$」和「不偷第 $n-1$ 间，考虑 $0 \dots n-2$」，各跑一遍本节的线性 DP 取最大——首尾冲突被两个子问题分别回避。这是「环形 → 线性」的通用拆解手法。

## 6. 相关题目与模板

**可复用模板**（「选或不选」线性 DP 骨架，滚动版）：

```cpp
// f[i] = max(不选 i, 选 i)
// 不选 i: f[i-1]；选 i: f[i-2] + cost[i]
int prev2 = 0, prev1 = 0;
for (int i = 0; i < n; i++) {
    int cur = max(prev1, prev2 + cost[i]);
    prev2 = prev1, prev1 = cur;
}
return prev1;
```

方法论总结：**带「相邻/相邻若干个互斥」约束的最优化，先枚举当前元素选或不选，把约束变成下标的偏移量（$i-1$ / $i-2$），转移方程就自己浮现了**。

**同类题目：**

- [LeetCode 213. 打家劫舍 II](https://leetcode.cn/problems/house-robber-ii/)：环形，拆两次线性 DP
- [LeetCode 337. 打家劫舍 III](https://leetcode.cn/problems/house-robber-iii/)：树形版，状态变成「偷/不偷当前子树根」
- [LeetCode 740. 删除并获得点数](https://leetcode.cn/problems/delete-and-earn-points/)：把「值相邻」转化为下标相邻，化归为本题
- [LeetCode 322. 零钱兑换](https://leetcode.cn/problems/coin-change/)：另一类经典 DP（完全背包），见本系列 [LeetCode 322 题解](../LeetCode_322/)

**一句话总结**：打家劫舍是「选或不选」型 DP 的原型——$dp[i] = \max(dp[i-1],\, dp[i-2] + nums[i])$，相邻约束变成下标偏移，两个滚动变量收工。
