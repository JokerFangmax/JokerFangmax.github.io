# LeetCode 108. 将有序数组转换为二叉搜索树

> 题目链接：[https://leetcode.cn/problems/convert-sorted-array-to-binary-search-tree/](https://leetcode.cn/problems/convert-sorted-array-to-binary-search-tree/)  
> 难度：简单  
> 标签：树、二叉搜索树、分治

---

## 1. 题目描述

给你一个**升序排列**的整数数组 `nums`，请把它转换成一棵**高度平衡**的二叉搜索树 (Binary Search Tree, BST)。

要求：树中每个节点的左右两棵子树的高度差的绝对值不超过 1；返回任意一棵满足条件的 BST 即可——答案不唯一。

**数据范围：**

- $1 \le nums.length \le 10^4$
- $-10^4 \le nums[i] \le 10^4$
- `nums` 按严格递增顺序排列

**示例：**

```
输入：nums = [-10,-3,0,5,9]

输出一：[0,-3,9,-10,null,5]     （根为 0，左子树取 [-10,-3]，右子树取 [5,9]）

        0
       / \
     -3   9
     /   /
   -10  5

注意 [0,-10,5,null,-3,null,9] 同样合法——平衡 BST 不唯一。
```

---

## 2. 思路分析

### 2.1 暴力：逐个插入会怎样

最朴素的想法：拿一棵空树，按数组顺序逐个做 BST 插入。但数组是**升序**的，逐个插入等价于往 BST 里不断插入递增序列——每个新节点都比全部已有节点大，全部落到右子树上，最终得到一条**向右倾斜的链**：

```
-10
   \
    -3
      \
       0
        \
         ...
```

高度 $n - 1$，完全不满足"平衡"要求。问题出在**输入的有序性恰好是最坏情况**，而我们没有利用它。

### 2.2 关键观察：有序数组就是 BST 的中序遍历

反过来看：对任何一棵 BST 做**中序遍历 (inorder traversal)**，得到的序列恰好升序。所以 `nums` 就是目标树的中序序列——我们要做的，是**给中序序列"设计"一棵形状平衡的树**。

只知道中序序列当然定不下一棵树（中序 $[1,2,3]$ 对应 5 种不同的 BST），但"平衡"给了我们一个自然的选择：

> **取中点做根，左半区间递归建左子树，右半区间递归建右子树。**

为什么取中点？两个理由同时成立：

1. **BST 性质**：左半区间所有值 $\le$ 中点值 $\le$ 右半区间所有值，中点放根，两侧各自独立成 BST 后拼起来仍是 BST；
2. **平衡性质**：左右区间长度至多差 1，递归下去每层都如此，整棵树的高度差处处 $\le 1$——这是**分治 (divide and conquer)** 的教科书应用：把大问题切成两个规模减半、结构相同的子问题。

### 2.3 用小例子走一遍

`nums = [-10,-3,0,5,9]`，区间用闭区间 $[l, r]$ 表示，中点取 $mid = \lfloor (l+r)/2 \rfloor$：

| 步骤 | 区间 | 元素 | mid | 根 | 左子区间 | 右子区间 |
|------|------|------|-----|----|----------|----------|
| 1 | $[0,4]$ | -10,-3,0,5,9 | 2 | **0** | $[0,1]$ | $[3,4]$ |
| 2 | $[0,1]$ | -10,-3 | 0 | **-10** | $[0,-1]$（空） | $[1,1]$ |
| 3 | $[1,1]$ | -3 | 1 | **-3** | 空 | 空 |
| 4 | $[3,4]$ | 5,9 | 3 | **5** | 空 | $[4,4]$ |
| 5 | $[4,4]$ | 9 | 4 | **9** | 空 | 空 |

逐层拼装：

```
第 1 层:      0
第 2 层:    /   \
          -10     5
第 3 层:     \     \
             -3     9
```

左子树高 2、右子树高 2，每个节点左右高度差 $\le 1$，且中序遍历为 `-10,-3,0,5,9`，两个条件都满足。

### 2.4 中点取左中点还是右中点

偶数长度区间有两个"中点"，如 $[0,3]$ 的 mid 可以是 1 或 2。两者都合法：

| 取法 | $mid$ 公式 | 偶数区间 $[0,3]$ 的划分 | 影响 |
|------|-----------|--------------------------|------|
| 左中点 | $\lfloor (l+r)/2 \rfloor$ | 左 2 个、右 1 个 | 左子树略深，代码最短 |
| 右中点 | $\lceil (l+r)/2 \rceil$ | 左 1 个、右 2 个 | 与上者镜像对称 |

无论哪种，两侧长度差恒 $\le 1$，平衡性不受影响，所以**题目答案不唯一时随便选一种即可**——本题用最常见的左中点。

## 3. 代码实现

```cpp
class Solution {
    // 递归建树：把 nums[l..r] 转成平衡 BST，返回根
    TreeNode* build(vector<int>& nums, int l, int r) {
        if (l > r) return nullptr;          // 空区间 -> 空树
        int mid = l + (r - l) / 2;          // 左中点，防溢出写法
        TreeNode* root = new TreeNode(nums[mid]);
        root->left  = build(nums, l, mid - 1);  // 左半递归
        root->right = build(nums, mid + 1, r);  // 右半递归
        return root;
    }
public:
    TreeNode* sortedArrayToBST(vector<int>& nums) {
        return build(nums, 0, (int)nums.size() - 1);
    }
};
```

几个实现细节：

1. **递归终止条件是 $l > r$ 而不是 $l \ge r$**。区间 $[l, l]$（单个元素）仍要建一个节点，只有真正越过右端点（如 $[0, -1]$）才返回空。写成 $\ge$ 会丢掉所有叶子。
2. **`mid = l + (r - l) / 2`** 防止 $l + r$ 溢出。本题 $n \le 10^4$ 用 $l + r$ 也不会炸，但这是值得固化的习惯。
3. **传引用不传值**。`vector` 按值传进 `build` 每层都拷贝 $O(n)$，总代价退化到 $O(n^2)$；传引用或用全局变量即可。

## 4. 复杂度分析

- **时间复杂度**：$O(n)$。每个元素恰好被 `new` 成一个节点一次，共 $n$ 次；每次递归调用本身的额外工作是 $O(1)$，总调用数 $O(n)$。
- **空间复杂度**：$O(\log n)$（不计输出树本身）。树高为 $O(\log n)$（这正是我们亲手保证的），递归栈深度等于树高；若计输出树则是 $O(n)$。

注意"高度平衡"在这里不只是题目要求，还**顺手优化了递归栈深度**——如果建出一条链，$n = 10^4$ 时递归 1 万层同样能过，但 $n$ 到 $10^6$ 就要爆栈了。

## 5. 常见疑问

**疑问一：为什么取中点就一定平衡？**

设 $T(h)$ 表示长度为 $n$ 的区间递归建出的树高。中点划分后左右区间长度为 $\lceil (n-1)/2 \rceil$ 与 $\lfloor (n-1)/2 \rfloor$，相差至多 1，所以左右子树高度差至多 1，且都是同样规则的产物，逐层归纳下去每个节点都满足平衡条件（这正是 AVL 树的定义）。反过来，如果取区间第一个元素做根（如 2.1 的逐个插入），左区间为空、右区间长 $n-1$，高度差 $n-1$，立刻失衡。

**疑问二：`nums` 有重复元素怎么办？**

本题声明严格递增，但若允许重复（如 LeetCode 108 的变体或剑指 Offer 题），只需固定"等于 mid 的值放右边（或左边）"的规则即可，划分仍然是 $[l, mid-1]$ 与 $[mid+1, r]$，BST 定义相应放宽为"左 $\le$ 根 $\le$ 右"。

**疑问三：能不能用迭代写？**

可以。用显式栈模拟递归（栈里存 `(节点, l, r)`，出栈时给节点挂孩子再入栈），可以避免递归；还有按层批量构造的写法——先递归求出每个下标对应的父节点编号再统一 `new`。但本题递归深度仅 $O(\log n)$，递归写法既短又安全，迭代属于屠龙刀。

## 6. 相关题目与模板

**可复用模板**（"有序序列 $\to$ 平衡 BST"通用骨架，把数组换成链表/前序序列配中序序列都围绕同一思想）：

```cpp
// nums[l..r] -> 平衡 BST
TreeNode* build(vector<int>& nums, int l, int r) {
    if (l > r) return nullptr;
    int mid = l + (r - l) / 2;
    TreeNode* root = new TreeNode(nums[mid]);
    root->left  = build(nums, l, mid - 1);
    root->right = build(nums, mid + 1, r);
    return root;
}
```

**一句话总结**：有序数组本身就是 BST 的中序遍历，**取中点做根、两侧递归**，BST 性质与平衡性质一次同时满足。
