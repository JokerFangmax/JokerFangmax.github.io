# LeetCode 279. 完全平方数

> 题目链接：[https://leetcode.cn/problems/perfect-squares/](https://leetcode.cn/problems/perfect-squares/)  
> 难度：中等  
> 标签：广度优先搜索、数学、动态规划

---

## 1. 题目描述

给定正整数 `n`，找到若干个**完全平方数**（如 $1, 4, 9, 16, \dots$）使它们的和恰好等于 `n`，返回**需要的最少个数**。

同一类平方数可以重复使用：例如 $12 = 4 + 4 + 4$，用了 3 个。

**数据范围：**

- $1 \le n \le 10^4$

**示例：**

```
输入：n = 12
输出：3
解释：12 = 4 + 4 + 4。
```

```
输入：n = 13
输出：2
解释：13 = 4 + 9。
```

---

## 2. 思路分析

### 2.1 暴力：每次随便减一个平方数

递归：`f(n) = 1 + min f(n - k*k)`，其中 $k^2 \le n$。不加记忆的话，$n = 10^4$ 时分支因子约 $100$，递归树指数爆炸。加记忆化后固然可行，但先看清结构：**每个状态 $j$ 只依赖更小的状态 $j - k^2$，且 $k^2$ 可以重复使用**——这正是「完全背包」(unbounded knapsack) 的形状：物品是 $\{1, 4, 9, \dots, \lfloor\sqrt n\rfloor^2\}$，容量是 $n$，求装满背包的最少物品数。

### 2.2 视角一：动态规划（完全背包）

设 $dp[j]$ 为凑出 $j$ 所需的最少平方数个数。转移时枚举「最后一个使用的平方数」$k^2$：

$$dp[j] = \min_{1 \le k \le \lfloor\sqrt j\rfloor} dp[j - k^2] + 1$$

边界 $dp[0] = 0$（凑 0 需要零个数），未凑出的状态记为 $+\infty$。

**逐步走一遍 $n = 12$**（候选平方数 $1, 4, 9$）：

| $j$ | 候选：$dp[j-1]+1$ / $dp[j-4]+1$ / $dp[j-9]+1$ | $dp[j]$ | 用的最后一个数 |
|-----|------------------------------------------------|---------|----------------|
| 1 | $dp[0]{+}1 = 1$ | 1 | 1 |
| 2 | $dp[1]{+}1 = 2$ | 2 | 1 |
| 3 | $dp[2]{+}1 = 3$ | 3 | 1 |
| 4 | $dp[3]{+}1=4$；$dp[0]{+}1=\mathbf{1}$ | 1 | 4 |
| 5 | $dp[4]{+}1=\mathbf{2}$ | 2 | 4 |
| 8 | $dp[7]{+}1=4$；$dp[4]{+}1=\mathbf{2}$ | 2 | 4 |
| 12 | $dp[11]{+}1=4$；$dp[8]{+}1=\mathbf{3}$ | 3 | 4（$12=8+4=4+4+4$） |

答案 $dp[12] = 3$，与 $12 = 4+4+4$ 一致。

### 2.3 视角二：广度优先搜索（BFS）——最短路径

把每个数字 $0 \dots n$ 看作图上的节点，从 $j$ 向 $j - k^2$（$k^2 \le j$）连一条边。「最少个数」就是从 $n$ 走到 $0$ 的**最短路**，而每条边权都是 1——无权图最短路正是广度优先搜索 (breadth-first search, BFS) 的主场：**第一次到达某节点时的层数就是最短步数**。

BFS 相比 DP 的实际优势：答案通常很小（由拉格朗日四平方定理，答案 $\le 4$），BFS 往往只展开两三层就命中 $0$，不必把 $1 \dots n$ 全部填满；劣势是最坏情形仍要 $O(n\sqrt n)$。两种视角殊途同归——DP 是「按 $j$ 从小到大填表」，BFS 是「按层数从小到大扩展」，本质都在利用最优子结构。

### 2.4 视角三：数学定理，O(√n) 判定

四平方和定理 (Lagrange's four-square theorem)：任何正整数都能写成 4 个平方数之和。勒让德三平方定理 (Legendre's three-square theorem) 进一步指出：$n$ 能写成 3 个平方数之和，当且仅当 $n$ 不形如 $4^a(8b+7)$。于是答案只可能是 $1, 2, 3, 4$：

| 判定（按序） | 条件 | 答案 |
|--------------|------|------|
| 是完全平方数 | $\exists k,\ n = k^2$ | 1 |
| 两平方和 | $\exists a, b,\ n = a^2 + b^2$（枚举 $a \le \sqrt n$） | 2 |
| 非三平方禁区 | $n \ne 4^a(8b+7)$ | 3 |
| 其余 | $n = 4^a(8b+7)$ | 4 |

例如 $n = 7 = 4^0 \cdot (8 \cdot 0 + 7)$ 落入禁区，答案 4（$7 = 4+1+1+1$）；$n = 12$ 不是平方数、也不能写成两平方之和（$12 = 4+8$? $8$ 非平方；$1+11$、$9+3$ 均否）、$12 \ne 4^a(8b+7)$，故答案 3，与 DP 表吻合。判定总代价 $O(\sqrt n)$，是最优解法。

## 3. 代码实现

```cpp
class Solution {
public:
    int numSquares(int n) {
        // dp[j] = 凑出 j 的最少平方数个数（完全背包）
        vector<int> dp(n + 1, INT_MAX);
        dp[0] = 0;
        for (int j = 1; j <= n; j++) {
            for (int k = 1; k * k <= j; k++) {
                // 枚举最后一个使用的平方数 k*k
                dp[j] = min(dp[j], dp[j - k * k] + 1);
            }
        }
        return dp[n];
    }
};
```

实现细节：

1. **初始化为 `INT_MAX`** 表示「尚未凑出」，配合 `+1` 不会溢出：`dp[j-k*k]` 若为 `INT_MAX` 说明那个子状态凑不出，但 $j-k^2$ 总能被 $1$ 凑出（全用 1），所以实际取 min 时每项都有效。
2. **内层枚举 $k$ 到 $\sqrt j$ 为止**，$k \cdot k \le j$ 用乘法比较，避免浮点 `sqrt` 的精度边界问题。
3. 若用 BFS 版本，队列元素是「剩余数」，用 `vis` 数组防止同一剩余数重复入队——每个节点只进队一次，这是 BFS 正确性与复杂度的关键。

## 4. 复杂度分析

- **时间复杂度**：$O(n \sqrt n)$。外层 $n$ 个状态，每个状态枚举至多 $\lfloor\sqrt n\rfloor \approx 100$ 个平方数；$n = 10^4$ 时约 $10^6$ 次运算。数学判定法可到 $O(\sqrt n)$。
- **空间复杂度**：$O(n)$。DP 数组长度 $n+1$（BFS 的队列与访问数组同阶；数学法只需 $O(1)$）。

| 解法 | 时间 | 空间 | 备注 |
|------|------|------|------|
| 记忆化递归 | $O(n\sqrt n)$ | $O(n)$ | 递归栈较深 |
| DP（本文） | $O(n\sqrt n)$ | $O(n)$ | 稳、通用 |
| BFS | $O(n\sqrt n)$ 最坏 | $O(n)$ | 答案小时先到达 |
| 数学定理 | $O(\sqrt n)$ | $O(1)$ | 需要两条定理 |

## 5. 常见疑问

**疑问一：贪心「先用最大的平方数减」为什么错？**

反例 $n = 12$：贪心先减 $9$ 得 $3$，再 $1+1+1$，共 4 个；而 $12 = 4+4+4$ 只要 3 个。和零钱兑换一样，**大额「面值」局部占优，却可能把剩余数带进难凑的死角**。凡是「可重复使用 + 求最少个数」的组合问题，先怀疑贪心、再用 DP 兜底。

**疑问二：DP 循环能不能倒着写？物品枚举放外层行不行？**

可以。完全背包求最小值时，「物品（平方数）外层、容量 $j$ 内层正序」同样正确——正序内层正对应「每件物品可无限次使用」。这与 0-1 背包（内层必须倒序）的区别值得吃透：本题若把内层倒序，含义变成每个平方数**只能用一次**，$12$ 就凑不出来了。

**疑问三：答案的上界为什么是 4？**

拉格朗日四平方定理保证任何正整数都是 4 个平方数之和，所以答案 $\in \{1,2,3,4\}$。这也解释了 BFS 为什么快：目标在第 $0$ 层，最坏第 4 层必然命中，搜索树的规模被定理封了顶。

## 6. 相关题目与模板

**可复用模板**（完全背包「恰好装满求最少件数」骨架，与零钱兑换同款）：

```cpp
// 物品集合 w[]（可无限次使用），凑出恰好为 n 的最少件数
vector<int> dp(n + 1, INT_MAX);
dp[0] = 0;                          // 恰好装满：只有容量 0 合法
for (int j = 1; j <= n; j++)
    for (int x : w)
        if (x <= j && dp[j - x] != INT_MAX)
            dp[j] = min(dp[j], dp[j - x] + 1);
```

方法论总结：**「最少多少步/件」= 无权图最短路 = BFS 或 DP，两者只是扩展顺序不同；一旦出现「可重复使用」，立刻联想到完全背包模型**。

**一句话总结**：完全平方数 = 完全背包的最小件数问题，$dp[j] = \min_k dp[j-k^2] + 1$；数学定理给出 $O(\sqrt n)$ 的优雅解，但 DP 模板可迁移性最强。
