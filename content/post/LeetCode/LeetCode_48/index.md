# LeetCode 48. 旋转图像

> 题目链接：[https://leetcode.cn/problems/rotate-image/](https://leetcode.cn/problems/rotate-image/)  
> 难度：中等  
> 标签：数组、数学、矩阵

---

## 1. 题目描述

给定一个 $n \times n$ 的二维矩阵 `matrix`，表示一张图片的像素。将图像**顺时针旋转 90 度**，必须**原地 (in-place)** 修改矩阵——不得申请另一个矩阵来做转存。

坐标语言表述：旋转后，原第 $i$ 行第 $j$ 列的元素应落在第 $j$ 行第 $n - 1 - i$ 列。即

$$matrix'[j][\,n-1-i\,] = matrix[i][j]$$

**数据范围：**

- $n = matrix.length = matrix[i].length$
- $1 \le n \le 20$
- $-1000 \le matrix[i][j] \le 1000$

**示例：**

```
输入：matrix = [[1,2,3],
               [4,5,6],
               [7,8,9]]

输出：[[7,4,1],
       [8,5,2],
       [9,6,3]]

输入：matrix = [[5,1,9,11],
               [2,4,8,10],
               [13,3,6,7],
               [15,14,12,16]]

输出：[[15,13,2,5],
       [14,3,4,1],
       [12,6,8,9],
       [16,7,10,11]]
```

## 2. 思路分析

### 2.1 暴力：开新矩阵直接抄公式

按 $matrix'[j][n-1-i] = matrix[i][j]$ 逐元素抄写到新矩阵，再整块赋回。$O(n^2)$ 时间正确，但违反"原地"要求——$O(n^2)$ 额外空间。难题在于：旋转是**整体的置换**，逐个搬运会互相踩踏，搬到一半时原值已被覆盖。

### 2.2 拆解旋转：沿主对角线翻转，再左右翻转

"顺时针旋转 90°"这个复杂变换，能否拆成简单变换的复合？观察旋转前后的坐标：

- 旋转：$(i, j) \to (j, n-1-i)$；
- 沿主对角线（左上—右下）转置 (transpose)：$(i, j) \to (j, i)$；
- 左右镜像（每行反转）：$(i, j) \to (i, n-1-j)$。

把两个简单变换复合：先转置 $(i,j) \to (j,i)$，再对结果左右镜像 $(j,i) \to (j, n-1-i)$——恰好就是旋转的坐标公式。即

$$\text{顺时针旋转 } 90^\circ = \text{转置} \circ \text{左右镜像}$$

用 $3 \times 3$ 的例子走一遍，`matrix = [[1,2,3],[4,5,6],[7,8,9]]`：

| 步骤 | 矩阵状态 | 说明 |
|------|----------|------|
| 原始 | `[[1,2,3],[4,5,6],[7,8,9]]` | |
| 转置 | `[[1,4,7],[2,5,8],[3,6,9]]` | $matrix[i][j] \leftrightarrow matrix[j][i]$ |
| 每行反转 | `[[7,4,1],[8,5,2],[9,6,3]]` | 行内左右互换 |

两步之后正是示例 1 的答案。两种简单变换都可以原地 $O(1)$ 空间完成，且各自的实现都不会互相覆盖（转置是成对交换，反转也是成对交换）。

### 2.3 为什么偏爱"两步法"而不是"四点循环"

另一条路线是把旋转看成一圈四个位置的循环搬运：$(i,j) \to (j, n-1-i) \to (n-1-i, n-1-j) \to (n-1-j, i) \to (i,j)$，用一个临时变量把这 4 个位置转一圈（左上四分之一区域每个点恰好领衔一圈）。它同样 $O(1)$ 空间，但下标全是 $n-1-i$、$n-1-j$ 的嵌套，写错一个就 WA，且四点循环的边界（内圈到哪停）需要单独推理。

| 方案 | 空间 | 代码风险 | 可推广性 |
|------|------|----------|----------|
| 新矩阵抄公式 | $O(n^2)$ | 低 | 违反题意 |
| 四点循环 | $O(1)$ | 高（嵌套下标） | 仅旋转 |
| **转置 + 反转** | $O(1)$ | 低（两个平凡变换） | 换翻转方向即得逆时针 |

两步法的每一半都是"闭着眼也不会写错"的基础操作，正确性由坐标公式一次性保证——**用简单变换的复合替代复杂变换，是矩阵题的通用降维手段**。

顺带把四个旋转方向都用"转置 + 镜像"凑齐：

- 顺时针 $90^\circ$ = 转置 + 左右镜像；
- 逆时针 $90^\circ$ = 转置 + 上下镜像；
- 旋转 $180^\circ$ = 左右镜像 + 上下镜像。

## 3. 代码实现

```cpp
class Solution {
public:
    void rotate(vector<vector<int>>& matrix) {
        int n = matrix.size();

        // 第一步：沿主对角线转置，matrix[i][j] <-> matrix[j][i]
        // j 从 i+1 开始：只遍历对角线上方的三角形，否则每对交换两次等于没换
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                swap(matrix[i][j], matrix[j][i]);
            }
        }

        // 第二步：每行左右反转，(i,j) -> (i,n-1-j)
        for (int i = 0; i < n; i++) {
            reverse(matrix[i].begin(), matrix[i].end());
        }
    }
};
```

两个实现细节：

1. **转置的内层从 $j = i + 1$ 开始**。转置由成对 `swap` 组成，若内层从 0 开始，每对 $(i,j)$ 会被交换两次，矩阵原封不动——这是本题最经典的"看起来全对、答案全错"的写法。
2. **两步的顺序可以交换吗？** 先反转行再转置得到的是逆时针旋转（$L \circ T$ 与 $T \circ L$ 复合顺序不同）。本题要顺时针，务必**先转置后反转行**。

## 4. 复杂度分析

- **时间复杂度**：$O(n^2)$。转置访问对角线上方约 $\frac{n^2}{2}$ 对元素，行反转访问 $\frac{n^2}{2}$ 对，共 $O(n^2)$——矩阵每个元素都要挪一次，已是最优。
- **空间复杂度**：$O(1)$。转置用 `swap` 原地进行，`reverse` 也是原地算法，只用了常数个临时变量。

对比暴力法的 $O(n^2)$ 额外空间：时间没有变差，空间从平方级压到常数级，这是"原地算法"的典型收益。

## 5. 常见疑问

**疑问一：为什么先转置再反转行，而不是反过来？**

变换复合不可交换。设行反转算子为 $L$（$L(i,j) = (i, n-1-j)$），转置为 $T$（$T(i,j) = (j,i)$）。先 $L$ 后 $T$：$(i,j) \xrightarrow{L} (i, n-1-j) \xrightarrow{T} (n-1-j, i)$，对照旋转目标 $(j, n-1-i)$——这不是顺时针，而是**逆时针**旋转的坐标。结论：想顺时针，先 $T$ 后 $L$；想逆时针，先 $L$ 后 $T$（或转置后做上下镜像）。判断复合顺序时老老实实把坐标代进去追一遍，别靠直觉。

**疑问二：$n$ 为奇数时中心元素要不要特判？**

不用。转置时中心元素 $(\frac{n-1}{2}, \frac{n-1}{2})$ 在对角线上，内层 `j` 从 $i+1$ 开始天然跳过了它（自己和自己交换无意义）；行反转时它落在行的正中间，`reverse` 对它也是无操作。两步中它都"原地不动"，而 $90^\circ$ 旋转本来就该把中心转到自己——公式自动成立，无需任何 `if`。

**疑问三：转置写在内层 $j$ 从 0 开始为什么结果"没变"？**

`swap(a,b)` 执行两次等于什么都没做。$j$ 从 0 扫到 $n-1$ 时，每一对 $(i,j)$、$(j,i)$ 会被访问两次、交换两次，矩阵回到原样；随后行反转只完成了"左右镜像"，最终结果整个错掉。这类 bug 的隐蔽之处在于程序不崩溃、不越界，只在小样例上能肉眼看出。同理提醒：想用"上下镜像 + 转置"（逆时针）时，上下镜像的外层同样只需遍历一半的行。

## 6. 相关题目与模板

**可复用模板**（矩阵原地旋转的变换分解，可按方向查表拼装）：

```cpp
// 顺时针 90 度：转置 + 每行反转
for (int i = 0; i < n; i++)
    for (int j = i + 1; j < n; j++)      // 注意 j 从 i+1 起
        swap(matrix[i][j], matrix[j][i]);
for (auto& row : matrix)
    reverse(row.begin(), row.end());     // 左右镜像

// 逆时针 90 度：转置 + 每列反转（上下镜像）
// for (int j = 0; j < n; j++)
//     for (int i = 0, k = n - 1; i < k; i++, k--)
//         swap(matrix[i][j], matrix[k][j]);
```

**方法论总结**：矩阵的整体几何变换（旋转、镜像、平移）优先分解为"转置 + 镜像"这类平凡操作的复合；每个平凡操作都能原地成对交换实现，从而既保住 $O(1)$ 空间，又把出错面缩到最小。验证分解是否正确，追一个具体坐标 $(i, j)$ 走完全程即可。
