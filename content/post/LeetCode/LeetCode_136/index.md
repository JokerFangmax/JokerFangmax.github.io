# LeetCode 136. 只出现一次的数字

> 题目链接：[https://leetcode.cn/problems/single-number/](https://leetcode.cn/problems/single-number/)  
> 难度：简单  
> 标签：位运算、数组

---

## 1. 题目描述

给你一个**非空**整数数组 `nums`，其中**除某个元素只出现一次外，其余每个元素都恰好出现两次**。找出那个只出现一次的元素。

进阶要求：设计线性时间、常数空间的算法。

**数据范围：**

- $1 \le nums.length \le 3 \times 10^4$
- $-3 \times 10^4 \le nums[i] \le 3 \times 10^4$
- 除一个元素出现一次外，其余元素均出现两次

**示例：**

```
输入：nums = [2,2,1]
输出：1

输入：nums = [4,1,2,1,2]
输出：4

输入：nums = [1]
输出：1
```

注意负数的存在——这排除了某些只适用于非负数的小聪明做法，但排不排除异或，见第 5 节。

---

## 2. 思路分析

### 2.1 暴力：逐个数数

对每个元素扫全数组数出现次数，$O(n^2)$；$n = 3 \times 10^4$ 时约 $9 \times 10^8$ 次比较，勉强但丑陋。

### 2.2 哈希表 / 排序

- **哈希计数**：一遍扫，`unordered_set` 里"见一次插入、见两次删除"，剩下的就是答案。时间 $O(n)$、空间 $O(n)$——满足进阶要求的前一半，栽在后一半（详见[哈希表模板笔记](../../algorithms/hash_table/)的"计数问题模式"）。
- **排序**：排序后成对元素相邻，扫一遍找出"邻居不等于自己"的那个。时间 $O(n \log n)$、空间视排序实现而定，且改变了数组。

两条路都不差，但都**没有利用题目的特殊结构**："恰好出现两次"是一个极强的条件——成对出现，暗示着**配对抵消**。

### 2.3 抵消的思路：加法的第一直觉

要配对抵消，第一直觉是求和：所有元素之和 $S$，去重后的和 $D$，则答案 $= 2D - S$（每个成对元素被数了两遍，独身元素只被数了一遍，差恰好多出一个独身者）。数学上完全正确！但它需要**先去重**（`unordered_set`），空间仍是 $O(n)$——好想法，卡在"去重要额外的表"上。

理想的抵消运算应该满足：**同一个数参与两次就互相抵消，参与一次就留下痕迹**。在整数运算里找这样的算子——

### 2.4 异或：三条性质完美拼上

**异或 (XOR, exclusive OR, 记作 $\oplus$)** 是按位的运算，恰好具备所需的一切：

1. **自反性**（抵消）：$a \oplus a = 0$——两个相同的数，每一位都相同，异或后全为 0；
2. **恒等性**（保留）：$a \oplus 0 = a$——0 不改变任何数；
3. **交换律 + 结合律**（与顺序无关）：$a \oplus b = b \oplus a$，$(a \oplus b) \oplus c = a \oplus (b \oplus c)$——累加结果与配对元素在数组里的位置次序无关。

把全部元素异或起来，按交换律/结合律任意重排（数学上合法，物理上无需真的重排），把配对的两两放在一起：

$$\underbrace{(a \oplus a)}_{0} \oplus \underbrace{(b \oplus b)}_{0} \oplus \cdots \oplus x = 0 \oplus 0 \oplus \cdots \oplus x = x$$

成对者互相湮灭，只剩那个独身的 $x$。**时间 $O(n)$、空间 $O(1)$、一行循环**，进阶要求全部达成。

### 2.5 用示例逐步走一遍

`nums = [4,1,2,1,2]`，维护累加异或值 $x$，每步看二进制：

| 步骤 | 元素 | 二进制（当前 $x$ → 元素） | 新 $x$ | 十进制 |
|---|---|---|---|---|
| 初始 | — | — | `000` | 0 |
| 1 | 4 | `000 ⊕ 100` | `100` | 4 |
| 2 | 1 | `100 ⊕ 001` | `101` | 5 |
| 3 | 2 | `101 ⊕ 010` | `111` | 7 |
| 4 | 1 | `111 ⊕ 001` | `110` | 6 |
| 5 | 2 | `110 ⊕ 010` | `100` | **4** |

中间值 5、7、6 看似毫无规律——没关系，**异或的中间结果没有意义，只有终态有意义**。按结合律重排后等价于 $(1 \oplus 1) \oplus (2 \oplus 2) \oplus 4 = 0 \oplus 0 \oplus 4 = 4$，配对元素在途中的"污染"最终全部自我修复。

再看"抵消"的微观过程（跟踪两个 `2` 的中间比特位，即 `010` 中值为 2 的那一位）：第 3 步第一个 2 进来，把该位从 0 翻成 1（`101 → 111`）；第 5 步第二个 2 再来，把它从 1 翻回 0（`110 → 100`）。**每个比特位上，同一个值每出现一次就翻转一次，出现偶数次必归零**——这正是"成对抵消"的按位视角。

## 3. 代码实现

```cpp
class Solution {
public:
    int singleNumber(vector<int>& nums) {
        int x = 0;
        for (int v : nums)
            x ^= v;          // 累加异或：成对元素自相湮灭，独身者存活
        return x;
    }
};
```

短得近乎敷衍，但每一处都有讲究：

1. **从 0 起累**：$0 \oplus a = a$，空数组（本题不出现，$n \ge 1$）或首个元素直接落入。
2. **`x` 是 `int`**：按位异或对有符号数同样良定义（C++ 中整数运算按位模式处理，$-3 \times 10^4$ 在 `int` 范围内无溢出问题）；`x ^= v` 不产生进位，永远安全。
3. 若追求极致常数，`std::accumulate(nums.begin(), nums.end(), 0, std::bit_xor<>())` 一行等价——但可读性见仁见智。

对比一下三个版本的"抵消"实现：

| 做法 | 时间 | 空间 | 抵消机制 |
|---|---|---|---|
| $2D - S$（数学和） | $O(n)$ | $O(n)$（去重表） | 求和后对半减 |
| 哈希集插入/删除 | $O(n)$ | $O(n)$ | 显式配对 |
| **累加异或** | $O(n)$ | $O(1)$ | 按位自动配对 |

## 4. 复杂度分析

- **时间复杂度**：$O(n)$。恰好一遍扫描，每个元素一次异或。$3 \times 10^4$ 规模下微秒级。
- **空间复杂度**：$O(1)$。一个累加变量。这是本题进阶条件的达成证明。

值得强调：异或是**按位并行**的抵消——32 条比特位上的配对抵消同时进行，互不干扰。换句话说，这道题在 32 个独立的"每比特计数"问题上同时工作：每比特上，出现偶数次的贡献归零，奇数次的留下。"自动并行 32 个子问题"正是位运算解法优雅的根源。

## 5. 常见疑问

**Q1：负数也能异或吗？会溢出吗？**

能，且不会溢出。C++ 中整数以补码 (two's complement) 存储并参与按位运算，`-5` 就是一串确定的比特模式（高位的 1 很多）。异或只翻转比特、不存在进位和符号扩展，$-30000 \oplus -30000 = 0$ 与正数情形完全一致。真正会出事的是"求和后减"类思路里 `int` 溢出的风险（本题量级 $3 \times 10^4 \times 3 \times 10^4 \times 2$ 已接近但未超上限，换成 $10^5$ 规模的同型题就爆了）——异或天然免疫。

**Q2：为什么"顺序无关"如此重要？**

数组里配对元素不一定相邻（示例 `[4,1,2,1,2]` 里两个 1 隔着一个 2）。若抵消运算不满足交换律/结合律，就得先"整理顺序"再配对（比如排序，$O(n \log n)$）。异或两条律都满足，使我们能**假装**配对元素彼此相邻——数学上重排表达式，物理上一个 `for` 循环顺序吃进去即可。这是"选择算子时先看运算律"的典型案例。

**Q3：出现三次怎么办？**

自反性失效了：$a \oplus a \oplus a = a$，三次异或不归零。得换武器——**逐位计数模 3**：统计每个比特位上 1 出现的总次数，模 3 的余数就是独身元素在该位的取值。这就是 [LeetCode 137. 只出现一次的数字 II](https://leetcode.cn/problems/single-number-ii/)，也是位运算从"一个技巧"升级为"一套方法论"（计数 + 取模）的台阶。

## 6. 相关题目与模板

**可复用模板**（成对抵消的位运算骨架，变形题通吃）：

```cpp
// 出现偶数次的元素全部抵消，只留出现奇数次的：
int x = 0;
for (int v : nums) x ^= v;

// 变体：出现 k 次抵消（k 进制逐位计数，代表 k = 3）：
// 对每个二进制位统计 1 的个数，模 k 的余数拼出答案
int ans = 0;
for (int b = 0; b < 32; b++) {
    int cnt = 0;
    for (int v : nums) cnt += (v >> b) & 1;
    if (cnt % 3) ans |= (1u << b);
}
```

**同类题目（一条完整的位运算成长线）：**

- [LeetCode 137. 只出现一次的数字 II](https://leetcode.cn/problems/single-number-ii/)：其余元素出现**三次**，异或失效，升级为逐位计数模 3
- [LeetCode 260. 只出现一次的数字 III](https://leetcode.cn/problems/single-number-iii/)：有**两个**独身元素——全体异或得到 $x \oplus y$，用其最低位的 1 把数组分成两组，各自异或
- [LeetCode 268. 丢失的数字](https://leetcode.cn/problems/missing-number/)：$0..n$ 缺一个，与下标一起异或，全部成对抵消
- [LeetCode 389. 找不同](https://leetcode.cn/problems/find-the-difference/)：两串字符差一个，转 ASCII 异或，同款骨架

**方法论总结**：见到"只有一个元素出现奇数次 / 只有一个元素与众不同"的题，条件反射式地过一遍位运算清单——出现两次用异或，出现 $k$ 次用逐位计数模 $k$，两个独身者先分组再异或。

**一句话总结**：只出现一次的数字是位运算的入场券——交换律和结合律让配对抵消**与顺序无关**，自反性让成对元素**自动湮灭**，一遍异或、$O(1)$ 空间，把"排序找邻居"和"哈希表配对"全部比了下去。
