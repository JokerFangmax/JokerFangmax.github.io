# LeetCode 32. 最长有效括号

> 题目链接：[https://leetcode.cn/problems/longest-valid-parentheses/](https://leetcode.cn/problems/longest-valid-parentheses/)  
> 难度：困难  
> 标签：栈、字符串、动态规划

---

## 1. 题目描述

给你一个只包含 `'('` 和 `')'` 的字符串 `s`，找出**最长的有效（格式正确且连续）括号子串**的长度。

有效括号串需满足：`"()"`、`"(())"`、`"()()"` 等完全匹配的形式。注意本题求的是**连续子串**（substring），不是子序列——`"(()"` 的答案是 2（中间的 `"()"`），不是 4。

**数据范围：**

- $0 \le s.length \le 3 \times 10^4$
- $s[i]$ 为 `'('` 或 `')'`

**示例：**

```
输入：s = "(()"
输出：2
解释：最长有效括号子串是 "()"。

输入：s = ")()())"
输出：4
解释：最长有效括号子串是 "()()"。

输入：s = ""
输出：0
```

---

## 2. 思路分析

### 2.1 暴力：枚举所有子串

枚举 $O(n^2)$ 个子串、每个用栈 $O(n)$ 验证合法性，总 $O(n^3)$，$n = 3 \times 10^4$ 必然超时。

### 2.2 关键观察：有效括号串的"自愈"结构

先手玩几个例子找规律。`")()())"` 的答案是 4，来自下标 1 到 4 的 `"()()"`：它由两段紧挨着的 `"()"` 拼成。`"(()())"` 整串有效，长度 6：外层括号包着 `"()()"`。

两条规律浮现：

1. **拼接**：一段有效串后面紧跟另一段有效串，合起来还是有效串（`"()" + "()" = "()()"`）；
2. **包裹**：一段有效串外面包一层 `(...)`，还是有效串，长度 +2。

这暗示"以 $i$ 结尾的最长有效长度"可以从更早的答案**跳拼**过来——典型的 DP 味道。而"匹配"这个动作天然是栈的行为，两条路都通。

### 2.3 动态规划：$dp[i]$ = 以 $i$ 结尾的有效长度

定义 $dp[i]$ 为**以 $s[i]$ 结尾**的最长有效括号子串长度。有效串一定以 `')'` 结尾，故 $s[i] = '('$ 时 $dp[i] = 0$。

若 $s[i] = ')'$，分两种情况（设 $len = dp[i-1]$，即紧邻的前一段有效串的长度）：

- **情况 A：$s[i-1] = '('$**。直接配对，$dp[i] = dp[i-2] + 2$——配对后还要尝试接上更前面那一段（`"()()"` 型拼接）。
- **情况 B：$s[i-1] = ')'$**。跳过前一段有效串（长度 $len$），看 $s[i - len - 1]$ 是否为 `'('` 能与 $s[i]$ 配对（`"(())"` 型包裹）。若是，$dp[i] = len + 2 + dp[i - len - 2]$——再继续向前拼接。

以 `s = "(()())"`（下标 0..5）走一遍：

| $i$ | $s[i]$ | 判断 | $dp[i]$ | 对应子串 |
|---|---|---|---|---|
| 0 | ( | — | 0 | — |
| 1 | ( | — | 0 | — |
| 2 | ) | $s[1]='('$，情况 A：$dp[0]+2$ | 2 | `"()"` |
| 3 | ( | — | 0 | — |
| 4 | ) | $s[3]='('$，情况 A：$dp[2]+2=4$ | 4 | `"()()"`（下标 1..4） |
| 5 | ) | $s[4]=')'$，情况 B：跳 $len=4$，$s[0]='('$，$4+2+dp[-1]=6$ | **6** | 整串 `"(()())"` |

答案 $6$。下标越界（$i - len - 1 < 0$ 等）按 0 处理。

### 2.4 栈解法：用"最后未匹配位置"丈量

栈解法更短：**栈里存下标**，栈底始终压着"最后一个未匹配的右括号"（或初始的 -1），作为**丈量有效段的参照点**。

- 遇 `'('`：下标入栈（等待配对）；
- 遇 `')'`：先弹栈顶——它就是与本 `')'` 配对的 `'('`（或暴露失败）。弹完若栈非空，当前有效段长度为 `i - 栈顶`（栈顶是本段之前最近的障碍物）；若栈空了，说明这个 `')'` 多余，把 `i` 入栈成为新参照点。

同样以 `s = ")()())"` 走一遍：

| $i$ | $s[i]$ | 栈操作 | 栈（下标） | 有效长度 | 说明 |
|---|---|---|---|---|---|
| 初始 | — | 压 -1 | [-1] | — | 参照点 |
| 0 | ) | 弹 -1，栈空，压 0 | [0] | 0 | 多余的 ) 成为新参照 |
| 1 | ( | 压 1 | [0,1] | — | — |
| 2 | ) | 弹 1，顶为 0 | [0] | $2-0=2$ | `"()"` |
| 3 | ( | 压 3 | [0,3] | — | — |
| 4 | ) | 弹 3，顶为 0 | [0] | $4-0=4$ | `"()()"` |
| 5 | ) | 弹 0，栈空，压 5 | [5] | 0 | 参照点更新 |

全程最大值 4，与期望一致。栈解法一气呵成，下面代码以它为主。

## 3. 代码实现

```cpp
class Solution {
public:
    int longestValidParentheses(string s) {
        int n = s.size(), ans = 0;
        stack<int> st;
        st.push(-1);                      // 栈底参照点：最后未匹配位置
        for (int i = 0; i < n; i++) {
            if (s[i] == '(') {
                st.push(i);               // 等待配对的左括号
            } else {
                st.pop();                 // 弹出的就是配对者（或失败信号）
                if (st.empty())
                    st.push(i);           // 这个 ')' 断了后路，成为新参照点
                else
                    ans = max(ans, i - st.top());   // 参照点之后的整段都有效
            }
        }
        return ans;
    }
};
```

三个实现细节：

1. **栈底常驻一个"参照点"**（初始 -1）。没有它，`"()"` 这种整串有效的 case 在弹完栈后无从丈量长度。参照点永远在栈底，中间全是未配对的 `'('` 下标。
2. **`i - st.top()` 而不是 `i - 弹出的下标`**。弹出的下标只是本次配对的 `'('`，配对左侧可能还连着前一段有效串（`"()()"` 的第二段）；栈顶参照点才是整段有效区间的**起点前一格**，一步量全。
3. **栈空时压入 `i`**。此时 `s[i]` 是多余的 `')'`，它左边再长的有效串也无法越过它延伸——它是新段的天花板，这正是参照点的语义。

## 4. 复杂度分析

- **时间复杂度**：$O(n)$。每个下标至多入栈一次、出栈一次。
- **空间复杂度**：$O(n)$。最坏全为 `'('`，栈满。

DP 解法同为 $O(n)/O(n)$。另有**正反两次扫描计数**的解法做到 $O(1)$ 空间：正向从左到右数 `left`/`right`，两数相等时更新答案，`right > left` 时清零；反向对称再做一遍（处理 `"(()"` 这种左多右少的尾巴）。两次扫描能过但细节多，栈解法最不易写错。

## 5. 常见疑问

**疑问一：DP 情况 B 里为什么要加 $dp[i - len - 2]$？**

画出来最清楚。设 $s = "\underline{(}\ ()\ \underline{)}\ ()\ \underline{)}"$... 用具体例子：`"()(())"` 求最后一位的 $dp$。$s[5] = ')'$，$s[4] = ')'$ 走情况 B：$len = dp[4] = 2$（中间的 `"(())"` 不对——$dp[4]$ 对应 `"(())"` 的内层 `"()"`，长度 2），配对者是 $s[5-2-1] = s[2] = '('$。配对后得到 `"(())"` 长度 $len + 2 = 4$，但下标 0..1 还有 `"()"` 可以拼上，它正是 $dp[i-len-2] = dp[1] = 2$。漏掉这一项，`"()(())"` 就只会答 4 而不是 6——**配对成功后，必须继续向左拼接更早的有效段**。

**疑问二：为什么不能用"栈匹配计数"或贪心扫一遍？**

两个典型错误。其一，只数配对数：`"()("` 配对 1 对，但有人直接答 $2 \times 1 = 2$ 恰好对；换成 `"(()"`，栈里剩一个 `'('`，若把已弹出的都算上会误答 4——**无效的 `'('` 夹在中间会把两段隔开**。其二，双计数器（数左右括号、相等时更新）正向扫会漏掉 `"(()"` 型答案：`left` 始终大于 `right`，永远等不到相等的那一刻——这正是 $O(1)$ 空间解法必须**反向再扫一遍**的原因。

**疑问三：空串、单字符怎么保证不越界？**

`n = 0` 循环不执行，返回 0；`n = 1` 时唯一的字符要么让栈压入、要么弹掉参照点再压回，`ans` 保持 0。DP 版则要小心情况 B 中 $i - len - 1$、$i - len - 2$ 可能小于 0，判越界取 0 即可。边界题型的通病是差一和负下标，写之前把 $i \ge 2$、$i - len - 2 \ge 0$ 的分支列全。

## 6. 相关题目与模板

**可复用模板**（括号匹配类问题的"栈存下标 + 参照点"骨架）：

```cpp
// 栈底压 -1 作参照点；')' 弹栈后栈空则压自身，否则用 i - st.top() 丈量
stack<int> st;
st.push(-1);
for (int i = 0; i < n; i++) {
    if (s[i] == '(') st.push(i);
    else {
        st.pop();
        if (st.empty()) st.push(i);          // 新障碍物
        else ans = max(ans, i - st.top());   // 有效段整段丈量
    }
}
```
