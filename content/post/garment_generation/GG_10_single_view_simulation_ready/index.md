# GG 10：单图到仿真就绪

> 📖 服装生成系列第十篇（前篇：[GG 09：版型生成的表示革新](../GG_09_representation_shifts/)）。GG 05–09 走完了**版型生成**链路：DSL → 观测恢复 → 自回归/扩散/潜空间/换表示——那一路的输入是文本或合成图，输出是"设计图"。本篇换问题：给定**一张真实照片**（或一段单目视频），恢复**能直接进物理仿真器**的资产——分离的人体、多件服装、每件带缝纫版型**和物理参数**。两篇论文代表两条互补路线：Dress-1-to-3（UCLA+Utah，TOG 2025）走**优化式**：显式版型 + 扩散伪 GT + 可微物理联合优化；DMap（EPFL Fua 组 + MBZUAI，SIGGRAPH 2025 会议版 + TPAMI 2026 期刊版）走**学习式**：pattern coordinates + 扩散先验补全 + 拟合精修。两篇全部对照 arXiv HTML 全文、Crossref DOI 记录与官方仓库核实（含 12 条勘误，见 §8.2）。

## 1. 这组论文解决什么问题？

GG 07–09 的生成系有一个从未被正面处理过的软肋，Dress-1-to-3 的批评一针见血：

> "their garment results lack physical material parameters. Therefore, they fail to reconstruct diverse shapes for garments with different physical materials"（§2）

同一件版型，雪纺和牛仔布悬垂出来是两个形状——没有物理参数的"版型生成"只覆盖了布料的一半自由度。而反向的问题同样成立：照片里看到的是**悬垂的结果**（3D 形状），要恢复的是**原因**（2D 裁片 + 缝合 + 材质）——一个严重病态的逆问题（GG 06 的病态性三实验：敏感度谱、类内>类间、内域盲区）。

单图设定还叠加了第三重困难：**深度零空间**。正视图对所有 $\theta_z$ 平移等价——单视角观测对整个深度方向是盲的（GG 06 的"单视角信息漏斗"在此取到极端）。

"**simulation-ready**" 在 Dress-1-to-3 里的操作定义：版型可缝合、可穿着静置在人体上、无自穿插/互穿、可无缝接入 CIPC 仿真器做动画。注意——**没有 DSR 之类的量化指标**，定量指标只有 CD 和 IoU 两个；"仿真就绪"本身是靠演示（§9.3 动画）而非数字证明的。

两条路线的分工：

| | Dress-1-to-3 | DMap（静态/动态） |
|---|---|---|
| 路线 | 优化式（无训练数据） | 学习式（CLOTH3D 系合成数据） |
| 版型表示 | 显式曲线（SewFormer 式 Bézier patch） | 隐式 UV 场（ISP/DISP 式） |
| 物理参数 | 有（$\kappa_s, \kappa_b$ 联合优化） | 无（物理只做 refinement 正则） |
| 扩散先验的角色 | 多视角伪 GT（MagicMan） | 先验补全（法线/映射/DISP 三套） |
| 耗时 | 预优化 10 min + 单卡 3090 < 2 h/件 | 静态 7（精修 24）min/帧；动态 3（精修 7）min/帧，74.1 GB 显存 |
| venue | TOG 44(4)（SIGGRAPH 2025） | SIGGRAPH 2025 Conf. + TPAMI 2026 |

### 方法流程鸟瞰

两条互补路线的流程（细节在 §3–4）：

**Dress-1-to-3（优化式，无训练数据）**——测试时解一个带物理的优化问题：

| 步骤 | 做什么 | 目的 |
|---|---|---|
| 1. 初估 | 预训练 SewFormer 从单图预测初始版型 + 缝合 | 病态逆问题不能从零开始——给优化一个像样的起点 |
| 2. 伪 GT | 预训练多视角扩散（MagicMan）生成轨道视角 RGB + 法线 | 补单图深度零空间；不重建 3D，直接当渲染损失的监督目标 |
| 3. 人体 | SMPL-X 初估 → 关键点 + 多视角 mask 由粗到细精调 | 服装要穿在正确的人身上才有正确的悬垂 |
| 4. 联合优化 | 可微 CIPC 前向把（版型, 物理参数）映射到静态悬垂，adjoint 反传（§4.1），渲染拟合伪 GT | 版型几何与材质一起解——同一版型雪纺和牛仔布悬垂不同 |

**DMap（学习式，合成数据训练）**——三套条件扩散 + 拟合（§4.2）：背面法线补全（把单视角看不见的半个世界先"想"出来）→ 映射扩散（法线 → UV 坐标图 + 深度图，把像素与布料参数坐标缝起来）→ DISP 拟合（不完整 UV map → 恢复完整版型与 rest mesh）→ 神经位移场 + 顶点两级精修（物理只当正则）。动态版（TPAMI 2026）再加：冻结空间模块 + 即插即用时间模块 + 免训练测试时引导拼长视频。

**勘误预告**：这两篇和 GG 07–09 的生成系之间**没有任何可拼的定量表格**（详见 §6）——Dress-1-to-3 引 SewingLDM 只是文字上标 concurrent work，不引 DressCode/GarmentDiffusion；DMap 两篇全文甚至不出现 SewingLDM/GarmentDiffusion/NeuralTailor/SewFormer 任何一个名字。把这两篇的数字和生成系拼在一张表里是本领域最容易犯的引用错误。

## 3. 表示法详解

### 3.1 Dress-1-to-3：显式版型 + 物理参数维度

版型侧完全继承 SewFormer 约定（GG 06 §3）：2D 平面上**二次 Bézier 曲线集合**构成 patch，曲线顶点 + 控制点为参数；缝合边按采样点数对齐后做 vertex-to-vertex 的 stitch 约束。**不是 GarmentCode 程序**。

在此之上新增两组维度：

1. **物理参数**：全局拉伸刚度 $\kappa_s$、弯曲刚度 $\kappa_b$——每个优化变量都进可微仿真前向；
2. **辅助渲染参数**：服装网格顶点色 $C_G$（服务于 RGB 渲染损失，非输出资产）。

完整优化变量表：Bézier 曲线顶点集 $P$、控制点集 $K$、$\kappa_s$、$\kappa_b$、$C_G$。两阶段训练：第一阶段冻结 $K$ 只动顶点（控制点管曲率形状，先粗后细）。

### 3.2 DMap：pattern coordinates 的三方对应

DMap 的"版型"不显式存在——它活在**UV 参数空间** $\Omega = [-1,1]^2$ 里，靠三方对应把像素、UV、3D 缝在一起（这是它和 GG 04 的 ISP 共享的地基，也是标题里 "pattern coordinates" 的含义）：

- **像素 → 3D**：估计服装深度图 $D^g$，相机反投影 $(X, Y, Z) = \mathcal{P}^{-1}(x, y, d)$；
- **像素 → UV**：预测 **UV-coordinate image** $C[x, y] = (u, v, \sigma)$——每个像素给出它对应布料上的参数坐标，$\sigma > 0$ 为前片、$\sigma < 0$ 为后片。**不需要 GT 版型作为输入**：UV 参数化是 ISP 训练时学出来的（CLOTH3D mesh 按切割规则分前后表面，再 ARAP 展平成两片 panel）；
- **UV → 3D**：**DISP**（= ISP + 扩散模型）学 UV positional map 的分布：$U[u, v] \in \mathbb{R}^3$ 为变形后 3D 位置，$\varnothing = (-1,-1,-1)$ 表示 panel 外，与 panel mask 联合建模。

一个先说清的定位（勘误 2 的正身）：**DMap 是图像/视频 → 服装重建任务，不是 pose → 服装变形**——后者是该组前作 DrapeNet/ISP 的设定。DMap 的动机链是：ISP（NeurIPS'23）只能 T-pose 悬垂 → GaRec（CVPR'24）加图像条件变形但过平滑、遮挡区不可见 → DMap 用扩散先验补全 + 映射 + 拟合。

两条路线的表示对照正是 GG 02 谱系的两端：**Dress-1-to-3 的版型可裁剪可制造但离散、难与渲染损失求导（要靠 cage/采样整套机制桥接，见 §4.1）；DMap 的 UV 场可微、与 CNN/扩散天然兼容，但"版型"只是参数化、要出裁片还得再走一步**。

## 4. 方法核心与数学推导

### 4.1 Dress-1-to-3：可微 CIPC 与 adjoint 方法

流水线四步：

1. **版型初估**：预训练 SewFormer 从单图预测初始版型 + 缝合 + 人体摆放；
2. **多视角伪 GT**：预训练多视角扩散模型 **MagicMan**（SMPL-X 条件的混合多视角扩散）生成轨道相机视角的多视角 RGB + 法线图。**勘误 3**：是 MagicMan，不是 Zero123++/MVDiffusion++（论文 Related Work 提到过后两者，但用的是 MagicMan）。关键设计：**这些多视角图不重建为 3D**——直接作为渲染损失的监督目标；
3. **人体侧**：OSX 初估 SMPL-X → DWPose 关键点 + 多视角 RGB/mask 由粗到细精调（Nvdiffrast 渲染）；
4. **联合优化**：可微物理前向把（版型, 物理参数）映射到静态悬垂，悬垂渲染去拟合伪 GT。

**可微 CIPC 的数学**。前向是 Codimensional IPC（GG 01）：解 $\nabla E(x) = 0$ 的隐式平衡。把隐式方程当作可微层，对参数 $\varsigma \in \{P, K, \kappa_s, \kappa_b\}$ 求梯度用 **adjoint 方法**：

$$G(x^\*, \varsigma) = \nabla E(x^\*; \varsigma) = 0, \qquad \frac{d\mathcal{L}}{d\varsigma} = \frac{\partial \mathcal{L}}{\partial \varsigma} - \lambda^\top \frac{\partial G}{\partial \varsigma}, \qquad \left(\frac{\partial G}{\partial x^\*}\right)^\top \lambda = \left(\frac{\partial \mathcal{L}}{\partial x^\*}\right)^\top$$

即：**不需要显式解出 $x^\*(\varsigma)$ 的导数**——解一个以能量 Hessian 为系数矩阵的线性系统得伴随向量 $\lambda$，再把 $\partial G/\partial \varsigma$ 用自动微分算掉。实现上是 **NVIDIA Warp 自动微分 + adjoint 结合**，作者强调这与本构模型无关（对比 Huang et al. 2024 的解析伴随 IPC 需逐本构手推）——换本构不用重推梯度。GG 09 实验 2(b) 验证过同构机制：隐函数定理给出 $dx^\*/d\theta = -(\partial s/\partial\theta)/(\partial s/\partial x)$，数值与有限差分差 1e-13。

两个工程细节值得记：**静置优化每步直接模拟 1 秒**到近静态平衡（吃 CIPC 的鲁棒性，不靠小步阻尼）；**优化过程不加摩擦**——摩擦力路径相关，会破坏梯度（历史依赖 = 不可微的滞后）。

**损失**：mask 渲染损失主导 + RGB/normal 渲染（$\lambda = 0.1$）+ 几何正则族——面积比、边界直角、小角度、离散一致性、comfort（ARAP 拉伸能）、Laplacian、缝合边长度/曲率一致。

**显式版型怎么进渲染损失**：可微化的边界弧长采样 + Delaunay 三角化 + 内部点调和坐标 cage（版型曲线动 → cage 带 → 内部网格点动）；另有 patch 对称化（解一个线性系统）、防翻转后处理、自动 remeshing + refitting。这一整套桥接机制的存在本身就是 §3.2 说的"显式表示难求导"的实证。

### 4.2 DMap 静态版：三套条件扩散 + 拟合

三套扩散各管一段，**训练目标全部是标准 $\varepsilon$-预测 MSE（条件 DDPM）**——没有自监督/物理训练损失，物理只在 refinement 当正则：

1. **背面法线补全** $\varepsilon^n_\theta$：以前面法线 $N_F$ + 前后身体分割 + 身体深度为条件，生成背面法线 $N_B$——单视角看不到的半个世界，先用法线"想"出来；
2. **映射模型** $\varepsilon^m_\theta$：image-to-image 翻译式条件扩散，从 $N_F / N_B$ 预测 UV 坐标图 + 服装深度图（前后联合）——$\S 3.2$ 的两条"像素→"对应就在这一步诞生；
3. **DISP 拟合**：两路合成**不完整**的 UV positional map $\tilde U$ 与 mask $\tilde M$，先以 $\tilde M$ 优化 ISP 潜码 $z$ 恢复完整 panel/rest mesh（ReLU(SDF) 内点 + 面积惩罚 + $\|z\|$ 正则），再以 $\tilde U / \tilde M$ 作 manifold guidance 引导 DISP 扩散逆过程生成完整 UV map。

之后 **refinement**：神经位移场 MLP $(V, \bar V) \mapsto \Delta V$ 先粗调、再直接优化顶点，损失 = mask/depth/normal 渲染 + UV 对齐 + 物理正则（strain/bend/gravity/collision，以恢复的 rest mesh 为参考）；人体侧另有 refinement，含保证人体在服装内的 order loss。

### 4.3 DMap 动态版（TPAMI 2026）：时空解耦 + 测试时引导

动态版不是"加个时序网络"那么简单，三个组件：

1. **时空解耦**：空间模块**直接继承静态版预训练权重并冻结**；即插即用的时间模块（卷积换线性层 + 跨帧 self-attention）单独训练——小数据（每对 8000 帧）不重训大模型；
2. **测试时引导（免训练）**：跨子序列重叠一致性 $G_{\text{across}}$ + 子序列内速度/加速度平滑 $G_{\text{within}}$ 引导时空法线扩散与映射扩散；映射扩散另有 depth-to-normal 引导 $G_{\text{D2N}}$ 和防穿插引导 $G_{\text{inter}}$。动机：视频扩散显存受限只能短片段，用 **T=10 的子序列 + 边界引导**拼长视频；
3. **投影式约束 $\mathrm{DDPM}_p$**：对 DISP 形变先验做 **range-null space 分解投影**——观测部分硬约束、未观测部分走先验，再加速度/加速度引导。

第 3 条值得停下来看：$\mathrm{DDPM}_p$ 的"观测子空间硬约束 + 零空间走先验"正是本篇实验 2 分析的结构（§5.3）——单视角观测的零空间里，先验填的东西决定了误差的下限。

静态版逐帧独立重建 + 逐帧物理精修 = 抖动放大；动态版时序建模把加速度压到 GT 以下。

**运行时间**（A100-80G）：DMap-Static 7 min/帧（精修后 24）；DMap-Dynamic 3 min/帧（精修后 7），74.1 GB 显存（峰值与视频长度无关，T=10 固定）；对照 GaRec† 1 min、ISP 19 min。对比 Dress-1-to-3 的 2 h/件（RTX 3090）——优化式与学习式的成本结构完全不同。

### 5.2 实验 1：pattern coordinates 的度量局部性（UV ≈ 布料测地）

**问题**：为什么学习服装变形要搬到 UV/pattern 坐标里做，而不是直接在 3D 空间做？机理是度量的：布料近乎不可伸长，它的"邻近"由**内蕴测地距离**定义；而褶皱/自遮挡让 3D 欧氏邻域混入大量"空间上贴着、布料上隔着好几层"的点。

**构造**：把一根近不可伸长布条（长 1，$v$ 方向宽 $H=0.5$）折成 16 折手风琴（折角 10°，层间隙 0.0107 = 布长的 1.1%）。折叠是**可展等距映射**：内蕴度量 $ds^2 = du^2 + H^2 dv^2$ 不变，布料测地距离有解析形式 $\sqrt{\Delta u^2 + H^2 \Delta v^2}$。

**(a) 等距性独立验证**：在 3D 折叠网格上建图（边权 = 3D 欧氏长度），Dijkstra 图测地 vs 解析内蕴距离，60 个源点：中位相对偏差 **6.1%**，且**全部偏差 $\geq 0$**（负偏差 = 图路径抄近路穿过空气——一例都没有）——6.1% 是八邻接方向量化的系统性绕远（浅斜率路径只能用对角线 + 轴向拼），不是几何误差。**结论：UV 参数距离 = 布料测地距离**。

**(b) 3D 感受野被褶皱污染**：取 3D 欧氏感受野半径 $r = 0.035$（≈ 3.3 个层间隙），200 个随机查询点：

| 指标 | 3D 感受野 | pattern 感受野（同半径） |
|---|---|---|
| 布料距离 > r 的点占比 | **80.0%** | 0（构造保证） |
| 布料距离 > 2r 的占比 | **55.2%** | 0 |
| 感受野内最远布料距离 | **5.7×r** | r |

一半以上的邻域点隔着两层以上的布。**在 3D 空间做卷积/注意力，"局部性"与布料的局部性脱钩**。

**(c) 3D 距离不携带布料距离信息**：随机点对上 Spearman $\rho(3D\text{ 距离}, \text{布料测地})$：全域 0.52，局部（$d_3 \leq 0.1$）也只到 0.59；更本质的是带内混淆——3D 距离同落 $[0.8g, 2.2g]$（$g$=层间隙）的点对，布料测地距离铺满 **13× 全谱**（0.009–0.125）。知道 3D 距离也定不了布料距离。

**读数**：pattern coordinates 的价值 = 把布料的**内蕴度量**变成参数空间的**欧氏度量**——卷积的局部性 = 布料的局部性，遮挡/自接触/褶皱不再破坏邻域结构。ISP 的 UV 空间（GG 04）与 DMap 的 pattern coordinates 是同一机理的两次落地；差别在于 DMap 把"像素 ↔ UV"的对应也学了（§3.2 的 UV-coordinate image），使单图观测能直接投进这个空间。

### 5.3 实验 2：单视角零空间 + 伪 GT 误差结构 + 先验低通

**问题**：Dress-1-to-3 的流程 = 初估 + 多视角扩散伪 GT + 可微物理精修。这条流程的误差结构是什么？哪部分误差能被治、哪部分治不了？

**构造**：服装横截面 = 单位圆 + Fourier 位移场（16 阶，真值只有 1–3 阶）。正视图观测 $x$（精确，各方法共享）；深度方向 $y$ 不观测 = **零空间**。伪 GT（MagicMan 式幻觉的模型）：真值 + 低频偏差（mode 2 幅度 0.15——平滑、plausible、但错）+ 高频噪声（mode ≥ 9，σ=0.06）。估计器 = 伪 GT + 强平滑先验（MAP：$\hat\theta_k = \theta^{\text{pg}}_k / (1 + \lambda k^4)$，$\lambda = 10^{-3}$）。

**(a) 先验是低通滤波器**：逐模传递函数 $1/(1+\lambda k^4)$：mode 2 → **0.984**（低频放行），mode 4 → 0.796，mode 10 → **0.091**，mode 16 → 0.015（高频压制）。

**(b) 深度方向 RMS 误差**：

| 方法 | RMS | 误差构成 |
|---|---|---|
| 单视角（零空间，先验填 0） | 0.1202 | 误差 = 真深度本身（一无所知） |
| + 伪 GT 直接信（无先验） | **0.1717** | 低频偏差 + 高频噪声全进——**幻觉比不知道更糟** |
| + 伪 GT + 平滑先验 | 0.1029 | 高频全压，低频偏差 **98% 原样放行** |
| 对照：同幅偏差在高频（mode 12） | **0.0091** | 同幅度偏差被先验压到 ~5% |
| 对照：完美伪 GT（无偏差）+ 先验 | 0.0068 | 先验自身代价 = 低频信号收缩，很小 |
| 双视角真观测（σ=0.01） | **0.0032** | 零空间根治，只剩观测噪声 |

**读数**：先验/物理正则**滤的是频率，不是对错**——高频噪声和高频偏差一起被压，低频偏差 98% 原样放行（第三行 vs 第四行：11× 的差距纯粹由偏差所在频段决定）。这解释了 Dress-1-to-3 自己的 Limitation 3"表面过度平滑"：seam/Laplacian 正则 + 法线图不一致性压制高频褶皱——**真高频和假高频一起死**。伪 GT 的价值必须靠先验兑现（0.103 < 0.120），且只到低频偏差为止；DMap 动态版的 $\mathrm{DDPM}_p$ 投影（观测子空间硬约束 + 零空间走先验）正是对这个结构的标准应对：**零空间里先验填什么，误差下限就是什么**。

### 5.4 实验 3：忽略时间维的频域代价（准静态 / 逐帧独立 vs 时序建模）

**问题**：DMap 静态版逐帧独立用于视频会抖（Table III：18.2 vs GT 3.7 mm/frame²）；GG 01/04 的准静态 draping 丢惯性项。这两种"忽略时间维"的代价在频域里长什么样？时序建模能补到哪里？

**构造**：受驱动阻尼振子（锚点 $a(t) = A\sin\omega t$ = 身体/pose 驱动，服装 = 惯性质量）：$m\ddot y = -k(y - a) - c\dot y$，取 $m=1, k=100, c=2$（$\omega_0 = 10$，$\zeta = 0.1$）。传递函数 $H(\omega) = \frac{k}{k - m\omega^2 + ic\omega}$。准静态映射 = $y = a$（即 $H \equiv 1$）。

**(a)** ODE 数值稳态 vs 解析 $H(\omega)$：最大相对误差 **2.8e-10**。

**(b) 时序修正自动恢复动力学系数**：从 3 个低频训练点（$\omega \leq 0.2\omega_0$）的数据拟合 $y \approx a + \alpha_1 \dot a + \alpha_2 \ddot a$：

$$\alpha_1 = -0.0213\ (\text{解析} -c/k = -0.0200), \qquad \alpha_2 = -0.0099\ (\text{解析} -m/k = -0.0100)$$

**"时序条件化"（速度/历史帧）在原理上就是在学动力学**——DMap 动态版时间模块（跨帧 self-attention + 速度/加速度引导）学的是这个东西。

**(c) 稳态 RMS 误差 / A**：

| $\omega/\omega_0$ | 准静态 \|H−1\| | +速度 | +速度+加速度 |
|---|---|---|---|
| 0.2 | 0.059 | 0.040 | **0.001** |
| 0.4 | 0.212 | 0.182 | **0.035** |
| 0.6 | 0.583 | 0.533 | **0.218** |
| 0.8 | 1.675 | 1.576 | 1.100 |
| 1.0 | 5.099 | 4.891 | **5.185**（反而放大） |

**读数**：准静态误差随驱动频率单调增长（$\omega = 0.6\omega_0$ 时误差已达激励幅值的 ~58%）；速度+加速度一阶修正在低频段吃掉大部分缺口（0.4 时 0.21→0.03），但共振段三列一起爆、修正项反而放大误差——修正是 $H$ 的泰勒展开，**共振必须真动力学**。这正是 "simulation-ready" 存在的理由：学习映射终究有不覆盖的频段，生成的版型要能进仿真器兜底。

## 6. 论文间关系

**组内对照**（同一问题、两条路线）：

- Dress-1-to-3 与 DMap 都用"扩散先验补单视角信息"，但用法相反：前者把多视角扩散输出当**伪 GT 监督**（优化式，逐件 2 小时），后者把扩散当**生成先验**（学习式，7 min/帧推理）；前者输出物理参数、后者不输出；前者版型显式可制造、后者版型隐式可微。GG 06 的"学出来的先验 vs 写下来的先验"辨析在这里有了第三种形态：**买来的先验**（预训练 MagicMan/自训练扩散）。
- 两者的 refinement 阶段惊人地同构：都是"渲染损失 + 物理正则（以 rest shape 为参考）直接优化顶点"—— Dress-1-to-3 是 DMap refinement 的优化式全量版。

**GaRec 桥**：Garment Recovery（CVPR'24，Fua 组）同时是 Dress-1-to-3 主表基线（CloSe/4D-Dress：CD 2.058/IoU 0.831 与 2.983/0.776）和 DMap 两篇主表基线（CLOTH3D 合成）——是三条线唯一的共同锚点。但**数据集、指标尺度（IoU 0–1 vs 百分数）、CD 协议都不同，不能合并成一张表**，只能叙述："Fua 组自评 GaRec→DMap 的提升"vs"Dress-1-to-3 在真实数据上对 GaRec 的优势"。

**与生成系（GG 07–09）的定量对比真空**：Dress-1-to-3 引 SewingLDM 只标 concurrent work、无数字；不引 DressCode/GarmentDiffusion（全文 grep 无）。DMap 两篇不引 SewingLDM/GarmentDiffusion/NeuralTailor/SewFormer（grep 为零）。最接近的正面交锋在 DMap 动态版**补充材料**：用 ChatGarment 做"估计版型→drape→拟合深度图"替代管线的**定性**对比（宽松裙/开衫上对齐更差）。DMap 动态版对版型系管线的批评原话："although such a pipeline can yield plausible animated garment meshes, it often has difficulty aligning the reconstructed geometry with the input observations"——生成系输出版型，重建系输出版型 + 对齐，批评点恰好是"对齐"。

**谱系定位**：GG 09 结尾说版型表示的三条新路（栅格/隐式场/程序）；本篇给出的是**任务轴上的新路**——从"生成一个合法版型"到"恢复一个可仿真资产"。生成系与重建系在 2026 年的交汇点（SewFusion 一类混合结构、DMap 动态版引 ChatGarment 做替代管线）会在 GG 12 总结。

## 7. 与 Work 3 的连接

Work 3 的方案是**视频先验蒸馏 → 缝纫版型生成**（SewingLDM baseline）。本篇两篇论文各提供了一个可借鉴组件：

1. **视频先验压的恰好是低频偏差**（实验 2 的直接推论）：Wan2.1 的时空块（8/14/17/21/29）携带跨视角一致性与遮挡补全信号——相对单图扩散伪 GT，视频是多视角**真观测的时序串联**，其约束落在观测子空间而非零空间。蒸馏损失应该显式做 range-null 分解：**观测子空间硬约束（像素对齐），零空间交给版型先验**——这正是 DMap $\mathrm{DDPM}_p$ 的结构，可以直接搬到 SewingLDM 微调损失里；
2. **pattern coordinates 是视频蒸馏的天然载体**（实验 1 的推论）：视频先验给出的是逐像素**表面**对应——天然生活在内蕴坐标里。"视频 → 3D mesh 再 → 版型"要多过一道有损变换（3D→UV 参数化在褶皱处歧义，实验 1(c) 的 13× 带内混淆）；"视频 → UV 场直接蒸馏"少这一道。P3 若走损失端蒸馏，对齐目标应设在 UV/pattern 空间而非 3D 空间；
3. **可微 CIPC adjoint 是物理正则的实现路径**：Warp AD + adjoint 与本构无关，意味着"版型 + 物理参数联合可微"可以外包给现成求解器——但 2 小时/件的成本只能离线用（蒸馏数据生产），不能进训练环；
4. **实验 3 给出兜底的必要性论证**：学习映射（无论 SewingLDM 还是蒸馏后的模型）在共振频段必然失准——所以 Work 3 的输出必须是**仿真就绪的版型**（带物理参数更好），让失准的频段交给仿真器。这同时呼应 Dress-1-to-3 对 SewingLDM 的批评：**P0 baseline 不输出物理参数**——Work 3 的自建评测可以加一项"同版型不同材质的悬垂区分度"。

## 8. 局限与勘误

### 8.1 论文自列局限

**Dress-1-to-3**（§10）：① 生成能力受限于 SewFormer 初估——不能新增初估中不存在的连通组件，多层服装被融成单层；② 优化后版型未必符合时装设计惯例（监督只有拟合渲染）；③ **表面过度平滑**（seam/Laplacian 正则 + 法线图不一致压制高频褶皱——实验 2 的低通机理实证）；④ 纹理与输入有 gap；⑤ 只优化静态悬垂，动态场景留作未来工作。

**DMap 静态版**：极小褶皱难恢复（可微渲染法线损失的插值近似抹平高频）；不能处理多层结构（ruffle 裙）；需要全身图；单图深度歧义无解；视频输入会抖。**动态版**：ISP/DISP 表示是统一 UV 空间的**单层曲面**——多层/口袋/连帽只能近似为单层；未来方向是多 panel 各自 UV 域 + 显式缝合（恰好是回到 GG 05 的 GarmentCode 式结构）。

### 8.3 本篇实验自注

（记录在 `scripts/garment_generation_experiments/README.md`）两个实现坑：

1. **手风琴折叠的段方向数组必须按段号索引**——初版误用 u 网格点索引，折痕结构整体错乱，但 3D 总长仍 = 布长（**等距性断言不报错**），"层"已不存在。教训：等距性检查抓不住拓扑/折叠结构错误，要靠"查询点的 3D 邻居段分布是否成紧密层"来诊断；
2. **图测地验证要求两方向分辨率相当**（$H\,dv \approx du$）——v 网格粗时阶梯效应主导（6 行时跨行偏差 ~28%），细化到 241 行后残余 6.1% 且全部为正（纯方向量化）；**负偏差才是危险信号**（图路径穿越空气），一例都不该有；
3. 实验 2 的先验若用软的 $\lambda \propto k^2$，"低频放行多少"会被**先验对真信号的收缩**污染（模式 2 误差 = 偏差泄漏 + 信号收缩的代数和，两者部分对消会伪造"改善"）——对照实验要用陡峭的 $k^4$ 把信号收缩压到 <3%，"放行"读数才干净。

## 9. 习题

**题 1**：实验 1 中折叠是等距映射，故布料测地 = 参数距离。(a) 证明八邻接网格的图测地**恒 ≥** 解析值（方向量化只绕远不抄近）；(b) 对 $(n, 1)$ 网格步的位移对，推导图测地的相对开销上界（提示：$n - 1 + \sqrt 2$ vs $\sqrt{n^2+1}$），并解释为什么中位偏差恰好落在 ~6%；(c) 若在 3D 网格上观察到**负**偏差，说明什么？
*提示*：(c) 负偏差 = 图上存在一条 3D 长度小于内蕴距离的路径——即网格里有穿越空气的边（折点错位、跨层直连），这正是初版段方向 bug 的判据。

**题 2**：Dress-1-to-3 的可微 CIPC 中，静置优化**不加摩擦**以保证路径无关。(a) 从 adjoint 公式出发解释：摩擦的路径相关性为什么会破坏 $\partial G/\partial\varsigma$ 的良定义性？(b) "每步直接模拟 1 秒到近平衡"依赖 CIPC 的什么性质？若用小步长阻尼积分代替，优化会多出什么项？
*提示*：(a) 摩擦力依赖历史（上一步的法向压力），平衡方程 $G(x, \varsigma) = 0$ 变成 $G(x, \varsigma, x_{\text{prev}}) = 0$——梯度还要对历史传播。(b) 大步长下的稳定性（IPC 的无穿透保证不依赖步长）；小步阻尼 = 引入人工耗散路径。

**题 3**：实验 2 的估计器 $\hat\theta_k = \theta^{\text{pg}}_k/(1+\lambda k^4)$ 是某个 MAP 问题的解。(a) 写出该问题（数据项 + 先验项）；(b) 证明传递函数的形式即 Tikhonov 正则的逐模增益；(c) DMap 的 $\mathrm{DDPM}_p$ 把"低通"换成了"range-null 投影"——两者的本质区别是什么？什么时候投影严格优于低通？
*提示*：(c) 低通按**频率**分配信任，投影按**是否被观测**分配信任——观测到的高频分量投影法保得住（低通法会压掉），未观测的低频分量两者都无解。观测掩码与频率带不对齐时（视频的观测是时空补丁而非频段），投影法是唯一正确的结构。

**题 4**：实验 3(b) 从 $\{(\omega_i, \hat H(\omega_i))\}$ 拟合出 $\alpha_1 \to -c/k, \alpha_2 \to -m/k$。(a) 证明 $\hat H - 1 = i\omega\alpha_1 - \omega^2\alpha_2$ 的 Taylor 展开在 $\omega \ll \omega_0$ 时逐项对应 $-ic\omega/k + m\omega^2/k + O(\omega^3)$；(b) 训练频率取到 $\omega = 0.35\omega_0$ 时系数偏差 ~14%（二阶污染），取 $\leq 0.2\omega_0$ 时 <5%——这对"DMap 动态版该用什么训练数据"意味着什么？
*提示*：(b) 训练分布的频段覆盖决定时序模块学到的修正系数的纯度；日常运动频谱 $\lesssim 0.5\omega_0$ 时安全，含快速甩动（趋近共振）时拟合系数被污染——对应论文的"快速运动仍是失败案例"。

**题 5**（思考）：综合 GG 09 §7 与本篇 §7：Work 3 的视频蒸馏有两条注入位置——A. 空间栅格/UV 场表示 + 表面对齐（本篇实验 1 机理）；B. SewingLDM 潜码 + $\mathrm{DDPM}_p$ 式 range-null 损失（本篇实验 2 机理）。P0 的 CFG 压制问题（n_panels {2:18, 4:2}）与视频先验的"多视角真观测"性质，分别对哪条路线构成支持/障碍？若两条都做，先证伪哪条的成本最低？
*提示*：视频先验治的是**观测子空间的约束**（低频对齐），CFG 压制是**零空间合法模式的多样性**——两者正交，这也是为什么"视频对齐"和"组合泛化"在 GG 09/10 两篇里分别出现。最低成本证伪：A 用冻结 Wan2.1 特征 + 小 UV 头做探针（不需要训生成模型）；B 在 P0 的 20 seeds 上加投影损失微调（不需要新表示）。
