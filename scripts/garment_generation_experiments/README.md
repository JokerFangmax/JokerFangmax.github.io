## 脚本内的勘误记录

部分脚本带有正文中同步勘误的实现坑（保留注释原样，作为"为什么数字变了"的依据）：

- `gg07_experiments.py` 实验 3：DDIM σ 比值方向写反会被 `max(0,·)` 静默钳 0，η=1 无声退化 η=0（两个采样器逐位相同 = bug 信号）；
- `gg07_experiments.py` 实验 3：VP 动力学误用 VE 约定的解析 score（均值不缩放）——对随机采样器几乎无感，却让确定性 DDIM 出现假性模式漂移（GG 07 §5.3 勘误）；
- `gg09_experiments.py` 实验 2：quilez 的 smin 若把 `h` 差分方向与混合方向**同时**写反（或只反一个），smooth union 静默变 smooth max——T 恤场整体为空、不报错；而 `h` 方向对、混合方向反（`(1-h)*a+h*b`）也是 max。正确组合：`h = clip(.5+.5*(b-a)/k)`，返回 `(1-h)*b + h*a`。"插值出的隐式场内部占比为 0" = 方向 bug 信号。
- `gg10_experiments.py` 实验 1：手风琴折叠的段方向数组必须按【段号】索引，误用 u 网格点索引时折痕结构整体错乱——但 3D 总长仍 = 布长（等距性断言不报错），"层"已不存在。教训：等距性检查抓不住拓扑/折叠结构的错误，要靠"查询点 3D 邻居的段分布是否成紧密层"来诊断。
- `gg10_experiments.py` 实验 1：图测地验证要求 v 方向分辨率与 u 相当（`H·dv ≈ du`），否则粗方向阶梯效应主导（v 网格 6 行时跨行偏差 ~28%，细化到 241 行后残余 6.1% 且全部为正——纯八邻接方向量化，浅斜率路径只能绕远；负偏差 = 穿越空气的捷径，一例都不该有）。
- `gg10_experiments.py` 实验 2：软先验（λ∝k²）下"低频放行多少"会被**先验对真信号的收缩**污染（模式 2 误差 = 偏差泄漏 + 信号收缩的代数和，信号-偏差部分对消会伪造出"改善"）；对照实验要用陡峭的 λ∝k⁴ 把信号收缩压到 <3%，"放行"读数才干净。
- `gg11_experiments.py` 平展：软规范权重必须与残差**同量级**（1e3 权重 vs 1e-3 残差 → trf 信任域停摆，残差卡 5.9e-3 伪影；健全性检查 = 输入平铺真值本身也压不下去，才能定位是求解器而非几何）；非可展面有残差地板 → 机器零容差永远打满 max_nfev，容差须设在地板之上（tol=1e-8 与 tol=1e-12 解完全相同）。
- `gg11_experiments.py` 实验 2：挂钉边选**顶边**（受张悬挂，平衡唯一）；钉底边会得到受压直立态——完美对称初值停在假稳定（真值 z≡0 装作稳定）、非对称初值翻折下垂，A/B 对比失效。平展解的 2D 规范任意（旋转/镜像），进仿真前须 Procrustes 对齐（刚体+镜像、无缩放）。B 管线在手风琴上的 3.4e-4 残差是**皱纹亚稳态**而非未收敛（残余速度 1.3e-7 时残差不变）——等距零能陷阱。
- `gg11_experiments.py` 实验 3：① SDS 更新符号必须 θ ← θ − η·g（DreamFusion 是最小化损失；写反目标变斥子）。② 高 λ 下不能用固定 MC 样本集求不动点——MC 噪声 ~λ/√N 制造伪根，须 Gauss–Hermite 求积。③ 多起点求根会跳支，主支要延拓追踪到分岔（λ=2 的"根"是近零 Jacobian 浅谷，须卡 cost 阈值）。④ 高 λ 动力学指数逃逸是结构性的（远场 ā(λ)<0 反恢复），梯度裁剪只能延缓——结论本身就是"该 regime 无吸引子"。⑤ 预算无关统计量（固定伪 GT 地板）的 200 种子 RMS 有 ±1.6σ 波动，须加到 20000 种子才贴理论线。
- `gg12_experiments.py` 打版器（GG 07 遗留）：`draft_front` 三个沉睡几何 bug——①领点用全身宽度插值（13–36cm）落在 1/4 身宽版型侧缝外；②腰线公式 height·7/8−20≈134 高出肩线 ~100cm，**每件自交**；③臀/胸宽同摆 y=0，臀>胸时底边自碰。GG 07 只用边向量（ΣE=0 与多边形有效性无关）从未暴露——换表示（边向量→栅格）会重新暴露生成器里的沉睡 bug（与 GG 10 段号索引 bug 同款教训）。
- `gg12_experiments.py` 镜像后片量化测试退化：round(−x)=−round(x) 精确成立 → 镜像量化后缝长差恒 0，测不出"量化破坏缝合"。须前后片各自随机朝向局部系独立量化 + 后片非镜像（共享肩缝公式保持真值缝合一致）。
- `gg12_experiments.py` PCA 秩退化两连：①固定样式参数下 draft 分段线性 → 秩 ≤6，潜空间曲线测不出——须注入逐件随机样式（跨分支 + 与测量相乘）；②PCA 只训前片 → 镜像后片 x<0 分布外（缝长差 8.5cm 假信号）——须全 panel 合并训练。
- `gg12_experiments.py` 复合密度积分：重叠模式不能走 log-sum-exp 相对形状（位置相关错因子让模式质量反向）——直接算密度（e^{−65} 在双精度内）逐点归一才对。
